# General models and specialist models: article evidence

Supporting record for `public/blog/reverse-engineering-models/index.html`.
The article is published from the English source and translated through the
website's gettext catalogs.

## Research scope

Repository history, maintained source and recorded comparison notes were reviewed
on 13 October 2026. This research did not run game targets, compile reconstruction
candidates or repeat historical runtime checks. Public commit availability was
checked through GitHub CLI.

The evidence describes specific historical functions and their recorded checks.
Source presence, compiler exactness, complete-product builds and runtime agreement
remain distinct. The proposed specialist/RL comparisons are future experiments;
no trained specialist was evaluated for this article.

controlled estimates of model-size effects.

## TH095 identifier-bucket reuse

[Supervisor::LoadDat, 2 September](https://github.com/N0zoM1z0/th095/commit/26bb64bdb093a13f73abd0ee8ae7ce199ee4658f).

Under observed VC7.1 build 3077, declaration order alone did not recover the real
local homes. Earlier background work established useful identifier buckets.
Backing the real file-size scalar with `averagedPanLocal12` places it at
`EBP-0x04` and the genuine 128-byte buffer at `EBP-0x88`. All 151 bytes and 15
relocations close.

This is compiler-context evidence. It does not establish a universal C++ rule
or uniquely recover the original author's variable name. The `gpt-web` label
does not identify this run's model individually.

## TH09 Luna enemy-spawn closure

[GPT-6-Luna-max, 27 September](https://github.com/N0zoM1z0/th09/commit/1eb843383941d00065622a9e353146c4bb96979e).

An ordinary loop with `continue`/`break`, branch-local RunEcl failure handling
and a shared success tail closes the 373-byte owner. TH08 source supplies the
source-family hypothesis; TH09 establishes the bounds, fields, ABI and callees.
Two independent cold builds and canonical replay are recorded.

The earlier stable 361-byte candidate is `gpt-web`, with an individually
unresolved model identity. This case demonstrates a useful discovery across
model tiers, not a measured specialist or smaller-parameter advantage.

## TH04 compiler diversity

[Player MAIN_0 cohort, 15 September](https://github.com/N0zoM1z0/th04/commit/6dce0a79d5b931f0e2a08475b90e0c33d2321b98).

Natural Turbo C++ 4.0J source produces a 629-byte update/miss contribution and a
334-byte renderer. Expression lifetimes, branch-local stores, declaration order
and a shared firing tail matter. Correct physical linker order avoids an extra
alignment byte. The recorded focused and aggregate replays cover 129 and 208
owners respectively. These are historical owned-extent checks; this checkpoint
does not establish whole-game execution.

TH08 uses VC7, while TH095/TH09 use VC7.1. Avoid treating every game's source
patterns as output from the same compiler. Shared game authorship supplies a
prior; target-local evidence validates an actual transfer.

## TH08 numerical investigation

[Polar motion and x87 behavior, 13 October](https://github.com/N0zoM1z0/th08/commit/af9cb1d3e839b15a78b47ac1701506083cc82847).

A collision divergence at stage 2 frame 6,825 leads back to a one-ULP
displacement difference at frame 5,573. Historical CRT wrappers retain a wider
x87 return despite storing a rounded float. A distinct i386 case involves x87
precision-control state. The record includes field probes and replay checks for
specified scenarios. Several preceding investigations use the same model; this
is breadth-of-investigation evidence, not a model-switch comparison.

## TH08 floating-literal oracle repair

[Repository-wide audit, 2 September](https://github.com/N0zoM1z0/th08/commit/a393f400786e4cc6cbb1000af0dad3276da12c78).

Literal payload checks previously depended on optional explicit `data_hex`
attestation. The fix decodes and target-checks every VC7 `__real@...` relocation.
The follow-up audits 1,548 relocations and corrects 12 stale rows in five already
accepted units. One source change corrects a bullet-spread increment from
`1.0f` to `32.0f`.

Affected-unit replay and a complete 1,106-unit cold replay are recorded after
repair. This defect is separate from the later one-ULP numerical investigation.
The RL consequence in the article is an inference: a reward based on the earlier
check could reinforce wrong source. The record does not describe an actual RL
exploit or trained model doing so.

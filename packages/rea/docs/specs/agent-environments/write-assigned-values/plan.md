# Implementation plan

1. **Explanation.** Creates accept members a whole-member copy stores and template text around copied values.
   Updates rule a fresh UUID `unique`, accepting a sent member so replaced, and child rows with only renewed UUIDs
   `renewed`; the update reads the type's other entities to tell a fresh UUID from a reference.
2. **Values.** Helpers find the UUIDs a value renewed and renew the UUIDs of a value.
3. **Apply and serve.** Updates take `unique` and `renewed` from the generator; serving renews the current entity's
   UUIDs.
4. **Schema, tests and docs.** The view's rule schema, unit, gate and serving tests, and the write specs.

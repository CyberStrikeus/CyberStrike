# Implementation plan

1. **Sorted creates.** Placed creates whose confirming read was a whole listing in collection order may be placed
   again; narrowing keeps the sorts a later listing follows and adds those its items show, the type's id field last.
2. **Listed references.** `referenceRule` reads a sent list of ids; `many` on the reference rule and its schema;
   `referencedValue` maps each id; the create merge lets an empty reference agree and frees the members it fixed.
3. **Hidden bodies.** Scenario records give a request with a body Playwright did not expose, and no `Content-Type`, a
   `bodySize` of 0.
4. **Toggles.** `toggledRules` turns a plan's `set` and a later call's opposite `set` into `toggle`; the rule's schema,
   serving, later-call checks and the action verdict.
5. **Skill, tests and docs.**

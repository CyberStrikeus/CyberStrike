插件是一个函数 `(input) => Promise<Hooks>`，返回一个包含钩子函数的对象。每个钩子接收一个 `input`（只读上下文），对于大多数钩子还有一个 `output` 对象，您可以**修改**它来改变行为。从钩子中抛出异常会中止操作。

<img src="/docs/images/diagrams/plugin-hook-architecture.svg" alt="插件钩子执行流程：chat.params/chat.headers 在 LLM 调用前，permission.ask 在工具前，tool.execute.before 修改参数或拦截，然后 tool.execute.after 转换输出" className="my-6 mx-auto max-w-xs" />

参阅[创建插件](/docs/configuration/creating-plugins)了解如何搭建和注册插件。本页面是每个钩子的参考。

## 钩子参考

| 钩子 | 运行时机 | 您可以… |
|------|----------|---------|
| `event` | 任何总线事件触发时 | 观察事件（日志、分析） |
| `config` | 配置加载后 | 检查/调整已加载的配置 |
| `tool` | 注册时 | 添加自定义工具（名称 → 定义映射） |
| `auth` | 注册时 | 添加自定义认证提供商 |
| `chat.message` | 收到用户消息时 | 读取/追加消息部分 |
| `chat.params` | LLM 调用前 | 更改 `temperature`、`topP`、`topK`、`options` |
| `chat.headers` | LLM 请求前 | 添加/修改请求 `headers` |
| `permission.ask` | 请求权限时 | 将 `status` 设为 `allow`/`deny`/`ask` |
| `command.execute.before` | 斜杠命令运行时 | 注入 `parts` |
| `tool.execute.before` | 工具运行前 | 修改 `args`，或抛出异常以拦截 |
| `tool.execute.after` | 工具运行后 | 转换 `title`/`output`/`metadata` |
| `tool.definition` | 工具发送到 LLM 时 | 重写工具的 `description`/`parameters` |
| `shell.env` | Shell 命令运行时 | 添加环境变量 |
| `experimental.chat.messages.transform` | LLM 调用前 | 重写完整消息列表 |
| `experimental.chat.system.transform` | LLM 调用前 | 重写系统提示词数组 |
| `experimental.session.compacting` | 压缩前 | 添加上下文或替换压缩提示 |
| `experimental.text.complete` | 文本部分完成时 | 重写已完成的文本 |

## 签名

每个钩子都是 `async` 的，返回 `Promise<void>`。

### 工具

```typescript
"tool.execute.before"?: (
  input: { tool: string; sessionID: string; callID: string },
  output: { args: any },
) => Promise<void>

"tool.execute.after"?: (
  input: { tool: string; sessionID: string; callID: string; args: any },
  output: { title: string; output: string; metadata: any },
) => Promise<void>

"tool.definition"?: (
  input: { toolID: string },
  output: { description: string; parameters: any },
) => Promise<void>
```

要**拦截**工具，从 `tool.execute.before` 中抛出异常：

```typescript
"tool.execute.before": async (input, output) => {
  if (input.tool === "bash" && /rm\s+-rf/.test(output.args.command)) {
    throw new Error("blocked: rm -rf")
  }
}
```

### 权限

```typescript
"permission.ask"?: (
  input: Permission,
  output: { status: "ask" | "deny" | "allow" },
) => Promise<void>
```

```typescript
"permission.ask": async (input, output) => {
  if (input.type === "read") output.status = "allow"
}
```

### 聊天

```typescript
"chat.message"?: (
  input: { sessionID: string; agent?: string; model?: { providerID: string; modelID: string }; messageID?: string; variant?: string },
  output: { message: UserMessage; parts: Part[] },
) => Promise<void>

"chat.params"?: (
  input: { sessionID: string; agent: string; model: Model; provider: ProviderContext; message: UserMessage },
  output: { temperature: number; topP: number; topK: number; options: Record<string, any> },
) => Promise<void>

"chat.headers"?: (
  input: { sessionID: string; agent: string; model: Model; provider: ProviderContext; message: UserMessage },
  output: { headers: Record<string, string> },
) => Promise<void>
```

### 命令与 Shell

```typescript
"command.execute.before"?: (
  input: { command: string; sessionID: string; arguments: string },
  output: { parts: Part[] },
) => Promise<void>

"shell.env"?: (
  input: { cwd: string },
  output: { env: Record<string, string> },
) => Promise<void>
```

### 生命周期

```typescript
event?:  (input: { event: Event }) => Promise<void>
config?: (input: Config) => Promise<void>
```

### 实验性

```typescript
"experimental.chat.messages.transform"?: (input: {}, output: { messages: { info: Message; parts: Part[] }[] }) => Promise<void>
"experimental.chat.system.transform"?:   (input: { sessionID?: string; model: Model }, output: { system: string[] }) => Promise<void>
"experimental.session.compacting"?:      (input: { sessionID: string }, output: { context: string[]; prompt?: string }) => Promise<void>
"experimental.text.complete"?:           (input: { sessionID: string; messageID: string; partID: string }, output: { text: string }) => Promise<void>
```

## 自定义工具与认证

`tool` 和 `auth` 钩子注册能力而非响应事件：

```typescript
return {
  tool: {
    my_scanner: {
      description: "Custom vulnerability scanner",
      parameters: { type: "object", properties: { target: { type: "string" } }, required: ["target"] },
      execute: async (args) => ({ title: `Scanned ${args.target}`, output: await scan(args.target) }),
    },
  },
}
```

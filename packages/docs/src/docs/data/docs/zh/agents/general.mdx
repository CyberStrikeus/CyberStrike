`general` 代理处理研究、复杂问题和多步骤任务。`cyberstrike` 主代理将受益于并行执行或不需要安全专家的工作委派给它。

## 概述

| 属性 | 值 |
|------|-----|
| **代理 ID** | `general` |
| **模式** | `subagent` |
| **工具访问** | 广泛（无漏洞报告或分级） |

## 使用场景

`cyberstrike` 代理将以下任务委派给 `general`：

- 跨多个来源研究复杂问题
- 并行执行多个独立的工作单元
- 不需要特定领域安全知识的任务
- 文件分析、代码审查和通用推理

## 限制

`general` 代理不能：

- 报告漏洞（`report_vulnerability`：拒绝）
- 分级发现（`triage_vulnerability`：拒绝）
- 访问 TODO 读写操作

这些限制确保安全敏感操作留给相应的专家代理。

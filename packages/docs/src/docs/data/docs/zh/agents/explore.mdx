`explore` 代理是一个快速的只读代理，专门用于搜索代码库和文件系统。它可以按模式查找文件、搜索代码关键字，并回答关于代码库结构的问题。

## 概述

| 属性 | 值 |
|------|-----|
| **代理 ID** | `explore` |
| **模式** | `subagent` |
| **工具访问** | 只读（grep、glob、list、bash、read、web search） |

## 使用场景

`cyberstrike` 代理在需要以下操作时委派给 `explore`：

- 按模式查找文件（例如 `src/components/**/*.tsx`）
- 搜索代码中的关键字或符号（例如"API endpoints"）
- 回答关于代码库结构的问题
- 不需要修改的快速查询

## 详细程度级别

委派给 `explore` 时，调用代理会指定详细程度级别：

| 级别 | 行为 |
|------|------|
| **quick** | 基本定向搜索——单个位置，首个匹配 |
| **medium** | 中等探索——多个位置 |
| **very thorough** | 跨命名约定和位置的全面分析 |

## 限制

`explore` 代理严格只读。它不能：

- 写入、编辑或创建文件
- 执行破坏性命令
- 报告漏洞
- 修改任何状态

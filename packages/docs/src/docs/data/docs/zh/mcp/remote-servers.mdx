远程 MCP 服务器通过 HTTP/HTTPS 连接，支持访问托管服务和共享基础设施。传输协议为 StreamableHTTP（带 SSE 回退）。

<Aside variant="tip">
  **需要安全工具？** 请参阅 [Bolt](/docs/mcp/bolt) 获取预装的安全工具。注意 Bolt 配置在其独立的顶级 `bolt` 键下，不在 `mcp` 下。
</Aside>

## 配置模式

远程服务器是扁平 `mcp` 映射中的一个条目，按服务器名称键控：

```json title="~/.config/cyberstrike/cyberstrike.json"
{
  "mcp": {
    "my-remote": {
      "type": "remote",
      "url": "https://mcp.example.com/mcp",
      "headers": { "Authorization": "Bearer {env:MY_TOKEN}" },
      "enabled": true,
      "timeout": 5000
    }
  }
}
```

| 字段 | 类型 | 描述 |
|------|------|------|
| `type` | `"remote"` | 必填。选择基于 HTTP 的服务器。 |
| `url` | string | 必填。服务器端点。 |
| `headers` | object | 可选。每个请求发送的头部（例如 API 密钥）。 |
| `oauth` | object \| `false` | 可选。OAuth 配置；设置 `false` 禁用 OAuth 自动检测。参见 [OAuth](/docs/mcp/oauth)。 |
| `enabled` | boolean | 可选。启动时连接（默认：true）。 |
| `timeout` | number | 可选。请求超时时间（毫秒）（默认：5000）。 |

<Aside variant="caution">
  `mcp` 对象是按服务器名称键控的**扁平映射**——没有 `servers` 包装器。传输协议仅为 StreamableHTTP/SSE（没有 WebSocket 传输），模式是严格的：`retry`、`keepalive`、`proxy`、TLS/`ca`/`cert` 和负载均衡字段**不存在**。
</Aside>

## 通过 TUI 添加

输入 `/mcps` 打开 MCP 管理器，按 `a` 添加，选择 **Remote**。输入服务器 **URL**；服务器**名称**从主机名自动派生（点变为连字符）。Cyberstrike 在保存前测试连接。这会写入上面所示的模式。

## 认证

### 通过头部的 API 密钥

将静态令牌或 API 密钥作为请求头发送。使用 `{env:VAR}` 避免将密钥存储在配置文件中：

```json
{
  "mcp": {
    "github-remote": {
      "type": "remote",
      "url": "https://api.githubcopilot.com/mcp/",
      "headers": { "Authorization": "Bearer {env:GITHUB_TOKEN}" }
    }
  }
}
```

### OAuth

对于使用 OAuth 的服务器，添加 `oauth` 块（或让 Cyberstrike 自动检测）。省略 `clientId` 时，将尝试动态客户端注册 (RFC 7591)：

```json
{
  "mcp": {
    "oauth-server": {
      "type": "remote",
      "url": "https://mcp.example.com/mcp",
      "oauth": { "scope": "read write" }
    }
  }
}
```

使用 `cyberstrike mcp auth <name>` 授权。完整流程请参阅 [OAuth](/docs/mcp/oauth)。设置 `"oauth": false` 禁用 OAuth 自动检测。

## 启用、禁用和超时

设置 `enabled: false` 保持服务器已配置但断开连接（或在 `/mcps` 中切换）。对慢速端点增加 `timeout`（毫秒）：

```json
{
  "mcp": {
    "slow-remote": {
      "type": "remote",
      "url": "https://mcp.example.com/mcp",
      "enabled": false,
      "timeout": 30000
    }
  }
}
```

## 故障排除

- **认证失败** — 验证头部或对 OAuth 服务器运行 `cyberstrike mcp auth <name>`；使用 `cyberstrike mcp debug <name>` 检查。
- **超时** — 增加 `timeout`，或确认端点可达。
- **配置被拒绝** — 模式是严格的；使用带有 `type: "remote"` + `url` 的扁平映射，且仅使用上面列出的字段。

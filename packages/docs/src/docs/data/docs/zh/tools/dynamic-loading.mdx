内置工具（bash、read、edit 等）始终可用。**MCP 工具按需加载**，这样连接一个拥有数百个工具的服务器不会淹没模型的上下文。四个工具驱动此功能。

## 加载工具

| 工具 | 用途 |
|------|------|
| `tool_search` | 按能力查找 MCP 工具（`query`，可选 `limit`） |
| `load_tools` | 将特定工具加载到活跃上下文中 |
| `unload_tools` | 移除已加载的工具以释放上下文 |
| `list_loaded_tools` | 显示当前已加载的工具 |

代理自动使用这些工具：它搜索某个能力，加载匹配的 MCP 工具，调用它，然后可以卸载它。

### tool_search

```json
{
  "query": "sql injection testing",
  "limit": 10
}
```

返回匹配的 MCP 工具及其描述。内置工具不需要搜索——它们始终可调用。

## 惰性加载 vs 始终可用

- **始终可用**——所有内置工具（`bash`、`read`、`edit`、`glob`、`grep`、`write`、`task`、`webfetch`、`websearch`、记忆工具等）。
- **按需加载**——由已连接的 MCP 服务器（包括 [Bolt](/docs/features/bolt)）暴露的工具。通过 `tool_search` 发现并用 `load_tools` 拉入。

## 禁用工具

`tools` 配置是工具名 → 布尔值的映射。将工具设为 `false` 即可禁用：

```json title="cyberstrike.json"
{
  "tools": {
    "websearch": false
  }
}
```

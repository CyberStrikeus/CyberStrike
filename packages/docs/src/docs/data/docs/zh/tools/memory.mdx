## 记忆工具

有四个记忆工具——没有删除、清除、导出或导入操作：

| 工具 | 用途 |
|------|------|
| `memory_write` | 向记忆中追加笔记 |
| `memory_read` | 读取已存储的记忆 |
| `memory_search` | 搜索已存储的笔记 |
| `memory_context` | 将相关记忆拉入当前上下文 |

## 存储布局

记忆是 `.cyberstrike/` 下的纯 Markdown 文件：

```
.cyberstrike/
├── MEMORY.md              ← 长期记忆
└── memory/
    └── 2026-07-03.md      ← 带日期的每日笔记
```

- **`MEMORY.md`** 保存持久的长期事实。
- **`memory/<YYYY-MM-DD>.md`** 文件是每日笔记；每个文件以 `# Daily Notes - <date>` 标题开头，会话运行时不断追加。

全局记忆（跨项目共享）位于 `~/.config/cyberstrike/memory/`。

由于一切都是磁盘上的 Markdown，您可以像其他项目文件一样读取、编辑或进行版本控制。

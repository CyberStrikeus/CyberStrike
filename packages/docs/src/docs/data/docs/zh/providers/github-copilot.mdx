Cyberstrike 支持 GitHub Copilot 作为 AI 提供商。通过 OAuth 使用您的 GitHub 账户进行认证，访问 Copilot 订阅中所有可用的模型——包括 Claude、GPT-4o 和 o 系列模型。

## 要求

- 拥有有效 **GitHub Copilot** 订阅（Individual、Business 或 Enterprise）的 GitHub 账户
- 对于 GitHub Enterprise：您的 GHE 服务器 URL

## 认证

GitHub Copilot 使用 **OAuth 设备流**——不需要 API 密钥。

### 登录

在 TUI 中运行：

```
/connect
```

从提供商列表中选择 **Login with GitHub Copilot**，然后选择您的部署方式：

| 部署 | 使用场景 |
|------|----------|
| **GitHub.com** | github.com 上的个人或组织账户 |
| **GitHub Enterprise** | 自托管的 GHE 或数据驻留实例 |

Cyberstrike 会打开浏览器窗口进行 GitHub 授权。输入终端中显示的设备码，授权应用，OAuth 令牌会自动保存。

## 可用模型

可用的模型取决于您的 Copilot 订阅层级。常见模型包括：

| 模型 | 提供商 |
|------|--------|
| `claude-sonnet-4-20250514` | Anthropic（通过 Copilot） |
| `claude-sonnet-5-5` | Anthropic（通过 Copilot） |
| `gpt-4o` | OpenAI（通过 Copilot） |
| `o3-mini` | OpenAI（通过 Copilot） |

运行 `/models` 查看您订阅中所有可用的模型并在它们之间切换。

<Aside variant="info">
  Claude 模型会自动通过 Anthropic Messages API（`/v1/messages`）路由，而不是 OpenAI 兼容端点（`/chat/completions`）。这是透明发生的——不需要配置。
</Aside>

## 配置

GitHub Copilot 除了 OAuth 登录外不需要手动配置。认证后提供商会自动注册。

要将 Copilot 模型设置为默认值：

```json title="cyberstrike.json"
{
  "model": "github-copilot/claude-sonnet-4-20250514"
}
```

### GitHub Enterprise

对于 GHE 实例，登录时会提示输入服务器 URL：

```
? Enter your GitHub Enterprise URL or domain
> company.ghe.com
```

Copilot API 端点会从您的 GHE 域名自动派生。

## 工作原理

1. **OAuth 设备流** — Cyberstrike 从 GitHub 请求设备码，您在浏览器中授权
2. **令牌交换** — OAuth 令牌（`ghu_...`）交换为短期 Copilot 会话令牌（约 30 分钟 TTL）
3. **自动刷新** — 会话令牌在过期前自动刷新
4. **模型路由** — Claude 模型使用 Anthropic Messages API；其他所有模型使用 OpenAI 兼容端点

## 故障排除

| 问题 | 解决方案 |
|------|----------|
| **401 Unauthorized** | 再次运行 `/connect`——您的会话令牌可能已过期 |
| **没有可用模型** | 在 github.com/settings/copilot 检查您的 Copilot 订阅是否活跃 |
| **GHE 连接被拒绝** | 验证企业 URL，并确认 GHE 实例已启用 Copilot |
| **Claude 模型 404** | 更新 Cyberstrike——Claude 路由修复已在 v1.1.16+ 中发布 |

<Aside variant="tip">
  如果您已有订阅，GitHub Copilot 是个不错的选择——不需要单独的 API 密钥，通过单次登录即可访问多个提供商的模型。
</Aside>

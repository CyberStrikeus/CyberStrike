Cyberstrike 提供四种界面来满足不同的工作流需求：

## 界面

| 界面 | 描述 | 状态 |
|------|------|------|
| [**TUI**](/docs/usage/tui) | 终端界面——功能最完整的界面，具有斜杠命令、会话管理和安全工具 | ✅ 可用 |
| [**CLI**](/docs/usage/cli) | 命令行界面——用于脚本、自动化和一次性命令 | ✅ 可用 |
| [**Web**](/docs/usage/web) | Web 界面——通过浏览器访问，支持远程访问 | ✅ 可用 |
| [**桌面应用**](/docs/usage/desktop-app) | 原生桌面应用程序——适用于 macOS、Windows 和 Linux | 🚧 即将推出 |

## 快速比较

| 特性 | TUI | CLI | Web | 桌面 |
|------|-----|-----|-----|------|
| 交互式会话 | ✅ | ❌ | ✅ | ✅ |
| 斜杠命令 | ✅ | ❌ | ✅ | ✅ |
| 脚本/自动化 | ❌ | ✅ | ❌ | ❌ |
| 远程访问 | ❌ | ❌ | ✅ | ❌ |
| 离线使用 | ✅ | ✅ | ✅ | ✅ |

## 入门

大多数用户从 TUI 开始：

```bash
cyberstrike
```

这将启动带有完整功能集的交互式终端会话。

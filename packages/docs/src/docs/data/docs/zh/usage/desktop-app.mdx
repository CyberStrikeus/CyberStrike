## 概述

桌面应用将 Cyberstrike 的 Web 界面包装在原生窗口中，自动管理后端服务器作为子进程。无需手动启动服务器或打开浏览器。

## 功能

- **原生窗口** - 拖放、系统菜单、键盘快捷键
- **自动服务器管理** - 后端在应用启动时自动运行
- **系统托盘** - 最小化到托盘以便后台运行
- **多平台** - macOS、Windows、Linux
- **自动更新** - 通过应用内更新保持最新

## 开发

要运行桌面应用的开发版本：

```bash
bun run --cwd packages/desktop dev
```

这将启动带有热重载的 Electron 开发服务器。

## 架构

桌面应用使用 Electron + electron-vite 构建：

- **主进程** - 管理窗口和后端服务器子进程
- **渲染进程** - 运行 Cyberstrike Web 应用
- **预加载** - 在渲染进程和 Node.js 之间桥接

后端作为子 Bun 进程在 `:4096` 上运行，Web 应用连接到 `localhost:4096`。

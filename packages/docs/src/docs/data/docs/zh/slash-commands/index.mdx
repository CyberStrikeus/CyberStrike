在输入开头键入 `/` 打开命令列表（或按 `Ctrl+P`）。输入时支持模糊匹配过滤。

<img src="/docs/images/gifs/g03-slash-autocomplete.gif" alt="输入斜杠打开带有模糊过滤的命令菜单" className="rounded-lg shadow-lg my-6 w-full" />

<img src="/docs/images/screenshots/s08-slash-menu.png" alt="输入 / 打开的斜杠命令菜单——按类别分组" className="rounded-lg shadow-lg my-6 w-full" />

## 会话

| 命令 | 别名 | 快捷键 | 操作 |
|------|------|--------|------|
| `/new` | `/clear` | `<leader>n` | 开始新会话 |
| `/sessions` | `/resume`、`/continue` | `<leader>l` | 打开会话选择器 |
| `/rename` | | `ctrl+r` | 重命名会话 |
| `/compact` | `/summarize` | `<leader>c` | 压缩（总结）会话 |
| `/fork` | | | 分叉会话 |
| `/timeline` | | `<leader>g` | 显示会话时间线 |
| `/export` | | `<leader>x` | 导出会话 |
| `/copy` | | | 复制最后一条消息 |
| `/share`、`/unshare` | | | 分享 / 停止分享 |
| `/undo`、`/redo` | | `<leader>u` / `<leader>r` | 撤消 / 重做最后一条消息 |
| `/timestamps`、`/thinking` | | | 切换时间戳 / 思考过程 |

## 选择器与系统

| 命令 | 快捷键 | 操作 |
|------|--------|------|
| `/models` | `<leader>m` | 模型选择器 |
| `/agents` | `<leader>a` | 代理选择器 |
| `/themes` | `<leader>t` | 主题选择器 |
| `/mcps` | | MCP 服务器管理器 |
| `/bolt` | | Bolt 服务器管理器 |
| `/connect` | | 连接提供商 |
| `/editor` | `<leader>e` | 在编辑器中打开消息 |
| `/skills` | | 浏览已加载的技能 |
| `/status` | `<leader>s` | 状态 |
| `/help` | | 帮助 |
| `/exit` | | 退出 |

## Web 测试与方法论

| 命令 | 别名 | 操作 |
|------|------|------|
| `/hackbrowser` | | 启动 Hacker Browser 爬取 |
| `/hackbrowser-stop` | | 停止正在运行的爬取 |
| `/vulnerabilities` | `/vuln`、`/vulns` | 查看捕获的漏洞 |
| `/web` | `/endpoints`、`/roles`、`/credentials` | 检查 Web 测试上下文 |
| `/methodology` | `/intel`、`/vrt`、`/chains` | 方法论引擎视图 |
| `/report` | | 生成报告 |
| `/qpause`、`/qresume` | | 暂停 / 恢复接入队列 |

<Aside variant="caution">
  命令名称是复数形式（`/models`、`/themes`、`/mcps`）。没有 `/agent-settings`、`/settings`、`/config`、`/vim`、`/provider`、`/model` 或 `<leader><leader>`/`Ctrl+Shift+P` 命令面板——命令列表通过 `Ctrl+P` 打开。
</Aside>

## @ 提及

在提示中使用 `@` 引用文件（可选行范围）：

```
@src/auth.ts#45-60 check these lines for vulnerabilities
```

## 自定义技能

将可复用的方法论打包为 `SKILL.md` 文件——参见[自定义技能](/docs/slash-commands/custom-skills)。

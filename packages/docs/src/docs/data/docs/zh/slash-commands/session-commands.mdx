会话命令管理当前对话——创建、恢复、分享和编辑消息历史。

<img src="/docs/images/gifs/session-commands.gif" alt="使用 leader+l 打开会话选择器" className="rounded-lg shadow-lg my-6 w-full" />

## 生命周期

| 命令 | 别名 | 操作 |
|------|------|------|
| `/new` | `/clear` | 开始**新**会话（`/clear` 是别名——它不仅仅是清除消息） |
| `/sessions` | `/resume`、`/continue` | 打开会话选择器以恢复过去的会话 |
| `/rename` | | 重命名当前会话 |
| `/fork` | | 从当前节点分叉会话 |
| `/timeline` | | 显示会话时间线 |
| `/export` | | 导出会话 |
| `/copy` | | 复制最后一条消息 |

## 消息

| 命令 | 别名 | 操作 |
|------|------|------|
| `/undo` | | 撤消最后一条消息 |
| `/redo` | | 重做 |
| `/compact` | `/summarize` | 压缩（总结）会话以回收上下文 |
| `/timestamps` | `/toggle-timestamps` | 切换消息时间戳 |
| `/thinking` | `/toggle-thinking` | 切换思考过程 |

## 分享

| 命令 | 操作 |
|------|------|
| `/share` | 分享当前会话 |
| `/unshare` | 停止分享 |

<Aside variant="caution">
  `/clear` 是 `/new` 的别名（它开始一个新会话），`/continue` 是 `/sessions` 的别名（它打开会话选择器）。没有 `/history`、`/memory`、`/cost`、`/save`、`/tag`、`/note`、`/retry` 或 `/template` 命令。
</Aside>

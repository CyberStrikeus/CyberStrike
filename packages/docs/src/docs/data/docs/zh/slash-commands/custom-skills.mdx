技能是一个可复用方法论的 Markdown 文件，代理可以按需引入。技能通过文件名发现——每个技能都存放在名为 **`SKILL.md`** 的文件中。

## 文件与位置

文件必须命名为 `SKILL.md`。Cyberstrike 在 `.cyberstrike/` 内的 `skill/` 或 `skills/` 目录下扫描 `**/SKILL.md`，也扫描 `skills/`（Claude Code 布局）：

```
.cyberstrike/
└── skills/
    └── sql-injection/
        └── SKILL.md
```

## 前置元数据

只有 `name` 和 `description` 是必需的。其余是用于分类和攻击链链接的可选元数据：

```markdown title="SKILL.md"
---
name: sql-injection
description: Methodology for testing SQL injection
version: "1.0.0"
author: you
tags: [injection, database]
category: injection
owasp_id: WSTG-INPV-05
tech_stack: [postgres, mysql]
cwe_ids: [CWE-89]
chains_with: [auth-bypass]
prerequisites: [request-capture]
---

Walk the tester through boolean-, error-, time-, and union-based SQLi:
1. Identify injectable parameters …
2. …
```

<Aside variant="caution">
  正文是纯 Markdown——**没有**模板（没有 `{{target}}`、`{% if %}`、`{% for %}` 或 `$ARGUMENTS`）。前置元数据**不**支持 `args`、`model`、`agent` 或 `permission` 字段，且文件必须严格命名为 `SKILL.md`（`my-skill.md` 之类的任意名称不会被加载）。
</Aside>

前置元数据中的 `name` 必须与技能的标识匹配——不匹配会被报告为错误。

## 使用技能

已加载的技能对代理可用，可以通过 `/skills` 命令浏览。当技能的方法论与任务相关时，代理会将其引入上下文。

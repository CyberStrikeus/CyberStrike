这些斜杠命令打开选择器和对话框。在 TUI 中输入 `/` 查看命令列表（或按 `Ctrl+P`）。

<img src="/docs/images/gifs/navigation-commands.gif" alt="打开命令列表并浏览选择器" className="rounded-lg shadow-lg my-6 w-full" />

## 选择器与对话框

| 命令 | 打开 |
|------|------|
| `/models` | 模型选择器 |
| `/agents` | 代理选择器 |
| `/themes` | 主题选择器 |
| `/mcps` | MCP 服务器管理器 |
| `/bolt` | Bolt 服务器管理器 |
| `/connect` | 连接 / 认证提供商 |
| `/sessions`（`/resume`、`/continue`） | 会话选择器 |
| `/editor` | 在外部编辑器中打开消息 |
| `/skills` | 浏览已加载的技能 |
| `/help` | 显示帮助 |
| `/status` | 显示状态 |
| `/exit` | 退出 Cyberstrike |

<Aside variant="caution">
  命令名称是复数形式：`/models`、`/themes`、`/mcps`（不是 `/model`、`/theme`、`/mcp`）。没有 `/provider`、`/vim`、`/config`、`/permission`、`/files`、`/cd`、`/tools`、`/version`、`/doctor`、`/docs`、`/changelog`、`/cost` 或 `/context` 命令——这些不存在。
</Aside>

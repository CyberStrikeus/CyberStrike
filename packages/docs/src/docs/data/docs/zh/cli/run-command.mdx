`cyberstrike run` 以非交互方式执行单个提示——适合自动化和脚本编写。在此模式下没有人回答权限提示，因此任何需要提示的工具会被自动拒绝（参见[自动化](/docs/permissions/automation)）。

## 基本用法

```bash
cyberstrike run "your prompt here"
```

当输入被管道传入时，也会从 stdin 读取提示：

```bash
echo "summarize the findings in report.json" | cyberstrike run
```

## 选项

| 标志 | 别名 | 描述 |
|------|------|------|
| `--model` | `-m` | 使用的模型，格式为 `provider/model` |
| `--agent` | | 使用的主代理（仅内置 `cyberstrike`） |
| `--format` | | 输出格式：`default` 或 `json`（默认：`default`） |
| `--file` | `-f` | 附加到消息的文件（可重复） |
| `--continue` | `-c` | 继续上次会话 |
| `--session` | `-s` | 要继续的会话 ID |
| `--fork` | | 继续前分叉会话（需要 `--continue`/`--session`） |
| `--share` | | 分享会话 |
| `--title` | | 会话标题 |
| `--variant` | | 模型变体 / 推理强度（例如 `high`、`max`、`minimal`） |
| `--thinking` | | 显示思考块 |
| `--attach` | | 附加到运行中的服务器（例如 `http://localhost:4096`） |
| `--dir` | | 运行目录（附加时为远程路径） |
| `--port` | | 本地服务器端口 |
| `--command` | | 运行命名命令；使用消息作为其参数 |

<Aside variant="caution">
  没有 `--output`、`--permission`、`--timeout`、`--verbose` 或 `--quiet` 标志。输出控制使用 `--format`（`default` | `json`）；推理显示使用 `--thinking`。
</Aside>

## 示例

### 用于脚本的 JSON 输出

```bash
cyberstrike run "scan example.com for OWASP Top 10 issues" --format json > report.json
```

### 选择模型并附加文件

```bash
cyberstrike run "review this code for auth bugs" \
  -m anthropic/claude-sonnet-4-20250514 \
  -f src/auth.ts -f src/session.ts
```

### 继续或分叉会话

```bash
cyberstrike run "now test the admin endpoints" --continue
cyberstrike run "try a different payload" --session <id> --fork
```

## `run` 中的权限

由于提示无法在非交互模式下回答，请通过 `CYBERSTRIKE_PERMISSION` 环境变量或配置的 `permission` 字段预批准脚本需要的工具：

```bash
CYBERSTRIKE_PERMISSION='{"bash":"allow","read":"allow"}' \
  cyberstrike run "enumerate services on the host" --format json
```

CI 模式请参阅[自动化](/docs/permissions/automation)。

## 退出码

`cyberstrike run` 成功时返回 `0`，出错（例如无效参数）或中断时返回非零代码。

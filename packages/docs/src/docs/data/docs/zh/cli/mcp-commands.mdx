`cyberstrike mcp` 命令管理 Model Context Protocol 服务器。有五个子命令：`list`、`add`、`auth`、`logout` 和 `debug`。

## `mcp list`

```bash
cyberstrike mcp list   # 别名: ls
```

列出已配置的 MCP 服务器。

## `mcp add`

```bash
cyberstrike mcp add
```

完全交互式——它会提示选择本地还是远程、命令或 URL 以及名称，然后在保存前测试连接。它**不接受**位置名称或标志；要脚本化服务器设置，请直接将条目写入 `cyberstrike.json`。

## `mcp auth`

```bash
cyberstrike mcp auth [name]        # 授权 OAuth 服务器
cyberstrike mcp auth list          # 列出 OAuth 授权的服务器
```

授权使用 OAuth 的远程服务器（需要时会打开浏览器）。参见 [OAuth](/docs/mcp/oauth)。

## `mcp logout`

```bash
cyberstrike mcp logout [name]
```

移除服务器存储的 OAuth 凭据。

## `mcp debug`

```bash
cyberstrike mcp debug <name>
```

检查服务器的连接——在服务器加载失败或其工具未显示时很有用。

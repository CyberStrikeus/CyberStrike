`cyberstrike auth` 命令管理 AI 提供商的凭据。它有三个子命令——`login`、`logout` 和 `list`——都不接受标志；每个都是交互式的。

## `auth login`

```bash
cyberstrike auth login [url]
```

启动交互式登录。Cyberstrike 显示提供商列表（从模型目录构建）并提示输入 API 密钥或 OAuth 流程。可选的 `url` 位置参数预选一个 well-known 提供商 URL；否则从菜单中选择提供商——您**不需要**将提供商作为标志传递。

```
? Select provider
❯ cyberstrike (recommended)
  anthropic (Claude Max or API key)
  github-copilot
  openai (ChatGPT Plus/Pro or API key)
  google
  openrouter
  …
```

凭据存储在数据目录中（`~/.local/share/cyberstrike/auth.json`）。

## `auth list`

```bash
cyberstrike auth list   # 别名: ls
```

列出您拥有凭据的提供商。

## `auth logout`

```bash
cyberstrike auth logout
```

交互式选择要移除的存储凭据。

<Aside variant="caution">
  没有 `auth status`、`auth verify`、`auth refresh` 或 `auth switch` 命令，也没有 `--key`/`--oauth`/`--json`/`--all` 标志。登录始终是交互式的 `auth login` 流程。
</Aside>

## 环境变量

除了存储凭据，您还可以通过环境变量提供提供商密钥——参见 [AI 提供商](/docs/providers) 和[环境变量](/docs/configuration/environment-variables)。例如：

```bash
export ANTHROPIC_API_KEY="sk-ant-..."
export OPENAI_API_KEY="sk-..."
export GOOGLE_GENERATIVE_AI_API_KEY="AI..."
```

Cyberstrike unterstuetzt GitHub Copilot als KI-Anbieter. Authentifizieren Sie sich mit Ihrem GitHub-Konto ueber OAuth und greifen Sie auf alle Modelle zu, die ueber Ihr Copilot-Abonnement verfuegbar sind — einschliesslich Claude, GPT-4o und o-Series-Modelle.

## Voraussetzungen

- Ein GitHub-Konto mit einem aktiven **GitHub Copilot**-Abonnement (Individual, Business oder Enterprise)
- Fuer GitHub Enterprise: Ihre GHE-Server-URL

## Authentifizierung

GitHub Copilot verwendet den **OAuth Device Flow** — kein API-Schluessel erforderlich.

### Anmeldung

Fuehren Sie in der TUI aus:

```
/connect
```

Waehlen Sie **Login with GitHub Copilot** aus der Anbieterliste und waehlen Sie dann Ihre Bereitstellung:

| Bereitstellung | Wann verwenden |
|----------------|----------------|
| **GitHub.com** | Persoenliche oder Organisationskonten auf github.com |
| **GitHub Enterprise** | Selbst gehostete GHE- oder Data-Residency-Instanzen |

Cyberstrike oeffnet ein Browserfenster fuer die GitHub-Autorisierung. Geben Sie den im Terminal angezeigten Geraetecode ein, autorisieren Sie die App, und der OAuth-Token wird automatisch gespeichert.

## Verfuegbare Modelle

Die verfuegbaren Modelle haengen von Ihrer Copilot-Abonnementstufe ab. Gaengige Modelle sind:

| Modell | Anbieter |
|--------|----------|
| `claude-sonnet-4-20250514` | Anthropic (ueber Copilot) |
| `claude-sonnet-5-5` | Anthropic (ueber Copilot) |
| `gpt-4o` | OpenAI (ueber Copilot) |
| `o3-mini` | OpenAI (ueber Copilot) |

Fuehren Sie `/models` aus, um alle in Ihrem Abonnement verfuegbaren Modelle anzuzeigen und zwischen ihnen zu wechseln.

<Aside variant="info">
  Claude-Modelle werden automatisch ueber die Anthropic Messages API (`/v1/messages`) statt ueber den OpenAI-kompatiblen Endpunkt (`/chat/completions`) geroutet. Dies geschieht transparent — keine Konfiguration erforderlich.
</Aside>

## Konfiguration

GitHub Copilot erfordert ueber die OAuth-Anmeldung hinaus keine manuelle Konfiguration. Der Anbieter wird nach der Authentifizierung automatisch registriert.

Um ein Copilot-Modell als Standard zu verwenden:

```json title="cyberstrike.json"
{
  "model": "github-copilot/claude-sonnet-4-20250514"
}
```

### GitHub Enterprise

Fuer GHE-Instanzen werden Sie waehrend der Anmeldung nach Ihrer Server-URL gefragt:

```
? Enter your GitHub Enterprise URL or domain
> company.ghe.com
```

Der Copilot-API-Endpunkt wird automatisch aus Ihrer GHE-Domain abgeleitet.

## Funktionsweise

1. **OAuth Device Flow** — Cyberstrike fordert einen Geraetecode von GitHub an, Sie autorisieren im Browser
2. **Token-Austausch** — Der OAuth-Token (`ghu_...`) wird gegen einen kurzlebigen Copilot-Sitzungstoken eingetauscht (~30 Min. TTL)
3. **Automatische Erneuerung** — Sitzungstoken werden vor dem Ablauf automatisch erneuert
4. **Modell-Routing** — Claude-Modelle verwenden die Anthropic Messages API; alle anderen den OpenAI-kompatiblen Endpunkt

## Fehlerbehebung

| Problem | Loesung |
|---------|---------|
| **401 Unauthorized** | Fuehren Sie `/connect` erneut aus — Ihr Sitzungstoken ist moeglicherweise abgelaufen |
| **Keine Modelle verfuegbar** | Pruefen Sie, ob Ihr Copilot-Abonnement unter github.com/settings/copilot aktiv ist |
| **GHE-Verbindung abgelehnt** | Ueberpruefen Sie die Enterprise-URL und ob Copilot auf Ihrer GHE-Instanz aktiviert ist |
| **Claude-Modell 404** | Aktualisieren Sie Cyberstrike — Claude-Routing-Fix wurde in v1.1.16+ ausgeliefert |

<Aside variant="tip">
  GitHub Copilot ist eine grossartige Option, wenn Sie bereits ein Abonnement haben — kein separater API-Schluessel erforderlich, und Sie erhalten Zugriff auf Modelle von mehreren Anbietern ueber eine einzige Anmeldung.
</Aside>

| **Ollama** | Lokale Modelle | Datenschutz, Offline-Nutzung |

## Anmeldedaten hinzufuegen

### Anbieter verbinden

Fuehren Sie in der TUI `/connect` aus, um den Anbieterdialog zu oeffnen. Waehlen Sie Ihren Anbieter und geben Sie Ihren API-Schluessel ein (oder autorisieren Sie sich ueber OAuth fuer GitHub Copilot).

### Umgebungsvariablen

Setzen Sie API-Schluessel in Ihrer Umgebung:

```bash
# Anthropic
export ANTHROPIC_API_KEY="sk-ant-..."

# OpenAI
export OPENAI_API_KEY="sk-..."

# Google
export GOOGLE_GENERATIVE_AI_API_KEY="AI..."

# OpenRouter
export OPENROUTER_API_KEY="sk-or-..."

# Groq
export GROQ_API_KEY="gsk_..."
```

Fuegen Sie sie Ihrem Shell-Profil (`~/.bashrc` oder `~/.zshrc`) hinzu fuer dauerhafte Speicherung.

### Konfigurationsdatei

Speichern Sie Anmeldedaten in `~/.config/cyberstrike/cyberstrike.json`:

```json
{
  "provider": {
    "anthropic": {
      "options": {
        "apiKey": "{env:ANTHROPIC_API_KEY}"
      }
    }
  }
}
```

## Anthropic

Claude-Modelle werden fuer komplexe Sicherheitsanalysen empfohlen.

### Authentifizierung

Fuehren Sie `/connect` in der TUI aus, waehlen Sie **Anthropic** und geben Sie Ihren API-Schluessel von [console.anthropic.com](https://console.anthropic.com) ein.

Oder ueber Umgebungsvariable:

```bash
export ANTHROPIC_API_KEY="sk-ant-..."
```

### Verfuegbare Modelle

| Modell | ID | Kontext | Am besten fuer |
|--------|-----|---------|----------------|
| Claude Opus 4.5 | `claude-opus-4-5-20251101` | 200K | Komplexe Analyse |
| Claude Sonnet 4 | `claude-sonnet-4-20250514` | 200K | Ausgewogene Leistung |
| Claude Haiku 4.5 | `claude-haiku-4-5-20251001` | 200K | Schnelle Aufgaben |

### Verwendung

Verwenden Sie `/models`, um ein Claude-Modell auszuwaehlen, oder setzen Sie einen Standard in der Konfiguration:

```json
{
  "model": "anthropic/claude-sonnet-4-20250514"
}
```

### Konfigurationsoptionen

```json
{
  "provider": {
    "anthropic": {
      "options": {
        "apiKey": "{env:ANTHROPIC_API_KEY}",
        "timeout": 300000
      }
    }
  }
}
```

## OpenRouter

Zugriff auf viele Modelle ueber eine einzige API mit kostenloser Stufe.

### Authentifizierung

Fuehren Sie `/connect` in der TUI aus, waehlen Sie **OpenRouter** und geben Sie Ihren API-Schluessel von [openrouter.ai/keys](https://openrouter.ai/keys) ein.

Oder ueber Umgebungsvariable:

```bash
export OPENROUTER_API_KEY="sk-or-..."
```

### Kostenlose Modelle

| Modell | ID |
|--------|-----|
| Llama 4 Scout | `meta-llama/llama-4-scout:free` |
| Gemini 2.0 Flash | `google/gemini-2.0-flash:free` |
| Mistral Small | `mistralai/mistral-small-3.2-24b-instruct:free` |

### Verwendung

Verwenden Sie `/models`, um ein OpenRouter-Modell auszuwaehlen, oder setzen Sie eines in der Konfiguration:

### Konfiguration

```json
{
  "model": "openrouter/meta-llama/llama-4-scout:free",
  "provider": {
    "openrouter": {
      "options": {
        "apiKey": "{env:OPENROUTER_API_KEY}"
      }
    }
  }
}
```

## AWS Bedrock

Claude und andere Modelle ueber AWS verwenden.

### Authentifizierung

AWS-Anmeldedaten konfigurieren:

```bash
# Ueber AWS CLI
aws configure

# Oder ueber Umgebungsvariablen
export AWS_ACCESS_KEY_ID="..."
export AWS_SECRET_ACCESS_KEY="..."
export AWS_REGION="us-east-1"
```

### Verfuegbare Modelle

| Modell | ID |
|--------|-----|
| Claude Sonnet | `anthropic.claude-sonnet-4-20250514-v1:0` |
| Claude Haiku | `anthropic.claude-haiku-4-5-20251001-v1:0` |
| Llama 3.3 | `meta.llama3-3-70b-instruct-v1:0` |

### Konfiguration

```json
{
  "model": "amazon-bedrock/anthropic.claude-sonnet-4-20250514-v1:0",
  "provider": {
    "amazon-bedrock": {
      "options": {
        "region": "us-east-1"
      }
    }
  }
}
```

## Ollama (Lokal)

Modelle lokal ausfuehren fuer Datenschutz und Offline-Nutzung.

### Einrichtung

1. Ollama installieren:

```bash
curl -fsSL https://ollama.com/install.sh | sh
```

2. Ein Modell herunterladen:

```bash
ollama pull llama3.3
```

3. Ollama starten:

```bash
ollama serve
```

### Verwendung

Kein API-Schluessel erforderlich. Verwenden Sie `/models`, um ein Ollama-Modell auszuwaehlen.

### Verfuegbare Modelle

| Modell | Pull-Befehl |
|--------|-------------|
| Llama 3.3 | `ollama pull llama3.3` |
| CodeLlama | `ollama pull codellama` |
| Mistral | `ollama pull mistral` |
| Qwen | `ollama pull qwen2.5` |

### Konfiguration

```json
{
  "model": "ollama/llama3.3",
  "provider": {
    "ollama": {
      "options": {
        "baseURL": "http://localhost:11434"
      }
    }
  }
}
```

## Benutzerdefiniert OpenAI-kompatibel

Verbindung zu jeder OpenAI-kompatiblen API.

### Konfiguration

```json
{
  "provider": {
    "custom-api": {
      "id": "custom-api",
      "name": "Custom API",
      "options": {
        "baseURL": "https://api.custom.example.com/v1",
        "apiKey": "{env:CUSTOM_API_KEY}"
      },
      "models": {
        "custom-model": {
          "name": "Custom Model",
          "contextLength": 32000
        }
      }
    }
  }
}
```

### Verwendung

Verwenden Sie `/models`, um das benutzerdefinierte Modell auszuwaehlen, oder setzen Sie es in der Konfiguration.

## Tipps zur Anbieterwahl

### Fuer komplexe Sicherheitsanalyse

Verwenden Sie Claude Opus 4.5 oder Sonnet 4:

```json
{
  "model": "anthropic/claude-opus-4-5-20251101"
}
```

### Fuer Kosteneffizienz

Verwenden Sie die kostenlose OpenRouter-Stufe oder Groq:

```json
{
  "model": "openrouter/meta-llama/llama-4-scout:free"
}
```

### Fuer Datenschutz

Verwenden Sie Ollama mit lokalen Modellen:

```json
{
  "model": "ollama/llama3.3"
}
```

### Fuer Enterprise

Verwenden Sie AWS Bedrock oder Azure OpenAI mit den Anmeldedaten Ihrer Organisation.

---

## Anmeldedaten verwalten

Verwenden Sie `/status` in der TUI, um verbundene Anbieter und aktive Anmeldedaten anzuzeigen.

Um Anmeldedaten zu entfernen, verwenden Sie den CLI-Befehl `cyberstrike auth logout` und waehlen Sie den zu entfernenden Anbieter aus.

<Aside variant="tip">
  Fuer Penetrationstest-Aufgaben, die komplexes Reasoning erfordern, empfehlen wir **Claude Opus 4.5** oder **Claude Sonnet 4**.
</Aside>

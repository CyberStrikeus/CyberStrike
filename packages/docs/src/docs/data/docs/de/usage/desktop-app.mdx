CyberStrike Desktop ist eine native Anwendung, die das gesamte Framework buendelt — Agenten, Tools, Vortex, HackBrowser, Bolt — in einer eigenstaendigen App. Kein Terminal erforderlich.

<Aside variant="caution">
  Die Desktop-App befindet sich in aktiver Entwicklung. Alle drei Plattformen sind fuer die erste Veroeffentlichung geplant.
</Aside>

## macOS <Badge text="Demnächst" variant="caution" size="md" />

Native macOS-App mit Apple Silicon- und Intel-Unterstuetzung. Verteilt als `.dmg`-Installationsprogramm.

- macOS 12 Monterey oder neuer
- Apple Silicon (M1+) oder Intel
- 500 MB Speicherplatz

## Windows <Badge text="Demnächst" variant="caution" size="md" />

Native Windows-App, verteilt als `.exe`-Installationsprogramm ueber NSIS.

- Windows 10 (1809) oder neuer
- x64-Architektur
- 500 MB Speicherplatz

<Aside variant="info">
  WSL ist **nicht** erforderlich. Die Desktop-App laeuft nativ unter Windows.
</Aside>

## Linux <Badge text="Demnächst" variant="caution" size="md" />

Linux-Builds, verteilt als `.AppImage`- und `.deb`-Pakete.

- Ubuntu 20.04+, Fedora 38+ oder vergleichbar
- x64-Architektur
- 500 MB Speicherplatz

## Was Sie erwarten koennen

Die Desktop-App bietet dieselben Faehigkeiten wie `cyberstrike web`, jedoch als natives Fenster:

- Volle TUI-Funktionsparitaet — alle Slash-Befehle, Agenten und Tools
- Integrierter HackBrowser — startet Chromium direkt aus der App
- Bolt-Serververwaltung — containerisierte Tools koppeln und verwalten
- MCP-Server-Panel — MCP-Verbindungen konfigurieren und ueberwachen
- Sitzungs-Tabs — mehrere Bewertungen gleichzeitig geoeffnet
- Offline-faehig — funktioniert mit lokalen Anbietern wie Ollama

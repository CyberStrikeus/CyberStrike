## Die Speicher-Werkzeuge

Es gibt vier Speicher-Werkzeuge — es gibt keine Loesch-, Bereinigungs-, Export- oder Import-Operation:

| Werkzeug | Zweck |
|----------|-------|
| `memory_write` | Eine Notiz im Speicher ablegen |
| `memory_read` | Gespeicherten Speicher lesen |
| `memory_search` | Gespeicherte Notizen durchsuchen |
| `memory_context` | Relevanten Speicher in den aktuellen Kontext laden |

## Speicher-Layout

Speicher besteht aus reinem Markdown unter `.cyberstrike/`:

```
.cyberstrike/
├── MEMORY.md              ← Langzeitspeicher
└── memory/
    └── 2026-07-03.md      ← Datierte Tagesnotizen
```

- **`MEMORY.md`** speichert dauerhafte Langzeitfakten.
- **`memory/<YYYY-MM-DD>.md`**-Dateien sind Tagesnotizen; jede beginnt mit einer `# Daily Notes - <datum>`-Ueberschrift und wird waehrend der Sitzung ergaenzt.

Globaler Speicher (projektuebergreifend geteilt) befindet sich unter `~/.config/cyberstrike/memory/`.

Da alles Markdown auf der Festplatte ist, koennen Sie es wie jede andere Projektdatei lesen, bearbeiten oder versionieren.

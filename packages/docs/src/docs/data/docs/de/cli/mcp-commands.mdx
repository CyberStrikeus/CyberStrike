Die `cyberstrike mcp`-Befehle verwalten Model Context Protocol Server. Es gibt fuenf Unterbefehle: `list`, `add`, `auth`, `logout` und `debug`.

## `mcp list`

```bash
cyberstrike mcp list   # Alias: ls
```

Listet die konfigurierten MCP-Server auf.

## `mcp add`

```bash
cyberstrike mcp add
```

Vollstaendig interaktiv — es fragt nach lokal vs. remote, dem Befehl oder der URL und einem Namen, testet dann die Verbindung vor dem Speichern. Es akzeptiert **keine** positionellen Namen oder Flags; um die Server-Einrichtung zu skripten, schreiben Sie den Eintrag direkt in `cyberstrike.json`.

## `mcp auth`

```bash
cyberstrike mcp auth [name]        # einen OAuth-Server autorisieren
cyberstrike mcp auth list          # OAuth-autorisierte Server auflisten
```

Autorisiert einen Remote-Server, der OAuth verwendet (oeffnet bei Bedarf den Browser). Siehe [OAuth](/docs/mcp/oauth).

## `mcp logout`

```bash
cyberstrike mcp logout [name]
```

Entfernt gespeicherte OAuth-Anmeldedaten fuer einen Server.

## `mcp debug`

```bash
cyberstrike mcp debug <name>
```

Untersucht die Verbindung eines Servers — nuetzlich, wenn ein Server nicht geladen werden kann oder seine Werkzeuge nicht angezeigt werden.

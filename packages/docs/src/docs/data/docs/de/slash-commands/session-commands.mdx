Sitzungsbefehle verwalten die aktuelle Konversation — Erstellen, Fortsetzen, Teilen und Bearbeiten des Nachrichtenverlaufs.

<img src="/docs/images/gifs/session-commands.gif" alt="Sitzungsauswahl oeffnen mit Leader+l" className="rounded-lg shadow-lg my-6 w-full" />

## Lebenszyklus

| Befehl | Aliase | Aktion |
|--------|--------|--------|
| `/new` | `/clear` | **Neue** Sitzung starten (`/clear` ist ein Alias — es loescht nicht nur Nachrichten) |
| `/sessions` | `/resume`, `/continue` | Sitzungsauswahl oeffnen, um eine fruehere Sitzung fortzusetzen |
| `/rename` | | Aktuelle Sitzung umbenennen |
| `/fork` | | Sitzung ab dem aktuellen Punkt forken |
| `/timeline` | | Sitzungszeitachse anzeigen |
| `/export` | | Sitzung exportieren |
| `/copy` | | Letzte Nachricht kopieren |

## Nachrichten

| Befehl | Aliase | Aktion |
|--------|--------|--------|
| `/undo` | | Letzte Nachricht rueckgaengig machen |
| `/redo` | | Wiederherstellen |
| `/compact` | `/summarize` | Sitzung komprimieren (zusammenfassen), um Kontext freizugeben |
| `/timestamps` | `/toggle-timestamps` | Nachrichtenzeitstempel umschalten |
| `/thinking` | `/toggle-thinking` | Denkbloecke umschalten |

## Teilen

| Befehl | Aktion |
|--------|--------|
| `/share` | Aktuelle Sitzung teilen |
| `/unshare` | Teilen beenden |

<Aside variant="caution">
  `/clear` ist ein Alias von `/new` (startet eine neue Sitzung) und `/continue` ist ein Alias von `/sessions` (oeffnet die Sitzungsauswahl). Es gibt keinen `/history`-, `/memory`-, `/cost`-, `/save`-, `/tag`-, `/note`-, `/retry`- oder `/template`-Befehl.
</Aside>

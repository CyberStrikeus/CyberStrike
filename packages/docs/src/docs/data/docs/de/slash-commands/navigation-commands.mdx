Diese Slash-Befehle oeffnen Auswahldialoge und Dialoge. Geben Sie `/` in der TUI ein, um die Befehlsliste zu sehen (oder druecken Sie `Ctrl+P`).

<img src="/docs/images/gifs/navigation-commands.gif" alt="Befehlsliste oeffnen und durch die Auswahldialoge navigieren" className="rounded-lg shadow-lg my-6 w-full" />

## Auswahldialoge & Dialoge

| Befehl | Oeffnet |
|--------|---------|
| `/models` | Modellauswahl |
| `/agents` | Agentenauswahl |
| `/themes` | Theme-Auswahl |
| `/mcps` | MCP-Server-Verwaltung |
| `/bolt` | Bolt-Server-Verwaltung |
| `/connect` | Anbieter verbinden / authentifizieren |
| `/sessions` (`/resume`, `/continue`) | Sitzungsauswahl |
| `/editor` | Nachricht im externen Editor oeffnen |
| `/skills` | Geladene Skills durchsuchen |
| `/help` | Hilfe anzeigen |
| `/status` | Status anzeigen |
| `/exit` | Cyberstrike beenden |

<Aside variant="caution">
  Befehlsnamen sind im Plural: `/models`, `/themes`, `/mcps` (nicht `/model`, `/theme`, `/mcp`). Es gibt keinen `/provider`-, `/vim`-, `/config`-, `/permission`-, `/files`-, `/cd`-, `/tools`-, `/version`-, `/doctor`-, `/docs`-, `/changelog`-, `/cost`- oder `/context`-Befehl — diese existieren nicht.
</Aside>

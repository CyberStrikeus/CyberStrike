Cyberstrike는 보안 평가를 위한 강력한 명령줄 인터페이스를 제공합니다. 이 레퍼런스는 사용 가능한 모든 명령어, 옵션 및 사용 패턴을 다룹니다.

## 명령어 구조

```
cyberstrike [global-options] <command> [command-options] [arguments]
```

## 전역 옵션

| 옵션 | 별칭 | 설명 |
|------|------|------|
| `--help` | `-h` | 도움말 정보 표시 |
| `--version` | `-v` | 버전 번호 표시 |
| `--print-logs` | | stderr에 로그 출력 |
| `--log-level` | | 로그 레벨 설정 (DEBUG, INFO, WARN, ERROR) |

## 대화형 모드

인수 없이 터미널 사용자 인터페이스를 실행합니다:

```bash
cyberstrike
```

### 대화형 모드 옵션

| 옵션 | 별칭 | 설명 |
|------|------|------|
| `--model <model>` | `-m` | `provider/model` 형식의 모델 |
| `--agent <name>` | | 사용할 보안 에이전트 |
| `--continue` | `-c` | 마지막 세션 이어하기 |
| `--session <id>` | `-s` | 특정 세션 재개 |

### 예시

```bash
# 특정 모델로 시작
cyberstrike --model anthropic/claude-sonnet-4-20250514

# 기본 에이전트 선택 (내장된 것은 'cyberstrike'만 제공)
cyberstrike --agent cyberstrike

# 이전 세션 이어하기
cyberstrike --continue
```

## run

대화형 모드 없이 단일 프롬프트를 실행합니다.

```bash
cyberstrike run [message..] [options]
```

### 옵션

| 옵션 | 별칭 | 설명 |
|------|------|------|
| `--model <model>` | `-m` | `provider/model` 형식의 모델 |
| `--agent <name>` | | 사용할 에이전트 |
| `--continue` | `-c` | 마지막 세션 이어하기 |
| `--session <id>` | `-s` | 특정 세션 재개 |
| `--file <path>` | `-f` | 메시지에 파일 첨부 |
| `--format <type>` | | 출력 형식: `default` 또는 `json` |
| `--share` | | 세션 공유 |
| `--title <text>` | | 세션 제목 설정 |
| `--attach <url>` | | 실행 중인 서버에 연결 |
| `--variant <type>` | | 모델 변형 (high, max, minimal) |

### 예시

```bash
# 단일 명령 실행
cyberstrike run "scan example.com for open ports"

# 요청에 파일 첨부
cyberstrike run "analyze this config" -f nginx.conf

# JSON으로 출력
cyberstrike run "list vulnerabilities" --format json

# 이전 세션 이어하기
cyberstrike run "now check for XSS" --continue
```

### 입력 파이핑

stdin에서 입력을 받습니다:

```bash
echo "analyze this code" | cyberstrike run
cat report.txt | cyberstrike run "summarize this"
```

## auth

AI 제공자의 인증 자격 증명을 관리합니다.

### auth login

AI 제공자의 자격 증명을 추가합니다:

```bash
cyberstrike auth login [url]
```

#### 대화형 로그인

```bash
cyberstrike auth login
# 목록에서 제공자 선택
# 프롬프트에서 API 키 입력
```

#### Well-Known URL 로그인

```bash
cyberstrike auth login https://custom-provider.example.com
```

### auth logout

저장된 자격 증명을 제거합니다:

```bash
cyberstrike auth logout
# 목록에서 제공자 선택
```

### auth list

구성된 모든 자격 증명을 표시합니다:

```bash
cyberstrike auth list
```

출력 내용:
- 제공자별 저장된 자격 증명
- 인증 유형 (api, oauth)
- 활성 환경 변수

## mcp

Model Context Protocol (MCP) 서버를 관리합니다.

### mcp list

구성된 MCP 서버와 상태를 나열합니다:

```bash
cyberstrike mcp list
```

상태 표시:
- `✓` 연결됨
- `○` 초기화되지 않음 / 비활성화됨
- `⚠` 인증 필요
- `✗` 실패

### mcp add

새 MCP 서버를 대화형으로 추가합니다:

```bash
cyberstrike mcp add
```

마법사가 다음을 요청합니다:
1. 위치 (프로젝트 또는 전역)
2. 서버 이름
3. 서버 유형 (로컬 또는 원격)
4. 연결 세부 정보

#### 로컬 서버 예시

```bash
# `cyberstrike mcp add` 실행 후:
# Location: Current project
# Name: filesystem
# Type: Local
# Command: npx @modelcontextprotocol/server-filesystem /path/to/dir
```

#### 원격 서버 예시

```bash
# `cyberstrike mcp add` 실행 후:
# Location: Global
# Name: custom-api
# Type: Remote
# URL: https://api.example.com/mcp
# OAuth: Yes/No
```

### mcp auth

OAuth 지원 MCP 서버와 인증합니다:

```bash
cyberstrike mcp auth [name]
```

### mcp auth list

모든 MCP 서버의 OAuth 상태를 나열합니다:

```bash
cyberstrike mcp auth list
```

### mcp logout

OAuth 자격 증명을 제거합니다:

```bash
cyberstrike mcp logout [name]
```

### mcp debug

서버 연결을 디버그합니다:

```bash
cyberstrike mcp debug <name>
```

## session

대화 세션을 관리합니다.

### session list

모든 세션을 나열합니다:

```bash
cyberstrike session list [options]
```

| 옵션 | 별칭 | 설명 |
|------|------|------|
| `--max-count <n>` | `-n` | 최근 N개 세션으로 제한 |
| `--format <type>` | | 출력: `table` 또는 `json` |

### 예시

```bash
# 가장 최근 10개 세션 나열
cyberstrike session list -n 10

# JSON으로 내보내기
cyberstrike session list --format json
```

## models

사용 가능한 AI 모델을 나열합니다.

## agent

보안 에이전트를 관리합니다.

```bash
cyberstrike agent [name]
```

```bash
cyberstrike agent
```


## serve

Cyberstrike API 서버를 시작합니다. `CYBERSTRIKE_SERVER_PASSWORD` 설정이 필요합니다.

```bash
CYBERSTRIKE_SERVER_PASSWORD=secret cyberstrike serve [options]
```

| 옵션 | 설명 |
|------|------|
| `--port <number>` | 서버 포트 (기본값: 4096) |
| `--hostname <address>` | 바인드 주소 |
| `--cors <origin>` | 허용된 CORS 오리진 |
| `--mdns` | mDNS를 통해 서버 광고 |

## completion

쉘 자동완성 스크립트를 생성합니다.

```bash
# Bash
cyberstrike completion >> ~/.bashrc

# Zsh
cyberstrike completion >> ~/.zshrc

# Fish
cyberstrike completion | source
```

## 환경 변수

환경 변수를 통해 Cyberstrike 동작을 구성합니다:

| 변수 | 설명 |
|------|------|
| `CYBERSTRIKE_AUTO_SHARE` | 세션 자동 공유 |
| `CYBERSTRIKE_PERMISSION` | JSON 권한 재정의 |
| `CYBERSTRIKE_CONFIG` | 커스텀 설정 파일 경로 |
| `ANTHROPIC_API_KEY` | Anthropic API 키 |
| `OPENAI_API_KEY` | OpenAI API 키 |
| `GOOGLE_GENERATIVE_AI_API_KEY` | Google AI (Gemini) API 키 |
| `OPENROUTER_API_KEY` | OpenRouter API 키 |

## 종료 코드

| 코드 | 의미 |
|------|------|
| `0` | 성공 |
| `1` | 오류 — 잘못된/알 수 없는 인수 또는 치명적 오류 |
| `130` | 중단됨 (Ctrl+C) |

## 설정 파일

Cyberstrike는 다음 위치에서 설정을 읽습니다:

| 경로 | 범위 |
|------|------|
| `./cyberstrike.json` | 프로젝트 |
| `./.cyberstrike/cyberstrike.json` | 프로젝트 |
| `~/.config/cyberstrike/cyberstrike.json` | 전역 |

스키마 세부 정보는 [구성 레퍼런스](/docs/configuration)를 참조하세요.

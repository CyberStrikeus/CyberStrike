`cyberstrike mcp` 명령어는 Model Context Protocol 서버를 관리합니다. `list`, `add`, `auth`, `logout`, `debug` 다섯 개의 하위 명령어가 있습니다.

  서버 설정은 `cyberstrike.json`에 있습니다 ([로컬](/docs/features/mcp#local-servers) / [원격](/docs/features/mcp#remote-servers) 서버 참조). 서버는 `/mcps` TUI 대화상자에서 대화형으로 관리됩니다. `mcp status`, `health`, `start`/`stop`/`restart`, `remove`, `config`, `tools`, `logs`, `export`/`import`, `install`, `update` 명령어는 없습니다.
</Aside>

## `mcp list`

```bash
cyberstrike mcp list   # alias: ls
```

구성된 MCP 서버를 나열합니다.

## `mcp add`

```bash
cyberstrike mcp add
```

완전히 대화형입니다 — 로컬 vs 원격, 명령어 또는 URL, 이름을 요청한 후 저장하기 전에 연결을 테스트합니다. 위치 이름이나 플래그를 받지 **않습니다**; 서버 설정을 스크립트로 작성하려면 `cyberstrike.json`에 직접 항목을 작성하세요.

## `mcp auth`

```bash
cyberstrike mcp auth [name]        # OAuth 서버 인증
cyberstrike mcp auth list          # OAuth 인증된 서버 나열
```

OAuth를 사용하는 원격 서버를 인증합니다 (필요시 브라우저를 엽니다). [OAuth](/docs/features/mcp#oauth)를 참조하세요.

## `mcp logout`

```bash
cyberstrike mcp logout [name]
```

서버의 저장된 OAuth 자격 증명을 제거합니다.

## `mcp debug`

```bash
cyberstrike mcp debug <name>
```

서버의 연결을 검사합니다 — 서버 로드 실패 또는 도구가 나타나지 않을 때 유용합니다.

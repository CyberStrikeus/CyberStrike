## 내장 추가 제공자

다음은 **이미 번들**되어 있습니다 — 제공자 구성이 필요하지 않습니다. API 키 환경 변수를 설정하고 `provider-id/model`로 모델을 선택하면 됩니다:

| 제공자 ID | 환경 변수 | 예시 모델 |
|-----------|-----------|-----------|
| `groq` | `GROQ_API_KEY` | `groq/llama-3.3-70b-versatile` |
| `togetherai` | `TOGETHER_API_KEY` | `togetherai/meta-llama/Llama-3.3-70B-Instruct-Turbo` |
| `deepinfra` | `DEEPINFRA_API_KEY` | `deepinfra/meta-llama/Llama-3.3-70B-Instruct` |
| `perplexity` | `PERPLEXITY_API_KEY` | `perplexity/sonar` |
| `openrouter` | `OPENROUTER_API_KEY` | `openrouter/anthropic/claude-sonnet-4` |

```bash
export GROQ_API_KEY="gsk_..."
cyberstrike --model groq/llama-3.3-70b-versatile
```

기타(`mistral`, `xai`, `deepseek`, `cohere`, `cerebras` 등)도 동일한 방식으로 작동합니다 — 키를 설정하고 `provider-id/model`을 사용합니다. [AI 제공자](/docs/providers)를 참조하세요.

## 커스텀 OpenAI 호환 제공자

번들되지 않은 엔드포인트(Fireworks, vLLM, LM Studio, 프라이빗 게이트웨이)의 경우, `provider` 아래에 정의합니다. 최상위 **`api`** 필드(기본 URL)로 로딩이 트리거됩니다; `npm`은 `@ai-sdk/openai-compatible`로 기본 설정되며, 원하는 모델을 나열합니다:

```json title="~/.config/cyberstrike/cyberstrike.json"
{
  "provider": {
    "my-endpoint": {
      "name": "My Endpoint",
      "api": "https://api.example.com/v1",
      "options": { "apiKey": "{env:MY_API_KEY}" },
      "models": {
        "my-model": { "name": "My Model" }
      }
    }
  },
  "model": "my-endpoint/my-model"
}
```

### vLLM

```json
{
  "provider": {
    "vllm": {
      "name": "vLLM",
      "api": "http://localhost:8000/v1",
      "models": { "llama-3.3-70b": { "name": "Llama 3.3 70B" } }
    }
  }
}
```

### LM Studio

```json
{
  "provider": {
    "lmstudio": {
      "name": "LM Studio",
      "api": "http://localhost:1234/v1",
      "models": { "local-model": { "name": "Local Model" } }
    }
  }
}
```

<Aside variant="caution">
  구성 전용 제공자는 `api` URL이 있기 때문에 로드됩니다 — `options.baseURL`만으로는 등록되지 않습니다. 최상위 `api` 필드를 사용하세요.
</Aside>

## Azure OpenAI

```json title="~/.config/cyberstrike/cyberstrike.json"
{
  "provider": {
    "azure": {
      "name": "Azure OpenAI",
      "options": {
        "apiKey": "{env:AZURE_API_KEY}"
      }
    }
  }
}
```

```bash
export AZURE_RESOURCE_NAME="your-resource"
export AZURE_API_KEY="..."
```

## 문제 해결

- **401 Unauthorized** — API 키 환경 변수를 확인하고 `{env:VAR}`로 참조되는지 확인합니다.
- **모델을 찾을 수 없음** — 모델 ID가 제공자의 형식과 일치하고 커스텀 제공자의 `models` 아래에 나열되어 있어야 합니다.
- **예기치 않은 응답** — 엔드포인트가 완전히 OpenAI 호환이 아닐 수 있습니다; 도구 호출과 스트리밍은 제공자마다 다릅니다.

Anthropic의 Claude 모델은 보안 분석을 위한 고급 추론 기능을 제공합니다. 이 가이드에서는 구성과 모범 사례를 다룹니다.

<img src="/docs/images/screenshots/anthropic-model-select.png" alt="Anthropic Claude 모델로 필터링된 모델 피커" className="rounded-lg shadow-lg my-6 w-full" />

## 사용 가능한 모델

Cyberstrike는 [models.dev](https://models.dev)에서 실시간으로 모델 카탈로그를 가져오므로, 정확한 목록은 Anthropic이 현재 제공하는 것을 추적합니다. 일반적인 선택:

| 모델 | 컨텍스트 | 최적 용도 |
|------|----------|-----------|
| `anthropic/claude-opus-4-5` | 200K | 가장 깊은 추론 — 복잡한 분석, 익스플로잇 연구 |
| `anthropic/claude-sonnet-4-5` | 200K | 균형 잡힌 기본값 — 일반 보안 테스트 |
| `anthropic/claude-haiku-4-5` | 200K | 빠르고 저렴 — 빠른 스캔, 대량 |

<Aside variant="tip">
  최신 플래그십(Opus 4.6/4.7/4.8, Sonnet 4.6/5, Fable 5)과 기타 모든 Claude 모델은 models.dev가 업데이트되면 자동으로 나타납니다. 전체 현재 목록은 `/models`를 실행하세요. `-latest` 별칭(예: `claude-opus-4-5`)은 패밀리의 최신 릴리스를 추적하고, 날짜 ID(예: `claude-opus-4-5-20251101`)는 특정 버전을 고정합니다.
</Aside>

## 인증

### API 키 설정

1. [console.anthropic.com](https://console.anthropic.com)에서 API 키를 발급받습니다
2. TUI에서 `/connect`를 실행하고, **Anthropic**을 선택하고, API 키를 입력합니다

### 환경 변수

```bash
export ANTHROPIC_API_KEY="sk-ant-..."
```

영구 적용을 위해 쉘 프로필에 추가합니다:

```bash
echo 'export ANTHROPIC_API_KEY="sk-ant-..."' >> ~/.zshrc
```

### 구성 파일

```json title="~/.config/cyberstrike/cyberstrike.json"
{
  "provider": {
    "anthropic": {
      "options": {
        "apiKey": "{env:ANTHROPIC_API_KEY}"
      }
    }
  }
}
```

## 모델 구성

### 기본 모델 설정

```json title="~/.config/cyberstrike/cyberstrike.json"
{
  "model": "anthropic/claude-sonnet-4-5"
}
```

### 모델 변경

TUI에서 `/models`를 사용하여 모델 피커를 열고 다른 Claude 모델을 선택합니다.

## 확장 사고

복잡한 보안 분석을 위해 확장 사고를 활성화합니다:

```json title="~/.config/cyberstrike/cyberstrike.json"
{
  "provider": {
    "anthropic": {
      "options": {
        "thinking": {
          "type": "enabled",
          "budgetTokens": 10000
        }
      }
    }
  }
}
```

### 확장 사고를 사용할 때

- 복잡한 취약점 체인
- 다단계 공격 계획
- 심층 분석이 필요한 코드 리뷰
- 아키텍처 보안 리뷰

## 토큰 사용량

세션 TUI 헤더에서 CyberStrike는 0이 아닌 출력 토큰이 있는 가장 최근 어시스턴트 메시지의 **컨텍스트 사용량**을 표시합니다: 토큰 합계(입력, 출력, 추론, 캐시 읽기/쓰기)와 모델이 컨텍스트 제한을 정의한 경우 **해당 제한의 백분율**. 또한 어시스턴트 메시지의 `cost` 합계로 **예상 세션 비용**을 USD로 표시합니다.

### 프롬프트 캐싱

직접 Anthropic 모델(`providerID` / SDK `npm` `@ai-sdk/anthropic`)의 경우, CyberStrike는 요청을 빌드할 때 선택된 시스템 및 최근 메시지에 Anthropic **임시** 캐시 제어를 추가합니다. 이 동작을 위한 별도의 `cacheControl` 플래그는 `provider.anthropic.options`에 없습니다.

## 속도 제한

속도 제한은 Anthropic 계정과 상품에 따라 다릅니다. 현재 할당량은 [Anthropic 문서](https://docs.anthropic.com)를 참조하세요.

**재시도 가능한** API 오류의 경우, CyberStrike는 **지수 백오프**(2초 시작, 시도당 2배, `Retry-After` 헤더가 없을 때 30초 상한)를 사용하며, 제공자가 `Retry-After` / `Retry-After-Ms`를 반환하면 이를 준수합니다.

## 모범 사례

### 모델 선택

| 작업 | 권장 모델 |
|------|-----------|
| 빠른 정찰 | `claude-haiku-4-5` |
| 웹 앱 테스트 | `claude-sonnet-4-5` |
| 복잡한 익스플로잇 | `claude-opus-4-5` |
| 코드 리뷰 | `claude-sonnet-4-5` |

### 비용 최적화

1. 반복 작업에 Haiku 사용
2. 긴 세션에 `/compact` (또는 `/summarize`) 사용
3. 집중된 프롬프트로 컨텍스트 제한

### 보안

1. API 키를 절대 리포지토리에 커밋하지 마세요
2. 환경 변수를 사용하세요
3. 정기적으로 키를 교체하세요
4. Anthropic 대시보드에서 사용량을 모니터링하세요

## 문제 해결

### 잘못된 API 키

```
Error: Invalid API key
```

키를 확인합니다:
- 앱에서 Anthropic을 연결할 때 설명된 형식과 일치하는지 (API 키는 일반적으로 `sk-ant-api…`로 시작)
- 후행 공백이 없는지
- [console.anthropic.com/settings/keys](https://console.anthropic.com/settings/keys)에서 키가 활성 상태인지

### 속도 제한 초과

```
Error: Rate limit exceeded
```

해결 방법:
- 기다렸다가 재시도
- 티어 업그레이드
- 더 작은 컨텍스트 사용

### 모델 사용 불가

```
Error: Model not found
```

모델 ID가 정확하고 해당 리전에서 사용 가능한지 확인합니다.

<Aside variant="tip">
  대부분의 보안 테스트 작업에 Claude Sonnet을 사용하세요. 더 깊은 추론이 필요한 복잡한 분석에만 Opus를 사용하세요.
</Aside>

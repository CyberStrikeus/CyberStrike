Cyberstrike는 GitHub Copilot을 AI 제공자로 지원합니다. GitHub 계정으로 OAuth를 통해 인증하고 Copilot 구독을 통해 사용 가능한 모든 모델(Claude, GPT-4o, o-시리즈 모델 포함)에 접근합니다.

## 요구 사항

- 활성 **GitHub Copilot** 구독이 있는 GitHub 계정 (Individual, Business, 또는 Enterprise)
- GitHub Enterprise의 경우: GHE 서버 URL

## 인증

GitHub Copilot은 **OAuth 디바이스 플로**를 사용합니다 — API 키가 필요하지 않습니다.

### 로그인

TUI에서 실행합니다:

```
/connect
```

제공자 목록에서 **Login with GitHub Copilot**을 선택하고 배포를 선택합니다:

| 배포 | 사용 시기 |
|------|-----------|
| **GitHub.com** | github.com의 개인 또는 조직 계정 |
| **GitHub Enterprise** | 자체 호스팅 GHE 또는 데이터 레지던시 인스턴스 |

Cyberstrike가 GitHub 인증을 위한 브라우저 창을 엽니다. 터미널에 표시된 디바이스 코드를 입력하고 앱을 인증하면 OAuth 토큰이 자동으로 저장됩니다.

## 사용 가능한 모델

사용 가능한 모델은 Copilot 구독 티어에 따라 다릅니다. 일반적인 모델:

| 모델 | 제공자 |
|------|--------|
| `claude-sonnet-4-20250514` | Anthropic (Copilot 경유) |
| `claude-sonnet-5-5` | Anthropic (Copilot 경유) |
| `gpt-4o` | OpenAI (Copilot 경유) |
| `o3-mini` | OpenAI (Copilot 경유) |

구독에서 사용 가능한 모든 모델을 보고 변경하려면 `/models`를 실행합니다.

<Aside variant="info">
  Claude 모델은 OpenAI 호환 엔드포인트(`/chat/completions`) 대신 Anthropic Messages API(`/v1/messages`)를 통해 자동으로 라우팅됩니다. 투명하게 처리됩니다 — 구성이 필요하지 않습니다.
</Aside>

## 구성

GitHub Copilot은 OAuth 로그인 외에 수동 구성이 필요하지 않습니다. 인증 후 제공자가 자동으로 등록됩니다.

Copilot 모델을 기본값으로 사용하려면:

```json title="cyberstrike.json"
{
  "model": "github-copilot/claude-sonnet-4-20250514"
}
```

### GitHub Enterprise

GHE 인스턴스의 경우, 로그인 중 서버 URL을 입력하라는 메시지가 표시됩니다:

```
? Enter your GitHub Enterprise URL or domain
> company.ghe.com
```

Copilot API 엔드포인트는 GHE 도메인에서 자동으로 도출됩니다.

## 작동 방식

1. **OAuth 디바이스 플로** — Cyberstrike가 GitHub에서 디바이스 코드를 요청하고, 브라우저에서 인증합니다
2. **토큰 교환** — OAuth 토큰(`ghu_...`)이 단기 Copilot 세션 토큰(~30분 TTL)으로 교환됩니다
3. **자동 갱신** — 세션 토큰은 만료 전에 자동으로 갱신됩니다
4. **모델 라우팅** — Claude 모델은 Anthropic Messages API를 사용하고, 나머지는 OpenAI 호환 엔드포인트를 사용합니다

## 문제 해결

| 문제 | 해결 방법 |
|------|-----------|
| **401 Unauthorized** | `/connect`를 다시 실행 — 세션 토큰이 만료되었을 수 있음 |
| **사용 가능한 모델 없음** | github.com/settings/copilot에서 Copilot 구독이 활성 상태인지 확인 |
| **GHE 연결 거부** | 엔터프라이즈 URL을 확인하고 GHE 인스턴스에서 Copilot이 활성화되어 있는지 확인 |
| **Claude 모델 404** | Cyberstrike 업데이트 — Claude 라우팅 수정이 v1.1.16+에서 출시됨 |

<Aside variant="tip">
  GitHub Copilot은 이미 구독이 있는 경우 훌륭한 옵션입니다 — 별도의 API 키가 필요하지 않으며, 단일 로그인으로 여러 제공자의 모델에 접근할 수 있습니다.
</Aside>

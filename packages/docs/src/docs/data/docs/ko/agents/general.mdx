`general` 에이전트는 조사, 복잡한 질문, 다단계 작업을 처리합니다. `cyberstrike` 기본 에이전트가 병렬 실행의 이점이 있거나 보안 전문가가 필요하지 않은 작업에 위임합니다.

## 개요

| 속성 | 값 |
|------|-----|
| **에이전트 ID** | `general` |
| **모드** | `subagent` |
| **도구 접근** | 광범위 (취약점 보고 또는 분류 제외) |

## 사용 시기

`cyberstrike` 에이전트가 다음의 경우 `general`에 위임합니다:

- 여러 소스에 걸쳐 복잡한 질문 조사
- 여러 독립적인 작업 단위를 병렬로 실행
- 도메인별 보안 지식이 필요하지 않은 작업
- 파일 분석, 코드 리뷰, 일반적인 추론

## 제한 사항

`general` 에이전트는 다음을 수행할 수 없습니다:

- 취약점 보고 (`report_vulnerability`: 거부됨)
- 발견 사항 분류 (`triage_vulnerability`: 거부됨)
- TODO 읽기/쓰기 작업 접근

이러한 제한은 보안 관련 민감한 작업이 적절한 전문 에이전트에 유지되도록 보장합니다.

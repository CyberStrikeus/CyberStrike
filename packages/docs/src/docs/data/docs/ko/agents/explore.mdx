`explore` 에이전트는 코드베이스와 파일 시스템 검색에 특화된 빠른 읽기 전용 에이전트입니다. 패턴으로 파일을 찾고, 키워드로 코드를 검색하고, 코드베이스 구조에 대한 질문에 답할 수 있습니다.

## 개요

| 속성 | 값 |
|------|-----|
| **에이전트 ID** | `explore` |
| **모드** | `subagent` |
| **도구 접근** | 읽기 전용 (grep, glob, list, bash, read, 웹 검색) |

## 사용 시기

`cyberstrike` 에이전트가 다음이 필요할 때 `explore`에 위임합니다:

- 패턴에 맞는 파일 찾기 (예: `src/components/**/*.tsx`)
- 키워드 또는 심볼로 코드 검색 (예: "API 엔드포인트")
- 코드베이스 구조에 대한 질문 답변
- 수정이 필요하지 않은 빠른 조회

## 정밀도 수준

`explore`에 위임할 때, 호출하는 에이전트가 정밀도 수준을 지정합니다:

| 수준 | 동작 |
|------|------|
| **quick** | 기본 대상 검색 — 단일 위치, 첫 번째 일치 |
| **medium** | 중간 수준 탐색 — 여러 위치 |
| **very thorough** | 네이밍 규칙과 위치에 걸친 포괄적 분석 |

## 제한 사항

`explore` 에이전트는 엄격하게 읽기 전용입니다. 다음을 수행할 수 없습니다:

- 파일 쓰기, 편집, 생성
- 파괴적 명령 실행
- 취약점 보고
- 상태 수정

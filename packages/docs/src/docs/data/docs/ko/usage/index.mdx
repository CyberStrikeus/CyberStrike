CyberStrike는 하네스와 상호작용하는 여러 방법을 제공합니다:

- **[TUI](/docs/usage/tui)** — 실시간 에이전트 출력, 슬래시 명령, 키보드 단축키가 있는 대화형 터미널 인터페이스
- **[CLI](/docs/usage/cli)** — 스크립팅, 파이프라인, 자동화를 위한 비대화형 모드
- **[Web](/docs/usage/web)** — 세션 탭, 사이드 패널, 통합 터미널이 있는 브라우저 기반 인터페이스
- **[데스크톱 앱](/docs/usage/desktop-app)** — macOS, Windows, Linux용 네이티브 애플리케이션 *(출시 예정)*

각 인터페이스는 동일한 기반 엔진에 연결되고 세션을 공유하므로 자유롭게 전환할 수 있습니다.

## 빠른 시작

```bash
# 대화형 TUI (기본)
cyberstrike

# 비대화형 CLI
cyberstrike run "scan example.com for open ports"

# 웹 인터페이스
cyberstrike web
```

## 인터페이스 선택

| 인터페이스 | 적합한 용도 |
|-----------|-----------|
| TUI | 일일 대화형 평가, 슬래시 명령, 키보드 중심 워크플로 |
| CLI | CI/CD 파이프라인, 스크립팅, 도구 출력 파이핑 |
| Web | 팀 협업, 시각적 사이드 패널, 브라우저 기반 워크플로 |
| 데스크톱 | 터미널 없이 네이티브 경험 *(출시 예정)* |

모든 인터페이스에서 보안 에이전트, MCP 도구, AI 제공자의 전체 범위를 지원합니다.

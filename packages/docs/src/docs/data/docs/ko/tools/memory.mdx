## 메모리 도구

네 가지 메모리 도구가 있습니다 — 삭제, 초기화, 내보내기, 가져오기 작업은 없습니다:

| 도구 | 용도 |
|------|------|
| `memory_write` | 메모리에 노트 추가 |
| `memory_read` | 저장된 메모리 읽기 |
| `memory_search` | 저장된 노트 전체 검색 |
| `memory_context` | 관련 메모리를 현재 컨텍스트로 가져오기 |

## 저장소 레이아웃

메모리는 `.cyberstrike/` 아래의 일반 Markdown입니다:

```
.cyberstrike/
├── MEMORY.md              ← 장기 메모리
└── memory/
    └── 2026-07-03.md      ← 날짜별 일일 노트
```

- **`MEMORY.md`**는 영속적인 장기 사실을 저장합니다.
- **`memory/<YYYY-MM-DD>.md`** 파일은 일별 노트입니다; 각각 `# Daily Notes - <date>` 제목으로 시작하며 세션 실행 중 추가됩니다.

전역 메모리 (프로젝트 간 공유)는 `~/.config/cyberstrike/memory/` 아래에 있습니다.

모든 것이 디스크의 Markdown이므로, 다른 프로젝트 파일처럼 읽고, 편집하고, 버전 관리할 수 있습니다.

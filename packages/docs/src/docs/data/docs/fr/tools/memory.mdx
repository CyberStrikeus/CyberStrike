Les outils de memoire permettent a l'agent de conserver des notes — decouvertes, details de la cible, contexte — qui persistent entre les sessions sous forme de fichiers Markdown dans votre projet.

## Les outils de memoire

Il y a quatre outils de memoire — il n'y a pas d'operation de suppression, de vidage, d'exportation ou d'importation :

| Outil | Objectif |
|-------|----------|
| `memory_write` | Ajouter une note a la memoire |
| `memory_read` | Lire la memoire stockee |
| `memory_search` | Rechercher dans les notes stockees |
| `memory_context` | Charger la memoire pertinente dans le contexte courant |

## Organisation du stockage

La memoire est du Markdown simple sous `.cyberstrike/` :

```
.cyberstrike/
├── MEMORY.md              ← memoire a long terme
└── memory/
    └── 2026-07-03.md      ← notes quotidiennes datees
```

- **`MEMORY.md`** contient les faits durables a long terme.
- Les fichiers **`memory/<YYYY-MM-DD>.md`** sont des notes par jour ; chacun commence par un titre `# Daily Notes - <date>` et est complete au fur et a mesure de la session.

La memoire globale (partagee entre les projets) se trouve sous `~/.config/cyberstrike/memory/`.

Comme tout est du Markdown sur disque, vous pouvez le lire, le modifier ou le versionner comme n'importe quel autre fichier du projet.

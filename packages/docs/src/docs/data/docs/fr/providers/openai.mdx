OpenAI fournit la famille GPT-5, GPT-4.1 et les modèles de raisonnement de la série o pour l'analyse de sécurité. Ce guide couvre l'installation et la configuration.

<img src="/docs/images/screenshots/openai-model-select.png" alt="Sélecteur de modèle filtré sur les modèles OpenAI" className="rounded-lg shadow-lg my-6 w-full" />

## Modèles disponibles

Cyberstrike récupère son catalogue de modèles en direct depuis [models.dev](https://models.dev), la liste exacte suit donc ce qu'OpenAI propose actuellement. Choix courants :

| Modèle | Contexte | Idéal pour |
|-------|---------|----------|
| `openai/gpt-5` | 400K | Tests de sécurité généraux (modèle phare) |
| `openai/gpt-5-mini` | 400K | Tâches rapides, volume élevé |
| `openai/gpt-5-nano` | 400K | Le moins cher, tâches simples |
| `openai/gpt-4.1` | 1M | Très grand contexte |
| `openai/o3` | 200K | Raisonnement approfondi étape par étape |

<Aside variant="tip">
  Les nouvelles versions GPT-5.x (5.1-5.5, plus les variantes Codex et Pro) apparaissent automatiquement lors des mises à jour de models.dev. Exécutez `/models` pour la liste complète actuelle.
</Aside>

## Authentification

### Configuration de la clé API

1. Obtenez votre clé API depuis [platform.openai.com](https://platform.openai.com)
2. Dans le TUI, exécutez `/connect`, sélectionnez **OpenAI**, et entrez votre clé API

### Variable d'environnement

```bash
export OPENAI_API_KEY="sk-proj-..."
```

### Fichier de configuration

```json title="~/.config/cyberstrike/cyberstrike.json"
{
  "provider": {
    "openai": {
      "options": {
        "apiKey": "{env:OPENAI_API_KEY}"
      }
    }
  }
}
```

## Configuration du modèle

### Définir le modèle par défaut

```json title="~/.config/cyberstrike/cyberstrike.json"
{
  "model": "openai/gpt-5"
}
```

### Changer de modèle

Utilisez `/models` dans le TUI pour choisir un autre modèle OpenAI.

### Utiliser les modèles de raisonnement

La série o (`o3`, `o4-mini`) et les variantes GPT-5 Pro excellent dans l'analyse de sécurité complexe. Sélectionnez-les via `/models`.

Idéal pour :
- Chaînes de vulnérabilités complexes
- Analyse de chemins d'attaque
- Analyse cryptographique
- Rétro-ingénierie

## ChatGPT Plus/Pro

Utilisez votre abonnement ChatGPT en exécutant `/connect` dans le TUI, en sélectionnant **OpenAI**, et en choisissant **ChatGPT Plus/Pro**. Cela déclenche un flux OAuth basé sur le navigateur.

<Aside variant="info">
  L'authentification ChatGPT nécessite un flux OAuth basé sur le navigateur.
</Aside>

## ID d'organisation

Pour les comptes d'organisation :

```json title="~/.config/cyberstrike/cyberstrike.json"
{
  "provider": {
    "openai": {
      "options": {
        "apiKey": "{env:OPENAI_API_KEY}",
        "organization": "org-..."
      }
    }
  }
}
```

## URL de base personnalisée

Pour les points de terminaison compatibles OpenAI :

```json
{
  "provider": {
    "openai": {
      "options": {
        "baseURL": "https://your-endpoint.com/v1"
      }
    }
  }
}
```

## Appel de fonctions

Les modèles GPT prennent en charge l'appel de fonctions pour l'utilisation d'outils :

```json
{
  "provider": {
    "openai": {
      "options": {
        "parallelToolCalls": true
      }
    }
  }
}
```

## Limites de débit

Limites de débit OpenAI par niveau :

| Niveau | RPM | TPM |
|------|-----|-----|
| Gratuit | 3 | 40 000 |
| Niveau 1 | 500 | 200 000 |
| Niveau 2 | 5 000 | 2 000 000 |
| Niveau 3+ | Limites plus élevées |

### Gestion des limites

```json
{
  "provider": {
    "openai": {
      "options": {
        "maxRetries": 3,
        "timeout": 60000
      }
    }
  }
}
```

## Bonnes pratiques

### Sélection du modèle

| Tâche | Modèle recommandé |
|------|-------------------|
| Scans rapides | `gpt-5-nano` |
| Tests généraux | `gpt-5` |
| Analyse complexe | `o3` |
| Sensible au coût | `gpt-5-mini` |

### Optimisation des coûts

1. Utilisez les modèles mini pour les tâches simples
2. Définissez un maximum de tokens raisonnable
3. Utilisez `/compact` pour les sessions longues
4. Surveillez l'utilisation sur le tableau de bord OpenAI

### Sécurité

1. Stockez les clés dans les variables d'environnement
2. Utilisez des clés API spécifiques au projet
3. Activez les limites d'utilisation dans le tableau de bord OpenAI
4. Faites une rotation des clés périodiquement

## Dépannage

### Clé API invalide

```
Error: Incorrect API key provided
```

Vérifiez :
- La clé commence par `sk-proj-` ou `sk-`
- Pas d'espace superflu
- La clé est active

### Quota insuffisant

```
Error: You exceeded your current quota
```

Solutions :
- Ajoutez des informations de facturation
- Vérifiez les limites d'utilisation
- Passez à un plan supérieur

### Accès au modèle

```
Error: The model does not exist or you do not have access
```

Certains modèles nécessitent :
- Un niveau d'utilisation supérieur pour les derniers modèles phares
- Une approbation de liste d'attente
- Un accord entreprise

<Aside variant="caution">
  Les modèles de raisonnement (la série o et les variantes GPT-5 Pro) ont une latence plus élevée en raison des étapes de raisonnement. Prévoyez des temps de réponse plus longs.
</Aside>

Les modèles Claude d'Anthropic offrent des capacités de raisonnement avancées pour l'analyse de sécurité. Ce guide couvre la configuration et les bonnes pratiques.

<img src="/docs/images/screenshots/anthropic-model-select.png" alt="Sélecteur de modèle filtré sur les modèles Anthropic Claude" className="rounded-lg shadow-lg my-6 w-full" />

## Modèles disponibles

Cyberstrike récupère son catalogue de modèles en direct depuis [models.dev](https://models.dev), la liste exacte suit donc ce qu'Anthropic propose actuellement. Choix courants :

| Modèle | Contexte | Idéal pour |
|-------|---------|----------|
| `anthropic/claude-opus-4-5` | 200K | Raisonnement le plus profond — analyse complexe, recherche d'exploits |
| `anthropic/claude-sonnet-4-5` | 200K | Par défaut équilibré — tests de sécurité généraux |
| `anthropic/claude-haiku-4-5` | 200K | Rapide, peu coûteux — scans rapides, volume élevé |

<Aside variant="tip">
  Les nouveaux modèles phares (Opus 4.6/4.7/4.8, Sonnet 4.6/5, Fable 5) et tous les autres modèles Claude apparaissent automatiquement lors des mises à jour de models.dev. Exécutez `/models` pour la liste complète actuelle. Les alias `-latest` (ex. `claude-opus-4-5`) suivent la dernière version d'une famille ; les ID datés (ex. `claude-opus-4-5-20251101`) fixent une version spécifique.
</Aside>

## Authentification

### Configuration de la clé API

1. Obtenez votre clé API depuis [console.anthropic.com](https://console.anthropic.com)
2. Dans le TUI, exécutez `/connect`, sélectionnez **Anthropic**, et entrez votre clé API

### Variable d'environnement

```bash
export ANTHROPIC_API_KEY="sk-ant-..."
```

Ajoutez-la à votre profil shell pour la persistance :

```bash
echo 'export ANTHROPIC_API_KEY="sk-ant-..."' >> ~/.zshrc
```

### Fichier de configuration

```json title="~/.config/cyberstrike/cyberstrike.json"
{
  "provider": {
    "anthropic": {
      "options": {
        "apiKey": "{env:ANTHROPIC_API_KEY}"
      }
    }
  }
}
```

## Configuration du modèle

### Définir le modèle par défaut

```json title="~/.config/cyberstrike/cyberstrike.json"
{
  "model": "anthropic/claude-sonnet-4-5"
}
```

### Changer de modèle

Utilisez `/models` dans le TUI pour ouvrir le sélecteur de modèle et choisir un autre modèle Claude.

## Réflexion étendue

Activez la réflexion étendue pour l'analyse de sécurité complexe :

```json title="~/.config/cyberstrike/cyberstrike.json"
{
  "provider": {
    "anthropic": {
      "options": {
        "thinking": {
          "type": "enabled",
          "budgetTokens": 10000
        }
      }
    }
  }
}
```

### Quand utiliser la réflexion étendue

- Chaînes de vulnérabilités complexes
- Planification d'attaques multi-étapes
- Revue de code avec analyse approfondie
- Revue de sécurité architecturale

## Utilisation des tokens

Dans l'en-tête du TUI de session, CyberStrike affiche l'**utilisation du contexte** pour le message assistant le plus récent avec des tokens de sortie non nuls : un total de tokens (entrée, sortie, raisonnement, et lecture/écriture du cache) et, lorsque le modèle définit une limite de contexte, un **pourcentage de cette limite**. Il affiche également le **coût estimé de la session** en USD comme la somme du `cost` des messages assistant.

### Mise en cache des prompts

Pour les modèles Anthropic directs (`providerID` / SDK `npm` `@ai-sdk/anthropic`), CyberStrike ajoute le contrôle de cache **éphémère** d'Anthropic aux messages système et récents sélectionnés lors de la construction de la requête. Il n'y a pas de flag `cacheControl` séparé dans `provider.anthropic.options` pour ce comportement.

## Limites de débit

Les limites de débit dépendent de votre compte et produit Anthropic ; consultez la [documentation d'Anthropic](https://docs.anthropic.com) pour les quotas actuels.

Pour les erreurs API **réessayables**, CyberStrike utilise un **backoff exponentiel** (commençant à 2s, doublant à chaque tentative, plafonné à 30s en l'absence d'en-têtes `Retry-After`) et respecte `Retry-After` / `Retry-After-Ms` lorsque le fournisseur les renvoie.

## Bonnes pratiques

### Sélection du modèle

| Tâche | Modèle recommandé |
|------|-------------------|
| Reconnaissance rapide | `claude-haiku-4-5` |
| Tests d'applications web | `claude-sonnet-4-5` |
| Exploits complexes | `claude-opus-4-5` |
| Revue de code | `claude-sonnet-4-5` |

### Optimisation des coûts

1. Utilisez Haiku pour les tâches répétitives
2. Utilisez `/compact` (ou `/summarize`) pour les sessions longues
3. Limitez le contexte avec des prompts ciblés

### Sécurité

1. Ne commitez jamais les clés API dans les dépôts
2. Utilisez les variables d'environnement
3. Faites une rotation des clés périodiquement
4. Surveillez l'utilisation sur le tableau de bord Anthropic

## Dépannage

### Clé API invalide

```
Error: Invalid API key
```

Vérifiez votre clé :
- Correspond au format décrit lors de la connexion Anthropic dans l'application (les clés API commencent généralement par `sk-ant-api...`)
- Pas d'espace en fin de chaîne
- La clé est active dans [console.anthropic.com/settings/keys](https://console.anthropic.com/settings/keys)

### Limite de débit dépassée

```
Error: Rate limit exceeded
```

Solutions :
- Attendez et réessayez
- Passez à un niveau supérieur
- Utilisez un contexte plus petit

### Modèle non disponible

```
Error: Model not found
```

Vérifiez que l'ID du modèle est correct et disponible dans votre région.

<Aside variant="tip">
  Utilisez Claude Sonnet pour la plupart des tâches de tests de sécurité. Réservez Opus pour les analyses complexes nécessitant un raisonnement plus profond.
</Aside>

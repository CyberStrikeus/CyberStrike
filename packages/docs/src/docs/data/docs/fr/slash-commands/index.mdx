Tapez `/` au début de l'entrée pour ouvrir la liste des commandes (ou appuyez sur `Ctrl+P`). La correspondance floue filtre à mesure que vous tapez.

## Session

| Commande | Alias | Raccourci | Action |
|----------|-------|-----------|--------|
| `/new` | `/clear` | `<leader>n` | Démarrer une nouvelle session |
| `/sessions` | `/resume`, `/continue` | `<leader>l` | Ouvrir le sélecteur de sessions |
| `/rename` | | `ctrl+r` | Renommer la session |
| `/compact` | `/summarize` | `<leader>c` | Compacter (résumer) la session |
| `/fork` | | | Dupliquer la session |
| `/timeline` | | `<leader>g` | Afficher la chronologie de la session |
| `/export` | | `<leader>x` | Exporter la session |
| `/copy` | | | Copier le dernier message |
| `/share`, `/unshare` | | | Partager / arrêter le partage |
| `/undo`, `/redo` | | `<leader>u` / `<leader>r` | Annuler / rétablir le dernier message |
| `/timestamps`, `/thinking` | | | Basculer les horodatages / blocs de réflexion |

## Tests web et méthodologie

| Commande | Alias | Action |
|----------|-------|--------|
| `/hackbrowser` | | Lancer le crawl Hacker Browser |
| `/hackbrowser-stop` | | Arrêter un crawl en cours |
| `/vulnerabilities` | `/vuln`, `/vulns` | Examiner les vulnérabilités capturées |
| `/web` | `/endpoints`, `/roles`, `/credentials` | Inspecter le contexte de test web |
| `/methodology` | `/intel`, `/vrt`, `/chains` | Vues du moteur de méthodologie |
| `/report` | | Générer un rapport |
| `/qpause`, `/qresume` | | Suspendre / reprendre la file d'attente d'ingestion |

<Aside variant="caution">
  Les noms de commandes sont au pluriel (`/models`, `/themes`, `/mcps`). Il n'existe pas de commande `/agent-settings`, `/settings`, `/config`, `/vim`, `/provider`, `/model`, ni de palette de commandes `<leader><leader>`/`Ctrl+Shift+P` — la liste des commandes s'ouvre avec `Ctrl+P`.
</Aside>

## Mentions @

Référencez un fichier (éventuellement une plage de lignes) dans votre invite avec `@` :

```
@src/auth.ts#45-60 check these lines for vulnerabilities
```

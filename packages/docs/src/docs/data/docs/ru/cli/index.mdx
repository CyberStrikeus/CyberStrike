## Структура команд

```
cyberstrike [global-options] <command> [command-options] [arguments]
```

## Глобальные параметры

| Параметр | Псевдоним | Описание |
|----------|-----------|----------|
| `--help` | `-h` | Показать справочную информацию |
| `--version` | `-v` | Показать номер версии |
| `--print-logs` | | Выводить логи в stderr |
| `--log-level` | | Установить уровень логирования (DEBUG, INFO, WARN, ERROR) |

## Интерактивный режим

Запуск терминального пользовательского интерфейса без аргументов:

```bash
cyberstrike
```

### Параметры интерактивного режима

| Параметр | Псевдоним | Описание |
|----------|-----------|----------|
| `--model <model>` | `-m` | Модель в формате `provider/model` |
| `--agent <name>` | | Агент безопасности для использования |
| `--continue` | `-c` | Продолжить последнюю сессию |
| `--session <id>` | `-s` | Возобновить конкретную сессию |

### Примеры

```bash
# Запуск с конкретной моделью
cyberstrike --model anthropic/claude-sonnet-4-20250514

# Выбор первичного агента (только 'cyberstrike' поставляется встроенным)
cyberstrike --agent cyberstrike

# Продолжить предыдущую сессию
cyberstrike --continue
```

## run

Выполнение одного промпта без входа в интерактивный режим.

```bash
cyberstrike run [message..] [options]
```

### Параметры

| Параметр | Псевдоним | Описание |
|----------|-----------|----------|
| `--model <model>` | `-m` | Модель в формате `provider/model` |
| `--agent <name>` | | Агент для использования |
| `--continue` | `-c` | Продолжить последнюю сессию |
| `--session <id>` | `-s` | Возобновить конкретную сессию |
| `--file <path>` | `-f` | Прикрепить файл(ы) к сообщению |
| `--format <type>` | | Формат вывода: `default` или `json` |
| `--share` | | Поделиться сессией |
| `--title <text>` | | Установить заголовок сессии |
| `--attach <url>` | | Подключиться к работающему серверу |
| `--variant <type>` | | Вариант модели (high, max, minimal) |

### Примеры

```bash
# Выполнить одну команду
cyberstrike run "scan example.com for open ports"

# Прикрепить файл к запросу
cyberstrike run "analyze this config" -f nginx.conf

# Вывод в формате JSON
cyberstrike run "list vulnerabilities" --format json

# Продолжить предыдущую сессию
cyberstrike run "now check for XSS" --continue
```

### Передача ввода через pipe

Приём ввода из stdin:

```bash
echo "analyze this code" | cyberstrike run
cat report.txt | cyberstrike run "summarize this"
```

## auth

Управление учётными данными аутентификации для ИИ-провайдеров.

### auth login

Добавление учётных данных ИИ-провайдера:

```bash
cyberstrike auth login [url]
```

#### Интерактивный вход

```bash
cyberstrike auth login
# Выберите провайдера из списка
# Введите API-ключ при запросе
```

#### Вход по Well-Known URL

```bash
cyberstrike auth login https://custom-provider.example.com
```

### auth logout

Удаление сохранённых учётных данных:

```bash
cyberstrike auth logout
# Выберите провайдера из списка
```

### auth list

Отображение всех настроенных учётных данных:

```bash
cyberstrike auth list
```

Показывает:
- Сохранённые учётные данные по провайдерам
- Тип аутентификации (api, oauth)
- Активные переменные окружения

## mcp

Управление серверами Model Context Protocol (MCP).

### mcp list

Список настроенных MCP-серверов и их статус:

```bash
cyberstrike mcp list
```

Индикаторы статуса:
- `✓` Подключён
- `○` Не инициализирован / Отключён
- `⚠` Требуется аутентификация
- `✗` Ошибка

### mcp add

Интерактивное добавление нового MCP-сервера:

```bash
cyberstrike mcp add
```

Мастер запрашивает:
1. Расположение (проект или глобальное)
2. Имя сервера
3. Тип сервера (локальный или удалённый)
4. Данные подключения

#### Пример локального сервера

```bash
# После запуска `cyberstrike mcp add`:
# Location: Current project
# Name: filesystem
# Type: Local
# Command: npx @modelcontextprotocol/server-filesystem /path/to/dir
```

#### Пример удалённого сервера

```bash
# После запуска `cyberstrike mcp add`:
# Location: Global
# Name: custom-api
# Type: Remote
# URL: https://api.example.com/mcp
# OAuth: Yes/No
```

### mcp auth

Аутентификация на MCP-сервере с поддержкой OAuth:

```bash
cyberstrike mcp auth [name]
```

### mcp auth list

Список статуса OAuth для всех MCP-серверов:

```bash
cyberstrike mcp auth list
```

### mcp logout

Удаление OAuth-учётных данных:

```bash
cyberstrike mcp logout [name]
```

### mcp debug

Отладка подключения к серверу:

```bash
cyberstrike mcp debug <name>
```

## session

Управление сессиями разговоров.

### session list

Список всех сессий:

```bash
cyberstrike session list [options]
```

| Параметр | Псевдоним | Описание |
|----------|-----------|----------|
| `--max-count <n>` | `-n` | Ограничить до N последних сессий |
| `--format <type>` | | Вывод: `table` или `json` |

### Примеры

```bash
# Список 10 последних сессий
cyberstrike session list -n 10

# Экспорт в JSON
cyberstrike session list --format json
```

## serve

Запуск API-сервера Cyberstrike. Требуется установить `CYBERSTRIKE_SERVER_PASSWORD`.

```bash
CYBERSTRIKE_SERVER_PASSWORD=secret cyberstrike serve [options]
```

| Параметр | Описание |
|----------|----------|
| `--port <number>` | Порт сервера (по умолчанию: 4096) |
| `--hostname <address>` | Адрес привязки |
| `--cors <origin>` | Разрешённый CORS-источник |
| `--mdns` | Объявление сервера через mDNS |

## completion

Генерация скриптов автодополнения для оболочки.

```bash
# Bash
cyberstrike completion >> ~/.bashrc

# Zsh
cyberstrike completion >> ~/.zshrc

# Fish
cyberstrike completion | source
```

## Переменные окружения

Настройка поведения Cyberstrike через переменные окружения:

| Переменная | Описание |
|------------|----------|
| `CYBERSTRIKE_AUTO_SHARE` | Автоматическое предоставление доступа к сессиям |
| `CYBERSTRIKE_PERMISSION` | JSON-переопределение разрешений |
| `CYBERSTRIKE_CONFIG` | Путь к пользовательскому файлу конфигурации |
| `ANTHROPIC_API_KEY` | API-ключ Anthropic |
| `OPENAI_API_KEY` | API-ключ OpenAI |
| `GOOGLE_GENERATIVE_AI_API_KEY` | API-ключ Google AI (Gemini) |
| `OPENROUTER_API_KEY` | API-ключ OpenRouter |

## Коды выхода

| Код | Значение |
|-----|----------|
| `0` | Успех |
| `1` | Ошибка — недопустимые/неизвестные аргументы или фатальная ошибка |
| `130` | Прервано (Ctrl+C) |

Команды `cyberstrike mcp` управляют серверами Model Context Protocol. Есть пять подкоманд: `list`, `add`, `auth`, `logout` и `debug`.

Не существует команд `mcp status`, `health`, `start`/`stop`/`restart`, `remove`, `config`, `tools`, `logs`, `export`/`import`, `install` или `update`.
</Aside>

## `mcp list`

```bash
cyberstrike mcp list   # псевдоним: ls
```

Показывает настроенные MCP-серверы.

## `mcp add`

```bash
cyberstrike mcp add
```

Полностью интерактивная — запрашивает локальный или удалённый тип, команду или URL, и имя, затем тестирует подключение перед сохранением. Не принимает **никаких** позиционных имён или флагов; для автоматизации настройки сервера запишите запись напрямую в `cyberstrike.json`.

## `mcp auth`

```bash
cyberstrike mcp auth [name]        # авторизация OAuth-сервера
cyberstrike mcp auth list          # список авторизованных OAuth-серверов
```

Авторизует удалённый сервер с OAuth (при необходимости открывает браузер). См. [OAuth](/docs/features/mcp#oauth).

## `mcp logout`

```bash
cyberstrike mcp logout [name]
```

Удаляет сохранённые OAuth-учётные данные сервера.

## `mcp debug`

```bash
cyberstrike mcp debug <name>
```

Проверяет подключение к серверу — полезно, когда сервер не загружается или его инструменты не отображаются.

Команды `cyberstrike auth` управляют учётными данными ИИ-провайдеров. Есть ровно три подкоманды — `login`, `logout` и `list` — и ни одна из них не принимает флагов; каждая интерактивна.

## `auth login`

```bash
cyberstrike auth login [url]
```

Запускает интерактивный вход. Cyberstrike показывает список провайдеров (построенный из каталога моделей) и запрашивает API-ключ или OAuth-поток. Необязательный позиционный `url` предварительно выбирает well-known URL провайдера; в противном случае провайдер выбирается из меню — вы **не** передаёте провайдера как флаг.

```
? Select provider
❯ cyberstrike (recommended)
  anthropic (Claude Max or API key)
  github-copilot
  openai (ChatGPT Plus/Pro or API key)
  google
  openrouter
  …
```

Учётные данные сохраняются в каталоге данных (`~/.local/share/cyberstrike/auth.json`).

## `auth list`

```bash
cyberstrike auth list   # псевдоним: ls
```

Показывает провайдеров, для которых у вас есть учётные данные.

## `auth logout`

```bash
cyberstrike auth logout
```

Интерактивный выбор сохранённых учётных данных для удаления.

<Aside variant="caution">
  Не существует команд `auth status`, `auth verify`, `auth refresh` или `auth switch`, а также флагов `--key`/`--oauth`/`--json`/`--all`. Вход всегда осуществляется через интерактивный поток `auth login`.
</Aside>

## Переменные окружения

Вместо хранения учётных данных вы можете предоставить ключи провайдеров через переменные окружения — см. [ИИ-провайдеры](/docs/providers) и [Переменные окружения](/docs/configuration/environment-variables). Например:

```bash
export ANTHROPIC_API_KEY="sk-ant-..."
export OPENAI_API_KEY="sk-..."
export GOOGLE_GENERATIVE_AI_API_KEY="AI..."
```

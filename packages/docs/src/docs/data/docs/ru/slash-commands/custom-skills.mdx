Навык — это Markdown-файл с повторно используемой методологией, которую агент может подключать по запросу. Навыки обнаруживаются по имени файла — каждый навык находится в файле с именем **`SKILL.md`**.

## Файл и расположение

Файл должен называться `SKILL.md`. Cyberstrike сканирует `**/SKILL.md` в каталогах `skill/` или `skills/` внутри `.cyberstrike/`, а также в `skills/` (формат Claude Code):

```
.cyberstrike/
└── skills/
    └── sql-injection/
        └── SKILL.md
```

## Метаданные (frontmatter)

Обязательны только `name` и `description`. Остальное — необязательные метаданные для категоризации и связывания с kill-chain:

```markdown title="SKILL.md"
---
name: sql-injection
description: Methodology for testing SQL injection
version: "1.0.0"
author: you
tags: [injection, database]
category: injection
owasp_id: WSTG-INPV-05
tech_stack: [postgres, mysql]
cwe_ids: [CWE-89]
chains_with: [auth-bypass]
prerequisites: [request-capture]
---

Walk the tester through boolean-, error-, time-, and union-based SQLi:
1. Identify injectable parameters …
2. …
```

<Aside variant="caution">
  Тело файла — обычный Markdown. Шаблонизации **нет** (ни `{{target}}`, ни `{% if %}`, ни `{% for %}`, ни `$ARGUMENTS`). Frontmatter **не** поддерживает поля `args`, `model`, `agent` или `permission`, и файл должен называться буквально `SKILL.md` (произвольные имена вроде `my-skill.md` не загружаются).
</Aside>

Значение `name` в frontmatter должно соответствовать идентификатору навыка — несовпадение сообщается как ошибка.

## Использование навыков

Загруженные навыки доступны агенту и могут быть просмотрены командой `/skills`. Агент подключает методологию навыка в контекст, когда она релевантна задаче.

Команды сессий управляют текущим разговором — создание, возобновление, обмен и редактирование истории сообщений.

<img src="/docs/images/gifs/session-commands.gif" alt="Открытие выбора сессий через leader+l" className="rounded-lg shadow-lg my-6 w-full" />

## Жизненный цикл

| Команда | Псевдонимы | Действие |
|---------|-----------|----------|
| `/new` | `/clear` | Начать **новую** сессию (`/clear` — псевдоним, он не просто очищает сообщения) |
| `/sessions` | `/resume`, `/continue` | Открыть выбор сессии для возобновления прошлой |
| `/rename` | | Переименовать текущую сессию |
| `/fork` | | Ответвить сессию от текущей точки |
| `/timeline` | | Показать временную шкалу сессии |
| `/export` | | Экспортировать сессию |
| `/copy` | | Копировать последнее сообщение |

## Сообщения

| Команда | Псевдонимы | Действие |
|---------|-----------|----------|
| `/undo` | | Отменить последнее сообщение |
| `/redo` | | Повторить |
| `/compact` | `/summarize` | Компактифицировать (сжать) сессию для освобождения контекста |
| `/timestamps` | `/toggle-timestamps` | Переключить метки времени сообщений |
| `/thinking` | `/toggle-thinking` | Переключить блоки мышления |

## Совместный доступ

| Команда | Действие |
|---------|----------|
| `/share` | Поделиться текущей сессией |
| `/unshare` | Прекратить совместный доступ |

<Aside variant="caution">
  `/clear` — псевдоним `/new` (начинает новую сессию), а `/continue` — псевдоним `/sessions` (открывает выбор сессии). Команд `/history`, `/memory`, `/cost`, `/save`, `/tag`, `/note`, `/retry` или `/template` не существует.
</Aside>

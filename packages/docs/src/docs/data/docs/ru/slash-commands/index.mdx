Введите `/` в начале строки ввода, чтобы открыть список команд (или нажмите `Ctrl+P`). Нечёткий поиск фильтрует по мере ввода.

## Сессии

| Команда | Псевдонимы | Сочетание | Действие |
|---------|-----------|-----------|----------|
| `/new` | `/clear` | `<leader>n` | Начать новую сессию |
| `/sessions` | `/resume`, `/continue` | `<leader>l` | Открыть выбор сессии |
| `/rename` | | `ctrl+r` | Переименовать сессию |
| `/compact` | `/summarize` | `<leader>c` | Компактифицировать (сжать) сессию |
| `/fork` | | | Ответвить сессию |
| `/timeline` | | `<leader>g` | Показать временную шкалу сессии |
| `/export` | | `<leader>x` | Экспортировать сессию |
| `/copy` | | | Копировать последнее сообщение |
| `/share`, `/unshare` | | | Поделиться / прекратить доступ |
| `/undo`, `/redo` | | `<leader>u` / `<leader>r` | Отменить / повторить последнее сообщение |
| `/timestamps`, `/thinking` | | | Переключить отображение меток времени / блоков мышления |

## Средства выбора и система

| Команда | Сочетание | Действие |
|---------|-----------|----------|
| `/models` | `<leader>m` | Выбор модели |
| `/agents` | `<leader>a` | Выбор агента |
| `/themes` | `<leader>t` | Выбор темы |
| `/mcps` | | Менеджер MCP-серверов |
| `/bolt` | | Менеджер серверов Bolt |
| `/connect` | | Подключить провайдера |
| `/editor` | `<leader>e` | Открыть сообщение в редакторе |
| `/skills` | | Просмотр загруженных навыков |
| `/status` | `<leader>s` | Статус |
| `/help` | | Справка |
| `/exit` | | Выход |

## Веб-тестирование и методология

| Команда | Псевдонимы | Действие |
|---------|-----------|----------|
| `/hackbrowser` | | Запустить краулинг Hacker Browser |
| `/hackbrowser-stop` | | Остановить работающий краулинг |
| `/vulnerabilities` | `/vuln`, `/vulns` | Просмотр обнаруженных уязвимостей |
| `/web` | `/endpoints`, `/roles`, `/credentials` | Просмотр контекста веб-тестирования |
| `/methodology` | `/intel`, `/vrt`, `/chains` | Представления движка методологии |
| `/report` | | Сгенерировать отчёт |
| `/qpause`, `/qresume` | | Приостановить / возобновить очередь обработки |

<Aside variant="caution">
  Имена команд во множественном числе (`/models`, `/themes`, `/mcps`). Команд `/agent-settings`, `/settings`, `/config`, `/vim`, `/provider`, `/model` и палитры команд `<leader><leader>`/`Ctrl+Shift+P` не существует — список команд открывается через `Ctrl+P`.
</Aside>

## Упоминания @

Ссылайтесь на файл (с опциональным диапазоном строк) в промпте с помощью `@`:

```
@src/auth.ts#45-60 check these lines for vulnerabilities
```

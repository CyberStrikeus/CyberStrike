Эти slash-команды открывают средства выбора и диалоги. Введите `/` в TUI, чтобы увидеть список команд (или нажмите `Ctrl+P`).

<img src="/docs/images/gifs/navigation-commands.gif" alt="Открытие списка команд и навигация по средствам выбора" className="rounded-lg shadow-lg my-6 w-full" />

## Средства выбора и диалоги

| Команда | Открывает |
|---------|-----------|
| `/models` | Выбор модели |
| `/agents` | Выбор агента |
| `/themes` | Выбор темы |
| `/mcps` | Менеджер MCP-серверов |
| `/bolt` | Менеджер серверов Bolt |
| `/connect` | Подключение / аутентификация провайдера |
| `/sessions` (`/resume`, `/continue`) | Выбор сессии |
| `/editor` | Открытие сообщения во внешнем редакторе |
| `/skills` | Просмотр загруженных навыков |
| `/help` | Справка |
| `/status` | Статус |
| `/exit` | Выход из Cyberstrike |

<Aside variant="caution">
  Имена команд во множественном числе: `/models`, `/themes`, `/mcps` (не `/model`, `/theme`, `/mcp`). Команд `/provider`, `/vim`, `/config`, `/permission`, `/files`, `/cd`, `/tools`, `/version`, `/doctor`, `/docs`, `/changelog`, `/cost` или `/context` не существует.
</Aside>

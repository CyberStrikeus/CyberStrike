Локальные MCP-серверы запускаются на вашей машине как дочерние процессы, взаимодействуя через stdio. Это альтернатива [Bolt](/docs/mcp/bolt) для пользователей, которые предпочитают запускать инструменты непосредственно на своей системе.

<Aside variant="tip">
  **Для инструментов безопасности предпочтительнее Bolt.** Локальный MCP требует самостоятельной установки каждого инструмента. Рекомендуемый подход с предустановленными плагинами инструментов безопасности см. в [Bolt](/docs/mcp/bolt).
</Aside>

## Когда использовать локальный MCP

- **Офлайн-среды** — не требуется сетевой доступ
- **Низкая задержка** — прямое взаимодействие процессов через stdio
- **Пользовательские инструменты** — ваши собственные MCP-серверы
- **Конфиденциальность** — данные никогда не покидают вашу машину

Cyberstrike также поставляет несколько локальных MCP-серверов, включённых по умолчанию: `github-security`, `cve` и `osint`. Ваша конфигурация объединяется поверх них.

## Схема конфигурации

Локальный сервер — это одна запись в плоской карте `mcp`, с ключом по имени сервера:

```json title="~/.config/cyberstrike/cyberstrike.json"
{
  "mcp": {
    "my-tools": {
      "type": "local",
      "command": ["npx", "-y", "my-mcp-server"],
      "environment": { "API_KEY": "{env:MY_API_KEY}" },
      "enabled": true,
      "timeout": 5000
    }
  }
}
```

| Поле | Тип | Описание |
|------|-----|----------|
| `type` | `"local"` | Обязательно. Выбирает stdio дочерний процесс. |
| `command` | `string[]` | Обязательно. Команда **и её аргументы** одним массивом. |
| `environment` | object | Необязательно. Дополнительные переменные окружения для процесса. |
| `enabled` | boolean | Необязательно. Запускать сервер при старте (по умолчанию: true). |
| `timeout` | number | Необязательно. Таймаут запроса в мс (по умолчанию: 5000). |

<Aside variant="caution">
  Объект `mcp` — это **плоская карта** с ключами по имени сервера — обёртки `servers` нет. `command` — единый массив (команда + аргументы вместе); отдельных полей `args`, `cwd`, `autoStart` или `restart` нет. Неизвестные ключи отклоняются.
</Aside>

## Добавление через TUI

Самый простой способ добавить локальный сервер — через TUI с помощью команды `/mcps`.

Введите `/mcps` для открытия менеджера MCP. Он показывает настроенные серверы с их статусом (`✓` включён / `○` отключён). Нажмите `space` для переключения сервера, `a` для добавления, `Enter` для действия с выбранным.

Для добавления локального сервера: нажмите `a` -> выберите **Local** -> введите **команду** (напр. `npx my-mcp-server`) -> необязательно добавьте **переменные окружения** (`KEY=VALUE, KEY2=VALUE2`) -> подтвердите автоматически определённое **имя**. Cyberstrike проверяет подключение перед сохранением; при неудаче сервер не добавляется.

TUI записывает именно ту схему, что показана выше.

## Примеры

### Node.js-сервер

```json
{
  "mcp": {
    "filesystem": {
      "type": "local",
      "command": ["npx", "-y", "@modelcontextprotocol/server-filesystem", "/path/to/allow"]
    }
  }
}
```

### Python-сервер

```json
{
  "mcp": {
    "python-tools": {
      "type": "local",
      "command": ["python", "-m", "mcp_server"]
    }
  }
}
```

### Бинарный файл или Docker

Поскольку `command` — полный argv, вы можете запустить бинарный файл напрямую или обернуть в Docker — специальных полей не нужно:

```json
{
  "mcp": {
    "docker-tools": {
      "type": "local",
      "command": ["docker", "run", "-i", "--rm", "--network=none", "mcp-tools:latest"]
    }
  }
}
```

## Переменные окружения

Передавайте переменные серверному процессу через `environment`. Используйте `{env:VAR}` для ссылки на переменную из вашей оболочки вместо захардкоженных секретов:

```json
{
  "mcp": {
    "api-tools": {
      "type": "local",
      "command": ["node", "server.js"],
      "environment": {
        "API_KEY": "{env:MY_API_KEY}",
        "DEBUG": "mcp:*"
      }
    }
  }
}
```

## Включение и отключение

Установите `enabled: false`, чтобы сохранить сервер настроенным, но неактивным (или переключайте в диалоге `/mcps`):

```json
{
  "mcp": {
    "heavy-tools": {
      "type": "local",
      "command": ["node", "server.js"],
      "enabled": false
    }
  }
}
```

## Медленно запускающиеся серверы

Увеличьте `timeout` (миллисекунды) для серверов, которым нужно больше 5 секунд по умолчанию для ответа:

```json
{
  "mcp": {
    "slow-tools": {
      "type": "local",
      "command": ["node", "server.js"],
      "timeout": 30000
    }
  }
}
```

## Устранение неполадок

- **Сервер не запускается** — убедитесь, что первый элемент `command` существует и является исполняемым, и что его зависимости установлены. Проверьте подключение с помощью `cyberstrike mcp debug <name>`.
- **Таймаут подключения** — увеличьте `timeout` или проверьте, что сервер быстро отвечает на `tools/list`.
- **Конфигурация отклонена** — схема `mcp` строгая; убедитесь, что вы используете плоскую карту с `type` + `command` (массив) и без неизвестных ключей.

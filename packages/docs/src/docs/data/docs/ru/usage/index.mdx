CyberStrike предлагает несколько способов взаимодействия с платформой:

- **[TUI](/docs/usage/tui)** — Интерактивный терминальный интерфейс с выводом агентов в реальном времени, slash-командами и горячими клавишами
- **[CLI](/docs/usage/cli)** — Неинтерактивный режим для скриптов, конвейеров и автоматизации
- **[Web](/docs/usage/web)** — Браузерный интерфейс с вкладками сессий, боковыми панелями и встроенным терминалом
- **[Настольное приложение](/docs/usage/desktop-app)** — Нативное приложение для macOS, Windows и Linux *(скоро)*

Каждый интерфейс подключается к одному и тому же базовому движку и разделяет сессии, поэтому вы можете свободно переключаться между ними.

## Быстрый старт

```bash
# Интерактивный TUI (по умолчанию)
cyberstrike

# Неинтерактивный CLI
cyberstrike run "scan example.com for open ports"

# Веб-интерфейс
cyberstrike web
```

## Выбор интерфейса

| Интерфейс | Лучше всего подходит для |
|-----------|------------------------|
| TUI | Ежедневные интерактивные оценки, slash-команды, работа с клавиатуры |
| CLI | CI/CD-конвейеры, скрипты, передача вывода инструментов через pipe |
| Web | Командная работа, визуальные боковые панели, рабочие процессы в браузере |
| Настольное приложение | Нативный опыт без терминала *(скоро)* |

Все интерфейсы поддерживают полный набор агентов безопасности, MCP-инструментов и AI-провайдеров.

CyberStrike Desktop — нативное приложение, которое объединяет весь инструментарий — агенты, инструменты, Vortex, HackBrowser, Bolt — в отдельное приложение. Терминал не требуется.

<Aside variant="caution">
  Настольное приложение находится в активной разработке. Все три платформы запланированы для первоначального релиза.
</Aside>

## macOS <Badge text="Скоро" variant="caution" size="md" />

Нативное приложение macOS с поддержкой Apple Silicon и Intel. Распространяется как `.dmg`-установщик.

- macOS 12 Monterey или новее
- Apple Silicon (M1+) или Intel
- 500 МБ дискового пространства

## Windows <Badge text="Скоро" variant="caution" size="md" />

Нативное приложение Windows, распространяемое как `.exe`-установщик через NSIS.

- Windows 10 (1809) или новее
- Архитектура x64
- 500 МБ дискового пространства

<Aside variant="info">
  WSL **не** требуется. Настольное приложение работает нативно на Windows.
</Aside>

## Linux <Badge text="Скоро" variant="caution" size="md" />

Сборки для Linux распространяются как `.AppImage` и `.deb`-пакеты.

- Ubuntu 20.04+, Fedora 38+ или аналогичные
- Архитектура x64
- 500 МБ дискового пространства

## Что ожидать

Настольное приложение предоставляет те же возможности, что и `cyberstrike web`, но как нативное окно:

- Полный паритет функций с TUI — все slash-команды, агенты и инструменты
- Интегрированный HackBrowser — запуск Chromium из приложения
- Управление сервером Bolt — сопряжение и управление контейнерными инструментами
- Панель MCP-серверов — настройка и мониторинг MCP-подключений
- Вкладки сессий — несколько оценок открыты одновременно
- Работа оффлайн — совместимость с локальными провайдерами, такими как Ollama

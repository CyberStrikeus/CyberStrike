## Встроенные дополнительные провайдеры

Они **уже включены** — конфигурация провайдера не нужна. Просто установите переменную окружения с API-ключом и выберите модель как `provider-id/model`:

| ID провайдера | Переменная окружения | Пример модели |
|---------------|---------------------|---------------|
| `groq` | `GROQ_API_KEY` | `groq/llama-3.3-70b-versatile` |
| `togetherai` | `TOGETHER_API_KEY` | `togetherai/meta-llama/Llama-3.3-70B-Instruct-Turbo` |
| `deepinfra` | `DEEPINFRA_API_KEY` | `deepinfra/meta-llama/Llama-3.3-70B-Instruct` |
| `perplexity` | `PERPLEXITY_API_KEY` | `perplexity/sonar` |
| `openrouter` | `OPENROUTER_API_KEY` | `openrouter/anthropic/claude-sonnet-4` |

```bash
export GROQ_API_KEY="gsk_..."
cyberstrike --model groq/llama-3.3-70b-versatile
```

Другие (`mistral`, `xai`, `deepseek`, `cohere`, `cerebras` и другие) работают аналогично — установите ключ и используйте `provider-id/model`. См. [ИИ-провайдеры](/docs/providers).

## Пользовательский OpenAI-совместимый провайдер

Для эндпоинта, который не включён в поставку (Fireworks, vLLM, LM Studio, частный шлюз), определите его в `provider`. Загрузка происходит через поле верхнего уровня **`api`** (базовый URL); `npm` по умолчанию использует `@ai-sdk/openai-compatible`, и вы перечисляете нужные модели:

```json title="~/.config/cyberstrike/cyberstrike.json"
{
  "provider": {
    "my-endpoint": {
      "name": "My Endpoint",
      "api": "https://api.example.com/v1",
      "options": { "apiKey": "{env:MY_API_KEY}" },
      "models": {
        "my-model": { "name": "My Model" }
      }
    }
  },
  "model": "my-endpoint/my-model"
}
```

### vLLM

```json
{
  "provider": {
    "vllm": {
      "name": "vLLM",
      "api": "http://localhost:8000/v1",
      "models": { "llama-3.3-70b": { "name": "Llama 3.3 70B" } }
    }
  }
}
```

### LM Studio

```json
{
  "provider": {
    "lmstudio": {
      "name": "LM Studio",
      "api": "http://localhost:1234/v1",
      "models": { "local-model": { "name": "Local Model" } }
    }
  }
}
```

<Aside variant="caution">
  Провайдер из конфигурации загружается, потому что имеет URL в `api` — одного `options.baseURL` недостаточно для регистрации. Используйте поле верхнего уровня `api`.
</Aside>

## Azure OpenAI

```json title="~/.config/cyberstrike/cyberstrike.json"
{
  "provider": {
    "azure": {
      "name": "Azure OpenAI",
      "options": {
        "apiKey": "{env:AZURE_API_KEY}"
      }
    }
  }
}
```

```bash
export AZURE_RESOURCE_NAME="your-resource"
export AZURE_API_KEY="..."
```

## Устранение неполадок

- **401 Unauthorized** — проверьте переменную окружения с API-ключом и что она указана через `{env:VAR}`.
- **Model not found** — id модели должен соответствовать формату провайдера и быть указан в `models` для пользовательского провайдера.
- **Unexpected response** — эндпоинт может быть не полностью OpenAI-совместимым; вызов инструментов и стриминг различаются у провайдеров.

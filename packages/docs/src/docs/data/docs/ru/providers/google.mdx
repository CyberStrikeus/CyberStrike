Модели Gemini от Google предлагают большие контекстные окна и мультимодальные возможности для анализа безопасности.

<img src="/docs/images/screenshots/gemini-model-select.png" alt="Выбор модели с фильтром по моделям Google Gemini" className="rounded-lg shadow-lg my-6 w-full" />

## Доступные модели

Cyberstrike загружает каталог моделей в реальном времени с [models.dev](https://models.dev), поэтому список точно отражает текущее предложение Google. Популярные варианты:

| Модель | Контекст | Лучше всего для |
|--------|---------|----------------|
| `google/gemini-2.5-pro` | 1M | Сложные рассуждения, большие кодовые базы |
| `google/gemini-2.5-flash` | 1M | Быстрый анализ (сбалансированный по умолчанию) |
| `google/gemini-2.5-flash-lite` | 1M | Быстрые задачи, большой объём |

<Aside variant="tip">
  Более новые релизы Gemini 3.x (`gemini-3-pro-preview`, `gemini-3.5-flash`, `gemini-3.1-pro-preview`) появляются автоматически при обновлении models.dev. Выполните `/models` для получения полного текущего списка.
</Aside>

## Аутентификация

### Настройка API-ключа

1. Получите API-ключ на [ai.google.dev](https://ai.google.dev)
2. В TUI выполните `/connect`, выберите **Google** и введите API-ключ

### Переменная окружения

```bash
export GOOGLE_GENERATIVE_AI_API_KEY="AI..."
```

### Файл конфигурации

```json title="~/.config/cyberstrike/cyberstrike.json"
{
  "provider": {
    "google": {
      "options": {
        "apiKey": "{env:GOOGLE_GENERATIVE_AI_API_KEY}"
      }
    }
  }
}
```

## Конфигурация модели

### Установка модели по умолчанию

```json title="~/.config/cyberstrike/cyberstrike.json"
{
  "model": "google/gemini-2.5-flash"
}
```

### Переключение моделей

Используйте `/models` в TUI для выбора другой модели Gemini.

## Преимущество большого контекста

Контекстное окно Gemini 1M-2M позволяет:

- Анализировать целые кодовые базы за раз
- Обрабатывать множество файлов одновременно
- Проводить длительные сессии оценки безопасности
- Выполнять комплексный анализ журналов

### Пример: полный обзор кодовой базы

```
> Analyze the entire src/ directory for security vulnerabilities
```

Модель может обработать сотни файлов за один запрос.

## Мультимодальные возможности

Gemini поддерживает анализ изображений:

```
> Analyze this screenshot for security issues
```

Полезно для:
- Анализа вывода инструментов безопасности в виде изображений
- Обработки сетевых диаграмм
- Обзора UI на предмет уязвимостей

## Режим мышления

Модели Gemini 2.5 поддерживают рассуждения ("thinking") для сложного анализа. Выберите одну через `/models`.

Лучше всего для:
- Сложных цепочек уязвимостей
- Многоэтапного планирования атак
- Глубокого анализа кода

## Google Vertex AI

Для корпоративных развёртываний:

### Настройка

```bash
# Аутентификация в Google Cloud
gcloud auth application-default login

# Установка проекта
gcloud config set project your-project-id
```

### Конфигурация

```json title="~/.config/cyberstrike/cyberstrike.json"
{
  "provider": {
    "google-vertex": {
      "options": {
        "project": "your-project-id",
        "location": "us-central1"
      }
    }
  }
}
```

### Доступные регионы

| Регион | Расположение |
|--------|-------------|
| us-central1 | Айова |
| us-east4 | Вирджиния |
| europe-west4 | Нидерланды |
| asia-northeast1 | Токио |

## Лимиты частоты запросов

Лимиты Google AI Studio:

| Тариф | RPM | TPM |
|-------|-----|-----|
| Бесплатный | 15 | 1,000,000 |
| Pay-as-you-go | 360 | 4,000,000 |

### Обработка лимитов

```json
{
  "provider": {
    "google": {
      "options": {
        "maxRetries": 3,
        "retryDelay": 1000
      }
    }
  }
}
```

## Настройки безопасности контента

Настройка фильтрации контента:

```json
{
  "provider": {
    "google": {
      "options": {
        "safetySettings": [
          {
            "category": "HARM_CATEGORY_DANGEROUS_CONTENT",
            "threshold": "BLOCK_NONE"
          }
        ]
      }
    }
  }
}
```

<Aside variant="caution">
  Настраивайте параметры безопасности осторожно. Некоторый контент тестирования безопасности может активировать фильтры.
</Aside>

## Лучшие практики

### Выбор модели

| Задача | Рекомендуемая модель |
|--------|---------------------|
| Быстрые сканирования | `gemini-2.5-flash` |

### Использование большого контекста

1. Включайте полные файлы вместо фрагментов
2. Предоставляйте полные файлы конфигурации
3. Включайте связанные тестовые файлы
4. Добавляйте документацию для контекста

### Оптимизация стоимости

1. Используйте модели Flash для большинства задач
2. Пользуйтесь бесплатным тарифом
3. Используйте контекст эффективно
4. Отслеживайте использование в Google Cloud Console

## Устранение неполадок

### Недействительный API-ключ

```
Error: API key not valid
```

Проверьте:
- Ключ получен с ai.google.dev
- API включён
- Нет лишних пробелов

### Квота превышена

```
Error: Quota exceeded
```

Решения:
- Дождитесь сброса квоты
- Включите биллинг
- Запросите увеличение квоты

### Регион недоступен

```
Error: Model not available in region
```

Попробуйте другие регионы или используйте Google AI Studio вместо Vertex.

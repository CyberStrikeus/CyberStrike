OpenAI предоставляет семейство GPT-5, GPT-4.1 и модели рассуждений серии o для анализа безопасности. Это руководство описывает настройку и конфигурацию.

<img src="/docs/images/screenshots/openai-model-select.png" alt="Выбор модели с фильтром по моделям OpenAI" className="rounded-lg shadow-lg my-6 w-full" />

## Доступные модели

Cyberstrike загружает каталог моделей в реальном времени с [models.dev](https://models.dev), поэтому список точно отражает текущее предложение OpenAI. Популярные варианты:

| Модель | Контекст | Лучше всего для |
|--------|---------|----------------|
| `openai/gpt-5` | 400K | Общее тестирование безопасности (флагман) |
| `openai/gpt-5-mini` | 400K | Быстрые задачи, большой объём |
| `openai/gpt-5-nano` | 400K | Самый дешёвый, простые задачи |
| `openai/gpt-4.1` | 1M | Очень большой контекст |
| `openai/o3` | 200K | Глубокие пошаговые рассуждения |

<Aside variant="tip">
  Более новые релизы GPT-5.x (5.1-5.5, а также варианты Codex и Pro) появляются автоматически при обновлении models.dev. Выполните `/models` для получения полного текущего списка.
</Aside>

## Аутентификация

### Настройка API-ключа

1. Получите API-ключ на [platform.openai.com](https://platform.openai.com)
2. В TUI выполните `/connect`, выберите **OpenAI** и введите API-ключ

### Переменная окружения

```bash
export OPENAI_API_KEY="sk-proj-..."
```

### Файл конфигурации

```json title="~/.config/cyberstrike/cyberstrike.json"
{
  "provider": {
    "openai": {
      "options": {
        "apiKey": "{env:OPENAI_API_KEY}"
      }
    }
  }
}
```

## Конфигурация модели

### Установка модели по умолчанию

```json title="~/.config/cyberstrike/cyberstrike.json"
{
  "model": "openai/gpt-5"
}
```

### Переключение моделей

Используйте `/models` в TUI для выбора другой модели OpenAI.

### Использование моделей рассуждений

Серия o (`o3`, `o4-mini`) и варианты GPT-5 Pro отлично справляются со сложным анализом безопасности. Выберите их через `/models`.

Лучше всего для:
- Сложных цепочек уязвимостей
- Анализа путей атак
- Криптографического анализа
- Реверс-инжиниринга

## ChatGPT Plus/Pro

Используйте подписку ChatGPT, выполнив `/connect` в TUI, выбрав **OpenAI** и затем **ChatGPT Plus/Pro**. Это запускает OAuth-поток через браузер.

<Aside variant="info">
  Аутентификация ChatGPT требует OAuth-потока через браузер.
</Aside>

## ID организации

Для аккаунтов организаций:

```json title="~/.config/cyberstrike/cyberstrike.json"
{
  "provider": {
    "openai": {
      "options": {
        "apiKey": "{env:OPENAI_API_KEY}",
        "organization": "org-..."
      }
    }
  }
}
```

## Пользовательский базовый URL

Для OpenAI-совместимых эндпоинтов:

```json
{
  "provider": {
    "openai": {
      "options": {
        "baseURL": "https://your-endpoint.com/v1"
      }
    }
  }
}
```

## Вызов функций

Модели GPT поддерживают вызов функций для использования инструментов:

```json
{
  "provider": {
    "openai": {
      "options": {
        "parallelToolCalls": true
      }
    }
  }
}
```

## Лимиты частоты запросов

Лимиты частоты OpenAI по тарифам:

| Тариф | RPM | TPM |
|-------|-----|-----|
| Бесплатный | 3 | 40,000 |
| Tier 1 | 500 | 200,000 |
| Tier 2 | 5,000 | 2,000,000 |
| Tier 3+ | Более высокие лимиты |

### Обработка лимитов

```json
{
  "provider": {
    "openai": {
      "options": {
        "maxRetries": 3,
        "timeout": 60000
      }
    }
  }
}
```

## Лучшие практики

### Выбор модели

| Задача | Рекомендуемая модель |
|--------|---------------------|
| Быстрые сканирования | `gpt-5-nano` |
| Общее тестирование | `gpt-5` |
| Сложный анализ | `o3` |
| Экономичность | `gpt-5-mini` |

### Оптимизация стоимости

1. Используйте mini-модели для простых задач
2. Устанавливайте разумное ограничение токенов
3. Используйте `/compact` для длинных сессий
4. Отслеживайте использование на панели OpenAI

### Безопасность

1. Храните ключи в переменных окружения
2. Используйте API-ключи для конкретных проектов
3. Включите лимиты использования на панели OpenAI
4. Регулярно ротируйте ключи

## Устранение неполадок

### Недействительный API-ключ

```
Error: Incorrect API key provided
```

Проверьте:
- Ключ начинается с `sk-proj-` или `sk-`
- Нет лишних пробелов
- Ключ активен

### Недостаточная квота

```
Error: You exceeded your current quota
```

Решения:
- Добавьте платёжную информацию
- Проверьте лимиты использования
- Обновите тарифный план

### Доступ к модели

```
Error: The model does not exist or you do not have access
```

Некоторые модели требуют:
- Более высокого тарифа использования для новейших флагманов
- Одобрения в списке ожидания
- Корпоративного соглашения

<Aside variant="caution">
  Модели рассуждений (серия o и варианты GPT-5 Pro) имеют более высокую задержку из-за шагов рассуждения. Планируйте более длительное время отклика.
</Aside>

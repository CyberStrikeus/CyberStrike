`escalation-hunter` — это агент-аналитик перекрёстной корреляции, работающий после завершения тестирования специалистами WSTG. Он анализирует все находки по всей сессии для выявления цепочечных уязвимостей, эскалации воздействия и построения новых векторов атак, которые отдельные специалисты могли бы пропустить.

## Обзор

| Свойство | Значение |
|----------|----------|
| **ID агента** | `escalation-hunter` |
| **Роль** | `analyst` |
| **Домен** | `@cyberstrike-io/web` |
| **Запускается после** | Завершения тестирования специалистами WSTG |

## Что он делает

Отдельные специалисты WSTG тестируют конечные точки изолированно — каждый фокусируется на своей категории. `escalation-hunter` пересекает все направления для поиска:

- **Цепочечных уязвимостей** — комбинация IDOR низкой серьёзности с фиксацией сессии для достижения захвата учётной записи
- **Эскалации воздействия** — находка средней серьёзности, становящаяся критической в сочетании с другой
- **Новых векторов атак** — последовательности запросов, которые при воспроизведении по порядку дают результат с более высоким воздействием
- **Межролевой эскалации** — границы привилегий, нарушающиеся при объединении находок разных специалистов

## Как это работает

1. Читает все находки из сессии (от всех специалистов WSTG)
2. Читает накопленные данные Vortex (паттерны трафика, совпадения правил, объекты, функции)
3. Определяет возможности корреляции между находками
4. Конструирует и **воспроизводит** предложенные цепочки атак для их верификации
5. Сообщает о подтверждённых эскалациях как о новых находках с составными доказательствами

`escalation-hunter` никогда не верит специалисту на слово — он проверяет предложенные цепочки, воспроизводя реальную последовательность HTTP.

## Пример

```
Specialist A: IDOR in GET /api/users/{id} (medium)
Specialist B: Missing rate limit on /api/auth/reset (low)
Specialist C: Email parameter in reset response body (info)

Escalation Hunter:
  Chain: enumerate user IDs via IDOR → trigger password reset for each →
         extract reset tokens from response → account takeover
  Verified: replayed 3-step chain → confirmed ATO
  Escalated: Critical (was medium + low + info individually)
```

<Aside variant="info">
  escalation-hunter запускается автоматически — вы не вызываете его напрямую. Он работает как финальный аналитический проход после завершения конвейера WSTG.
</Aside>

Агент `general` обрабатывает исследования, сложные вопросы и многошаговые задачи. Первичный агент `cyberstrike` делегирует ему работу, которая выигрывает от параллельного выполнения или не требует специализированного агента безопасности.

## Обзор

| Свойство | Значение |
|----------|----------|
| **ID агента** | `general` |
| **Режим** | `subagent` |
| **Доступ к инструментам** | Широкий (без отчётов об уязвимостях и триажа) |

## Когда используется

Агент `cyberstrike` делегирует `general` для:

- Исследования сложных вопросов по множеству источников
- Выполнения нескольких независимых единиц работы параллельно
- Задач, не требующих предметных знаний в области безопасности
- Анализа файлов, обзора кода и общего рассуждения

## Ограничения

Агент `general` не может:

- Сообщать об уязвимостях (`report_vulnerability`: запрещено)
- Проводить триаж находок (`triage_vulnerability`: запрещено)
- Выполнять операции чтения/записи TODO

Эти ограничения гарантируют, что операции, связанные с безопасностью, остаются за соответствующими специализированными агентами.

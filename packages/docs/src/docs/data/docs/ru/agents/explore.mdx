Агент `explore` — это быстрый агент только для чтения, специализирующийся на поиске по кодовым базам и файловым системам. Он может находить файлы по паттернам, искать ключевые слова в коде и отвечать на структурные вопросы о кодовой базе.

## Обзор

| Свойство | Значение |
|----------|----------|
| **ID агента** | `explore` |
| **Режим** | `subagent` |
| **Доступ к инструментам** | Только чтение (grep, glob, list, bash, read, веб-поиск) |

## Когда используется

Агент `cyberstrike` делегирует задачи `explore`, когда нужно:

- Найти файлы по паттерну (например, `src/components/**/*.tsx`)
- Искать ключевые слова или символы в коде (например, «API endpoints»)
- Ответить на вопросы о структуре кодовой базы
- Выполнить быстрые поиски, не требующие модификации

## Уровни тщательности

При делегировании `explore` вызывающий агент указывает уровень тщательности:

| Уровень | Поведение |
|---------|-----------|
| **quick** | Базовый целенаправленный поиск — одно местоположение, первое совпадение |
| **medium** | Умеренное исследование — несколько местоположений |
| **very thorough** | Всеобъемлющий анализ по соглашениям об именовании и местоположениям |

## Ограничения

Агент `explore` строго ограничен чтением. Он не может:

- Записывать, редактировать или создавать файлы
- Выполнять деструктивные команды
- Сообщать об уязвимостях
- Изменять какое-либо состояние

Агент `cyberstrike` — это первичный агент по умолчанию. Он обеспечивает наступательное тестирование безопасности с поддержкой ИИ и полным доступом к инструментам и может делегировать задачи специализированным подагентам для предметных задач.

## Обзор

При запуске `cyberstrike` без указания агента автоматически запускается агент `cyberstrike`. Это агент наступательной безопасности общего назначения, предназначенный для решения широкого спектра задач — от разведки и оценки уязвимостей до эксплуатации и составления отчётов.

### Конфигурация агента

| Свойство | Значение |
|----------|----------|
| **ID агента** | `cyberstrike` |
| **Режим** | `primary` |
| **Доступ к инструментам** | Полный (все инструменты разрешены) |
| **Может задавать вопросы** | Да |

## Запуск агента

Агент `cyberstrike` является агентом по умолчанию — он запускается автоматически:

```bash
cyberstrike
```

Переключайте агентов в любое время в TUI с помощью `/agents` или `<leader>a`.

## Возможности

Агент `cyberstrike` имеет доступ ко всем доступным инструментам и не ограничен определённым доменом безопасности. Он может:

- Выполнять тестирование безопасности веб-приложений
- Проводить аудит облачной инфраструктуры
- Выполнять тестирование на проникновение в сети
- Запускать автоматизированные сканирования с инструментами Nuclei, Nmap и SQLMap
- Просматривать и взаимодействовать с веб-приложениями
- Читать, записывать и анализировать файлы
- Задавать уточняющие вопросы, когда задача неоднозначна

## Делегирование специализированным агентам

Когда задача требует глубокой предметной экспертизы, агент `cyberstrike` делегирует специализированным подагентам:

| Подагент | Когда используется |
|----------|-------------------|
| [`wstg-agent`](/docs/agents/wstg-agent) | Конвейер веб-безопасности OWASP WSTG — направляет 13 специализированных агентов |
| [`escalation-hunter`](/docs/agents/escalation-hunter) | Перекрёстная корреляция — связывает находки, эскалирует воздействие |
| [`triage`](/docs/agents/triage) | Независимая проверка черновиков уязвимостей |
| [`general`](/docs/agents/general) | Исследования, параллельные многошаговые задачи |
| [`explore`](/docs/agents/explore) | Поиск по кодовой базе и файловой системе только для чтения |

Делегирование происходит автоматически на основе задачи. Конвейер веб-безопасности (агенты WSTG) запускается при захвате HTTP-трафика через [HackBrowser](/docs/features/hackbrowser) или [расширение Chrome](/docs/tools/chrome-extension).

## Модель разрешений

Агент `cyberstrike` использует наиболее широкий набор разрешений:

- Все инструменты разрешены по умолчанию
- Может задавать уточняющие вопросы (`question: allow`)
- Файлы `.env` требуют подтверждения перед чтением
- Доступ к внешним каталогам за пределами проекта требует подтверждения
- Пользовательские правила `deny` в `cyberstrike.json` всегда соблюдаются

## Конфигурация

### Установка как агент по умолчанию

Агент `cyberstrike` является агентом по умолчанию и не требует настройки. Для явного указания:

```json title="cyberstrike.json"
{
  "default_agent": "cyberstrike"
}
```

### Пользовательские инструкции

`instructions` — это список файлов (или glob-шаблонов), содержимое которых добавляется к системному промпту — поместите контекст проекта в файл и укажите ссылку на него:

```json title="cyberstrike.json"
{
  "instructions": ["AGENTS.md", "docs/security-context.md"]
}
```

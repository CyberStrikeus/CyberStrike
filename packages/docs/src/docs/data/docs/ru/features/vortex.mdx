Vortex — это HTTP-движок трафика Cyberstrike. Он перехватывает, сохраняет и анализирует HTTP-запросы, проходящие через систему — будь то захваченные [HackBrowser](/docs/features/hackbrowser), [расширением Chrome](/docs/tools/chrome-extension) или введённые через API.

## Что делает Vortex

| Возможность | Описание |
|-------------|----------|
| **Захват трафика** | Сохраняет каждую пару запрос/ответ с полными заголовками и телом |
| **DSL-движок** | Фильтрация и запросы к трафику с помощью специализированного языка выражений |
| **Сопоставление правил** | Применение правил-как-данных (detect, canary, transform) к захваченному трафику |
| **Воспроизведение** | Повторная отправка захваченных запросов с модификациями для тестирования |
| **Корреляция сигналов** | Перекрёстная проверка находок между запросами для обнаружения цепочечных уязвимостей |

## DSL-запросы

Vortex включает движок выражений для фильтрации HTTP-трафика. Запросы по методу, пути, статусу, заголовкам, содержимому тела и другим параметрам:

```
method == "POST" && path contains "/api/" && status >= 400
```

```
header["content-type"] contains "json" && body contains "token"
```

DSL поддерживает булеву логику, сопоставление строк, числовые сравнения и доступ к вложенным полям.

## Правила

Правила Vortex — это декларативные данные, а не код. Три формы правил покрывают типичные паттерны:

| Форма | Назначение | Пример |
|-------|------------|--------|
| **Detect** | Пометка трафика, соответствующего паттерну | Конфиденциальные данные в телах ответов |
| **Canary** | Внедрение маркеров и отслеживание их отражения | SSRF, открытое перенаправление, инъекция заголовков |
| **Transform** | Модификация запросов перед воспроизведением | Удаление заголовков авторизации, замена значений параметров |

Правила можно загружать из встроенных наборов или определять для каждого проекта.

## Интеграция с HackBrowser

Когда HackBrowser захватывает трафик, Vortex обрабатывает его автоматически:

1. Запрос поступает через `POST /session/ingest`
2. Vortex сохраняет запрос и применяет активные правила
3. Сработавшие правила генерируют сигналы
4. Сигналы поступают в конвейер анализа proxy-agent

## Использование

Vortex работает как часть бэкенда Cyberstrike — отдельная настройка не требуется. Трафик проходит через него при использовании HackBrowser, расширения Chrome или конвейера WSTG.

Используйте `/web` в TUI для просмотра накопленных данных Vortex: захваченных запросов, сработавших правил и сгенерированных сигналов. Связанные команды:

| Команда | Что показывает |
|---------|----------------|
| `/web` | Захваченные конечные точки, роли, учётные данные |
| `/vulnerabilities` | Находки из сигналов Vortex + тестирования WSTG |
| `/methodology` | Покрытие и статус методологии |

<Aside variant="tip">
  Vortex включён в бесплатный план. Уровень ИИ-анализа (рассуждение proxy-agent, корреляция сигналов) — это то, что делает его мощным — и он работает на вашем настроенном ИИ-провайдере.
</Aside>

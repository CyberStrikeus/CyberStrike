Cyberstrike использует Model Context Protocol (MCP) для интеграции внешних инструментов. Любой MCP-совместимый сервер — локальный или удалённый — может быть подключён, предоставляя ИИ-агенту доступ к его инструментам во время оценки.

## Встроенные серверы

Cyberstrike поставляется с тремя MCP-серверами, включёнными по умолчанию:

| Сервер | Назначение |
|--------|------------|
| `github-security` | Анализ безопасности репозиториев GitHub |
| `cve` | Поиск уязвимостей CVE/NVD/EPSS/KEV |
| `osint` | Сбор разведывательных данных из открытых источников |

Ваша конфигурация объединяется поверх этих серверов.

## Добавление серверов

MCP-серверы размещаются в плоской карте `mcp` в конфигурации, с ключами по имени:

```json title="cyberstrike.json"
{
  "mcp": {
    "my-tools": {
      "type": "local",
      "command": ["your-mcp-server"]
    }
  }
}
```

### Локальные серверы (stdio)

Локальные серверы запускаются как дочерние процессы:

```json
{
  "mcp": {
    "filesystem": {
      "type": "local",
      "command": ["npx", "-y", "@modelcontextprotocol/server-filesystem", "/path/to/dir"]
    }
  }
}
```

### Удалённые серверы (HTTP)

Удалённые серверы подключаются через StreamableHTTP или SSE:

```json
{
  "mcp": {
    "remote-tools": {
      "type": "remote",
      "url": "https://mcp.example.com/sse"
    }
  }
}
```

Удалённые серверы поддерживают [OAuth-аутентификацию](/docs/features/mcp#oauth) для защищённых конечных точек.

## Управление

| Команда | Что управляет |
|---------|---------------|
| `/mcps` | Локальные и удалённые MCP-серверы (добавление, переключение, удаление) |
| `/bolt` | Серверы Bolt конкретно (добавление, сопряжение, переключение, удаление) |

В обоих диалогах: **a** для добавления, **пробел** для переключения, **esc** для закрытия.

## Совместимость моделей

<Aside variant="caution">
  Модели на основе подпроцессов не могут использовать MCP-инструменты. Используйте модель с прямым API (например, `anthropic/claude-sonnet-4-20250514`, `openai/gpt-4o`) для полной интеграции MCP.
</Aside>

## Приоритет конфигурации

Записи MCP следуют стандартной [иерархии конфигурации](/docs/configuration#configuration-hierarchy): проектный `.cyberstrike/` переопределяет проектный `cyberstrike.json`, который переопределяет глобальный `~/.config/cyberstrike/`, который переопределяет встроенные серверы.

Cyberstrike поставляется со специализированными функциями для автоматизированного тестирования на проникновение. Каждая функция глубоко интегрирована с ИИ-агентом — агент решает, когда и как их использовать, исходя из цели и контекста разговора.

## Основные возможности

| Возможность | Назначение |
|-------------|------------|
| [Vortex](/docs/features/vortex) | HTTP-движок трафика — перехват, воспроизведение и сопоставление запросов с помощью DSL |
| [HackBrowser](/docs/features/hackbrowser) | ИИ-управляемый автономный веб-сканер с захватом контекста UI |
| [Bolt](/docs/features/bolt) | Контейнерный сервер инструментов безопасности (nmap, nuclei, sqlmap и 30+ других) |
| [MCP](/docs/features/mcp) | Model Context Protocol — подключение любого внешнего сервера инструментов |

## Как они работают вместе

Типичная оценка веб-приложения использует несколько возможностей совместно:

1. **HackBrowser** сканирует цель, захватывая HTTP-трафик с контекстом UI
2. **Vortex** обрабатывает захваченный трафик — применяет правила, отмечает аномалии, коррелирует сигналы
3. **proxy-agent** анализирует отмеченные запросы и запускает тестировщиков уязвимостей
4. **Bolt** предоставляет тяжёлые инструменты (шаблоны nuclei, фаззинг, перечисление поддоменов), когда агенту они нужны
5. Серверы **MCP** расширяют набор инструментов пользовательскими или сторонними интеграциями

Каждая возможность может использоваться и независимо. HackBrowser работает без Vortex, Bolt работает без HackBrowser, а MCP-серверы работают вне зависимости от других настроек.

Bolt — это контейнерный MCP-сервер, предоставляющий инструменты безопасности. Он работает в Docker-контейнере (Ubuntu 24.04) и предоставляет каждый инструмент напрямую — без мета-инструментов, без динамической загрузки, просто вызывайте нужный инструмент.

## Зачем Bolt?

| Возможность | Без Bolt | С Bolt |
|-------------|----------|--------|
| Установка инструментов | Вручную для каждого | Предустановлены |
| Поддержка платформ | Только Linux для большинства | Любая платформа с Docker |
| Изоляция | Инструменты работают на вашей системе | Изолированы в контейнере |
| Обновления | Вручную | `docker pull` |

## Что внутри

Bolt предоставляет инструменты двумя способами:

- **7 нативных плагинов** — `subfinder`, `nmap`, `nuclei`, `httpx`, `ffuf`, `run-command`, `wordlist`
- **~26 агрегированных stdio MCP-серверов** — `dnsx`, `amass`, `katana`, `sqlmap`, `wpscan`, `gobuster`, `masscan`, `hydra`, `hashcat`, `john`, `impacket` и другие

Каждый — это непосредственно вызываемый инструмент — агент вызывает его за один ход.

## Быстрый старт

### 1. Запуск контейнера Bolt

```bash
docker run -d \
  --name bolt \
  --restart unless-stopped \
  -p 3001:3001 \
  -v bolt-data:/data \
  -e MCP_ADMIN_TOKEN=$(openssl rand -hex 32) \
  --cap-add NET_RAW \
  --cap-add NET_ADMIN \
  ghcr.io/cyberstrikeus/bolt:latest

docker logs bolt | grep -i token
```

### 2. Подключение к Cyberstrike

Выполните `/bolt` в TUI, нажмите **a** для добавления, введите URL `http://localhost:3001` и укажите токен администратора.

### 3. Использование инструментов

Введите задачу напрямую — агент вызывает инструменты Bolt автоматически:

```
> Run nmap against 192.168.1.1 with service detection
> Use subfinder to enumerate subdomains of example.com
> Scan https://target.com with nuclei
```

## Конфигурация

Серверы Bolt настраиваются в ключе **`bolt`** — не в `mcp`:

```json title="~/.config/cyberstrike/cyberstrike.json"
{
  "bolt": {
    "local": {
      "url": "http://localhost:3001",
      "enabled": true,
      "timeout": 30000
    }
  }
}
```

<Aside variant="caution">
  Bolt — это **не** запись `mcp`. Аутентификация выполняется через Ed25519 pairing, и токен администратора используется только на этапе сопряжения.
</Aside>

## Аутентификация

Bolt использует **подпись запросов Ed25519**, инициируемую однократным сопряжением:

1. `POST /pair` с токеном администратора — код сопряжения
2. Cyberstrike генерирует пару ключей Ed25519
3. `POST /pair/exchange` с кодом + открытым ключом клиента — открытый ключ сервера + ID клиента
4. Каждый последующий запрос **подписывается** закрытым ключом клиента

Токен администратора используется только на шаге 1 — он не сохраняется в конфигурации.

## Управление через TUI

- **`/bolt`** — управление серверами Bolt (добавление/сопряжение, переключение, удаление)
- **`/mcps`** — управление обычными MCP-серверами

## Примеры использования

```
> Use bolt to scan 192.168.1.0/24 for open ports and services   # nmap
> Find all subdomains of example.com                            # subfinder
> Scan https://target.com with nuclei                           # nuclei
> Fuzz directories on https://target.com                        # ffuf
> Run "dig +short example.com"                                  # run-command
```

## Устранение неполадок

- **Отказ в соединении** — проверьте, что контейнер запущен (`docker ps`) и `curl http://localhost:3001/health` отвечает.
- **Требуется повторное сопряжение** — если URL Bolt изменился, выполните сопряжение заново через `/bolt`.
- **Инструменты недоступны** — убедитесь, что сервер подключён в `/bolt`, используйте модель с прямым API.

<Aside variant="danger">
  Используйте инструменты Bolt только против авторизованных целей. Несанкционированное тестирование на проникновение незаконно.
</Aside>

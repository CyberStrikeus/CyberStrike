Модели Claude от Anthropic обеспечивают продвинутые возможности рассуждений для анализа безопасности. Это руководство описывает конфигурацию и лучшие практики.

<img src="/docs/images/screenshots/anthropic-model-select.png" alt="Выбор модели с фильтром по моделям Anthropic Claude" className="rounded-lg shadow-lg my-6 w-full" />

## Доступные модели

Cyberstrike загружает каталог моделей в реальном времени с [models.dev](https://models.dev), поэтому список точно отражает текущее предложение Anthropic. Популярные варианты:

| Модель | Контекст | Лучше всего для |
|--------|---------|----------------|
| `anthropic/claude-opus-4-5` | 200K | Глубочайшие рассуждения — сложный анализ, исследование эксплойтов |
| `anthropic/claude-sonnet-4-5` | 200K | Сбалансированный вариант по умолчанию — общее тестирование безопасности |
| `anthropic/claude-haiku-4-5` | 200K | Быстрый, недорогой — быстрые сканирования, большой объём |

<Aside variant="tip">
  Новые флагманы (Opus 4.6/4.7/4.8, Sonnet 4.6/5, Fable 5) и все другие модели Claude появляются автоматически при обновлении models.dev. Выполните `/models` для получения полного текущего списка. Псевдонимы с `-latest` (напр. `claude-opus-4-5`) отслеживают новейший релиз в семействе; датированные ID (напр. `claude-opus-4-5-20251101`) фиксируют конкретную версию.
</Aside>

## Аутентификация

### Настройка API-ключа

1. Получите API-ключ на [console.anthropic.com](https://console.anthropic.com)
2. В TUI выполните `/connect`, выберите **Anthropic** и введите API-ключ

### Переменная окружения

```bash
export ANTHROPIC_API_KEY="sk-ant-..."
```

Добавьте в профиль оболочки для сохранения:

```bash
echo 'export ANTHROPIC_API_KEY="sk-ant-..."' >> ~/.zshrc
```

### Файл конфигурации

```json title="~/.config/cyberstrike/cyberstrike.json"
{
  "provider": {
    "anthropic": {
      "options": {
        "apiKey": "{env:ANTHROPIC_API_KEY}"
      }
    }
  }
}
```

## Конфигурация модели

### Установка модели по умолчанию

```json title="~/.config/cyberstrike/cyberstrike.json"
{
  "model": "anthropic/claude-sonnet-4-5"
}
```

### Переключение моделей

Используйте `/models` в TUI, чтобы открыть выбор моделей и выбрать другую модель Claude.

## Расширенное мышление

Включите расширенное мышление для сложного анализа безопасности:

```json title="~/.config/cyberstrike/cyberstrike.json"
{
  "provider": {
    "anthropic": {
      "options": {
        "thinking": {
          "type": "enabled",
          "budgetTokens": 10000
        }
      }
    }
  }
}
```

### Когда использовать расширенное мышление

- Сложные цепочки уязвимостей
- Многоэтапное планирование атак
- Обзор кода с глубоким анализом
- Обзор безопасности архитектуры

## Использование токенов

В заголовке TUI сессии CyberStrike показывает **использование контекста** для последнего сообщения ассистента с ненулевым количеством выходных токенов: общее количество токенов (входные, выходные, reasoning и кэш чтения/записи) и, когда модель определяет лимит контекста, **процент от этого лимита**. Также отображается **оценочная стоимость сессии** в USD как сумма `cost` по сообщениям ассистента.

### Кэширование промптов

Для прямых моделей Anthropic (`providerID` / SDK `npm` `@ai-sdk/anthropic`) CyberStrike добавляет **эфемерное** управление кэшем Anthropic к выбранным системным и недавним сообщениям при построении запроса. Отдельного флага `cacheControl` в `provider.anthropic.options` для этого поведения нет.

## Лимиты частоты запросов

Лимиты частоты зависят от вашего аккаунта Anthropic и продукта; актуальные квоты см. в [документации Anthropic](https://docs.anthropic.com).

Для **повторяемых** ошибок API CyberStrike использует **экспоненциальный бэкофф** (начиная с 2 с, удваиваясь за каждую попытку, с максимумом 30 с при отсутствии заголовков `Retry-After`) и учитывает `Retry-After` / `Retry-After-Ms`, когда провайдер их возвращает.

## Лучшие практики

### Выбор модели

| Задача | Рекомендуемая модель |
|--------|---------------------|
| Быстрая разведка | `claude-haiku-4-5` |
| Тестирование веб-приложений | `claude-sonnet-4-5` |
| Сложные эксплойты | `claude-opus-4-5` |
| Обзор кода | `claude-sonnet-4-5` |

### Оптимизация стоимости

1. Используйте Haiku для повторяющихся задач
2. Используйте `/compact` (или `/summarize`) для длинных сессий
3. Ограничивайте контекст фокусированными промптами

### Безопасность

1. Никогда не коммитьте API-ключи в репозитории
2. Используйте переменные окружения
3. Регулярно ротируйте ключи
4. Отслеживайте использование на панели Anthropic

## Устранение неполадок

### Недействительный API-ключ

```
Error: Invalid API key
```

Проверьте ключ:
- Соответствует формату, описанному при подключении Anthropic в приложении (API-ключи обычно начинаются с `sk-ant-api...`)
- Нет завершающих пробелов
- Ключ активен в [console.anthropic.com/settings/keys](https://console.anthropic.com/settings/keys)

### Превышен лимит частоты

```
Error: Rate limit exceeded
```

Решения:
- Подождите и повторите
- Обновите тарифный план
- Используйте меньший контекст

### Модель недоступна

```
Error: Model not found
```

Проверьте, что ID модели верен и модель доступна в вашем регионе.

<Aside variant="tip">
  Используйте Claude Sonnet для большинства задач тестирования безопасности. Оставьте Opus для сложного анализа, требующего более глубоких рассуждений.
</Aside>

## Поддерживаемые провайдеры

| Провайдер | Модели | Лучше всего для |
|-----------|--------|----------------|
| **Anthropic** | Claude Opus 4.5, Sonnet 4, Haiku | Сложные рассуждения, длинный контекст |
| **OpenAI** | GPT-4o, o1, o1-preview | Универсальное использование, быстрые ответы |
| **Google** | Gemini 2.0 Flash, Pro | Мультимодальность, большой контекст |
| **AWS Bedrock** | Claude, Llama, Titan | Корпоративное использование, on-prem |
| **Azure OpenAI** | GPT-4, GPT-4o | Корпоративное соответствие |
| **Google Vertex AI** | Gemini, Claude | Корпоративный GCP |
| **OpenRouter** | Множество моделей | Бесплатный тариф, разнообразие моделей |
| **Groq** | Llama 3.3, Mixtral | Скорость, экономичность |
| **Ollama** | Локальные модели | Конфиденциальность, офлайн-работа |

## Добавление учётных данных

### Подключение провайдера

В TUI выполните `/connect`, чтобы открыть диалог провайдера. Выберите провайдера и введите API-ключ (или авторизуйтесь через OAuth для GitHub Copilot).

### Переменные окружения

Установите API-ключи в окружении:

```bash
# Anthropic
export ANTHROPIC_API_KEY="sk-ant-..."

# OpenAI
export OPENAI_API_KEY="sk-..."

# Google
export GOOGLE_GENERATIVE_AI_API_KEY="AI..."

# OpenRouter
export OPENROUTER_API_KEY="sk-or-..."

# Groq
export GROQ_API_KEY="gsk_..."
```

Добавьте в профиль оболочки (`~/.bashrc` или `~/.zshrc`) для сохранения.

### Файл конфигурации

Храните учётные данные в `~/.config/cyberstrike/cyberstrike.json`:

```json
{
  "provider": {
    "anthropic": {
      "options": {
        "apiKey": "{env:ANTHROPIC_API_KEY}"
      }
    }
  }
}
```

## Anthropic

Модели Claude рекомендуются для сложного анализа безопасности.

### Аутентификация

Выполните `/connect` в TUI, выберите **Anthropic** и введите API-ключ с [console.anthropic.com](https://console.anthropic.com).

Или через переменную окружения:

```bash
export ANTHROPIC_API_KEY="sk-ant-..."
```

### Доступные модели

| Модель | ID | Контекст | Лучше всего для |
|--------|-----|---------|----------------|
| Claude Opus 4.5 | `claude-opus-4-5-20251101` | 200K | Сложный анализ |
| Claude Sonnet 4 | `claude-sonnet-4-20250514` | 200K | Сбалансированная производительность |
| Claude Haiku 4.5 | `claude-haiku-4-5-20251001` | 200K | Быстрые задачи |

### Использование

Используйте `/models` для выбора модели Claude или установите модель по умолчанию в конфигурации:

```json
{
  "model": "anthropic/claude-sonnet-4-20250514"
}
```

### Параметры конфигурации

```json
{
  "provider": {
    "anthropic": {
      "options": {
        "apiKey": "{env:ANTHROPIC_API_KEY}",
        "timeout": 300000
      }
    }
  }
}
```

## OpenRouter

Доступ ко множеству моделей через единый API с бесплатным тарифом.

### Аутентификация

Выполните `/connect` в TUI, выберите **OpenRouter** и введите API-ключ с [openrouter.ai/keys](https://openrouter.ai/keys).

Или через переменную окружения:

```bash
export OPENROUTER_API_KEY="sk-or-..."
```

### Модели бесплатного тарифа

| Модель | ID |
|--------|-----|
| Llama 4 Scout | `meta-llama/llama-4-scout:free` |
| Gemini 2.0 Flash | `google/gemini-2.0-flash:free` |
| Mistral Small | `mistralai/mistral-small-3.2-24b-instruct:free` |

### Использование

Используйте `/models` для выбора модели OpenRouter или установите в конфигурации:

### Конфигурация

```json
{
  "model": "openrouter/meta-llama/llama-4-scout:free",
  "provider": {
    "openrouter": {
      "options": {
        "apiKey": "{env:OPENROUTER_API_KEY}"
      }
    }
  }
}
```

## AWS Bedrock

Использование Claude и других моделей через AWS.

### Аутентификация

Настройте учётные данные AWS:

```bash
# Через AWS CLI
aws configure

# Или через переменные окружения
export AWS_ACCESS_KEY_ID="..."
export AWS_SECRET_ACCESS_KEY="..."
export AWS_REGION="us-east-1"
```

### Доступные модели

| Модель | ID |
|--------|-----|
| Claude Sonnet | `anthropic.claude-sonnet-4-20250514-v1:0` |
| Claude Haiku | `anthropic.claude-haiku-4-5-20251001-v1:0` |
| Llama 3.3 | `meta.llama3-3-70b-instruct-v1:0` |

### Конфигурация

```json
{
  "model": "amazon-bedrock/anthropic.claude-sonnet-4-20250514-v1:0",
  "provider": {
    "amazon-bedrock": {
      "options": {
        "region": "us-east-1"
      }
    }
  }
}
```

## Ollama (локально)

Запуск моделей локально для конфиденциальности и офлайн-работы.

### Настройка

1. Установите Ollama:

```bash
curl -fsSL https://ollama.com/install.sh | sh
```

2. Загрузите модель:

```bash
ollama pull llama3.3
```

3. Запустите Ollama:

```bash
ollama serve
```

### Использование

API-ключ не нужен. Используйте `/models` для выбора модели Ollama.

### Доступные модели

| Модель | Команда загрузки |
|--------|-----------------|
| Llama 3.3 | `ollama pull llama3.3` |
| CodeLlama | `ollama pull codellama` |
| Mistral | `ollama pull mistral` |
| Qwen | `ollama pull qwen2.5` |

### Конфигурация

```json
{
  "model": "ollama/llama3.3",
  "provider": {
    "ollama": {
      "options": {
        "baseURL": "http://localhost:11434"
      }
    }
  }
}
```

## Пользовательский OpenAI-совместимый

Подключение к любому OpenAI-совместимому API.

### Конфигурация

```json
{
  "provider": {
    "custom-api": {
      "id": "custom-api",
      "name": "Custom API",
      "options": {
        "baseURL": "https://api.custom.example.com/v1",
        "apiKey": "{env:CUSTOM_API_KEY}"
      },
      "models": {
        "custom-model": {
          "name": "Custom Model",
          "contextLength": 32000
        }
      }
    }
  }
}
```

### Использование

Используйте `/models` для выбора пользовательской модели или установите в конфигурации.

## Советы по выбору провайдера

### Для сложного анализа безопасности

Используйте Claude Opus 4.5 или Sonnet 4:

```json
{
  "model": "anthropic/claude-opus-4-5-20251101"
}
```

### Для экономичности

Используйте бесплатный тариф OpenRouter или Groq:

```json
{
  "model": "openrouter/meta-llama/llama-4-scout:free"
}
```

### Для конфиденциальности

Используйте Ollama с локальными моделями:

```json
{
  "model": "ollama/llama3.3"
}
```

### Для корпоративного использования

Используйте AWS Bedrock или Azure OpenAI с учётными данными вашей организации.

## Управление учётными данными

Используйте `/status` в TUI для просмотра подключённых провайдеров и активных учётных данных.

Для удаления учётных данных используйте CLI-команду `cyberstrike auth logout` и выберите провайдера для удаления.

<Aside variant="tip">
  Для задач тестирования на проникновение, требующих сложных рассуждений, мы рекомендуем **Claude Opus 4.5** или **Claude Sonnet 4**.
</Aside>

Шаблоны разрешений обеспечивают детальное управление, сопоставляя аргумент инструмента (строку команды, путь к файлу) с glob-шаблоном и связывая его с действием.

## Формат

Запись разрешения — это либо одно действие, либо карта **glob -> действие**. Синтаксиса `Tool(pattern)` и массивов allow/deny нет — ключ инструмента группирует его шаблоны:

```json
{
  "permission": {
    "bash": {
      "*": "ask",
      "ls *": "allow",
      "git status": "allow",
      "rm -rf *": "deny"
    },
    "edit": {
      "reports/**": "allow",
      ".env*": "deny"
    }
  }
}
```

Glob сопоставляется с аргументом инструмента: для `bash` это строка команды, для `edit`/`read` — путь к файлу.

## Подстановочные знаки

Поддерживаются только два подстановочных знака:

| Токен | Совпадения |
|-------|-----------|
| `*` | любая последовательность символов (включая `/`) |
| `?` | любой одиночный символ |

<Aside variant="caution">
  `*` и `?` — **единственные** подстановочные знаки. Символы `[`, `]`, `{`, `}`, `(`, `)` и `|` сопоставляются **буквально**. `**` не существует (ведёт себя так же, как `*`), а отрицание (`!pattern`) не поддерживается.
</Aside>

Шаблон, заканчивающийся на пробел + `*`, также совпадает с командой без аргументов — поэтому `"ls *"` совпадает и с `ls`, и с `ls -la`.

## Приоритет

Когда несколько шаблонов совпадают, побеждает **более специфичный (длинный) шаблон**. Шаблоны оцениваются от самого короткого, и применяется последнее совпадение — так что широкий `"*": "ask"` может быть переопределён более длинным `"git status": "allow"`:

```json
{
  "permission": {
    "bash": {
      "*": "ask",
      "npm *": "allow",
      "npm publish*": "deny"
    }
  }
}
```

Здесь `npm test` разрешён, а `npm publish` запрещён.

## Примеры

### Разрешить набор инструментов, заблокировать опасные части

```json
{
  "permission": {
    "bash": {
      "*": "ask",
      "git *": "allow",
      "git push*": "ask",
      "rm -rf *": "deny"
    }
  }
}
```

### Ограничить редактирование определённым каталогом

```json
{
  "permission": {
    "edit": {
      "*": "deny",
      "src/**": "allow",
      "src/secrets/**": "deny"
    }
  }
}
```

Cyberstrike поддерживает GitHub Copilot как ИИ-провайдер. Аутентифицируйтесь через аккаунт GitHub с помощью OAuth и получите доступ ко всем моделям, доступным через вашу подписку Copilot — включая Claude, GPT-4o и модели серии o.

## Требования

- Аккаунт GitHub с активной подпиской **GitHub Copilot** (Individual, Business или Enterprise)
- Для GitHub Enterprise: URL вашего сервера GHE

## Аутентификация

GitHub Copilot использует **OAuth device flow** — API-ключ не требуется.

### Вход

В TUI выполните:

```
/connect
```

Выберите **Login with GitHub Copilot** из списка провайдеров, затем выберите вариант развёртывания:

| Развёртывание | Когда использовать |
|---------------|-------------------|
| **GitHub.com** | Личные аккаунты или аккаунты организаций на github.com |
| **GitHub Enterprise** | Самостоятельно размещённый GHE или инстансы с резидентностью данных |

Cyberstrike открывает окно браузера для авторизации GitHub. Введите код устройства, показанный в терминале, авторизуйте приложение, и токен OAuth сохраняется автоматически.

## Доступные модели

Доступные модели зависят от тарифа вашей подписки Copilot. Распространённые модели:

| Модель | Провайдер |
|--------|----------|
| `claude-sonnet-4-20250514` | Anthropic (через Copilot) |
| `claude-sonnet-5-5` | Anthropic (через Copilot) |
| `gpt-4o` | OpenAI (через Copilot) |
| `o3-mini` | OpenAI (через Copilot) |

Выполните `/models`, чтобы увидеть все модели, доступные по вашей подписке, и переключаться между ними.

<Aside variant="info">
  Модели Claude автоматически маршрутизируются через Anthropic Messages API (`/v1/messages`) вместо OpenAI-совместимого эндпоинта (`/chat/completions`). Это происходит прозрачно — настройка не требуется.
</Aside>

## Конфигурация

GitHub Copilot не требует ручной настройки помимо OAuth-входа. Провайдер регистрируется автоматически после аутентификации.

Чтобы использовать модель Copilot по умолчанию:

```json title="cyberstrike.json"
{
  "model": "github-copilot/claude-sonnet-4-20250514"
}
```

### GitHub Enterprise

Для инстансов GHE вам будет предложено ввести URL сервера при входе:

```
? Enter your GitHub Enterprise URL or domain
> company.ghe.com
```

Эндпоинт Copilot API определяется из вашего домена GHE автоматически.

## Как это работает

1. **OAuth device flow** — Cyberstrike запрашивает код устройства у GitHub, вы авторизуетесь в браузере
2. **Обмен токенов** — OAuth-токен (`ghu_...`) обменивается на краткоживущий токен сессии Copilot (~30 мин TTL)
3. **Автообновление** — токены сессии обновляются автоматически до истечения
4. **Маршрутизация моделей** — модели Claude используют Anthropic Messages API; все остальные — OpenAI-совместимый эндпоинт

## Устранение неполадок

| Проблема | Решение |
|----------|---------|
| **401 Unauthorized** | Выполните `/connect` снова — токен сессии мог истечь |
| **Нет доступных моделей** | Проверьте, активна ли подписка Copilot на github.com/settings/copilot |
| **GHE connection refused** | Проверьте URL enterprise и что Copilot включён на вашем инстансе GHE |
| **Claude model 404** | Обновите Cyberstrike — исправление маршрутизации Claude вышло в v1.1.16+ |

<Aside variant="tip">
  GitHub Copilot — отличный вариант, если у вас уже есть подписка — отдельный API-ключ не нужен, и вы получаете доступ к моделям от нескольких провайдеров через один вход.
</Aside>

Cyberstrike — это инструмент наступательной безопасности с поддержкой ИИ. Вы описываете цель — веб-приложение, API, сеть — и Cyberstrike проводит оценку. Он выбирает инструменты, запускает подходящих агентов, тестирует уязвимости и сообщает о результатах.

Представьте это как ИИ-пентестера, работающего вместе с вами. Вы сохраняете контроль через единый разговорный интерфейс, пока система выполняет тяжёлую работу: сканирование, анализ трафика, тестирование инъекций, проверки авторизации и поиск цепочек из отдельных результатов.

Под капотом система объединяет 100+ инструментов безопасности, 15+ специализированных агентов, 65+ детерминированных тестовых скриптов на основе OWASP WSTG, а также выделенные движки для [веб-сканирования](/docs/features/hackbrowser), [анализа трафика](/docs/features/vortex), [контейнерных инструментов](/docs/features/bolt) и [внешних интеграций](/docs/features/mcp).

## Системные требования

Перед установкой Cyberstrike убедитесь, что ваша система соответствует этим требованиям:

| Требование | Минимум | Рекомендовано |
|------------|---------|---------------|
| Операционная система | macOS 12+, Ubuntu 20.04+, Windows 10+ | macOS 14+, Ubuntu 22.04+ |
| Оперативная память | 4 ГБ | 8 ГБ |
| Дисковое пространство | 500 МБ | 2 ГБ |
| Node.js | 18.0+ | 20.0+ |

## Установка Cyberstrike

Выберите предпочтительный метод установки в зависимости от вашей операционной системы и менеджера пакетов.

### npm (Рекомендуется)

1. Откройте терминал
2. Выполните команду установки:

```bash
npm install -g @cyberstrike-io/cyberstrike@latest
```

3. Проверьте установку:

```bash
cyberstrike --version
```

Поддержка Homebrew пока недоступна.

### curl (Linux/macOS)

Выполните скрипт установки:

```bash
curl -fsSL https://cyberstrike.io/install | bash
```

### iwr (Windows/Powershell)

Выполните скрипт установки:

```bash
iwr -useb https://cyberstrike.io/install.ps1 | iex
```

<Aside variant="caution">
  Проверяйте скрипты перед их выполнением. Скрипт установки доступен на [github.com/CyberStrikeus/CyberStrike](https://github.com/CyberStrikeus/CyberStrike).
</Aside>

### Docker

<Aside variant="caution">
  Образ Docker скоро будет доступен. Пока используйте npm или curl.
</Aside>

## Подключение ИИ-провайдера

<div className="rounded-lg overflow-hidden my-6 border border-gray-200 dark:border-gray-700">
  <img src="/docs/images/gifs/g02-auth-login.gif" alt="Процесс авторизации Cyberstrike" className="w-full" />
</div>

Для работы Cyberstrike требуется ИИ-провайдер. Поддерживаются следующие провайдеры:

| Провайдер | Бесплатный план | Метод авторизации |
|-----------|-----------------|-------------------|
| GitHub Copilot | С подпиской | OAuth (без API-ключа) |
| OpenRouter | Да | API-ключ |
| Anthropic | Нет | API-ключ |
| OpenAI | Нет | API-ключ |
| Google Gemini | Да | API-ключ |
| Ollama | Да (Локально) | Не требуется |

### Настройка аутентификации

<div className="rounded-lg overflow-hidden my-6 border border-gray-200 dark:border-gray-700">
  <img src="/docs/images/screenshots/s02-auth.jpg" alt="Диалог выбора модели Cyberstrike" className="w-full" />
</div>

1. Запустите Cyberstrike и выполните команду подключения:

```
/connect
```

2. Выберите провайдера из списка и введите API-ключ (или авторизуйтесь через OAuth для GitHub Copilot)

3. Сменить модель можно в любой момент с помощью:

```
/models
```

### Использование переменных окружения

Альтернативно, установите API-ключи как переменные окружения:

```bash
# Anthropic
export ANTHROPIC_API_KEY="sk-ant-..."

# OpenAI
export OPENAI_API_KEY="sk-..."

# Google
export GOOGLE_GENERATIVE_AI_API_KEY="AI..."

# OpenRouter
export OPENROUTER_API_KEY="sk-or-..."
```

Добавьте их в профиль оболочки (`~/.bashrc`, `~/.zshrc`) для сохранения между сессиями.

### Описание цели

Введите задачу напрямую. Система решит, что запускать:

```
> Test https://app.example.com for OWASP Top 10 vulnerabilities
```

Что происходит под капотом:

1. Первичный агент `cyberstrike` читает вашу цель
2. `/hackbrowser` запускается для сканирования цели и захвата HTTP-трафика
3. [Vortex](/docs/features/vortex) обрабатывает каждый запрос — применяет правила, отмечает аномалии
4. `wstg-agent` направляет специализированных агентов на основе сигналов запросов
5. 13 специалистов WSTG тестируют инъекции, обход авторизации, IDOR, проблемы сессий, криптографические уязвимости и другое
6. `escalation-hunter` связывает находки для обнаружения составных уязвимостей
7. Агент `triage` независимо проверяет каждую находку, воспроизводя HTTP-доказательства
8. Вы получаете проверенные находки с доказательствами, уровнем серьёзности и рекомендациями по исправлению

### Что входит в систему

| Уровень | Описание |
|---------|----------|
| **Агенты** | 15+ специализированных агентов — конвейер WSTG, триаж, эскалация, общий, исследование |
| **Инструменты** | 100+ встроенных инструментов — воспроизведение HTTP, проверки инъекций, проверки доступа, разведка, поиск по коду |
| **Навыки** | 65+ детерминированных тестовых скриптов WSTG, загружаемых специалистами во время выполнения |
| **Vortex** | HTTP-движок трафика с DSL-запросами, сопоставлением правил и корреляцией сигналов |
| **HackBrowser** | ИИ-управляемый сканер на Chromium с захватом контекста UI |
| **Bolt** | 30+ контейнерных инструментов безопасности (nmap, nuclei, sqlmap, hydra и другие) |
| **MCP** | 3 встроенных сервера (github-security, cve, osint) + любой пользовательский MCP-сервер |

Вы работаете с одним приглашением для ввода. Система оркестрирует всё остальное.

## Конфигурация

Создайте файл `cyberstrike.json` в каталоге проекта для установки параметров по умолчанию:

```json title="cyberstrike.json"
{
  "$schema": "https://cyberstrike.io/config.json",
  "model": "anthropic/claude-sonnet-4-20250514"
}
```

При запуске `cyberstrike` в этом каталоге настройки загружаются автоматически. Вы также можете сменить модель в любой момент с помощью `/models` в TUI.

### Иерархия конфигурации

Cyberstrike загружает конфигурацию из нескольких источников в следующем порядке:

1. Переменные окружения (наивысший приоритет)
2. Конфигурация проекта (`cyberstrike.json`)
3. Пользовательская конфигурация (`~/.config/cyberstrike/cyberstrike.json`)
4. Значения по умолчанию (наименьший приоритет)

Подробные параметры конфигурации см. в [Справочнике по конфигурации](/docs/configuration).

## Основные слэш-команды

| Команда | Действие |
|---------|----------|
| `/connect` | Подключить ИИ-провайдера |
| `/models` | Сменить модель |
| `/hackbrowser` | Запустить автономный веб-сканер |
| `/bolt` | Управление серверами инструментов Bolt |
| `/mcps` | Управление MCP-серверами |
| `/vulnerabilities` | Просмотр находок |
| `/web` | Просмотр захваченного веб-трафика |
| `/report` | Создать отчёт |
| `/help` | Показать все команды |

TUI Cyberstrike управляется сочетаниями клавиш на основе лидер-клавиши для эффективной навигации. На этой странице перечислены основные значения по умолчанию. Полный список действий и способы настройки см. в разделе [Привязки клавиш](/docs/configuration/keybindings).

## Лидер-клавиша

Лидер-клавиша по умолчанию — `Ctrl+X`. Многие сочетания используют `<leader>` с последующим нажатием другой клавиши.

Для смены лидер-клавиши:

```json title="~/.config/cyberstrike/cyberstrike.json"
{
  "keybinds": {
    "leader": "ctrl+a"
  }
}
```

## Сочетания для сессий

| Сочетание | Действие |
|-----------|----------|
| `<leader>n` | Новая сессия |
| `<leader>l` | Список сессий |
| `<leader>c` | Сжатие/резюмирование сессии |
| `<leader>g` | Временная шкала сессии |
| `<leader>x` | Экспорт сессии |
| `Ctrl+R` | Переименование сессии |
| `Ctrl+D` | Удаление сессии |
| `Escape` | Прерывание текущей сессии |

## Навигация

| Сочетание | Действие |
|-----------|----------|
| `PageUp` / `PageDown` | Прокрутка на страницу |
| `Ctrl+Alt+U` | Прокрутка вверх на полстраницы |
| `Ctrl+Alt+D` | Прокрутка вниз на полстраницы |
| `Ctrl+G` / `Home` | Переход к первому сообщению |
| `Ctrl+Alt+G` / `End` | Переход к последнему сообщению |
| `<leader>y` | Копирование сообщения |
| `<leader>u` | Отмена сообщения (откат) |
| `<leader>r` | Повтор сообщения |

## Ввод

| Сочетание | Действие |
|-----------|----------|
| `Enter` | Отправить сообщение |
| `Shift+Enter` | Новая строка |
| `Ctrl+V` | Вставить |
| `Ctrl+C` | Очистить ввод |
| `Escape` | Прервать текущую сессию |

## Модель и агент

| Сочетание | Действие |
|-----------|----------|
| `<leader>m` | Выбор модели |
| `<leader>a` | Выбор агента |
| `Tab` | Следующий агент |
| `Shift+Tab` | Предыдущий агент |

## Интерфейс

| Сочетание | Действие |
|-----------|----------|
| `<leader>t` | Выбор темы |
| `<leader>s` | Просмотр статуса |
| `<leader>b` | Переключение боковой панели |
| `<leader>e` | Открыть во внешнем редакторе |
| `Ctrl+P` | Список команд |

## Диалоги

Когда диалог открыт (выбор модели, список сессий и т.д.), перемещайтесь стрелками, нажимайте `Enter` для выбора и `Escape` для закрытия. Несколько привязок специфичных для диалогов:

| Сочетание | Действие |
|-----------|----------|
| `Ctrl+F` | Переключить избранное модели (в диалоге моделей) |
| `F2` / `Shift+F2` | Перейти к следующей / предыдущей недавней модели |

## Запросы разрешений

Когда инструменту требуется одобрение, появляется встроенный запрос с тремя вариантами — **Разрешить один раз**, **Разрешить всегда** и **Отклонить**. Используйте стрелки и `Enter` для выбора; `Escape` отклоняет.

## Настройка привязок клавиш

Переопределите значения по умолчанию в разделе `keybinds` вашей конфигурации. Принимаются только допустимые имена действий (объект проверяется строго):

```json title="~/.config/cyberstrike/cyberstrike.json"
{
  "keybinds": {
    "leader": "ctrl+x",
    "app_exit": "ctrl+c,ctrl+d,<leader>q",
    "session_new": "<leader>n",
    "session_list": "<leader>l",
    "model_list": "<leader>m",
    "agent_list": "<leader>a",
    "theme_list": "<leader>t",
    "status_view": "<leader>s",
    "sidebar_toggle": "<leader>b",
    "editor_open": "<leader>e",
    "session_export": "<leader>x",
    "session_timeline": "<leader>g",
    "session_rename": "ctrl+r"
  }
}
```

Все настраиваемые действия и их значения по умолчанию см. в разделе [Привязки клавиш](/docs/configuration/keybindings).

## Формат привязок клавиш

- **Модификаторы**: `ctrl`, `alt`, `shift`, `super`
- **Специальные клавиши**: `return`, `escape`, `tab`, `space`, `backspace`, `pageup`, `pagedown`, `home`, `end`
- **Лидер**: `<leader>` (заменяется настроенной лидер-клавишей)
- **Альтернативы**: `ctrl+c,ctrl+d` (запятая разделяет альтернативные привязки для одного действия)
- **Отключение**: `none`

### Примеры

```
ctrl+alt+u          # Ctrl + Alt + U
alt+shift+f         # Alt + Shift + F
<leader>n           # Лидер-клавиша, затем N
ctrl+c,ctrl+d       # любая из привязок активирует действие
```

Встроенные инструменты (bash, read, edit, ...) всегда доступны. **MCP-инструменты загружаются по запросу**, чтобы подключение сервера с сотнями инструментов не перегружало контекст модели. Этим управляют четыре инструмента.

## Инструменты загрузки

| Инструмент | Назначение |
|------------|-----------|
| `tool_search` | Поиск MCP-инструментов по возможности (`query`, необязательный `limit`) |
| `load_tools` | Загрузка конкретных инструментов в активный контекст |
| `unload_tools` | Удаление загруженных инструментов для освобождения контекста |
| `list_loaded_tools` | Отображение текущих загруженных инструментов |

Агент использует их автоматически: ищет возможность, загружает подходящий MCP-инструмент, вызывает его и может выгрузить после использования.

### tool_search

```json
{
  "query": "sql injection testing",
  "limit": 10
}
```

Возвращает подходящие MCP-инструменты с описаниями. Встроенные инструменты не нужно искать — они всегда доступны для вызова.

## Ленивая vs постоянная загрузка

- **Всегда доступны** — все встроенные инструменты (`bash`, `read`, `edit`, `glob`, `grep`, `write`, `task`, `webfetch`, `websearch`, инструменты памяти, ...).
- **Загружаются по запросу** — инструменты, предоставляемые подключёнными MCP-серверами (включая [Bolt](/docs/mcp/bolt)). Обнаруживаются через `tool_search` и загружаются через `load_tools`.

## Отключение инструмента

Конфигурация `tools` — это карта имя инструмента -> boolean. Установите `false` для отключения:

```json title="cyberstrike.json"
{
  "tools": {
    "websearch": false
  }
}
```

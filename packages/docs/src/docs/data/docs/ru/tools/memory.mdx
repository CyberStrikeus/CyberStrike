Инструменты памяти позволяют агенту вести заметки — результаты, данные о целях, контекст — которые сохраняются между сессиями как Markdown-файлы в вашем проекте.

## Инструменты памяти

Существует четыре инструмента памяти — операций удаления, очистки, экспорта или импорта нет:

| Инструмент | Назначение |
|------------|-----------|
| `memory_write` | Добавление заметки в память |
| `memory_read` | Чтение сохранённой памяти |
| `memory_search` | Поиск по сохранённым заметкам |
| `memory_context` | Загрузка релевантной памяти в текущий контекст |

## Структура хранилища

Память — это обычный Markdown в `.cyberstrike/`:

```
.cyberstrike/
├── MEMORY.md              ← долгосрочная память
└── memory/
    └── 2026-07-03.md      ← датированные ежедневные заметки
```

- **`MEMORY.md`** хранит устойчивые, долгосрочные факты.
- **`memory/<YYYY-MM-DD>.md`** — файлы ежедневных заметок; каждый начинается с заголовка `# Daily Notes - <date>` и дополняется по ходу сессии.

Глобальная память (общая для всех проектов) расположена в `~/.config/cyberstrike/memory/`.

Поскольку всё хранится как Markdown на диске, вы можете читать, редактировать и управлять версиями как любой другой файл проекта.

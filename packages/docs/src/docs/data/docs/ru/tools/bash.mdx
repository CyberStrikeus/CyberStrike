## Обзор

Инструмент Bash позволяет:

- Запускать инструменты безопасности (nmap, nuclei, sqlmap)
- Выполнять команды системного администрирования
- Проводить git-операции
- Управлять пакетами
- Запускать пользовательские скрипты

## Базовое использование

### Простые команды

```
> Run nmap scan on 192.168.1.1
```

Выполняет:
```bash
nmap -sV 192.168.1.1
```

### С аргументами

```
> Check open ports on target with service detection
```

Выполняет:
```bash
nmap -sV -sC -p- 192.168.1.1
```

### Конвейерные команды

```
> Find all .env files and search for API keys
```

Выполняет:
```bash
find . -name "*.env*" -exec grep -l "API" {} \;
```

## Инструменты безопасности

### Сканирование сети

```
> Scan the network 10.0.0.0/24 for live hosts
```

```bash
nmap -sn 10.0.0.0/24
```

### Сканирование уязвимостей

```
> Run nuclei templates against https://target.com
```

```bash
nuclei -u https://target.com -t cves/
```

### Веб-тестирование

```
> Fuzz directories on target website
```

```bash
ffuf -u https://target.com/FUZZ -w /usr/share/wordlists/dirb/common.txt
```

### Атаки на пароли

```
> Test for default credentials on SSH
```

```bash
hydra -L users.txt -P passwords.txt ssh://192.168.1.1
```

## Таймаут команд

### Таймаут по умолчанию

Таймаут команд по умолчанию — 120 секунд.

### Долго выполняющиеся команды

Для длительных операций:

```
> Run comprehensive port scan (may take a while)
```

Агент использует подходящий таймаут:
```bash
timeout 600 nmap -p- -sV 192.168.1.1
```

### Фоновое выполнение

```
> Start the scan in background
```

```bash
nmap -p- 192.168.1.1 > scan_results.txt &
```

## Рабочий каталог

### Текущий каталог

Команды выполняются в текущем рабочем каталоге:

```
> List files in current directory
```

```bash
ls -la
```

### Смена каталога

```
> Navigate to the web directory and list contents
```

```bash
cd /var/www/html && ls -la
```

## Переменные окружения

### Использование переменных

```
> Use the target IP from environment
```

```bash
nmap -sV $TARGET_IP
```

### Установка переменных

```
> Set target and scan
```

```bash
export TARGET="192.168.1.1" && nmap $TARGET
```

## Обработка вывода

### Захват вывода

```
> Save scan results to file
```

```bash
nmap -sV 192.168.1.1 -oN scan_results.txt
```

### JSON-вывод

```
> Get scan results in JSON format
```

```bash
nmap -sV 192.168.1.1 -oX - | xq .
```

### Разбор результатов

```
> Extract open ports from nmap output
```

```bash
grep "^[0-9]" scan_results.txt | cut -d'/' -f1
```

## Контроль разрешений

### Опасные команды

Деструктивные команды требуют явного разрешения:

| Тип команды | Пример | Требует разрешения |
|-------------|--------|-------------------|
| Только чтение | `ls`, `cat`, `nmap` | Нет |
| Модификация файлов | `rm`, `mv` | Да |
| Системные изменения | `apt install` | Да |
| Сетевые атаки | `msfconsole` | Да |

### Автоматическое одобрение команд

```json title="~/.config/cyberstrike/cyberstrike.json"
{
  "permission": {
    "bash": {
      "nmap *": "allow",
      "nuclei *": "allow",
      "ffuf *": "allow"
    }
  }
}
```

### Блокировка опасных команд

```json
{
  "permission": {
    "bash": {
      "rm -rf *": "deny",
      "dd *": "deny",
      ":(){ :|:& };:": "deny"
    }
  }
}
```

Разрешение `bash` сопоставляет glob-шаблон (по строке команды) с действием (`ask`, `allow` или `deny`). В качестве подстановочных знаков поддерживаются только `*` и `?`. Полную модель разрешений см. в [Разрешения](/docs/permissions).

## Рабочие процессы тестирования безопасности

### Разведка

```
> Perform initial reconnaissance on target.com

1. DNS enumeration
2. Subdomain discovery
3. Port scanning
4. Service identification
```

Выполняет несколько команд:

```bash
dig target.com ANY
subfinder -d target.com
nmap -sV -sC target.com
```

### Эксплуатация

```
> Attempt SQL injection with sqlmap
```

```bash
sqlmap -u "https://target.com/page?id=1" --batch --dbs
```

### Пост-эксплуатация

```
> Enumerate the compromised system
```

```bash
uname -a
id
cat /etc/passwd
ls -la /home/
```

## Обработка ошибок

### Ошибки команд

Неудавшиеся команды показывают вывод ошибки:

```
Command failed:
$ nmap -sV nonexistent.host
Host seems down. If it is really up, but blocking our ping probes, try -Pn
```

### Логика повторных попыток

```
> Retry the scan with -Pn flag
```

```bash
nmap -sV -Pn 192.168.1.1
```

## Лучшие практики

1. **Проверяйте цели** — перепроверяйте IP-адреса и домены
2. **Используйте таймауты** — устанавливайте подходящие таймауты для длительных сканирований
3. **Сохраняйте результаты** — всегда сохраняйте важные результаты
4. **Проверяйте разрешения** — убедитесь в авторизованном доступе
5. **Убирайте за собой** — удаляйте временные файлы после тестирования

<Aside variant="danger">
  Никогда не запускайте команды против целей без авторизации. Несанкционированный доступ незаконен.
</Aside>

## Устранение неполадок

### Команда не найдена

```
Error: command not found: nuclei
```

Установите инструмент или проверьте PATH:

```bash
which nuclei
export PATH=$PATH:/opt/tools
```

### Отказ в доступе

```
Error: permission denied
```

Может потребоваться sudo:

```bash
sudo nmap -sS 192.168.1.1
```

### Таймаут

```
Error: command timed out
```

Используйте явный таймаут или фоновое выполнение.

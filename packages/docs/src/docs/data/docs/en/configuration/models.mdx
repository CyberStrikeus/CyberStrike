CyberStrike supports **9,000+ models** across **230+ providers** through a live catalog powered by [models.dev](https://models.dev). New models appear automatically — no upgrade needed.

Run `/models` in the TUI to browse what's available with your configured providers, or use `--model provider/model-id` at launch.

## How Model Selection Works

CyberStrike uses two model slots:

| Slot | Purpose | Default |
|------|---------|---------|
| **model** | Primary reasoning — orchestration, analysis, exploit research | Your configured default |
| **small_model** | Fast tasks — tool selection, quick classification, summaries | Auto-selected or configured |

Set them in `cyberstrike.json`:

```json title="cyberstrike.json"
{
  "model": "anthropic/claude-sonnet-5-5",
  "small_model": "anthropic/claude-haiku-5-5"
}
```

Or at launch:

```bash
cyberstrike --model anthropic/claude-opus-5-5
```

Or switch mid-session with `/models` in the TUI — it shows all models from your configured providers, sorted by capability.

## Model Capabilities

Every model in the catalog carries metadata that CyberStrike uses for routing and feature gating:

| Capability | What It Means |
|------------|--------------|
| **Context** | Maximum tokens the model can process (input + output combined) |
| **Output** | Maximum tokens the model can generate in a single response |
| **Tool Call** | Whether the model can invoke tools — required for agent-driven testing |
| **Reasoning** | Whether the model supports extended thinking / chain-of-thought |
| **Attachment** | Whether the model accepts file attachments (images, PDFs) |
| **Input Modalities** | What the model can read: text, image, audio, video, PDF |
| **Output Modalities** | What the model can produce: text, image, audio |

<Aside variant="caution">
  Models without **tool call** support cannot drive CyberStrike's security testing tools. They can still be used for analysis and conversation, but agents won't be able to execute probes or queries.
</Aside>

### Reasoning Options

Models with reasoning support may offer different ways to control it:

| Option | How It Works |
|--------|-------------|
| **effort** | Set reasoning intensity: `low`, `medium`, `high` — the model adjusts how much it thinks |
| **toggle** | Enable or disable reasoning entirely |
| **budget_tokens** | Set a specific token budget for the thinking process |

Configure reasoning in `cyberstrike.json`:

```json title="cyberstrike.json"
{
  "provider": {
    "anthropic": {
      "options": {
        "thinking": {
          "type": "enabled",
          "budgetTokens": 10000
        }
      }
    }
  }
}
```

## Custom & Self-Hosted Models

Any OpenAI-compatible endpoint works with CyberStrike. Define it in `cyberstrike.json`:

```json title="cyberstrike.json"
{
  "provider": {
    "my-llm": {
      "name": "My Local LLM",
      "api": "http://localhost:8000/v1",
      "models": {
        "my-model": {
          "name": "My Model",
          "limit": { "context": 128000, "output": 16384 },
          "tool_call": true
        }
      }
    }
  },
  "model": "my-llm/my-model"
}
```

Common self-hosted setups:

| Software | Default URL |
|----------|------------|
| vLLM | `http://localhost:8000/v1` |
| LM Studio | `http://localhost:1234/v1` |
| Ollama | `http://localhost:11434/v1` |
| text-generation-webui | `http://localhost:5000/v1` |

## Filtering Models

Control which models appear with whitelist and blacklist:

```json title="cyberstrike.json"
{
  "provider": {
    "anthropic": {
      "whitelist": ["claude-opus-5-5", "claude-sonnet-5-5", "claude-haiku-5-5"],
      "blacklist": ["claude-fable-5", "claude-fable-5-1"]
    }
  }
}
```

Or disable entire providers:

```json title="cyberstrike.json"
{
  "disabled_providers": ["openrouter", "groq"],
  "enabled_providers": ["anthropic", "openai"]
}
```

## Live Catalog

The model catalog refreshes automatically from [models.dev](https://models.dev) every hour. You can also force a refresh by restarting CyberStrike.

To override the catalog source:

```bash
CYBERSTRIKE_MODELS_URL=https://my-mirror.example.com cyberstrike
CYBERSTRIKE_MODELS_PATH=/path/to/local/models.json cyberstrike
CYBERSTRIKE_DISABLE_MODELS_FETCH=true cyberstrike
```

<Aside variant="tip">
  This page shows a snapshot of available models. The live catalog at [models.dev](https://models.dev) has the most current list. Run `/models` in CyberStrike for real-time availability based on your configured providers.
</Aside>

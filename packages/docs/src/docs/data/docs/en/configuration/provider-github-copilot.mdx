Cyberstrike supports GitHub Copilot as an AI provider. Authenticate with your GitHub account via OAuth and access all models available through your Copilot subscription — including Claude, GPT-4o, and o-series models.

## Requirements

- A GitHub account with an active **GitHub Copilot** subscription (Individual, Business, or Enterprise)
- For GitHub Enterprise: your GHE server URL

## Authentication

GitHub Copilot uses the **OAuth device flow** — no API key required.

### Login

In the TUI, run:

```
/connect
```

Select **Login with GitHub Copilot** from the provider list, then choose your deployment:

| Deployment | When to use |
|------------|-------------|
| **GitHub.com** | Personal or org accounts on github.com |
| **GitHub Enterprise** | Self-hosted GHE or data residency instances |

Cyberstrike opens a browser window for GitHub authorization. Enter the device code shown in the terminal, authorize the app, and the OAuth token is saved automatically.

## Available Models

The models available depend on your Copilot subscription tier. Common models include:

| Model | Provider |
|-------|----------|
| `claude-sonnet-4-20250514` | Anthropic (via Copilot) |
| `claude-sonnet-5-5` | Anthropic (via Copilot) |
| `gpt-4o` | OpenAI (via Copilot) |
| `o3-mini` | OpenAI (via Copilot) |

Run `/models` to see all models available on your subscription and switch between them.

<Aside variant="info">
  Claude models are automatically routed through the Anthropic Messages API (`/v1/messages`) instead of the OpenAI-compatible endpoint (`/chat/completions`). This happens transparently — no configuration needed.
</Aside>

## Configuration

GitHub Copilot requires no manual configuration beyond the OAuth login. The provider is registered automatically after authentication.

To use a Copilot model as default:

```json title="cyberstrike.json"
{
  "model": "github-copilot/claude-sonnet-4-20250514"
}
```

### GitHub Enterprise

For GHE instances, you'll be prompted for your server URL during login:

```
? Enter your GitHub Enterprise URL or domain
> company.ghe.com
```

The Copilot API endpoint is derived from your GHE domain automatically.

## How It Works

1. **OAuth device flow** — Cyberstrike requests a device code from GitHub, you authorize in the browser
2. **Token exchange** — The OAuth token (`ghu_...`) is exchanged for a short-lived Copilot session token (~30 min TTL)
3. **Auto-refresh** — Session tokens are refreshed automatically before expiry
4. **Model routing** — Claude models use the Anthropic Messages API; all others use the OpenAI-compatible endpoint

## Troubleshooting

| Issue | Fix |
|-------|-----|
| **401 Unauthorized** | Run `/connect` again — your session token may have expired |
| **No models available** | Check your Copilot subscription is active at github.com/settings/copilot |
| **GHE connection refused** | Verify the enterprise URL and that Copilot is enabled on your GHE instance |
| **Claude model 404** | Update Cyberstrike — Claude routing fix shipped in v1.1.16+ |

<Aside variant="tip">
  GitHub Copilot is a great option if you already have a subscription — no separate API key needed, and you get access to models from multiple providers through a single login.
</Aside>

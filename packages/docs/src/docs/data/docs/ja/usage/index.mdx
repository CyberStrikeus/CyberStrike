CyberStrikeはハーネスとの複数の対話方法を提供します：

- **[TUI](/docs/usage/tui)** — リアルタイムのエージェント出力、スラッシュコマンド、キーボードショートカット付きのインタラクティブターミナルインターフェース
- **[CLI](/docs/usage/cli)** — スクリプティング、パイプライン、自動化のための非対話型モード
- **[Web](/docs/usage/web)** — セッションタブ、サイドパネル、統合ターミナル付きのブラウザベースインターフェース
- **[デスクトップアプリ](/docs/usage/desktop-app)** — macOS、Windows、Linux向けのネイティブアプリケーション *（近日公開）*

各インターフェースは同じ基盤エンジンに接続し、セッションを共有するため、自由に切り替えることができます。

## クイックスタート

```bash
# インタラクティブTUI（デフォルト）
cyberstrike

# 非対話型CLI
cyberstrike run "scan example.com for open ports"

# Webインターフェース
cyberstrike web
```

## インターフェースの選択

| インターフェース | 最適な用途 |
|-----------|----------|
| TUI | 日常的なインタラクティブ評価、スラッシュコマンド、キーボード駆動のワークフロー |
| CLI | CI/CDパイプライン、スクリプティング、ツール出力のパイプ |
| Web | チームコラボレーション、ビジュアルサイドパネル、ブラウザベースのワークフロー |
| デスクトップ | ターミナル不要のネイティブエクスペリエンス *（近日公開）* |

すべてのインターフェースは、セキュリティエージェント、MCPツール、AIプロバイダーの全範囲をサポートしています。

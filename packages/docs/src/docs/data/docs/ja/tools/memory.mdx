## メモリツール

4つのメモリツールがあります — 削除、クリア、エクスポート、インポート操作はありません：

| ツール | 目的 |
|------|---------|
| `memory_write` | メモリにノートを追加 |
| `memory_read` | 保存されたメモリを読み取り |
| `memory_search` | 保存されたノートを横断検索 |
| `memory_context` | 関連するメモリを現在のコンテキストに取り込み |

## ストレージレイアウト

メモリは `.cyberstrike/` 配下のプレーンなMarkdownです：

```
.cyberstrike/
├── MEMORY.md              ← 長期メモリ
└── memory/
    └── 2026-07-03.md      ← 日付付きデイリーノート
```

- **`MEMORY.md`** は永続的な長期的事実を保持します。
- **`memory/<YYYY-MM-DD>.md`** ファイルは日ごとのノートです。各ファイルは `# Daily Notes - <date>` の見出しで始まり、セッション中に追記されます。

グローバルメモリ（プロジェクト間で共有）は `~/.config/cyberstrike/memory/` に格納されます。

すべてがディスク上のMarkdownなので、他のプロジェクトファイルと同様に読み取り、編集、バージョン管理できます。

組み込みツール（bash, read, edit, ...）は常に利用可能です。**MCPツールはオンデマンドで読み込まれる**ため、数百のツールを持つサーバーに接続してもモデルのコンテキストが溢れることはありません。4つのツールがこれを制御します。

<img src="/docs/images/diagrams/tool-loading.svg" alt="MCPツール読み込みサイクル：サーバーが数百のツールを公開し、tool_searchが機能で検索、load_toolsがコンテキストに取り込み、エージェントが呼び出し、unload_toolsでコンテキストを解放" className="my-6" />

## 読み込みツール

| ツール | 目的 |
|------|---------|
| `tool_search` | 機能でMCPツールを検索（`query`、オプションの `limit`） |
| `load_tools` | 特定のツールをアクティブコンテキストに読み込み |
| `unload_tools` | 読み込まれたツールを削除してコンテキストを解放 |
| `list_loaded_tools` | 現在読み込まれているツールを表示 |

エージェントはこれらを自動的に使用します：機能を検索し、一致するMCPツールを読み込み、呼び出し、その後アンロードできます。

### tool_search

```json
{
  "query": "sql injection testing",
  "limit": 10
}
```

一致するMCPツールとその説明を返します。組み込みツールは検索不要です — 常に呼び出し可能です。

## 遅延読み込みと常時利用可能

- **常時利用可能** — すべての組み込みツール（`bash`、`read`、`edit`、`glob`、`grep`、`write`、`task`、`webfetch`、`websearch`、メモリツール、...）。
- **オンデマンド読み込み** — 接続されたMCPサーバー（[Bolt](/docs/features/bolt)を含む）が公開するツール。`tool_search` で検出され、`load_tools` で取り込まれます。

## ツールの無効化

`tools` 設定はツール名 → ブール値のマップです。ツールを `false` に設定して無効化します：

```json title="cyberstrike.json"
{
  "tools": {
    "websearch": false
  }
}
```

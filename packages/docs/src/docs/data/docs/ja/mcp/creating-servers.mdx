カスタムMCPサーバーを作成して、専用のツールや統合機能でCyberstrikeを拡張できます。[Bolt](/docs/mcp/bolt)が提供する機能以上のものが必要な場合に便利です。

<img src="/docs/images/diagrams/mcp-server-architecture.svg" alt="MCPサーバーアーキテクチャ: CyberstrikeのMCPクライアントがstdioまたはStreamableHTTP/SSEでトランスポートに接続し、リクエストハンドラー(tools/list、tools/call、resources)とツール関数にルーティング" className="my-6" />

## 概要

MCPサーバーは以下を行います:

- Cyberstrikeにツールを公開
- ツールの実行を処理
- リソースを管理
- 複数のトランスポートをサポート
- カスタム統合を実現

## クイックスタート

### TypeScriptサーバー

```typescript title="src/index.ts"
import { Server } from "@modelcontextprotocol/sdk/server/index.js";
import { StdioServerTransport } from "@modelcontextprotocol/sdk/server/stdio.js";

const server = new Server({
  name: "my-security-tools",
  version: "1.0.0"
}, {
  capabilities: {
    tools: {}
  }
});

// Define tools
server.setRequestHandler("tools/list", async () => ({
  tools: [{
    name: "port-scan",
    description: "Scan ports on a target host",
    inputSchema: {
      type: "object",
      properties: {
        host: { type: "string", description: "Target hostname or IP" },
        ports: { type: "string", description: "Port range (e.g., 1-1000)" }
      },
      required: ["host"]
    }
  }]
}));

// Handle tool calls
server.setRequestHandler("tools/call", async (request) => {
  const { name, arguments: args } = request.params;

  if (name === "port-scan") {
    const result = await scanPorts(args.host, args.ports);
    return { content: [{ type: "text", text: result }] };
  }

  throw new Error(`Unknown tool: ${name}`);
});

// Start server
const transport = new StdioServerTransport();
await server.connect(transport);
```

### Pythonサーバー

```python title="server.py"
import asyncio
from mcp.server import Server
from mcp.server.stdio import stdio_server

server = Server("my-security-tools")

@server.list_tools()
async def list_tools():
    return [{
        "name": "port-scan",
        "description": "Scan ports on a target host",
        "inputSchema": {
            "type": "object",
            "properties": {
                "host": {"type": "string", "description": "Target hostname"},
                "ports": {"type": "string", "description": "Port range"}
            },
            "required": ["host"]
        }
    }]

@server.call_tool()
async def call_tool(name: str, arguments: dict):
    if name == "port-scan":
        result = await scan_ports(arguments["host"], arguments.get("ports"))
        return [{"type": "text", "text": result}]
    raise ValueError(f"Unknown tool: {name}")

async def main():
    async with stdio_server() as streams:
        await server.run(streams[0], streams[1])

asyncio.run(main())
```

## トランスポートオプション

### Stdio (デフォルト)

```typescript
import { StdioServerTransport } from "@modelcontextprotocol/sdk/server/stdio.js";

const transport = new StdioServerTransport();
await server.connect(transport);
```

### HTTP/SSE

```typescript
import { SSEServerTransport } from "@modelcontextprotocol/sdk/server/sse.js";
import express from "express";

const app = express();
const transport = new SSEServerTransport("/sse", app);

app.listen(3000);
await server.connect(transport);
```

<Aside variant="info">
  Cyberstrikeは**stdio**サーバー(ローカル)と**StreamableHTTP/SSE**サーバー(リモート)に接続します。WebSocketクライアントトランスポートはありません -- WebSocketのみのサーバーは構築しないでください。
</Aside>

## Cyberstrikeへの登録

サーバーが動作したら、`cyberstrike.json`に追加します。stdioサーバーは`local`エントリで、`command`は完全なargvです:

```json title="cyberstrike.json"
{
  "mcp": {
    "my-security-tools": {
      "type": "local",
      "command": ["node", "dist/index.js"]
    }
  }
}
```

HTTP/SSEサーバーは`remote`エントリです:

```json
{
  "mcp": {
    "my-security-tools": {
      "type": "remote",
      "url": "https://localhost:3000/sse"
    }
  }
}
```

または、TUIで`/mcps`を使用して対話的に追加できます。完全なスキーマについては[ローカルサーバー](/docs/mcp/local-servers)と[リモートサーバー](/docs/mcp/remote-servers)を参照してください。

## セキュリティに関する考慮事項

### 入力バリデーション

```typescript
function sanitizeHost(host: string): string {
  // Validate host format
  if (!/^[\w.-]+$/.test(host)) {
    throw new Error("Invalid host format");
  }
  return host;
}
```

### コマンドインジェクション防止

```typescript
import { execFile } from "child_process";

// Safe: Uses execFile with array arguments
async function safeScan(host: string): Promise<string> {
  return new Promise((resolve, reject) => {
    execFile("nmap", ["-sV", host], (error, stdout) => {
      if (error) reject(error);
      else resolve(stdout);
    });
  });
}

// Unsafe: Don't do this
// exec(`nmap -sV ${host}`) // Command injection vulnerability!
```

## ベストプラクティス

1. **明確な説明** - ツールを詳細にドキュメント化する
2. **入力バリデーション** - すべての入力をバリデーションする
3. **エラーハンドリング** - 意味のあるエラーを返す
4. **ロギング** - デバッグ用に操作を記録する
5. **テスト** - すべてのツールを徹底的にテストする
6. **セキュリティ** - インジェクション攻撃を防止する

<Aside variant="tip">
  まずはシンプルなstdioトランスポートから始め、リモートアクセスが必要になったらHTTP/SSEを追加してください。
</Aside>

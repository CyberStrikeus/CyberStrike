スキルは、エージェントがオンデマンドで読み込める再利用可能なメソドロジーのMarkdownファイルです。スキルはファイル名で検出されます — すべてのスキルは **`SKILL.md`** という名前のファイルに格納されます。

## ファイルと配置場所

ファイルは `SKILL.md` という名前でなければなりません。Cyberstrikeは `.cyberstrike/` 内の `skill/` または `skills/` ディレクトリ配下、および `skills/`（Claude Code レイアウト）配下で `**/SKILL.md` を検索します：

```
.cyberstrike/
└── skills/
    └── sql-injection/
        └── SKILL.md
```

## フロントマター

`name` と `description` のみ必須です。残りはカテゴリ分けやキルチェーンリンクに使用されるオプションのメタデータです：

```markdown title="SKILL.md"
---
name: sql-injection
description: Methodology for testing SQL injection
version: "1.0.0"
author: you
tags: [injection, database]
category: injection
owasp_id: WSTG-INPV-05
tech_stack: [postgres, mysql]
cwe_ids: [CWE-89]
chains_with: [auth-bypass]
prerequisites: [request-capture]
---

Walk the tester through boolean-, error-, time-, and union-based SQLi:
1. Identify injectable parameters …
2. …
```

<Aside variant="caution">
  本文はプレーンMarkdownです — テンプレート機能は**ありません**（`{{target}}`、`{% if %}`、`{% for %}`、`$ARGUMENTS` などは使用不可）。フロントマターは `args`、`model`、`agent`、`permission` フィールドを**サポートしていません**。また、ファイルは文字通り `SKILL.md` という名前でなければなりません（`my-skill.md` のような任意の名前は読み込まれません）。
</Aside>

フロントマターの `name` はスキルのIDと一致する必要があります — 不一致はエラーとして報告されます。

## スキルの使用

読み込まれたスキルはエージェントから利用可能で、`/skills` コマンドで閲覧できます。エージェントはタスクに関連するスキルのメソドロジーをコンテキストに取り込みます。

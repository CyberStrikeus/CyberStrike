セッションコマンドは現在の会話を管理します — 作成、再開、共有、メッセージ履歴の編集を行います。

<img src="/docs/images/gifs/session-commands.gif" alt="leader+lでセッションピッカーを開く" className="rounded-lg shadow-lg my-6 w-full" />

## ライフサイクル

| コマンド | エイリアス | アクション |
|---------|---------|--------|
| `/new` | `/clear` | **新しい**セッションを開始（`/clear` はエイリアスです — メッセージをクリアするだけではありません） |
| `/sessions` | `/resume`, `/continue` | 過去のセッションを再開するためのセッションピッカーを開く |
| `/rename` | | 現在のセッション名を変更 |
| `/fork` | | 現在の時点からセッションをフォーク |
| `/timeline` | | セッションタイムラインを表示 |
| `/export` | | セッションをエクスポート |
| `/copy` | | 最後のメッセージをコピー |

## メッセージ

| コマンド | エイリアス | アクション |
|---------|---------|--------|
| `/undo` | | 最後のメッセージを元に戻す |
| `/redo` | | やり直す |
| `/compact` | `/summarize` | セッションをコンパクト化（要約）してコンテキストを回復 |
| `/timestamps` | `/toggle-timestamps` | メッセージのタイムスタンプ表示を切替 |
| `/thinking` | `/toggle-thinking` | 思考ブロックの表示を切替 |

## 共有

| コマンド | アクション |
|---------|--------|
| `/share` | 現在のセッションを共有 |
| `/unshare` | 共有を停止 |

<Aside variant="caution">
  `/clear` は `/new` のエイリアスです（新しいセッションを開始します）。`/continue` は `/sessions` のエイリアスです（セッションピッカーを開きます）。`/history`、`/memory`、`/cost`、`/save`、`/tag`、`/note`、`/retry`、`/template` コマンドは存在しません。
</Aside>

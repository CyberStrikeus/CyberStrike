これらのスラッシュコマンドはピッカーとダイアログを開きます。TUIで `/` を入力するとコマンドリストが表示されます（または `Ctrl+P` を押します）。

<img src="/docs/images/gifs/navigation-commands.gif" alt="コマンドリストを開いてピッカーをナビゲートする" className="rounded-lg shadow-lg my-6 w-full" />

## ピッカーとダイアログ

| コマンド | 開くもの |
|---------|-------|
| `/models` | モデルピッカー |
| `/agents` | エージェントピッカー |
| `/themes` | テーマピッカー |
| `/mcps` | MCPサーバーマネージャー |
| `/bolt` | Boltサーバーマネージャー |
| `/connect` | プロバイダーの接続 / 認証 |
| `/sessions` (`/resume`, `/continue`) | セッションピッカー |
| `/editor` | 外部エディタでメッセージを開く |
| `/skills` | 読み込み済みスキルを閲覧 |
| `/help` | ヘルプを表示 |
| `/status` | ステータスを表示 |
| `/exit` | CyberStrikeを終了 |

<Aside variant="caution">
  コマンド名は複数形です：`/models`、`/themes`、`/mcps`（`/model`、`/theme`、`/mcp` ではありません）。`/provider`、`/vim`、`/config`、`/permission`、`/files`、`/cd`、`/tools`、`/version`、`/doctor`、`/docs`、`/changelog`、`/cost`、`/context` コマンドは存在しません。
</Aside>

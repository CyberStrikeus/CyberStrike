`cyberstrike mcp` コマンドはModel Context Protocolサーバーを管理します。サブコマンドは `list`、`add`、`auth`、`logout`、`debug` の5つです。

<Aside variant="caution">
  サーバー設定は `cyberstrike.json` に保存されます（[ローカル](/docs/features/mcp#local-servers) / [リモート](/docs/features/mcp#remote-servers)サーバーを参照）。サーバーはTUIの `/mcps` ダイアログでインタラクティブに管理されます。`mcp status`、`health`、`start`/`stop`/`restart`、`remove`、`config`、`tools`、`logs`、`export`/`import`、`install`、`update` コマンドはありません。
</Aside>

## `mcp list`

```bash
cyberstrike mcp list   # エイリアス: ls
```

設定済みのMCPサーバーを一覧表示します。

## `mcp add`

```bash
cyberstrike mcp add
```

完全にインタラクティブ — ローカル vs リモート、コマンドまたはURL、名前の入力を求め、保存前に接続をテストします。位置引数やフラグは**受け付けません**。サーバー設定をスクリプトで行う場合は、`cyberstrike.json` に直接エントリを書き込んでください。

## `mcp auth`

```bash
cyberstrike mcp auth [name]        # OAuthサーバーを認証
cyberstrike mcp auth list          # OAuth認証済みサーバーを一覧表示
```

OAuthを使用するリモートサーバーを認証します（必要に応じてブラウザが開きます）。[OAuth](/docs/features/mcp#oauth)を参照してください。

## `mcp logout`

```bash
cyberstrike mcp logout [name]
```

サーバーの保存済みOAuth認証情報を削除します。

## `mcp debug`

```bash
cyberstrike mcp debug <name>
```

サーバーの接続を検査します — サーバーの読み込みに失敗したり、ツールが表示されない場合に便利です。

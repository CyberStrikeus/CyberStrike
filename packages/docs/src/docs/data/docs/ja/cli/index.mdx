## コマンド構造

```
cyberstrike [グローバルオプション] <コマンド> [コマンドオプション] [引数]
```

## グローバルオプション

| オプション | エイリアス | 説明 |
|--------|-------|-------------|
| `--help` | `-h` | ヘルプ情報を表示 |
| `--version` | `-v` | バージョン番号を表示 |
| `--print-logs` | | stderrにログを出力 |
| `--log-level` | | ログレベルを設定（DEBUG、INFO、WARN、ERROR） |

## インタラクティブモード

引数なしでターミナルユーザーインターフェースを起動します：

```bash
cyberstrike
```

### インタラクティブモードオプション

| オプション | エイリアス | 説明 |
|--------|-------|-------------|
| `--model <model>` | `-m` | `provider/model` 形式のモデル |
| `--agent <name>` | | 使用するセキュリティエージェント |
| `--continue` | `-c` | 前回のセッションを続行 |
| `--session <id>` | `-s` | 特定のセッションを再開 |

### 例

```bash
# 特定のモデルで開始
cyberstrike --model anthropic/claude-sonnet-4-20250514

# プライマリエージェントを選択（組み込みは 'cyberstrike' のみ）
cyberstrike --agent cyberstrike

# 前回のセッションを続行
cyberstrike --continue
```

## run

インタラクティブモードに入らず、単一のプロンプトを実行します。

```bash
cyberstrike run [message..] [options]
```

### オプション

| オプション | エイリアス | 説明 |
|--------|-------|-------------|
| `--model <model>` | `-m` | `provider/model` 形式のモデル |
| `--agent <name>` | | 使用するエージェント |
| `--continue` | `-c` | 前回のセッションを続行 |
| `--session <id>` | `-s` | 特定のセッションを再開 |
| `--file <path>` | `-f` | メッセージにファイルを添付 |
| `--format <type>` | | 出力形式：`default` または `json` |
| `--share` | | セッションを共有 |
| `--title <text>` | | セッションタイトルを設定 |
| `--attach <url>` | | 実行中のサーバーに接続 |
| `--variant <type>` | | モデルバリアント（high、max、minimal） |

### 例

```bash
# 単一コマンドを実行
cyberstrike run "scan example.com for open ports"

# リクエストにファイルを添付
cyberstrike run "analyze this config" -f nginx.conf

# JSON形式で出力
cyberstrike run "list vulnerabilities" --format json

# 前回のセッションを続行
cyberstrike run "now check for XSS" --continue
```

### パイプ入力

stdinからの入力を受け付けます：

```bash
echo "analyze this code" | cyberstrike run
cat report.txt | cyberstrike run "summarize this"
```

## auth

AIプロバイダーの認証情報を管理します。

### auth login

AIプロバイダーの認証情報を追加します：

```bash
cyberstrike auth login [url]
```

#### インタラクティブログイン

```bash
cyberstrike auth login
# リストからプロバイダーを選択
# プロンプトに従ってAPIキーを入力
```

#### Well-Known URLログイン

```bash
cyberstrike auth login https://custom-provider.example.com
```

### auth logout

保存された認証情報を削除します：

```bash
cyberstrike auth logout
# リストからプロバイダーを選択
```

### auth list

設定済みのすべての認証情報を表示します：

```bash
cyberstrike auth list
```

表示内容：
- プロバイダー別の保存済み認証情報
- 認証タイプ（api、oauth）
- アクティブな環境変数

## mcp

Model Context Protocol（MCP）サーバーを管理します。

### mcp list

設定済みのMCPサーバーとそのステータスを一覧表示します：

```bash
cyberstrike mcp list
```

ステータスインジケーター：
- `✓` 接続済み
- `○` 未初期化 / 無効
- `⚠` 認証が必要
- `✗` 失敗

### mcp add

新しいMCPサーバーをインタラクティブに追加します：

```bash
cyberstrike mcp add
```

ウィザードで以下を設定します：
1. 場所（プロジェクトまたはグローバル）
2. サーバー名
3. サーバータイプ（ローカルまたはリモート）
4. 接続の詳細

#### ローカルサーバーの例

```bash
# `cyberstrike mcp add` 実行後：
# 場所: 現在のプロジェクト
# 名前: filesystem
# タイプ: ローカル
# コマンド: npx @modelcontextprotocol/server-filesystem /path/to/dir
```

#### リモートサーバーの例

```bash
# `cyberstrike mcp add` 実行後：
# 場所: グローバル
# 名前: custom-api
# タイプ: リモート
# URL: https://api.example.com/mcp
# OAuth: Yes/No
```

### mcp auth

OAuth対応のMCPサーバーで認証します：

```bash
cyberstrike mcp auth [name]
```

### mcp auth list

すべてのMCPサーバーのOAuthステータスを一覧表示します：

```bash
cyberstrike mcp auth list
```

### mcp logout

OAuth認証情報を削除します：

```bash
cyberstrike mcp logout [name]
```

### mcp debug

OAuthの接続問題をデバッグします：

```bash
cyberstrike mcp debug <name>
```

## session

会話セッションを管理します。

### session list

すべてのセッションを一覧表示します：

```bash
cyberstrike session list [options]
```

| オプション | エイリアス | 説明 |
|--------|-------|-------------|
| `--max-count <n>` | `-n` | 最新のN件に制限 |
| `--format <type>` | | 出力：`table` または `json` |

### 例

```bash
# 最新10件のセッションを表示
cyberstrike session list -n 10

# JSONとしてエクスポート
cyberstrike session list --format json
```

## serve

Cyberstrike APIサーバーを起動します。`CYBERSTRIKE_SERVER_PASSWORD` の設定が必要です。

```bash
CYBERSTRIKE_SERVER_PASSWORD=secret cyberstrike serve [options]
```

| オプション | 説明 |
|--------|-------------|
| `--port <number>` | サーバーポート（デフォルト：4096） |
| `--hostname <address>` | バインドアドレス |
| `--cors <origin>` | 許可するCORSオリジン |
| `--mdns` | mDNSでサーバーを公開 |

## completion

シェル補完スクリプトを生成します。

```bash
# Bash
cyberstrike completion >> ~/.bashrc

# Zsh
cyberstrike completion >> ~/.zshrc

# Fish
cyberstrike completion | source
```

## 環境変数

環境変数でCyberstrikeの動作を設定します：

| 変数 | 説明 |
|----------|-------------|
| `CYBERSTRIKE_AUTO_SHARE` | セッションを自動共有 |
| `CYBERSTRIKE_PERMISSION` | JSONパーミッションオーバーライド |
| `CYBERSTRIKE_CONFIG` | カスタム設定ファイルのパス |
| `ANTHROPIC_API_KEY` | Anthropic APIキー |
| `OPENAI_API_KEY` | OpenAI APIキー |
| `GOOGLE_GENERATIVE_AI_API_KEY` | Google AI（Gemini）APIキー |
| `OPENROUTER_API_KEY` | OpenRouter APIキー |

## 終了コード

| コード | 意味 |
|------|---------|
| `0` | 成功 |
| `1` | エラー — 無効/不明な引数、または致命的なエラー |
| `130` | 中断（Ctrl+C） |

## 設定ファイル

Cyberstrikeは以下の場所から設定を読み込みます：

| パス | スコープ |
|------|-------|
| `./cyberstrike.json` | プロジェクト |
| `./.cyberstrike/cyberstrike.json` | プロジェクト |
| `~/.config/cyberstrike/cyberstrike.json` | グローバル |

スキーマの詳細は[設定リファレンス](/docs/configuration)を参照してください。

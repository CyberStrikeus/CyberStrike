`general` エージェントは、リサーチ、複雑な質問、マルチステップタスクを処理します。`cyberstrike` プライマリエージェントは、並列実行の恩恵を受ける作業やセキュリティ固有のスペシャリストを必要としない作業を委任します。

## 概要

| プロパティ | 値 |
|----------|-------|
| **エージェントID** | `general` |
| **モード** | `subagent` |
| **ツールアクセス** | 広範（脆弱性報告やトリアージを除く） |

## 使用タイミング

`cyberstrike` エージェントは以下の場合に `general` に委任します：

- 複数のソースにまたがる複雑な質問の調査
- 独立した複数の作業単位の並列実行
- ドメイン固有のセキュリティ知識を必要としないタスク
- ファイル分析、コードレビュー、一般的な推論

## 制限事項

`general` エージェントは以下ができません：

- 脆弱性の報告（`report_vulnerability`：拒否）
- 発見のトリアージ（`triage_vulnerability`：拒否）
- TODO読み取り/書き込み操作へのアクセス

これらの制限により、セキュリティに関わる操作は適切なスペシャリストエージェントに留まります。

`explore` エージェントは、コードベースやファイルシステムの検索に特化した高速な読み取り専用エージェントです。パターンによるファイル検索、キーワードによるコード検索、コードベースの構造に関する質問への回答が可能です。

## 概要

| プロパティ | 値 |
|----------|-------|
| **エージェントID** | `explore` |
| **モード** | `subagent` |
| **ツールアクセス** | 読み取り専用（grep、glob、list、bash、read、web search） |

## 使用タイミング

`cyberstrike` エージェントは以下が必要な場合に `explore` に委任します：

- パターンに一致するファイルの検索（例：`src/components/**/*.tsx`）
- キーワードやシンボルによるコード検索（例：「APIエンドポイント」）
- コードベースの構造に関する質問への回答
- 変更を必要としない素早い検索

## 徹底度レベル

`explore` への委任時に、呼び出し元のエージェントが徹底度レベルを指定します：

| レベル | 動作 |
|-------|----------|
| **quick** | 基本的な絞り込み検索 — 単一の場所、最初の一致 |
| **medium** | 中程度の探索 — 複数の場所 |
| **very thorough** | 命名規則と場所を横断した包括的な分析 |

## 制限事項

`explore` エージェントは厳密に読み取り専用です。以下はできません：

- ファイルの書き込み、編集、作成
- 破壊的なコマンドの実行
- 脆弱性の報告
- いかなる状態の変更

## ビルトイン追加プロバイダー

これらは**既にバンドルされています** -- プロバイダー設定は不要です。APIキーの環境変数を設定し、`provider-id/model`としてモデルを選択するだけです:

| プロバイダーID | 環境変数 | モデルの例 |
|-------------|---------|---------------|
| `groq` | `GROQ_API_KEY` | `groq/llama-3.3-70b-versatile` |
| `togetherai` | `TOGETHER_API_KEY` | `togetherai/meta-llama/Llama-3.3-70B-Instruct-Turbo` |
| `deepinfra` | `DEEPINFRA_API_KEY` | `deepinfra/meta-llama/Llama-3.3-70B-Instruct` |
| `perplexity` | `PERPLEXITY_API_KEY` | `perplexity/sonar` |
| `openrouter` | `OPENROUTER_API_KEY` | `openrouter/anthropic/claude-sonnet-4` |

```bash
export GROQ_API_KEY="gsk_..."
cyberstrike --model groq/llama-3.3-70b-versatile
```

その他(`mistral`、`xai`、`deepseek`、`cohere`、`cerebras`など)も同様に動作します -- キーを設定して`provider-id/model`を使用します。[AIプロバイダー](/docs/configuration/providers)を参照してください。

## カスタムOpenAI互換プロバイダー

バンドルされていないエンドポイント(Fireworks、vLLM、LM Studio、プライベートゲートウェイ)の場合、`provider`の下に定義します。ロードはトップレベルの**`api`**フィールド(ベースURL)によってトリガーされます。`npm`はデフォルトで`@ai-sdk/openai-compatible`になり、使用するモデルをリストします:

```json title="~/.config/cyberstrike/cyberstrike.json"
{
  "provider": {
    "my-endpoint": {
      "name": "My Endpoint",
      "api": "https://api.example.com/v1",
      "options": { "apiKey": "{env:MY_API_KEY}" },
      "models": {
        "my-model": { "name": "My Model" }
      }
    }
  },
  "model": "my-endpoint/my-model"
}
```

### vLLM

```json
{
  "provider": {
    "vllm": {
      "name": "vLLM",
      "api": "http://localhost:8000/v1",
      "models": { "llama-3.3-70b": { "name": "Llama 3.3 70B" } }
    }
  }
}
```

### LM Studio

```json
{
  "provider": {
    "lmstudio": {
      "name": "LM Studio",
      "api": "http://localhost:1234/v1",
      "models": { "local-model": { "name": "Local Model" } }
    }
  }
}
```

<Aside variant="caution">
  設定のみのプロバイダーは`api` URLがあるためにロードされます -- `options.baseURL`だけでは登録されません。トップレベルの`api`フィールドを使用してください。
</Aside>

## Azure OpenAI

```json title="~/.config/cyberstrike/cyberstrike.json"
{
  "provider": {
    "azure": {
      "name": "Azure OpenAI",
      "options": {
        "apiKey": "{env:AZURE_API_KEY}"
      }
    }
  }
}
```

```bash
export AZURE_RESOURCE_NAME="your-resource"
export AZURE_API_KEY="..."
```

## トラブルシューティング

- **401 Unauthorized** -- APIキー環境変数と`{env:VAR}`で参照されていることを確認してください。
- **モデルが見つからない** -- モデルIDがプロバイダーの形式と一致し、カスタムプロバイダーの場合は`models`の下にリストされている必要があります。
- **予期しないレスポンス** -- エンドポイントが完全にOpenAI互換でない可能性があります。ツール呼び出しとストリーミングはプロバイダーによって異なります。

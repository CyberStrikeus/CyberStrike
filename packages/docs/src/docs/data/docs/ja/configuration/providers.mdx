Cyberstrike supports 25+ AI providers. The model catalog is pulled live from [models.dev](https://models.dev) — new models appear automatically. Run `/models` in the TUI to see what's available.

## Adding Credentials

Three ways, in priority order:

### 1. Environment Variables

```bash
export ANTHROPIC_API_KEY="sk-ant-..."
export OPENAI_API_KEY="sk-..."
```

### 2. TUI Login

Run `/connect` in the TUI to open the provider dialog. Select your provider and enter your API key or authorize via OAuth.

Credentials are stored in `~/.local/share/cyberstrike/auth.json`.

### 3. Configuration File

```json title="cyberstrike.json"
{
  "provider": {
    "anthropic": {
      "options": {
        "apiKey": "{env:ANTHROPIC_API_KEY}"
      }
    }
  }
}
```

## Provider Configuration

Each provider entry in `cyberstrike.json` can set:

```json
{
  "provider": {
    "<provider-id>": {
      "name": "Display Name",
      "api": "https://api.example.com/v1",
      "npm": "@ai-sdk/openai-compatible",
      "env": ["MY_API_KEY"],
      "options": {},
      "models": {
        "model-id": {
          "name": "Model Name",
          "id": "api-model-id"
        }
      },
      "blacklist": ["model-to-hide"],
      "whitelist": ["only-these-models"]
    }
  }
}
```

| Field | Purpose |
|-------|---------|
| `api` | Base URL — **triggers provider loading** for custom endpoints |
| `npm` | AI SDK package (defaults to `@ai-sdk/openai-compatible`) |
| `env` | Environment variable names for the API key |
| `options` | Passed to the SDK factory (apiKey, baseURL, timeout, headers, etc.) |
| `models` | Override or add models to the catalog |
| `blacklist` / `whitelist` | Filter which models appear |

## Model Selection

Use `provider-id/model-id` format everywhere:

```json title="cyberstrike.json"
{
  "model": "anthropic/claude-sonnet-4-5"
}
```

Or at launch:

```bash
cyberstrike --model anthropic/claude-sonnet-4-5
```

Or switch mid-session with `/models` in the TUI.

## Disabling / Enabling Providers

```json title="cyberstrike.json"
{
  "disabled_providers": ["openrouter", "groq"],
  "enabled_providers": ["anthropic", "openai"]
}
```

`enabled_providers` is a whitelist — only listed providers appear. `disabled_providers` is a blacklist. They can be combined.

## Model Catalog

CyberStrike pulls model metadata (pricing, context limits, capabilities) from [models.dev](https://models.dev) and caches it locally. The catalog auto-updates, so new models appear without upgrading CyberStrike.

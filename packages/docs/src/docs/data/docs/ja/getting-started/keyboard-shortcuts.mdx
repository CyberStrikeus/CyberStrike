CyberstrikeのTUIは、効率的なナビゲーションのためにリーダーベースのキーボードショートカットで操作します。このページでは一般的なデフォルトを一覧にしています。すべてのアクションの完全なリストとカスタマイズ方法については、[キーバインド](/docs/configuration/keybindings)を参照してください。

## リーダーキー

デフォルトのリーダーキーは`Ctrl+X`です。多くのショートカットは`<leader>`の後に別のキーを押す形式です。

リーダーキーを変更するには：

```json title="~/.config/cyberstrike/cyberstrike.json"
{
  "keybinds": {
    "leader": "ctrl+a"
  }
}
```

## セッションショートカット

| ショートカット | アクション |
|--------------|----------|
| `<leader>n` | 新しいセッション |
| `<leader>l` | セッション一覧 |
| `<leader>c` | セッションの圧縮/要約 |
| `<leader>g` | セッションタイムライン |
| `<leader>x` | セッションのエクスポート |
| `Ctrl+R` | セッション名の変更 |
| `Ctrl+D` | セッションの削除 |
| `Escape` | 実行中のセッションを中断 |

## ナビゲーション

| ショートカット | アクション |
|--------------|----------|
| `PageUp` / `PageDown` | 1ページスクロール |
| `Ctrl+Alt+U` | 半ページ上にスクロール |
| `Ctrl+Alt+D` | 半ページ下にスクロール |
| `Ctrl+G` / `Home` | 最初のメッセージにジャンプ |
| `Ctrl+Alt+G` / `End` | 最後のメッセージにジャンプ |
| `<leader>y` | メッセージをコピー |
| `<leader>u` | メッセージを元に戻す（リバート） |
| `<leader>r` | メッセージをやり直す |

## 入力

| ショートカット | アクション |
|--------------|----------|
| `Enter` | メッセージを送信 |
| `Shift+Enter` | 改行 |
| `Ctrl+V` | 貼り付け |
| `Ctrl+C` | 入力をクリア |
| `Escape` | 実行中のセッションを中断 |

## モデルとエージェント

| ショートカット | アクション |
|--------------|----------|
| `<leader>m` | モデル選択 |
| `<leader>a` | エージェント選択 |
| `Tab` | 次のエージェント |
| `Shift+Tab` | 前のエージェント |

## インターフェース

| ショートカット | アクション |
|--------------|----------|
| `<leader>t` | テーマ選択 |
| `<leader>s` | ステータス表示 |
| `<leader>b` | サイドバーの切り替え |
| `<leader>e` | 外部エディタで開く |
| `Ctrl+P` | コマンドリスト |

## ダイアログ

ダイアログが開いている時（モデル選択、セッション一覧など）、矢印キーで移動し、`Enter`で選択、`Escape`で閉じます。ダイアログ固有のバインドもあります：

| ショートカット | アクション |
|--------------|----------|
| `Ctrl+F` | モデルのお気に入りを切り替え（モデルダイアログ内） |
| `F2` / `Shift+F2` | 次/前の最近のモデルに切り替え |

## 権限プロンプト

ツールが承認を必要とする時、3つのオプション — **1回許可**、**常に許可**、**拒否** — を持つインラインプロンプトが表示されます。矢印キーと`Enter`で選択します。`Escape`は拒否になります。

## キーバインドのカスタマイズ

設定の`keybinds`でデフォルトを上書きします。有効なアクション名のみ受け付けられます（オブジェクトは厳密に検証されます）：

```json title="~/.config/cyberstrike/cyberstrike.json"
{
  "keybinds": {
    "leader": "ctrl+x",
    "app_exit": "ctrl+c,ctrl+d,<leader>q",
    "session_new": "<leader>n",
    "session_list": "<leader>l",
    "model_list": "<leader>m",
    "agent_list": "<leader>a",
    "theme_list": "<leader>t",
    "status_view": "<leader>s",
    "sidebar_toggle": "<leader>b",
    "editor_open": "<leader>e",
    "session_export": "<leader>x",
    "session_timeline": "<leader>g",
    "session_rename": "ctrl+r"
  }
}
```

すべての設定可能なアクションとデフォルト値については[キーバインド](/docs/configuration/keybindings)を参照してください。

## キーバインドの形式

- **修飾キー**: `ctrl`、`alt`、`shift`、`super`
- **特殊キー**: `return`、`escape`、`tab`、`space`、`backspace`、`pageup`、`pagedown`、`home`、`end`
- **リーダー**: `<leader>`（設定されたリーダーキーに置き換わります）
- **代替**: `ctrl+c,ctrl+d`（コンマで1つのアクションに対する代替バインドを区切ります）
- **無効化**: `none`

### 例

```
ctrl+alt+u          # Ctrl + Alt + U
alt+shift+f         # Alt + Shift + F
<leader>n           # リーダーキーの後にN
ctrl+c,ctrl+d       # どちらのバインドでもアクションがトリガーされる
```

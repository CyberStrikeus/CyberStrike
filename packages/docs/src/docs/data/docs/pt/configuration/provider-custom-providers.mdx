## Provedores Extras Integrados

Estes ja estao **integrados** — voce nao precisa de nenhuma configuracao de provedor. Basta definir a variavel de ambiente da chave de API e selecionar um modelo como `provider-id/model`:

| ID do Provedor | Variavel de ambiente | Modelo de exemplo |
|----------------|---------------------|-------------------|
| `groq` | `GROQ_API_KEY` | `groq/llama-3.3-70b-versatile` |
| `togetherai` | `TOGETHER_API_KEY` | `togetherai/meta-llama/Llama-3.3-70B-Instruct-Turbo` |
| `deepinfra` | `DEEPINFRA_API_KEY` | `deepinfra/meta-llama/Llama-3.3-70B-Instruct` |
| `perplexity` | `PERPLEXITY_API_KEY` | `perplexity/sonar` |
| `openrouter` | `OPENROUTER_API_KEY` | `openrouter/anthropic/claude-sonnet-4` |

```bash
export GROQ_API_KEY="gsk_..."
cyberstrike --model groq/llama-3.3-70b-versatile
```

Outros (`mistral`, `xai`, `deepseek`, `cohere`, `cerebras` e mais) funcionam da mesma forma — defina sua chave e use `provider-id/model`. Veja [Provedores de IA](/docs/configuration/providers).

## Provedor Personalizado Compativel com OpenAI

Para um endpoint que nao esta integrado (Fireworks, vLLM, LM Studio, um gateway privado), defina-o sob `provider`. O carregamento e acionado pelo campo de nivel superior **`api`** (a URL base); `npm` padroniza para `@ai-sdk/openai-compatible`, e voce lista os modelos que deseja:

```json title="~/.config/cyberstrike/cyberstrike.json"
{
  "provider": {
    "my-endpoint": {
      "name": "My Endpoint",
      "api": "https://api.example.com/v1",
      "options": { "apiKey": "{env:MY_API_KEY}" },
      "models": {
        "my-model": { "name": "My Model" }
      }
    }
  },
  "model": "my-endpoint/my-model"
}
```

### vLLM

```json
{
  "provider": {
    "vllm": {
      "name": "vLLM",
      "api": "http://localhost:8000/v1",
      "models": { "llama-3.3-70b": { "name": "Llama 3.3 70B" } }
    }
  }
}
```

### LM Studio

```json
{
  "provider": {
    "lmstudio": {
      "name": "LM Studio",
      "api": "http://localhost:1234/v1",
      "models": { "local-model": { "name": "Local Model" } }
    }
  }
}
```

<Aside variant="caution">
  Um provedor somente de config e carregado porque tem uma URL `api` — `options.baseURL` sozinho nao o registrara. Use o campo de nivel superior `api`.
</Aside>

## Azure OpenAI

```json title="~/.config/cyberstrike/cyberstrike.json"
{
  "provider": {
    "azure": {
      "name": "Azure OpenAI",
      "options": {
        "apiKey": "{env:AZURE_API_KEY}"
      }
    }
  }
}
```

```bash
export AZURE_RESOURCE_NAME="your-resource"
export AZURE_API_KEY="..."
```

## Solucao de Problemas

- **401 Unauthorized** — verifique a variavel de ambiente da chave de API e se esta referenciada com `{env:VAR}`.
- **Model not found** — o ID do modelo deve corresponder ao formato do provedor e estar listado em `models` para um provedor personalizado.
- **Unexpected response** — o endpoint pode nao ser totalmente compativel com OpenAI; chamadas de ferramentas e streaming variam por provedor.

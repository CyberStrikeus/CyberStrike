## Visao Geral

Vantagens do Ollama:

- Privacidade completa de dados
- Sem custos de API
- Operacao offline
- Sem limites de taxa
- Controle total sobre modelos

## Instalacao

### macOS

```bash
brew install ollama
```

### Linux

```bash
curl -fsSL https://ollama.com/install.sh | sh
```

### Windows

Baixe em [ollama.com/download](https://ollama.com/download)

## Iniciando o Ollama

```bash
ollama serve
```

O servidor roda em `http://localhost:11434` por padrao.

## Modelos Disponiveis

### Modelos Recomendados

| Modelo | Tamanho | Melhor Para |
|--------|---------|-------------|
| llama3.3:70b | 40GB | Melhor qualidade, requer GPU de alto nivel |
| llama3.3 | 4.7GB | Bom equilibrio de qualidade e velocidade |
| codellama:34b | 19GB | Analise de codigo |
| mistral | 4.1GB | Proposito geral rapido |
| mixtral:8x7b | 26GB | Alta qualidade, eficiente |
| deepseek-coder:33b | 19GB | Revisao de seguranca de codigo |
| qwen2.5:72b | 41GB | Excelente raciocinio |

### Baixar Modelos

```bash
# Recomendado para testes de seguranca
ollama pull llama3.3

# Para revisao de codigo
ollama pull codellama:34b

# Opcao leve
ollama pull mistral
```

## Configuracao

O Ollama **nao** e um provedor integrado — voce o define como um provedor personalizado compativel com OpenAI. A chave e o campo de nivel superior `api` (a URL base, com o sufixo `/v1`):

```json title="~/.config/cyberstrike/cyberstrike.json"
{
  "provider": {
    "ollama": {
      "name": "Ollama",
      "api": "http://localhost:11434/v1",
      "models": {
        "llama3.3": { "name": "Llama 3.3" }
      }
    }
  },
  "model": "ollama/llama3.3"
}
```

### Host Personalizado

Para um servidor Ollama remoto:

```json
{
  "provider": {
    "ollama": {
      "name": "Ollama",
      "api": "http://192.168.1.100:11434/v1",
      "models": { "llama3.3": { "name": "Llama 3.3" } }
    }
  }
}
```

## Configuracao de Modelo

### Comprimento de Contexto

Aumente a janela de contexto:

```bash
ollama run llama3.3 --num-ctx 8192
```

### Camadas GPU

Controle o uso de GPU:

```bash
OLLAMA_NUM_GPU=999 ollama serve  # Usar todas as camadas GPU
OLLAMA_NUM_GPU=0 ollama serve    # Apenas CPU
```

## Modelos Personalizados

### Criar Modelfile

```dockerfile title="Modelfile"
FROM llama3.3

SYSTEM """
You are a security testing assistant specialized in:
- Web application vulnerabilities
- Code security review
- Network penetration testing

Always follow OWASP guidelines and report findings with:
- Vulnerability name
- Severity (Critical/High/Medium/Low)
- Evidence
- Remediation steps
"""

PARAMETER temperature 0.7
PARAMETER num_ctx 8192
```

### Construir Modelo Personalizado

```bash
ollama create security-assistant -f Modelfile
```

## Otimizacao de Desempenho

### Requisitos de Hardware

| Tamanho do Modelo | RAM Minima | GPU Recomendada |
|-------------------|-----------|-----------------|
| 7B | 8GB | 8GB VRAM |
| 13B | 16GB | 12GB VRAM |
| 34B | 32GB | 24GB VRAM |
| 70B | 64GB | 48GB VRAM |

### Quantizacao

Use modelos quantizados para menor uso de memoria:

```bash
ollama pull llama3.3:q4_0  # quantizacao 4-bit
ollama pull llama3.3:q8_0  # quantizacao 8-bit
```

## Uso Offline

### Pre-baixar Modelos

```bash
ollama pull llama3.3
ollama pull codellama
```

### Sistemas Air-Gapped

1. Baixe modelos em um sistema conectado
2. Copie `~/.ollama/models/` para o sistema air-gapped
3. Execute Ollama sem internet

## Implantacao Docker

```bash
docker run -d \
  --gpus all \
  -v ollama:/root/.ollama \
  -p 11434:11434 \
  --name ollama \
  ollama/ollama
```

## Solucao de Problemas

### Conexao Recusada

Certifique-se que o Ollama esta rodando:

```bash
ollama serve
```

### Sem Memoria

Solucoes:
- Use modelo menor
- Use versao quantizada
- Reduza comprimento de contexto
- Defina `OLLAMA_NUM_GPU=0` para CPU

<Aside variant="tip">
  Para melhores resultados, use llama3.3:70b com uma GPU de alto nivel. Para sistemas com recursos limitados, mistral oferece boa qualidade com requisitos menores.
</Aside>

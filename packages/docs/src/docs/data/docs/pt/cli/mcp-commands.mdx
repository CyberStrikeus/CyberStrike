Os comandos `cyberstrike mcp` gerenciam servidores Model Context Protocol. Existem cinco subcomandos: `list`, `add`, `auth`, `logout` e `debug`.

## `mcp list`

```bash
cyberstrike mcp list   # alias: ls
```

Lista os servidores MCP configurados.

## `mcp add`

```bash
cyberstrike mcp add
```

Totalmente interativo — solicita local vs remoto, o comando ou URL e um nome, depois testa a conexao antes de salvar. Nao aceita **nenhum** nome posicional ou flags; para automatizar a configuracao de servidores, escreva a entrada em `cyberstrike.json` diretamente.

## `mcp auth`

```bash
cyberstrike mcp auth [name]        # autorizar um servidor OAuth
cyberstrike mcp auth list          # listar servidores OAuth autorizados
```

Autoriza um servidor remoto que usa OAuth (abre o navegador se necessario). Veja [OAuth](/docs/features/mcp#oauth).

## `mcp logout`

```bash
cyberstrike mcp logout [name]
```

Remove credenciais OAuth armazenadas de um servidor.

## `mcp debug`

```bash
cyberstrike mcp debug <name>
```

Inspeciona a conexao de um servidor — util quando um servidor nao carrega ou suas ferramentas nao aparecem.

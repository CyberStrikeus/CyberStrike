## Estrutura de Comando

```
cyberstrike [opcoes-globais] <comando> [opcoes-do-comando] [argumentos]
```

## Opcoes Globais

| Opcao | Alias | Descricao |
|-------|-------|-----------|
| `--help` | `-h` | Exibir informacoes de ajuda |
| `--version` | `-v` | Mostrar numero da versao |
| `--print-logs` | | Imprimir logs no stderr |
| `--log-level` | | Definir nivel de log (DEBUG, INFO, WARN, ERROR) |

## Modo Interativo

Inicie a interface de terminal sem argumentos:

```bash
cyberstrike
```

### Opcoes do Modo Interativo

| Opcao | Alias | Descricao |
|-------|-------|-----------|
| `--model <model>` | `-m` | Modelo no formato `provider/model` |
| `--agent <name>` | | Agente de seguranca a usar |
| `--continue` | `-c` | Continuar ultima sessao |
| `--session <id>` | `-s` | Retomar sessao especifica |

### Exemplos

```bash
# Iniciar com modelo especifico
cyberstrike --model anthropic/claude-sonnet-4-20250514

# Selecionar um agente primario (apenas 'cyberstrike' vem integrado)
cyberstrike --agent cyberstrike

# Continuar sessao anterior
cyberstrike --continue
```

## run

Executar um unico prompt sem entrar no modo interativo.

```bash
cyberstrike run [message..] [options]
```

### Opcoes

| Opcao | Alias | Descricao |
|-------|-------|-----------|
| `--model <model>` | `-m` | Modelo no formato `provider/model` |
| `--agent <name>` | | Agente a usar |
| `--continue` | `-c` | Continuar ultima sessao |
| `--session <id>` | `-s` | Retomar sessao especifica |
| `--file <path>` | `-f` | Anexar arquivo(s) a mensagem |
| `--format <type>` | | Formato de saida: `default` ou `json` |
| `--share` | | Compartilhar a sessao |
| `--title <text>` | | Definir titulo da sessao |
| `--attach <url>` | | Conectar a servidor em execucao |
| `--variant <type>` | | Variante do modelo (high, max, minimal) |

### Exemplos

```bash
# Executar comando unico
cyberstrike run "scan example.com for open ports"

# Anexar arquivo a requisicao
cyberstrike run "analyze this config" -f nginx.conf

# Saida como JSON
cyberstrike run "list vulnerabilities" --format json

# Continuar sessao anterior
cyberstrike run "now check for XSS" --continue
```

### Redirecionamento de Entrada

Aceitar entrada do stdin:

```bash
echo "analyze this code" | cyberstrike run
cat report.txt | cyberstrike run "summarize this"
```

## auth

Gerenciar credenciais de autenticacao para provedores de IA.

### auth login

Adicionar credenciais para um provedor de IA:

```bash
cyberstrike auth login [url]
```

#### Login Interativo

```bash
cyberstrike auth login
# Selecione o provedor da lista
# Insira a chave de API quando solicitado
```

#### Login por URL Well-Known

```bash
cyberstrike auth login https://custom-provider.example.com
```

### auth logout

Remover credenciais armazenadas:

```bash
cyberstrike auth logout
# Selecione o provedor da lista
```

### auth list

Exibir todas as credenciais configuradas:

```bash
cyberstrike auth list
```

A saida mostra:
- Credenciais armazenadas por provedor
- Tipo de autenticacao (api, oauth)
- Variaveis de ambiente ativas

## mcp

Gerenciar servidores Model Context Protocol (MCP).

### mcp list

Listar servidores MCP configurados e seu status:

```bash
cyberstrike mcp list
```

Indicadores de status:
- `✓` Conectado
- `○` Nao inicializado / Desabilitado
- `⚠` Necessita autenticacao
- `✗` Falhou

### mcp add

Adicionar um novo servidor MCP interativamente:

```bash
cyberstrike mcp add
```

O assistente solicita:
1. Localizacao (projeto ou global)
2. Nome do servidor
3. Tipo de servidor (local ou remoto)
4. Detalhes de conexao

#### Exemplo de Servidor Local

```bash
# Apos executar `cyberstrike mcp add`:
# Location: Current project
# Name: filesystem
# Type: Local
# Command: npx @modelcontextprotocol/server-filesystem /path/to/dir
```

#### Exemplo de Servidor Remoto

```bash
# Apos executar `cyberstrike mcp add`:
# Location: Global
# Name: custom-api
# Type: Remote
# URL: https://api.example.com/mcp
# OAuth: Yes/No
```

### mcp auth

Autenticar com um servidor MCP habilitado para OAuth:

```bash
cyberstrike mcp auth [name]
```

### mcp auth list

Listar status OAuth de todos os servidores MCP:

```bash
cyberstrike mcp auth list
```

### mcp logout

Remover credenciais OAuth:

```bash
cyberstrike mcp logout [name]
```

### mcp debug

Depurar problemas de conexao OAuth:

```bash
cyberstrike mcp debug <name>
```

## session

Gerenciar sessoes de conversa.

### session list

Listar todas as sessoes:

```bash
cyberstrike session list [options]
```

| Opcao | Alias | Descricao |
|-------|-------|-----------|
| `--max-count <n>` | `-n` | Limitar a N sessoes recentes |
| `--format <type>` | | Saida: `table` ou `json` |

### Exemplos

```bash
# Listar 10 sessoes mais recentes
cyberstrike session list -n 10

# Exportar como JSON
cyberstrike session list --format json
```

## serve

Iniciar o servidor API do Cyberstrike. Requer `CYBERSTRIKE_SERVER_PASSWORD` definido.

```bash
CYBERSTRIKE_SERVER_PASSWORD=secret cyberstrike serve [options]
```

| Opcao | Descricao |
|-------|-----------|
| `--port <number>` | Porta do servidor (padrao: 4096) |
| `--hostname <address>` | Endereco de bind |
| `--cors <origin>` | Origem CORS permitida |
| `--mdns` | Anunciar o servidor via mDNS |

## Variaveis de Ambiente

Configure o comportamento do Cyberstrike por variaveis de ambiente:

| Variavel | Descricao |
|----------|-----------|
| `CYBERSTRIKE_AUTO_SHARE` | Auto-compartilhar sessoes |
| `CYBERSTRIKE_PERMISSION` | Sobrescrita de permissao em JSON |
| `CYBERSTRIKE_CONFIG` | Caminho para arquivo de configuracao personalizado |
| `ANTHROPIC_API_KEY` | Chave de API Anthropic |
| `OPENAI_API_KEY` | Chave de API OpenAI |
| `GOOGLE_GENERATIVE_AI_API_KEY` | Chave de API Google AI (Gemini) |
| `OPENROUTER_API_KEY` | Chave de API OpenRouter |

---

## Codigos de Saida

| Codigo | Significado |
|--------|-------------|
| `0` | Sucesso |
| `1` | Erro — argumentos invalidos/desconhecidos, ou erro fatal |
| `130` | Interrompido (Ctrl+C) |

## Arquivos de Configuracao

O Cyberstrike le a configuracao destes locais:

| Caminho | Escopo |
|---------|--------|
| `./cyberstrike.json` | Projeto |
| `./.cyberstrike/cyberstrike.json` | Projeto |
| `~/.config/cyberstrike/cyberstrike.json` | Global |

Consulte a [Referencia de Configuracao](/docs/configuration) para detalhes do schema.

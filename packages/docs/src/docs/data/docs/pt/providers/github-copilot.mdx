O Cyberstrike suporta GitHub Copilot como provedor de IA. Autentique com sua conta GitHub via OAuth e acesse todos os modelos disponiveis pela sua assinatura Copilot — incluindo Claude, GPT-4o e modelos da serie o.

## Requisitos

- Uma conta GitHub com uma assinatura ativa do **GitHub Copilot** (Individual, Business ou Enterprise)
- Para GitHub Enterprise: a URL do seu servidor GHE

## Autenticacao

O GitHub Copilot usa o **fluxo de dispositivo OAuth** — nenhuma chave de API necessaria.

### Login

Na TUI, execute:

```
/connect
```

Selecione **Login with GitHub Copilot** na lista de provedores, entao escolha sua implantacao:

| Implantacao | Quando usar |
|-------------|-------------|
| **GitHub.com** | Contas pessoais ou de organizacao no github.com |
| **GitHub Enterprise** | Instancias GHE auto-hospedadas ou de residencia de dados |

O Cyberstrike abre uma janela do navegador para autorizacao GitHub. Insira o codigo de dispositivo mostrado no terminal, autorize o app e o token OAuth e salvo automaticamente.

## Modelos Disponiveis

Os modelos disponiveis dependem do tier da sua assinatura Copilot. Modelos comuns incluem:

| Modelo | Provedor |
|--------|----------|
| `claude-sonnet-4-20250514` | Anthropic (via Copilot) |
| `claude-sonnet-5-5` | Anthropic (via Copilot) |
| `gpt-4o` | OpenAI (via Copilot) |
| `o3-mini` | OpenAI (via Copilot) |

Execute `/models` para ver todos os modelos disponiveis na sua assinatura e alternar entre eles.

<Aside variant="info">
  Modelos Claude sao automaticamente roteados pela API de Mensagens da Anthropic (`/v1/messages`) em vez do endpoint compativel com OpenAI (`/chat/completions`). Isso acontece transparentemente — nenhuma configuracao necessaria.
</Aside>

## Configuracao

O GitHub Copilot nao requer configuracao manual alem do login OAuth. O provedor e registrado automaticamente apos a autenticacao.

Para usar um modelo Copilot como padrao:

```json title="cyberstrike.json"
{
  "model": "github-copilot/claude-sonnet-4-20250514"
}
```

### GitHub Enterprise

Para instancias GHE, voce sera solicitado pela URL do seu servidor durante o login:

```
? Enter your GitHub Enterprise URL or domain
> company.ghe.com
```

O endpoint da API Copilot e derivado do seu dominio GHE automaticamente.

## Como Funciona

1. **Fluxo de dispositivo OAuth** — Cyberstrike solicita um codigo de dispositivo do GitHub, voce autoriza no navegador
2. **Troca de token** — O token OAuth (`ghu_...`) e trocado por um token de sessao Copilot de curta duracao (~30 min TTL)
3. **Auto-renovacao** — Tokens de sessao sao renovados automaticamente antes de expirar
4. **Roteamento de modelos** — Modelos Claude usam a API de Mensagens da Anthropic; todos os outros usam o endpoint compativel com OpenAI

## Solucao de Problemas

| Problema | Solucao |
|----------|---------|
| **401 Unauthorized** | Execute `/connect` novamente — seu token de sessao pode ter expirado |
| **Nenhum modelo disponivel** | Verifique se sua assinatura Copilot esta ativa em github.com/settings/copilot |
| **Conexao recusada GHE** | Verifique a URL enterprise e se o Copilot esta habilitado na sua instancia GHE |
| **Claude model 404** | Atualize o Cyberstrike — correcao de roteamento Claude enviada na v1.1.16+ |

<Aside variant="tip">
  GitHub Copilot e uma otima opcao se voce ja tem uma assinatura — nenhuma chave de API separada necessaria, e voce tem acesso a modelos de multiplos provedores com um unico login.
</Aside>

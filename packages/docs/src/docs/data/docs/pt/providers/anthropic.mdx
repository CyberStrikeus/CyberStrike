Os modelos Claude da Anthropic oferecem capacidades avancadas de raciocinio para analise de seguranca. Este guia cobre configuracao e boas praticas.

<img src="/docs/images/screenshots/anthropic-model-select.png" alt="Seletor de modelos filtrado para modelos Anthropic Claude" className="rounded-lg shadow-lg my-6 w-full" />

## Modelos Disponiveis

O Cyberstrike busca seu catalogo de modelos ao vivo em [models.dev](https://models.dev), entao a lista exata acompanha o que a Anthropic oferece atualmente. Escolhas comuns:

| Modelo | Contexto | Melhor para |
|--------|----------|-------------|
| `anthropic/claude-opus-4-5` | 200K | Raciocinio mais profundo — analise complexa, pesquisa de exploits |
| `anthropic/claude-sonnet-4-5` | 200K | Padrao equilibrado — testes de seguranca gerais |
| `anthropic/claude-haiku-4-5` | 200K | Rapido, baixo custo — varreduras rapidas, alto volume |

<Aside variant="tip">
  Modelos flagship mais recentes (Opus 4.6/4.7/4.8, Sonnet 4.6/5, Fable 5) e todo outro modelo Claude aparecem automaticamente conforme models.dev atualiza. Execute `/models` para a lista completa atual. Aliases com `-latest` (ex: `claude-opus-4-5`) rastreiam o release mais recente de uma familia; IDs datados (ex: `claude-opus-4-5-20251101`) fixam uma versao especifica.
</Aside>

## Autenticacao

### Configuracao de Chave de API

1. Obtenha sua chave de API em [console.anthropic.com](https://console.anthropic.com)
2. Na TUI, execute `/connect`, selecione **Anthropic** e insira sua chave de API

### Variavel de Ambiente

```bash
export ANTHROPIC_API_KEY="sk-ant-..."
```

Adicione ao seu perfil de shell para persistencia:

```bash
echo 'export ANTHROPIC_API_KEY="sk-ant-..."' >> ~/.zshrc
```

### Arquivo de Configuracao

```json title="~/.config/cyberstrike/cyberstrike.json"
{
  "provider": {
    "anthropic": {
      "options": {
        "apiKey": "{env:ANTHROPIC_API_KEY}"
      }
    }
  }
}
```

## Configuracao de Modelo

### Definir Modelo Padrao

```json title="~/.config/cyberstrike/cyberstrike.json"
{
  "model": "anthropic/claude-sonnet-4-5"
}
```

### Trocando Modelos

Use `/models` na TUI para abrir o seletor de modelos e selecionar um modelo Claude diferente.

## Raciocinio Estendido

Habilite raciocinio estendido para analise de seguranca complexa:

```json title="~/.config/cyberstrike/cyberstrike.json"
{
  "provider": {
    "anthropic": {
      "options": {
        "thinking": {
          "type": "enabled",
          "budgetTokens": 10000
        }
      }
    }
  }
}
```

### Quando Usar Raciocinio Estendido

- Cadeias de vulnerabilidades complexas
- Planejamento de ataques multi-etapa
- Revisao de codigo com analise profunda
- Revisao de seguranca de arquitetura

## Uso de Tokens

No cabecalho da sessao TUI, o CyberStrike mostra **uso de contexto** para a mensagem de assistente mais recente com tokens de saida nao-zero: um total de tokens (entrada, saida, raciocinio e leitura/escrita de cache) e, quando o modelo define um limite de contexto, uma **porcentagem desse limite**. Tambem mostra **custo estimado da sessao** em USD como a soma de `cost` nas mensagens de assistente.

### Cache de Prompt

Para modelos Anthropic diretos (`providerID` / SDK `npm` `@ai-sdk/anthropic`), o CyberStrike adiciona controle de cache **efemero** da Anthropic a mensagens de sistema e recentes selecionadas ao construir a requisicao. Nao existe um flag `cacheControl` separado em `provider.anthropic.options` para esse comportamento.

## Limites de Taxa

Limites de taxa dependem da sua conta e produto Anthropic; consulte a [documentacao da Anthropic](https://docs.anthropic.com) para cotas atuais.

Para erros de API **retentaveis**, o CyberStrike usa **backoff exponencial** (comecando em 2s, dobrando por tentativa, limitado a 30s quando nenhum header `Retry-After` esta presente) e honra `Retry-After` / `Retry-After-Ms` quando o provedor os retorna.

## Boas Praticas

### Selecao de Modelo

| Tarefa | Modelo Recomendado |
|--------|-------------------|
| Reconhecimento rapido | `claude-haiku-4-5` |
| Testes de app web | `claude-sonnet-4-5` |
| Exploits complexos | `claude-opus-4-5` |
| Revisao de codigo | `claude-sonnet-4-5` |

### Otimizacao de Custos

1. Use Haiku para tarefas repetitivas
2. Use `/compact` (ou `/summarize`) para sessoes longas
3. Limite o contexto com prompts focados

### Seguranca

1. Nunca commite chaves de API em repositorios
2. Use variaveis de ambiente
3. Rotacione chaves periodicamente
4. Monitore uso no dashboard da Anthropic

## Solucao de Problemas

### Chave de API Invalida

```
Error: Invalid API key
```

Verifique sua chave:
- Corresponde ao formato descrito ao conectar Anthropic no app (chaves de API tipicamente comecam com `sk-ant-api...`)
- Sem espacos em branco no final
- Chave esta ativa em [console.anthropic.com/settings/keys](https://console.anthropic.com/settings/keys)

### Limite de Taxa Excedido

```
Error: Rate limit exceeded
```

Solucoes:
- Aguarde e tente novamente
- Atualize seu tier
- Use contexto menor

### Modelo Nao Disponivel

```
Error: Model not found
```

Verifique se o ID do modelo esta correto e disponivel na sua regiao.

<Aside variant="tip">
  Use Claude Sonnet para a maioria das tarefas de testes de seguranca. Reserve Opus para analises complexas que requerem raciocinio mais profundo.
</Aside>

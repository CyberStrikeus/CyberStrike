## Adicionando Credenciais

### Conectar um Provedor

Na TUI, execute `/connect` para abrir o dialogo de provedores. Selecione seu provedor e insira sua chave de API (ou autorize via OAuth para GitHub Copilot).

### Variaveis de Ambiente

Defina chaves de API no seu ambiente:

```bash
# Anthropic
export ANTHROPIC_API_KEY="sk-ant-..."

# OpenAI
export OPENAI_API_KEY="sk-..."

# Google
export GOOGLE_GENERATIVE_AI_API_KEY="AI..."

# OpenRouter
export OPENROUTER_API_KEY="sk-or-..."

# Groq
export GROQ_API_KEY="gsk_..."
```

Adicione ao seu perfil do shell (`~/.bashrc` ou `~/.zshrc`) para persistencia.

### Arquivo de Configuracao

Armazene credenciais em `~/.config/cyberstrike/cyberstrike.json`:

```json
{
  "provider": {
    "anthropic": {
      "options": {
        "apiKey": "{env:ANTHROPIC_API_KEY}"
      }
    }
  }
}
```

## Anthropic

Modelos Claude sao recomendados para analise de seguranca complexa.

### Autenticacao

Execute `/connect` na TUI, selecione **Anthropic** e insira sua chave de API de [console.anthropic.com](https://console.anthropic.com).

Ou via ambiente:

```bash
export ANTHROPIC_API_KEY="sk-ant-..."
```

### Modelos Disponiveis

| Modelo | ID | Contexto | Melhor Para |
|--------|-----|---------|-------------|
| Claude Opus 4.5 | `claude-opus-4-5-20251101` | 200K | Analise complexa |
| Claude Sonnet 4 | `claude-sonnet-4-20250514` | 200K | Desempenho equilibrado |
| Claude Haiku 4.5 | `claude-haiku-4-5-20251001` | 200K | Tarefas rapidas |

### Uso

Use `/models` para selecionar um modelo Claude, ou defina um padrao na configuracao:

```json
{
  "model": "anthropic/claude-sonnet-4-20250514"
}
```

### Opcoes de Configuracao

```json
{
  "provider": {
    "anthropic": {
      "options": {
        "apiKey": "{env:ANTHROPIC_API_KEY}",
        "timeout": 300000
      }
    }
  }
}
```

## OpenAI

Modelos GPT-4 fornecem respostas rapidas e confiaveis.

### Autenticacao

Execute `/connect` na TUI, selecione **OpenAI** e insira sua chave de API de [platform.openai.com](https://platform.openai.com).

Ou via ambiente:

```bash
export OPENAI_API_KEY="sk-..."
```

### Modelos Disponiveis

| Modelo | ID | Contexto | Melhor Para |
|--------|-----|---------|-------------|
| GPT-4o | `gpt-4o` | 128K | Proposito geral |
| GPT-4o Mini | `gpt-4o-mini` | 128K | Eficiencia de custo |
| o1 | `o1` | 200K | Raciocinio complexo |
| o1 Preview | `o1-preview` | 128K | Tarefas avancadas |

### Uso

Use `/models` para selecionar um modelo OpenAI, ou defina um na configuracao.

### Opcoes de Configuracao

```json

  "provider": {

      "options": {
        "apiKey": "{env:OPENAI_API_KEY}",
        "baseURL": "https://api.openai.com/v1"
      }
    }
  }
}
```

## OpenRouter

Acesse muitos modelos por uma unica API com nivel gratuito.

### Autenticacao

Execute `/connect` na TUI, selecione **OpenRouter** e insira sua chave de API de [openrouter.ai/keys](https://openrouter.ai/keys).

Ou via ambiente:

```bash
export OPENROUTER_API_KEY="sk-or-..."
```

### Modelos do Nivel Gratuito

| Modelo | ID |
|--------|-----|
| Llama 4 Scout | `meta-llama/llama-4-scout:free` |
| Gemini 2.0 Flash | `google/gemini-2.0-flash:free` |
| Mistral Small | `mistralai/mistral-small-3.2-24b-instruct:free` |

### Uso

Use `/models` para selecionar um modelo OpenRouter, ou defina um na configuracao:

### Configuracao

```json
{
  "model": "openrouter/meta-llama/llama-4-scout:free",
  "provider": {
    "openrouter": {
      "options": {
        "apiKey": "{env:OPENROUTER_API_KEY}"
      }
    }
  }
}
```

## AWS Bedrock

Use Claude e outros modelos pela AWS.

### Autenticacao

Configure credenciais AWS:

```bash
# Via AWS CLI
aws configure

# Ou via ambiente
export AWS_ACCESS_KEY_ID="..."
export AWS_SECRET_ACCESS_KEY="..."
export AWS_REGION="us-east-1"
```

### Modelos Disponiveis

| Modelo | ID |
|--------|-----|
| Claude Sonnet | `anthropic.claude-sonnet-4-20250514-v1:0` |
| Claude Haiku | `anthropic.claude-haiku-4-5-20251001-v1:0` |
| Llama 3.3 | `meta.llama3-3-70b-instruct-v1:0` |

### Configuracao

```json
{
  "model": "amazon-bedrock/anthropic.claude-sonnet-4-20250514-v1:0",
  "provider": {
    "amazon-bedrock": {
      "options": {
        "region": "us-east-1"
      }
    }
  }
}
```

## Ollama (Local)

Execute modelos localmente para privacidade e uso offline.

### Configuracao

1. Instale o Ollama:

```bash
curl -fsSL https://ollama.com/install.sh | sh
```

2. Baixe um modelo:

```bash
ollama pull llama3.3
```

3. Inicie o Ollama:

```bash
ollama serve
```

### Uso

Nenhuma chave de API necessaria. Use `/models` para selecionar um modelo Ollama.

### Modelos Disponiveis

| Modelo | Comando Pull |
|--------|-------------|
| Llama 3.3 | `ollama pull llama3.3` |
| CodeLlama | `ollama pull codellama` |
| Mistral | `ollama pull mistral` |
| Qwen | `ollama pull qwen2.5` |

### Configuracao

```json
{
  "model": "ollama/llama3.3",
  "provider": {
    "ollama": {
      "options": {
        "baseURL": "http://localhost:11434"
      }
    }
  }
}
```

## OpenAI-Compatible Personalizado

Conecte a qualquer API compativel com OpenAI.

### Configuracao

```json
{
  "provider": {
    "custom-api": {
      "id": "custom-api",
      "name": "Custom API",
      "options": {
        "baseURL": "https://api.custom.example.com/v1",
        "apiKey": "{env:CUSTOM_API_KEY}"
      },
      "models": {
        "custom-model": {
          "name": "Custom Model",
          "contextLength": 32000
        }
      }
    }
  }
}
```

### Uso

Use `/models` para selecionar o modelo personalizado, ou defina na configuracao.

## Dicas de Selecao de Provedor

### Para Analise de Seguranca Complexa

Use Claude Opus 4.5 ou Sonnet 4:

```json
{
  "model": "anthropic/claude-opus-4-5-20251101"
}
```

### Para Eficiencia de Custo

Use o nivel gratuito do OpenRouter ou Groq:

```json
{
  "model": "openrouter/meta-llama/llama-4-scout:free"
}
```

### Para Privacidade

Use Ollama com modelos locais:

```json
{
  "model": "ollama/llama3.3"
}
```

### Para Empresas

Use AWS Bedrock ou Azure OpenAI com as credenciais da sua organizacao.

---

## Gerenciando Credenciais

Use `/status` na TUI para ver provedores conectados e credenciais ativas.

Para remover credenciais, use o comando CLI `cyberstrike auth logout` e selecione o provedor a remover.

<Aside variant="tip">
  Para tarefas de teste de penetracao que requerem raciocinio complexo, recomendamos **Claude Opus 4.5** ou **Claude Sonnet 4**.
</Aside>

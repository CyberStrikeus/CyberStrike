## As Ferramentas de Memoria

Existem quatro ferramentas de memoria — nao ha operacao de excluir, limpar, exportar ou importar:

| Ferramenta | Finalidade |
|------------|------------|
| `memory_write` | Adicionar uma nota a memoria |
| `memory_read` | Ler memoria armazenada |
| `memory_search` | Pesquisar nas notas armazenadas |
| `memory_context` | Trazer memoria relevante para o contexto atual |

## Layout de Armazenamento

Memoria e Markdown simples sob `.cyberstrike/`:

```
.cyberstrike/
├── MEMORY.md              ← memoria de longo prazo
└── memory/
    └── 2026-07-03.md      ← notas diarias datadas
```

- **`MEMORY.md`** armazena fatos duraveis de longo prazo.
- Arquivos **`memory/<YYYY-MM-DD>.md`** sao notas por dia; cada um comeca com um cabecalho `# Daily Notes - <data>` e recebe novas entradas conforme a sessao progride.

Memoria global (compartilhada entre projetos) fica em `~/.config/cyberstrike/memory/`.

Como tudo e Markdown em disco, voce pode ler, editar ou versionar como qualquer outro arquivo do projeto.

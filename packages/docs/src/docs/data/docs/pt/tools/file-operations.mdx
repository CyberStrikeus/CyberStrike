## Ferramenta Read

Le conteudo de arquivos com numeros de linha.

### Uso Basico

```
> Read the contents of src/auth/login.ts
```

### Leitura Parcial de Arquivo

```
> Read lines 50-100 of src/auth/login.ts
```

### Multiplos Arquivos

```
> Read both config.json and package.json
```

### Analise de Imagens

A ferramenta Read pode analisar imagens:

```
> Read the screenshot at ./evidence/vuln-poc.png
```

### Analise de PDF

```
> Read the security report at ./reports/pentest.pdf
```

## Ferramenta Write

Cria ou sobrescreve arquivos.

### Criar Novo Arquivo

```
> Write a Python script to exploit the SQL injection to exploit.py
```

### Sobrescrever Arquivo

```
> Replace the contents of config.json with the secure configuration
```

<Aside variant="caution">
  A ferramenta Write sobrescreve arquivos existentes sem aviso. Use Edit para modificacoes parciais.
</Aside>

## Ferramenta Edit

Faz edicoes precisas em arquivos existentes.

### Substituicao de String

```
> Edit src/auth/login.ts to replace "SELECT * FROM users WHERE id = " + userId with parameterized query
```

### Edicao Multi-linha

```
> Edit the vulnerable function in auth.ts to add input validation
```

### Substituir Tudo

```
> Replace all instances of "http://" with "https://" in config files
```

### Boas Praticas

1. Leia o arquivo primeiro para entender o contexto
2. Seja especifico sobre o que mudar
3. Inclua contexto suficiente ao redor para correspondencias unicas
4. Verifique as mudancas apos editar

## Ferramenta Glob

Encontra arquivos por correspondencia de padroes.

### Padroes Basicos

```
> Find all TypeScript files in the project
```

Padrao: `**/*.ts`

### Multiplas Extensoes

```
> Find all JavaScript and TypeScript files
```

Padrao: `**/*.{js,ts}`

### Diretorios Especificos

```
> Find all config files in the src directory
```

Padrao: `src/**/config.*`

### Padroes Comuns

| Padrao | Corresponde |
|--------|-------------|
| `**/*.ts` | Todos os arquivos TypeScript |
| `src/**/*.test.ts` | Arquivos de teste em src |
| `**/package.json` | Todos os arquivos package.json |
| `**/.env*` | Arquivos de ambiente |
| `**/secret*` | Arquivos com "secret" no nome |

### Padroes para Varredura de Seguranca

```
> Find files that might contain credentials

Padroes:
- **/*.env*
- **/secrets.*
- **/*credentials*
- **/*password*
- **/config.json
```

## Ferramenta Grep

Pesquisa conteudo de arquivos com regex.

### Pesquisa Basica

```
> Search for "password" in all files
```

### Pesquisa Regex

```
> Search for API key patterns in the codebase
```

Padrao: `(api[_-]?key|apikey)\s*[:=]\s*['"][^'"]+['"]`

### Sem Diferenciar Maiusculas

```
> Search for "SELECT" case insensitively
```

### Filtro por Tipo de Arquivo

```
> Search for "eval(" only in JavaScript files
```

### Linhas de Contexto

```
> Search for "TODO" with 2 lines of context before and after
```

### Pesquisas Focadas em Seguranca

| Finalidade | Padrao |
|------------|--------|
| Injecao SQL | `(SELECT|INSERT|UPDATE|DELETE).*\+.*\$` |
| Injecao de Comando | `(exec|spawn|system)\s*\(` |
| Segredos Hardcoded | `(password\|secret\|key)\s*=\s*['"][^'"]&#123;8,&#125;` |
| Desserializacao Insegura | `(pickle|marshal|yaml\.load)` |
| Pontos de XSS | `(innerHTML|outerHTML|document\.write)` |

## Fluxo de Trabalho de Analise de Arquivos

### 1. Descobrir Arquivos

```
> Find all files that might handle user input
```

### 2. Pesquisar Padroes

```
> Search these files for SQL query construction
```

### 3. Ler Arquivos Suspeitos

```
> Read the files that matched the SQL pattern
```

### 4. Documentar Descobertas

```
> Write a summary of the SQL injection findings to findings.md
```

## Consideracoes de Permissao

Operacoes de arquivo podem requerer permissao:

| Operacao | Chave de permissao | Comportamento padrao |
|----------|--------------------|----------------------|
| Read | `read` | Permitido (somente leitura) |
| Glob | `glob` | Permitido (somente leitura) |
| Grep | `grep` | Permitido (somente leitura) |
| Write | `edit` | Requer permissao |
| Edit | `edit` | Requer permissao |

Tanto a ferramenta Write quanto a Edit sao controladas pela mesma chave de permissao `edit`.

### Auto-aprovar Escritas

Para automacao, mapeie globs de caminho de arquivo para acoes sob `edit`:

```json title="~/.config/cyberstrike/cyberstrike.json"
{
  "permission": {
    "edit": {
      "reports/**": "allow",
      "findings/**": "allow"
    }
  }
}
```

Apenas `*` e `?` sao suportados como curingas. Veja [Permissoes](/docs/configuration/permissions) para o modelo completo.

## Manipulacao de Arquivos Grandes

### Paginacao

Para arquivos grandes:

```
> Read the first 100 lines of large-log.txt
> Read lines 100-200 of large-log.txt
```

### Arquivos Binarios

A ferramenta Read lida com arquivos binarios:

```
> Read the binary at ./malware.exe and analyze its strings
```

## Integracao com Testes de Seguranca

### Revisao de Codigo

```
> Analyze all authentication-related files for security issues

1. Encontrar arquivos de auth: Glob **/*auth*.{ts,js}
2. Pesquisar vulnerabilidades: Padroes Grep
3. Ler e analisar correspondencias
4. Documentar descobertas
```

### Auditoria de Configuracao

```
> Review all configuration files for security misconfigurations

1. Encontrar configs: Glob **/{config,settings}*.{json,yaml,yml}
2. Ler cada arquivo
3. Verificar exposicao de dados sensiveis
4. Verificar padroes seguros
```

### Deteccao de Segredos

```
> Scan the codebase for hardcoded secrets

1. Glob em todos os arquivos fonte
2. Grep por padroes de segredos
3. Ler correspondencias para verificacao
4. Relatar descobertas
```

<Aside variant="tip">
  Combine Glob e Grep para varredura eficiente do codebase. Comece amplo, depois refine.
</Aside>

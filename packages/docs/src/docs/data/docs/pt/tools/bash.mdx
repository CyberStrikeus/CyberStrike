## Visao Geral

A ferramenta Bash permite:

- Executar ferramentas de seguranca (nmap, nuclei, sqlmap)
- Comandos de administracao de sistema
- Operacoes Git
- Gerenciamento de pacotes
- Scripts personalizados

## Uso Basico

### Comandos Simples

```
> Run nmap scan on 192.168.1.1
```

Executa:
```bash
nmap -sV 192.168.1.1
```

### Com Argumentos

```
> Check open ports on target with service detection
```

Executa:
```bash
nmap -sV -sC -p- 192.168.1.1
```

### Comandos Encadeados

```
> Find all .env files and search for API keys
```

Executa:
```bash
find . -name "*.env*" -exec grep -l "API" {} \;
```

## Ferramentas de Seguranca

### Varredura de Rede

```
> Scan the network 10.0.0.0/24 for live hosts
```

```bash
nmap -sn 10.0.0.0/24
```

### Varredura de Vulnerabilidades

```
> Run nuclei templates against https://target.com
```

```bash
nuclei -u https://target.com -t cves/
```

### Testes Web

```
> Fuzz directories on target website
```

```bash
ffuf -u https://target.com/FUZZ -w /usr/share/wordlists/dirb/common.txt
```

### Ataques de Senha

```
> Test for default credentials on SSH
```

```bash
hydra -L users.txt -P passwords.txt ssh://192.168.1.1
```

## Timeout de Comando

### Timeout Padrao

Comandos expiram apos 120 segundos por padrao.

### Comandos de Longa Duracao

Para operacoes prolongadas:

```
> Run comprehensive port scan (may take a while)
```

O agente usara timeout apropriado:
```bash
timeout 600 nmap -p- -sV 192.168.1.1
```

### Execucao em Segundo Plano

```
> Start the scan in background
```

```bash
nmap -p- 192.168.1.1 > scan_results.txt &
```

## Diretorio de Trabalho

### Diretorio Atual

Comandos executam no diretorio de trabalho atual:

```
> List files in current directory
```

```bash
ls -la
```

### Mudar Diretorio

```
> Navigate to the web directory and list contents
```

```bash
cd /var/www/html && ls -la
```

## Variaveis de Ambiente

### Usando Variaveis

```
> Use the target IP from environment
```

```bash
nmap -sV $TARGET_IP
```

### Definindo Variaveis

```
> Set target and scan
```

```bash
export TARGET="192.168.1.1" && nmap $TARGET
```

## Tratamento de Saida

### Capturando Saida

```
> Save scan results to file
```

```bash
nmap -sV 192.168.1.1 -oN scan_results.txt
```

### Saida JSON

```
> Get scan results in JSON format
```

```bash
nmap -sV 192.168.1.1 -oX - | xq .
```

### Analisando Resultados

```
> Extract open ports from nmap output
```

```bash
grep "^[0-9]" scan_results.txt | cut -d'/' -f1
```

## Controle de Permissao

### Comandos Perigosos

Comandos destrutivos requerem permissao explicita:

| Tipo de Comando | Exemplo | Requer Permissao |
|-----------------|---------|------------------|
| Somente leitura | `ls`, `cat`, `nmap` | Nao |
| Modificacao de arquivo | `rm`, `mv` | Sim |
| Alteracoes de sistema | `apt install` | Sim |
| Ataques de rede | `msfconsole` | Sim |

### Auto-aprovar Comandos

```json title="~/.config/cyberstrike/cyberstrike.json"
{
  "permission": {
    "bash": {
      "nmap *": "allow",
      "nuclei *": "allow",
      "ffuf *": "allow"
    }
  }
}
```

### Bloquear Comandos Perigosos

```json
{
  "permission": {
    "bash": {
      "rm -rf *": "deny",
      "dd *": "deny",
      ":(){ :|:& };:": "deny"
    }
  }
}
```

A permissao `bash` mapeia um glob (correspondido contra a string do comando) a uma acao (`ask`, `allow` ou `deny`). Apenas `*` e `?` sao suportados como curingas. Veja [Permissoes](/docs/permissions) para o modelo completo.

## Fluxos de Trabalho de Testes de Seguranca

### Reconhecimento

```
> Perform initial reconnaissance on target.com

1. DNS enumeration
2. Subdomain discovery
3. Port scanning
4. Service identification
```

Executa multiplos comandos:

```bash
dig target.com ANY
subfinder -d target.com
nmap -sV -sC target.com
```

### Exploracao

```
> Attempt SQL injection with sqlmap
```

```bash
sqlmap -u "https://target.com/page?id=1" --batch --dbs
```

### Pos-Exploracao

```
> Enumerate the compromised system
```

```bash
uname -a
id
cat /etc/passwd
ls -la /home/
```

## Tratamento de Erros

### Erros de Comando

Comandos que falharam mostram saida de erro:

```
Command failed:
$ nmap -sV nonexistent.host
Host seems down. If it is really up, but blocking our ping probes, try -Pn
```

### Logica de Nova Tentativa

```
> Retry the scan with -Pn flag
```

```bash
nmap -sV -Pn 192.168.1.1
```

## Boas Praticas

1. **Verifique alvos** - Confirme IPs e dominios
2. **Use timeouts** - Defina timeouts apropriados para varreduras longas
3. **Salve saida** - Sempre salve resultados importantes
4. **Verifique permissoes** - Garanta acesso autorizado
5. **Limpe** - Remova arquivos temporarios apos testes

<Aside variant="danger">
  Nunca execute comandos contra alvos sem autorizacao. Acesso nao autorizado e ilegal.
</Aside>

## Solucao de Problemas

### Comando Nao Encontrado

```
Error: command not found: nuclei
```

Instale a ferramenta ou verifique o PATH:

```bash
which nuclei
export PATH=$PATH:/opt/tools
```

### Permissao Negada

```
Error: permission denied
```

Pode precisar de sudo:

```bash
sudo nmap -sS 192.168.1.1
```

### Timeout

```
Error: command timed out
```

Use timeout explicito ou execucao em segundo plano.

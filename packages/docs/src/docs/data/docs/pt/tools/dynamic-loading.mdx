Ferramentas integradas (bash, read, edit, ...) estao sempre disponiveis. **Ferramentas MCP sao carregadas sob demanda** para que conectar um servidor com centenas de ferramentas nao sobrecarregue o contexto do modelo. Quatro ferramentas conduzem esse processo.

<img src="/docs/images/diagrams/tool-loading.svg" alt="Ciclo de carregamento de ferramenta MCP: um servidor expoe centenas de ferramentas; tool_search encontra uma por capacidade, load_tools a traz para o contexto, o agente a chama, e unload_tools libera o contexto" className="my-6" />

## As Ferramentas de Carregamento

| Ferramenta | Finalidade |
|------------|------------|
| `tool_search` | Encontrar ferramentas MCP por capacidade (`query`, `limit` opcional) |
| `load_tools` | Carregar ferramentas especificas no contexto ativo |
| `unload_tools` | Remover ferramentas carregadas para liberar contexto |
| `list_loaded_tools` | Mostrar quais ferramentas estao carregadas atualmente |

O agente usa essas ferramentas automaticamente: busca por uma capacidade, carrega a ferramenta MCP correspondente, a chama e pode descarrega-la depois.

### tool_search

```json
{
  "query": "teste de injecao sql",
  "limit": 10
}
```

Retorna ferramentas MCP correspondentes com suas descricoes. Ferramentas integradas nao precisam ser buscadas — sao sempre chamadas diretamente.

## O Que e Lazy vs Sempre Ativo

- **Sempre disponivel** — toda ferramenta integrada (`bash`, `read`, `edit`, `glob`, `grep`, `write`, `task`, `webfetch`, `websearch`, ferramentas de memoria, ...).
- **Carregada sob demanda** — ferramentas expostas por servidores MCP conectados (incluindo [Bolt](/docs/features/bolt)). Sao descobertas com `tool_search` e trazidas com `load_tools`.

## Desabilitando uma Ferramenta

A config `tools` e um mapa de nome de ferramenta para boolean. Defina uma ferramenta como `false` para desabilita-la:

```json title="cyberstrike.json"
{
  "tools": {
    "websearch": false
  }
}
```

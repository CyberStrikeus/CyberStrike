Digite `/` no inicio da entrada para abrir a lista de comandos (ou pressione `Ctrl+P`). A correspondencia fuzzy filtra enquanto voce digita.

## Sessao

| Comando | Aliases | Atalho | Acao |
|---------|---------|--------|------|
| `/new` | `/clear` | `<leader>n` | Iniciar nova sessao |
| `/sessions` | `/resume`, `/continue` | `<leader>l` | Abrir seletor de sessoes |
| `/rename` | | `ctrl+r` | Renomear a sessao |
| `/compact` | `/summarize` | `<leader>c` | Compactar (resumir) a sessao |
| `/fork` | | | Bifurcar a sessao |
| `/timeline` | | `<leader>g` | Mostrar a linha do tempo da sessao |
| `/export` | | `<leader>x` | Exportar a sessao |
| `/copy` | | | Copiar a ultima mensagem |
| `/share`, `/unshare` | | | Compartilhar / parar de compartilhar |
| `/undo`, `/redo` | | `<leader>u` / `<leader>r` | Desfazer / refazer a ultima mensagem |
| `/timestamps`, `/thinking` | | | Alternar timestamps / blocos de raciocinio |

## Testes Web e Metodologia

| Comando | Aliases | Acao |
|---------|---------|------|
| `/hackbrowser` | | Lancar o crawl do Hacker Browser |
| `/hackbrowser-stop` | | Parar um crawl em execucao |
| `/vulnerabilities` | `/vuln`, `/vulns` | Revisar vulnerabilidades capturadas |
| `/web` | `/endpoints`, `/roles`, `/credentials` | Inspecionar o contexto de testes web |
| `/methodology` | `/intel`, `/vrt`, `/chains` | Visualizacoes do motor de metodologia |
| `/report` | | Gerar um relatorio |
| `/qpause`, `/qresume` | | Pausar / retomar a fila de ingestao |

<Aside variant="caution">
  Nomes de comandos sao no plural (`/models`, `/themes`, `/mcps`). Nao existe `/agent-settings`, `/settings`, `/config`, `/vim`, `/provider`, `/model`, nem uma paleta de comandos `<leader><leader>`/`Ctrl+Shift+P` — a lista de comandos abre com `Ctrl+P`.
</Aside>

## Mencoes @

Referencie um arquivo (opcionalmente um intervalo de linhas) no seu prompt com `@`:

```
@src/auth.ts#45-60 check these lines for vulnerabilities
```

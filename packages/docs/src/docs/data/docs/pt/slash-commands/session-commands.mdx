Comandos de sessao gerenciam a conversa atual — criando, retomando, compartilhando e editando o historico de mensagens.

<img src="/docs/images/gifs/session-commands.gif" alt="Abrindo o seletor de sessoes com leader+l" className="rounded-lg shadow-lg my-6 w-full" />

## Ciclo de Vida

| Comando | Aliases | Acao |
|---------|---------|------|
| `/new` | `/clear` | Iniciar uma **nova** sessao (`/clear` e um alias — nao apenas limpa mensagens) |
| `/sessions` | `/resume`, `/continue` | Abrir o seletor de sessoes para retomar uma sessao anterior |
| `/rename` | | Renomear a sessao atual |
| `/fork` | | Bifurcar a sessao a partir do ponto atual |
| `/timeline` | | Mostrar a linha do tempo da sessao |
| `/export` | | Exportar a sessao |
| `/copy` | | Copiar a ultima mensagem |

## Mensagens

| Comando | Aliases | Acao |
|---------|---------|------|
| `/undo` | | Desfazer a ultima mensagem |
| `/redo` | | Refazer |
| `/compact` | `/summarize` | Compactar (resumir) a sessao para recuperar contexto |
| `/timestamps` | `/toggle-timestamps` | Alternar timestamps das mensagens |
| `/thinking` | `/toggle-thinking` | Alternar blocos de raciocinio |

## Compartilhamento

| Comando | Acao |
|---------|------|
| `/share` | Compartilhar a sessao atual |
| `/unshare` | Parar de compartilhar |

<Aside variant="caution">
  `/clear` e um alias de `/new` (inicia uma nova sessao), e `/continue` e um alias de `/sessions` (abre o seletor de sessoes). Nao existe comando `/history`, `/memory`, `/cost`, `/save`, `/tag`, `/note`, `/retry` ou `/template`.
</Aside>

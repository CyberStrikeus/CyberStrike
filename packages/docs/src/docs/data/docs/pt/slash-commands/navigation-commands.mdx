Estes comandos slash abrem seletores e dialogos. Digite `/` na TUI para ver a lista de comandos (ou pressione `Ctrl+P`).

<img src="/docs/images/gifs/navigation-commands.gif" alt="Abrindo a lista de comandos e navegando nos seletores" className="rounded-lg shadow-lg my-6 w-full" />

## Seletores e Dialogos

| Comando | Abre |
|---------|------|
| `/models` | Seletor de modelos |
| `/agents` | Seletor de agentes |
| `/themes` | Seletor de temas |
| `/mcps` | Gerenciador de servidores MCP |
| `/bolt` | Gerenciador de servidor Bolt |
| `/connect` | Conectar / autenticar um provedor |
| `/sessions` (`/resume`, `/continue`) | Seletor de sessoes |
| `/editor` | Abrir a mensagem no seu editor externo |
| `/skills` | Navegar skills carregadas |
| `/help` | Mostrar ajuda |
| `/status` | Mostrar status |
| `/exit` | Sair do Cyberstrike |

<Aside variant="caution">
  Nomes de comandos sao no plural: `/models`, `/themes`, `/mcps` (nao `/model`, `/theme`, `/mcp`). Nao existe comando `/provider`, `/vim`, `/config`, `/permission`, `/files`, `/cd`, `/tools`, `/version`, `/doctor`, `/docs`, `/changelog`, `/cost` ou `/context` — eles nao existem.
</Aside>

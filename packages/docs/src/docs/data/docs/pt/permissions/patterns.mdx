Padroes de permissao fornecem controle granular correspondendo o argumento de uma ferramenta (uma string de comando, um caminho de arquivo) contra um glob e mapeando-o para uma acao.

## Formato

Uma entrada de permissao e uma acao unica, ou um mapa de **glob → acao**. Nao existe sintaxe `Tool(pattern)` e nao ha arrays allow/deny — a chave da ferramenta agrupa seus padroes:

```json
{
  "permission": {
    "bash": {
      "*": "ask",
      "ls *": "allow",
      "git status": "allow",
      "rm -rf *": "deny"
    },
    "edit": {
      "reports/**": "allow",
      ".env*": "deny"
    }
  }
}
```

O glob corresponde ao argumento da ferramenta: para `bash` e a string do comando, para `edit`/`read` e o caminho do arquivo.

## Curingas

Apenas dois curingas sao suportados:

| Token | Corresponde |
|-------|-------------|
| `*` | qualquer sequencia de caracteres (incluindo `/`) |
| `?` | qualquer caractere unico |

<Aside variant="caution">
  `*` e `?` sao os **unicos** curingas. Caracteres como `[`, `]`, `{`, `}`, `(`, `)` e `|` sao correspondidos **literalmente**. Nao existe `**` (ele se comporta igual a `*`), e negacao (`!pattern`) nao e suportada.
</Aside>

Um padrao que termina com espaco + `*` tambem corresponde ao comando base sem argumentos — entao `"ls *"` corresponde tanto a `ls` quanto a `ls -la`.

## Precedencia

Quando varios padroes correspondem, o **padrao mais especifico (mais longo) vence**. Padroes sao avaliados do mais curto ao mais longo, e a ultima correspondencia se aplica — entao um amplo `"*": "ask"` pode ser sobrescrito por um mais longo `"git status": "allow"`:

```json
{
  "permission": {
    "bash": {
      "*": "ask",
      "npm *": "allow",
      "npm publish*": "deny"
    }
  }
}
```

Aqui `npm test` e permitido, mas `npm publish` e negado.

## Exemplos

### Permitir uma toolchain, bloquear as partes perigosas

```json
{
  "permission": {
    "bash": {
      "*": "ask",
      "git *": "allow",
      "git push*": "ask",
      "rm -rf *": "deny"
    }
  }
}
```

### Restringir edicoes a um diretorio

```json
{
  "permission": {
    "edit": {
      "*": "deny",
      "src/**": "allow",
      "src/secrets/**": "deny"
    }
  }
}
```

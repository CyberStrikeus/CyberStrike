Cyberstrike स्वचालित पेनेट्रेशन टेस्टिंग के लिए विशेष रूप से निर्मित विशेषताओं के साथ आता है। प्रत्येक विशेषता AI एजेंट के साथ गहराई से एकीकृत है — एजेंट लक्ष्य और वार्तालाप संदर्भ के आधार पर तय करता है कि कब और कैसे उनका उपयोग करना है।

## मुख्य विशेषताएं

| विशेषता | यह क्या करती है |
|---------|--------------|
| [Vortex](/docs/features/vortex) | HTTP ट्रैफिक इंजन — DSL के साथ अनुरोधों को इंटरसेप्ट, रीप्ले और रूल-मैच करें |
| [HackBrowser](/docs/features/hackbrowser) | UI संदर्भ कैप्चर के साथ AI-संचालित स्वायत्त वेब क्रॉलर |
| [Bolt](/docs/features/bolt) | कंटेनराइज़्ड सुरक्षा उपकरण सर्वर (nmap, nuclei, sqlmap, और 30+ अधिक) |
| [MCP](/docs/features/mcp) | Model Context Protocol — किसी भी बाहरी टूल सर्वर से कनेक्ट करें |

## ये एक साथ कैसे काम करते हैं

एक सामान्य वेब एप्लिकेशन मूल्यांकन कई विशेषताओं का एक साथ उपयोग करता है:

1. **HackBrowser** लक्ष्य को क्रॉल करता है, UI संदर्भ के साथ HTTP ट्रैफिक कैप्चर करता है
2. **Vortex** कैप्चर किए गए ट्रैफिक को प्रोसेस करता है — नियम लागू करता है, विसंगतियां फ्लैग करता है, सिग्नल सहसंबंधित करता है
3. **proxy-agent** फ्लैग किए गए अनुरोधों का विश्लेषण करता है और कमजोरी परीक्षकों को भेजता है
4. **Bolt** भारी उपकरण प्रदान करता है (nuclei टेम्पलेट्स, फज़िंग, सबडोमेन एन्यूमरेशन) जब एजेंट को उनकी आवश्यकता होती है
5. **MCP** सर्वर कस्टम या तृतीय-पक्ष एकीकरण के साथ टूलसेट का विस्तार करते हैं

प्रत्येक विशेषता स्वतंत्र रूप से भी उपयोग की जा सकती है। HackBrowser बिना Vortex के काम करता है, Bolt बिना HackBrowser के काम करता है, और MCP सर्वर इस बात की परवाह किए बिना काम करते हैं कि और क्या कॉन्फ़िगर किया गया है।

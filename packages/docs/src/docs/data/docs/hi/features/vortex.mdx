Vortex Cyberstrike का HTTP ट्रैफिक इंजन है। यह सिस्टम से गुजरने वाले HTTP अनुरोधों को इंटरसेप्ट, संग्रहीत और विश्लेषण करता है — चाहे वे [HackBrowser](/docs/features/hackbrowser), [Chrome Extension](/docs/tools/chrome-extension), या API के माध्यम से इंजेक्ट किए गए हों।

## Vortex क्या करता है

| क्षमता | विवरण |
|------------|-------------|
| **ट्रैफिक कैप्चर** | पूर्ण हेडर और बॉडी के साथ प्रत्येक HTTP अनुरोध/प्रतिक्रिया जोड़ी को संग्रहीत करता है |
| **DSL इंजन** | एक विशेष रूप से निर्मित अभिव्यक्ति भाषा के साथ ट्रैफिक को फ़िल्टर और क्वेरी करें |
| **नियम मिलान** | कैप्चर किए गए ट्रैफिक के विरुद्ध डेटा-के-रूप-में-नियम (detect, canary, transform) लागू करें |
| **रीप्ले** | परीक्षण के लिए संशोधनों के साथ कैप्चर किए गए अनुरोधों को पुनः भेजें |
| **सिग्नल सहसंबंध** | श्रृंखलित कमजोरियों का पता लगाने के लिए अनुरोधों में निष्कर्षों को क्रॉस-रेफरेंस करें |

## DSL क्वेरीज

Vortex में HTTP ट्रैफिक फ़िल्टर करने के लिए एक अभिव्यक्ति इंजन शामिल है। मेथड, पथ, स्थिति, हेडर, बॉडी सामग्री, और अधिक द्वारा क्वेरी करें:

```
method == "POST" && path contains "/api/" && status >= 400
```

```
header["content-type"] contains "json" && body contains "token"
```

DSL बूलियन लॉजिक, स्ट्रिंग मिलान, संख्यात्मक तुलना, और नेस्टेड फ़ील्ड एक्सेस का समर्थन करता है।

## नियम

Vortex नियम घोषणात्मक डेटा हैं — कोड नहीं। तीन नियम आकृतियां सामान्य पैटर्न कवर करती हैं:

| आकृति | उद्देश्य | उदाहरण |
|-------|---------|---------|
| **Detect** | पैटर्न से मेल खाने वाले ट्रैफिक को फ्लैग करें | प्रतिक्रिया बॉडी में संवेदनशील डेटा |
| **Canary** | मार्कर इंजेक्ट करें और उनके प्रतिबिंब की निगरानी करें | SSRF, ओपन रीडायरेक्ट, हेडर इंजेक्शन |
| **Transform** | रीप्ले से पहले अनुरोधों को संशोधित करें | ऑथ हेडर हटाएं, पैरामीटर मान बदलें |

नियमों को अंतर्निर्मित पैक से लोड किया जा सकता है या प्रति-प्रोजेक्ट परिभाषित किया जा सकता है।

## HackBrowser के साथ एकीकरण

जब HackBrowser ट्रैफिक कैप्चर करता है, Vortex इसे स्वचालित रूप से प्रोसेस करता है:

1. `POST /session/ingest` के माध्यम से अनुरोध आता है
2. Vortex अनुरोध को संग्रहीत करता है और सक्रिय नियम लागू करता है
3. मिलान किए गए नियम सिग्नल उत्पन्न करते हैं
4. सिग्नल proxy-agent की विश्लेषण पाइपलाइन में फीड होते हैं

## उपयोग

Vortex Cyberstrike बैकएंड के हिस्से के रूप में चलता है — कोई अलग सेटअप आवश्यक नहीं। जब भी आप HackBrowser, Chrome Extension, या WSTG पाइपलाइन का उपयोग करते हैं, ट्रैफिक इसके माध्यम से बहता है।

संचित Vortex डेटा का निरीक्षण करने के लिए TUI में `/web` का उपयोग करें: कैप्चर किए गए अनुरोध, मिलान किए गए नियम, और उत्पन्न सिग्नल। संबंधित कमांड:

| कमांड | क्या दिखाती है |
|---------|---------------|
| `/web` | कैप्चर किए गए एंडपॉइंट्स, भूमिकाएं, क्रेडेंशियल्स |
| `/vulnerabilities` | Vortex सिग्नल + WSTG परीक्षण से निष्कर्ष |
| `/methodology` | कवरेज और कार्यप्रणाली स्थिति |

<Aside variant="tip">
  Vortex मुफ्त टियर में शामिल है। AI विश्लेषण परत (proxy-agent तर्क, सिग्नल सहसंबंध) वह है जो इसे शक्तिशाली बनाती है — और वह आपके कॉन्फ़िगर किए गए AI प्रदाता पर चलती है।
</Aside>

Cyberstrike बाहरी उपकरणों को एकीकृत करने के लिए Model Context Protocol (MCP) का उपयोग करता है। कोई भी MCP-संगत सर्वर — स्थानीय या दूरस्थ — कनेक्ट किया जा सकता है, जिससे AI एजेंट को मूल्यांकन के दौरान उसके उपकरणों तक पहुंच मिलती है।

## अंतर्निर्मित सर्वर

Cyberstrike डिफ़ॉल्ट रूप से तीन MCP सर्वर सक्षम करके आता है:

| सर्वर | उद्देश्य |
|--------|---------|
| `github-security` | GitHub रिपॉजिटरी सुरक्षा विश्लेषण |
| `cve` | CVE/NVD/EPSS/KEV कमजोरी लुकअप |
| `osint` | ओपन सोर्स इंटेलिजेंस संग्रह |

आपकी अपनी कॉन्फ़िगरेशन इनके ऊपर मर्ज की जाती है।

## सर्वर जोड़ना

MCP सर्वर आपकी कॉन्फ़िग में फ्लैट `mcp` मैप के तहत जाते हैं, नाम से कीड:

```json title="cyberstrike.json"
{
  "mcp": {
    "my-tools": {
      "type": "local",
      "command": ["your-mcp-server"]
    }
  }
}
```

### स्थानीय सर्वर (stdio)

स्थानीय सर्वर चाइल्ड प्रोसेस के रूप में चलते हैं:

```json
{
  "mcp": {
    "filesystem": {
      "type": "local",
      "command": ["npx", "-y", "@modelcontextprotocol/server-filesystem", "/path/to/dir"]
    }
  }
}
```

### दूरस्थ सर्वर (HTTP)

दूरस्थ सर्वर StreamableHTTP या SSE के माध्यम से कनेक्ट होते हैं:

```json
{
  "mcp": {
    "remote-tools": {
      "type": "remote",
      "url": "https://mcp.example.com/sse"
    }
  }
}
```

दूरस्थ सर्वर संरक्षित एंडपॉइंट्स के लिए [OAuth प्रमाणीकरण](/docs/mcp/oauth) का समर्थन करते हैं।

## प्रबंधन

| कमांड | क्या प्रबंधित करती है |
|---------|-----------------|
| `/mcps` | स्थानीय और दूरस्थ MCP सर्वर (जोड़ें, टॉगल करें, हटाएं) |
| `/bolt` | विशेष रूप से Bolt सर्वर (जोड़ें, पेयर करें, टॉगल करें, हटाएं) |

दोनों डायलॉग में: जोड़ने के लिए **a**, टॉगल के लिए **space**, बंद करने के लिए **esc**।

## मॉडल संगतता

<Aside variant="caution">
  सबप्रोसेस-आधारित मॉडल MCP उपकरणों तक नहीं पहुंच सकते। पूर्ण MCP एकीकरण के लिए direct-API मॉडल (जैसे `anthropic/claude-sonnet-4-20250514`, `openai/gpt-4o`) का उपयोग करें।
</Aside>

## कॉन्फ़िगरेशन प्राथमिकता

MCP एंट्रीज मानक [कॉन्फ़िगरेशन पदानुक्रम](/docs/configuration#configuration-hierarchy) का पालन करती हैं: प्रोजेक्ट `.cyberstrike/` प्रोजेक्ट `cyberstrike.json` को ओवरराइड करता है, जो ग्लोबल `~/.config/cyberstrike/` को ओवरराइड करता है, जो अंतर्निर्मित सर्वरों को ओवरराइड करता है।

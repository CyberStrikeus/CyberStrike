अनुमति पैटर्न एक उपकरण के आर्गुमेंट (कमांड स्ट्रिंग, फ़ाइल पथ) को glob के विरुद्ध मिलान करके और इसे एक कार्रवाई से मैप करके सूक्ष्म नियंत्रण प्रदान करते हैं।

## प्रारूप

अनुमति प्रविष्टि या तो एक एकल कार्रवाई है, या **glob → कार्रवाई** का मैप है। कोई `Tool(pattern)` सिंटैक्स नहीं और कोई allow/deny ऐरे नहीं — टूल कुंजी अपने पैटर्न को समूहीकृत करती है:

```json
{
  "permission": {
    "bash": {
      "*": "ask",
      "ls *": "allow",
      "git status": "allow",
      "rm -rf *": "deny"
    },
    "edit": {
      "reports/**": "allow",
      ".env*": "deny"
    }
  }
}
```

glob उपकरण के आर्गुमेंट से मिलान करता है: `bash` के लिए यह कमांड स्ट्रिंग है, `edit`/`read` के लिए यह फ़ाइल पथ है।

## वाइल्डकार्ड

केवल दो वाइल्डकार्ड समर्थित हैं:

| टोकन | मिलान |
|-------|---------|
| `*` | वर्णों का कोई भी अनुक्रम (`/` सहित) |
| `?` | कोई भी एकल वर्ण |

<Aside variant="caution">
  `*` और `?` **एकमात्र** वाइल्डकार्ड हैं। `[`, `]`, `{`, `}`, `(`, `)`, और `|` जैसे वर्ण **शाब्दिक रूप से** मिलान किए जाते हैं। कोई `**` नहीं है (यह `*` जैसा ही व्यवहार करता है), और नकारात्मकता (`!pattern`) समर्थित नहीं है।
</Aside>

जो पैटर्न एक स्पेस + `*` में समाप्त होता है, वह बिना आर्गुमेंट के केवल कमांड से भी मेल खाता है — इसलिए `"ls *"` `ls` और `ls -la` दोनों से मेल खाता है।

## प्राथमिकता

जब कई पैटर्न मेल खाते हैं, तो **अधिक विशिष्ट (लंबा) पैटर्न जीतता है**। पैटर्न सबसे छोटे से पहले मूल्यांकित किए जाते हैं, और अंतिम मिलान लागू होता है — इसलिए एक व्यापक `"*": "ask"` को एक लंबे `"git status": "allow"` द्वारा ओवरराइड किया जा सकता है:

```json
{
  "permission": {
    "bash": {
      "*": "ask",
      "npm *": "allow",
      "npm publish*": "deny"
    }
  }
}
```

यहाँ `npm test` की अनुमति है, लेकिन `npm publish` अस्वीकृत है।

## उदाहरण

### टूलचेन की अनुमति दें, खतरनाक भागों को ब्लॉक करें

```json
{
  "permission": {
    "bash": {
      "*": "ask",
      "git *": "allow",
      "git push*": "ask",
      "rm -rf *": "deny"
    }
  }
}
```

### संपादन को एक डायरेक्टरी तक प्रतिबंधित करें

```json
{
  "permission": {
    "edit": {
      "*": "deny",
      "src/**": "allow",
      "src/secrets/**": "deny"
    }
  }
}
```

`cyberstrike mcp` कमांड Model Context Protocol सर्वर प्रबंधित करते हैं। पांच उप-कमांड हैं: `list`, `add`, `auth`, `logout`, और `debug`।

## `mcp list`

```bash
cyberstrike mcp list   # alias: ls
```

कॉन्फ़िगर किए गए MCP सर्वर सूचीबद्ध करता है।

## `mcp add`

```bash
cyberstrike mcp add
```

पूरी तरह इंटरैक्टिव — यह स्थानीय बनाम रिमोट, कमांड या URL, और एक नाम के लिए पूछता है, फिर सहेजने से पहले कनेक्शन का परीक्षण करता है। यह **कोई** पोज़िशनल नाम या फ़्लैग नहीं लेता; सर्वर सेटअप को स्क्रिप्ट करने के लिए, सीधे `cyberstrike.json` में एंट्री लिखें।

## `mcp auth`

```bash
cyberstrike mcp auth [name]        # OAuth सर्वर को अधिकृत करें
cyberstrike mcp auth list          # OAuth-अधिकृत सर्वर सूचीबद्ध करें
```

एक रिमोट सर्वर को अधिकृत करता है जो OAuth उपयोग करता है (आवश्यकता होने पर ब्राउज़र खोलता है)। [OAuth](/docs/features/mcp#oauth) देखें।

## `mcp logout`

```bash
cyberstrike mcp logout [name]
```

किसी सर्वर के लिए संग्रहीत OAuth क्रेडेंशियल हटाता है।

## `mcp debug`

```bash
cyberstrike mcp debug <name>
```

किसी सर्वर के कनेक्शन का निरीक्षण करता है — उपयोगी जब कोई सर्वर लोड होने में विफल हो या उसके टूल दिखाई न दें।

## कमांड संरचना

```
cyberstrike [global-options] <command> [command-options] [arguments]
```

## वैश्विक विकल्प

| विकल्प | संक्षिप्त | विवरण |
|--------|-------|-------------|
| `--help` | `-h` | सहायता जानकारी प्रदर्शित करें |
| `--version` | `-v` | संस्करण संख्या दिखाएं |
| `--print-logs` | | stderr पर लॉग प्रिंट करें |
| `--log-level` | | लॉग स्तर सेट करें (DEBUG, INFO, WARN, ERROR) |

## इंटरैक्टिव मोड

बिना आर्गुमेंट के टर्मिनल यूज़र इंटरफ़ेस लॉन्च करें:

```bash
cyberstrike
```

### इंटरैक्टिव मोड विकल्प

| विकल्प | संक्षिप्त | विवरण |
|--------|-------|-------------|
| `--model <model>` | `-m` | `provider/model` प्रारूप में मॉडल |
| `--agent <name>` | | उपयोग करने के लिए सुरक्षा एजेंट |
| `--continue` | `-c` | अंतिम सत्र जारी रखें |
| `--session <id>` | `-s` | विशिष्ट सत्र फिर से शुरू करें |

### उदाहरण

```bash
# विशिष्ट मॉडल के साथ शुरू करें
cyberstrike --model anthropic/claude-sonnet-4-20250514

# प्राथमिक एजेंट चुनें (केवल 'cyberstrike' बिल्ट-इन आता है)
cyberstrike --agent cyberstrike

# पिछला सत्र जारी रखें
cyberstrike --continue
```

## run

इंटरैक्टिव मोड में प्रवेश किए बिना एकल प्रॉम्प्ट निष्पादित करें।

```bash
cyberstrike run [message..] [options]
```

### विकल्प

| विकल्प | संक्षिप्त | विवरण |
|--------|-------|-------------|
| `--model <model>` | `-m` | `provider/model` प्रारूप में मॉडल |
| `--agent <name>` | | उपयोग करने के लिए एजेंट |
| `--continue` | `-c` | अंतिम सत्र जारी रखें |
| `--session <id>` | `-s` | विशिष्ट सत्र फिर से शुरू करें |
| `--file <path>` | `-f` | संदेश में फ़ाइल(ें) संलग्न करें |
| `--format <type>` | | आउटपुट प्रारूप: `default` या `json` |
| `--share` | | सत्र साझा करें |
| `--title <text>` | | सत्र शीर्षक सेट करें |
| `--attach <url>` | | चल रहे सर्वर से जुड़ें |
| `--variant <type>` | | मॉडल वेरिएंट (high, max, minimal) |

### उदाहरण

```bash
# एकल कमांड चलाएं
cyberstrike run "scan example.com for open ports"

# अनुरोध में फ़ाइल संलग्न करें
cyberstrike run "analyze this config" -f nginx.conf

# JSON के रूप में आउटपुट
cyberstrike run "list vulnerabilities" --format json

# पिछला सत्र जारी रखें
cyberstrike run "now check for XSS" --continue
```

### पाइपिंग इनपुट

stdin से इनपुट स्वीकार करें:

```bash
echo "analyze this code" | cyberstrike run
cat report.txt | cyberstrike run "summarize this"
```

## auth

AI प्रदाताओं के लिए प्रमाणीकरण क्रेडेंशियल प्रबंधित करें।

### auth login

AI प्रदाता के लिए क्रेडेंशियल जोड़ें:

```bash
cyberstrike auth login [url]
```

#### इंटरैक्टिव लॉगिन

```bash
cyberstrike auth login
# सूची से प्रदाता चुनें
# पूछे जाने पर API कुंजी दर्ज करें
```

#### Well-Known URL लॉगिन

```bash
cyberstrike auth login https://custom-provider.example.com
```

### auth logout

संग्रहीत क्रेडेंशियल हटाएं:

```bash
cyberstrike auth logout
# सूची से प्रदाता चुनें
```

### auth list

सभी कॉन्फ़िगर किए गए क्रेडेंशियल प्रदर्शित करें:

```bash
cyberstrike auth list
```

आउटपुट दिखाता है:
- प्रदाता के अनुसार संग्रहीत क्रेडेंशियल
- प्रमाणीकरण प्रकार (api, oauth)
- सक्रिय पर्यावरण चर

## mcp

Model Context Protocol (MCP) सर्वर प्रबंधित करें।

### mcp list

कॉन्फ़िगर किए गए MCP सर्वर और उनकी स्थिति सूचीबद्ध करें:

```bash
cyberstrike mcp list
```

स्थिति संकेतक:
- `✓` कनेक्टेड
- `○` आरंभ नहीं हुआ / अक्षम
- `⚠` प्रमाणीकरण आवश्यक
- `✗` विफल

### mcp add

इंटरैक्टिव रूप से एक नया MCP सर्वर जोड़ें:

```bash
cyberstrike mcp add
```

विज़ार्ड पूछता है:
1. स्थान (प्रोजेक्ट या वैश्विक)
2. सर्वर का नाम
3. सर्वर प्रकार (स्थानीय या रिमोट)
4. कनेक्शन विवरण

#### स्थानीय सर्वर उदाहरण

```bash
# `cyberstrike mcp add` चलाने के बाद:
# Location: Current project
# Name: filesystem
# Type: Local
# Command: npx @modelcontextprotocol/server-filesystem /path/to/dir
```

#### रिमोट सर्वर उदाहरण

```bash
# `cyberstrike mcp add` चलाने के बाद:
# Location: Global
# Name: custom-api
# Type: Remote
# URL: https://api.example.com/mcp
# OAuth: Yes/No
```

### mcp auth

OAuth-सक्षम MCP सर्वर के साथ प्रमाणित करें:

```bash
cyberstrike mcp auth [name]
```

### mcp auth list

सभी MCP सर्वर के लिए OAuth स्थिति सूचीबद्ध करें:

```bash
cyberstrike mcp auth list
```

### mcp logout

OAuth क्रेडेंशियल हटाएं:

```bash
cyberstrike mcp logout [name]
```

### mcp debug

OAuth कनेक्शन समस्याओं को डीबग करें:

```bash
cyberstrike mcp debug <name>
```

## session

बातचीत सत्र प्रबंधित करें।

### session list

सभी सत्र सूचीबद्ध करें:

```bash
cyberstrike session list [options]
```

| विकल्प | संक्षिप्त | विवरण |
|--------|-------|-------------|
| `--max-count <n>` | `-n` | N हाल के सत्रों तक सीमित करें |
| `--format <type>` | | आउटपुट: `table` या `json` |

### उदाहरण

```bash
# 10 सबसे हाल के सत्र सूचीबद्ध करें
cyberstrike session list -n 10

# JSON के रूप में निर्यात करें
cyberstrike session list --format json
```

## models

उपलब्ध AI मॉडल सूचीबद्ध करें।

```bash
cyberstrike models
```

प्रदाता के अनुसार व्यवस्थित सभी मॉडल प्रदर्शित करता है:
- मॉडल पहचानकर्ता
- मॉडल नाम
- क्षमताएं

## agent

सुरक्षा एजेंट प्रबंधित करें।

```bash
cyberstrike agent [name]
```

### एजेंट सूचीबद्ध करना

```bash
cyberstrike agent
# उपलब्ध एजेंट दिखाता है
```

### एजेंट जानकारी

```bash
cyberstrike agent web-application
# एजेंट विवरण और प्रॉम्प्ट दिखाता है
```

## github

GitHub App इंटीग्रेशन।

### github install

रिपॉज़िटरी में Cyberstrike GitHub App इंस्टॉल करें:

```bash
cyberstrike github install
```

### github run

GitHub इवेंट के विरुद्ध Cyberstrike चलाएं (CI वर्कफ़्लो द्वारा उपयोग किया जाता है):

```bash
cyberstrike github run
```

## serve

Cyberstrike API सर्वर शुरू करें। `CYBERSTRIKE_SERVER_PASSWORD` सेट होना आवश्यक है।

```bash
CYBERSTRIKE_SERVER_PASSWORD=secret cyberstrike serve [options]
```

| विकल्प | विवरण |
|--------|-------------|
| `--port <number>` | सर्वर पोर्ट (डिफ़ॉल्ट: 4096) |
| `--hostname <address>` | बाइंड पता |
| `--cors <origin>` | अनुमत CORS ऑरिजिन |
| `--mdns` | mDNS पर सर्वर का विज्ञापन करें |

## completion

शेल कंप्लीशन स्क्रिप्ट जनरेट करें।

```bash
# Bash
cyberstrike completion >> ~/.bashrc

# Zsh
cyberstrike completion >> ~/.zshrc

# Fish
cyberstrike completion | source
```

## पर्यावरण चर

पर्यावरण चर के माध्यम से Cyberstrike व्यवहार कॉन्फ़िगर करें:

| चर | विवरण |
|----------|-------------|
| `CYBERSTRIKE_AUTO_SHARE` | सत्र स्वचालित रूप से साझा करें |
| `CYBERSTRIKE_PERMISSION` | JSON अनुमति ओवरराइड |
| `CYBERSTRIKE_CONFIG` | कस्टम कॉन्फ़िग फ़ाइल का पथ |
| `ANTHROPIC_API_KEY` | Anthropic API कुंजी |
| `OPENAI_API_KEY` | OpenAI API कुंजी |
| `GOOGLE_GENERATIVE_AI_API_KEY` | Google AI (Gemini) API कुंजी |
| `OPENROUTER_API_KEY` | OpenRouter API कुंजी |

## कॉन्फ़िगरेशन फ़ाइलें

Cyberstrike इन स्थानों से कॉन्फ़िगरेशन पढ़ता है:

| पथ | दायरा |
|------|-------|
| `./cyberstrike.json` | प्रोजेक्ट |
| `./.cyberstrike/cyberstrike.json` | प्रोजेक्ट |
| `~/.config/cyberstrike/cyberstrike.json` | वैश्विक |

स्कीमा विवरण के लिए [कॉन्फ़िगरेशन संदर्भ](/docs/configuration) देखें।

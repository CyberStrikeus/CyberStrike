Cyberstrike एक AI प्रदाता के रूप में GitHub Copilot का समर्थन करता है। OAuth से अपने GitHub खाते से प्रमाणित करें और अपनी Copilot सदस्यता के माध्यम से उपलब्ध सभी मॉडल एक्सेस करें — जिसमें Claude, GPT-4o, और o-सीरीज़ मॉडल शामिल हैं।

## आवश्यकताएँ

- एक सक्रिय **GitHub Copilot** सदस्यता (Individual, Business, या Enterprise) वाला GitHub खाता
- GitHub Enterprise के लिए: आपका GHE सर्वर URL

## प्रमाणीकरण

GitHub Copilot **OAuth डिवाइस फ़्लो** का उपयोग करता है — कोई API कुंजी की आवश्यकता नहीं।

### लॉगिन

TUI में चलाएँ:

```
/connect
```

प्रदाता सूची से **Login with GitHub Copilot** चुनें, फिर अपना डिप्लॉयमेंट चुनें:

| डिप्लॉयमेंट | कब उपयोग करें |
|------------|-------------|
| **GitHub.com** | github.com पर व्यक्तिगत या org खाते |
| **GitHub Enterprise** | सेल्फ-होस्टेड GHE या डेटा रेज़िडेंसी इंस्टेंस |

Cyberstrike GitHub अधिकृति के लिए एक ब्राउज़र विंडो खोलता है। टर्मिनल में दिखाया गया डिवाइस कोड दर्ज करें, ऐप को अधिकृत करें, और OAuth टोकन स्वचालित रूप से सेव हो जाता है।

## उपलब्ध मॉडल

उपलब्ध मॉडल आपकी Copilot सदस्यता टियर पर निर्भर करते हैं। सामान्य मॉडल शामिल हैं:

| मॉडल | प्रदाता |
|-------|----------|
| `claude-sonnet-4-20250514` | Anthropic (Copilot के माध्यम से) |
| `claude-sonnet-5-5` | Anthropic (Copilot के माध्यम से) |
| `gpt-4o` | OpenAI (Copilot के माध्यम से) |
| `o3-mini` | OpenAI (Copilot के माध्यम से) |

अपनी सदस्यता पर उपलब्ध सभी मॉडल देखने और उनके बीच स्विच करने के लिए `/models` चलाएँ।

<Aside variant="info">
  Claude मॉडल स्वचालित रूप से OpenAI-संगत एंडपॉइंट (`/chat/completions`) के बजाय Anthropic Messages API (`/v1/messages`) के माध्यम से रूट किए जाते हैं। यह पारदर्शी रूप से होता है — कोई कॉन्फ़िगरेशन की आवश्यकता नहीं।
</Aside>

## कॉन्फ़िगरेशन

GitHub Copilot को OAuth लॉगिन के अलावा कोई मैनुअल कॉन्फ़िगरेशन की आवश्यकता नहीं। प्रमाणीकरण के बाद प्रदाता स्वचालित रूप से रजिस्टर हो जाता है।

Copilot मॉडल को डिफ़ॉल्ट के रूप में उपयोग करने के लिए:

```json title="cyberstrike.json"
{
  "model": "github-copilot/claude-sonnet-4-20250514"
}
```

### GitHub Enterprise

GHE इंस्टेंस के लिए, लॉगिन के दौरान आपसे आपका सर्वर URL पूछा जाएगा:

```
? Enter your GitHub Enterprise URL or domain
> company.ghe.com
```

Copilot API एंडपॉइंट आपके GHE डोमेन से स्वचालित रूप से प्राप्त होता है।

## यह कैसे काम करता है

1. **OAuth डिवाइस फ़्लो** — Cyberstrike GitHub से डिवाइस कोड का अनुरोध करता है, आप ब्राउज़र में अधिकृत करते हैं
2. **टोकन एक्सचेंज** — OAuth टोकन (`ghu_...`) एक अल्पकालिक Copilot सत्र टोकन (~30 मिनट TTL) के लिए एक्सचेंज किया जाता है
3. **ऑटो-रिफ़्रेश** — सत्र टोकन समाप्ति से पहले स्वचालित रूप से रिफ़्रेश किए जाते हैं
4. **मॉडल रूटिंग** — Claude मॉडल Anthropic Messages API का उपयोग करते हैं; अन्य सभी OpenAI-संगत एंडपॉइंट का उपयोग करते हैं

## समस्या निवारण

| समस्या | समाधान |
|-------|-----|
| **401 Unauthorized** | `/connect` फिर से चलाएँ — आपका सत्र टोकन समाप्त हो सकता है |
| **कोई मॉडल उपलब्ध नहीं** | github.com/settings/copilot पर अपनी Copilot सदस्यता सक्रिय होने की जाँच करें |
| **GHE कनेक्शन अस्वीकृत** | एंटरप्राइज़ URL सत्यापित करें और कि आपके GHE इंस्टेंस पर Copilot सक्षम है |
| **Claude मॉडल 404** | Cyberstrike अपडेट करें — Claude रूटिंग फ़िक्स v1.1.16+ में शिप हुआ |

<Aside variant="tip">
  यदि आपके पास पहले से सदस्यता है तो GitHub Copilot एक बढ़िया विकल्प है — कोई अलग API कुंजी की आवश्यकता नहीं, और आपको एक ही लॉगिन के माध्यम से कई प्रदाताओं के मॉडल एक्सेस मिलता है।
</Aside>

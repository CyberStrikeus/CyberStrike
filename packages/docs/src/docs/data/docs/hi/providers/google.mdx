Google के Gemini मॉडल सुरक्षा विश्लेषण के लिए बड़ी संदर्भ विंडो और मल्टीमोडल क्षमताएँ प्रदान करते हैं।

<img src="/docs/images/screenshots/gemini-model-select.png" alt="Model picker filtered to Google Gemini models" className="rounded-lg shadow-lg my-6 w-full" />

## उपलब्ध मॉडल

Cyberstrike अपना मॉडल कैटलॉग [models.dev](https://models.dev) से लाइव पुल करता है, इसलिए सटीक सूची Google की वर्तमान पेशकश को ट्रैक करती है। सामान्य चयन:

| मॉडल | संदर्भ | सर्वोत्तम उपयोग |
|-------|---------|----------|
| `google/gemini-2.5-pro` | 1M | जटिल तर्क, बड़े कोडबेस |
| `google/gemini-2.5-flash` | 1M | तेज़ विश्लेषण (संतुलित डिफ़ॉल्ट) |
| `google/gemini-2.5-flash-lite` | 1M | त्वरित कार्य, उच्च मात्रा |

<Aside variant="tip">
  नई Gemini 3.x रिलीज़ (`gemini-3-pro-preview`, `gemini-3.5-flash`, `gemini-3.1-pro-preview`) models.dev अपडेट होने पर स्वचालित रूप से दिखाई देती हैं। पूरी वर्तमान सूची के लिए `/models` चलाएँ।
</Aside>

## प्रमाणीकरण

### API कुंजी सेटअप

1. [ai.google.dev](https://ai.google.dev) से अपनी API कुंजी प्राप्त करें
2. TUI में `/connect` चलाएँ, **Google** चुनें, और अपनी API कुंजी दर्ज करें

### पर्यावरण चर

```bash
export GOOGLE_GENERATIVE_AI_API_KEY="AI..."
```

### कॉन्फ़िगरेशन फ़ाइल

```json title="~/.config/cyberstrike/cyberstrike.json"
{
  "provider": {
    "google": {
      "options": {
        "apiKey": "{env:GOOGLE_GENERATIVE_AI_API_KEY}"
      }
    }
  }
}
```

## मॉडल कॉन्फ़िगरेशन

### डिफ़ॉल्ट मॉडल सेट करें

```json title="~/.config/cyberstrike/cyberstrike.json"
{
  "model": "google/gemini-2.5-flash"
}
```

### मॉडल बदलना

TUI में `/models` का उपयोग करके एक अलग Gemini मॉडल चुनें।

## बड़ी संदर्भ विंडो का लाभ

Gemini की 1M-2M संदर्भ विंडो सक्षम करती है:

- एक बार में पूरे कोडबेस का विश्लेषण
- एक साथ कई फ़ाइलों को प्रोसेस करना
- लंबे सुरक्षा मूल्यांकन सत्र
- व्यापक लॉग विश्लेषण

### उदाहरण: पूर्ण कोडबेस समीक्षा

```
> Analyze the entire src/ directory for security vulnerabilities
```

मॉडल एक ही अनुरोध में सैकड़ों फ़ाइलों को प्रोसेस कर सकता है।

## मल्टीमोडल क्षमताएँ

Gemini छवि विश्लेषण का समर्थन करता है:

```
> Analyze this screenshot for security issues
```

इसके लिए उपयोगी:
- सुरक्षा टूल आउटपुट छवियों का विश्लेषण
- नेटवर्क डायग्राम प्रोसेस करना
- सुरक्षा खामियों के लिए UI की समीक्षा

## थिंकिंग मोड

Gemini 2.5 मॉडल जटिल विश्लेषण के लिए रीज़निंग ("थिंकिंग") का समर्थन करते हैं। `/models` के माध्यम से एक चुनें।

इसके लिए सर्वोत्तम:
- जटिल भेद्यता श्रृंखलाएँ
- बहु-चरणीय हमला योजना
- गहन कोड विश्लेषण

## Google Vertex AI

एंटरप्राइज़ डिप्लॉयमेंट के लिए:

### सेटअप

```bash
# Authenticate with Google Cloud
gcloud auth application-default login

# Set project
gcloud config set project your-project-id
```

### कॉन्फ़िगरेशन

```json title="~/.config/cyberstrike/cyberstrike.json"
{
  "provider": {
    "google-vertex": {
      "options": {
        "project": "your-project-id",
        "location": "us-central1"
      }
    }
  }
}
```

### उपलब्ध क्षेत्र

| क्षेत्र | स्थान |
|--------|----------|
| us-central1 | आयोवा |
| us-east4 | वर्जीनिया |
| europe-west4 | नीदरलैंड |
| asia-northeast1 | टोक्यो |

## दर सीमाएँ

| टियर | RPM | TPM |
|------|-----|-----|
| मुफ्त | 15 | 1,000,000 |
| पे-ऐज़-यू-गो | 360 | 4,000,000 |

```json
{
```

## सुरक्षा सेटिंग्स

कंटेंट फ़िल्टरिंग कॉन्फ़िगर करें:

```json
{
  "provider": {
    "google": {
      "options": {
        "safetySettings": [
          {
            "category": "HARM_CATEGORY_DANGEROUS_CONTENT",
            "threshold": "BLOCK_NONE"
          }
        ]
      }
    }
  }
}
```

<Aside variant="caution">
  सुरक्षा सेटिंग्स सावधानी से समायोजित करें। कुछ सुरक्षा परीक्षण सामग्री फ़िल्टर ट्रिगर कर सकती है।
</Aside>

## सर्वोत्तम प्रथाएँ

### मॉडल चयन

| कार्य | अनुशंसित मॉडल |
|------|-------------------|
| त्वरित स्कैन | `gemini-2.5-flash` |
| बड़ा कोडबेस | `gemini-2.5-pro` |
| जटिल विश्लेषण | `gemini-2.5-pro` |
| उच्च मात्रा | `gemini-2.5-flash-lite` |

### बड़ी संदर्भ विंडो का लाभ उठाना

1. स्निपेट के बजाय पूरी फ़ाइलें शामिल करें
2. पूर्ण कॉन्फ़िगरेशन फ़ाइलें प्रदान करें
3. संबंधित टेस्ट फ़ाइलें शामिल करें
4. संदर्भ के लिए दस्तावेज़ जोड़ें

### लागत अनुकूलन

1. अधिकांश कार्यों के लिए Flash मॉडल का उपयोग करें
2. मुफ्त टियर का लाभ उठाएँ
3. संदर्भ को कुशलता से उपयोग करें
4. Google Cloud Console में उपयोग की निगरानी करें

## समस्या निवारण

### अमान्य API कुंजी

```
Error: API key not valid
```

सत्यापित करें:
- कुंजी ai.google.dev से है
- API सक्षम है
- कोई अतिरिक्त व्हाइटस्पेस नहीं

### कोटा पार

```
Error: Quota exceeded
```

समाधान:
- कोटा रीसेट की प्रतीक्षा करें
- बिलिंग सक्षम करें
- कोटा बढ़ाने का अनुरोध करें

### क्षेत्र उपलब्ध नहीं

```
Error: Model not available in region
```

अलग क्षेत्र आज़माएँ या Vertex के बजाय Google AI Studio का उपयोग करें।

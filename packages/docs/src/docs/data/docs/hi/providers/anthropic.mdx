Anthropic के Claude मॉडल सुरक्षा विश्लेषण के लिए उन्नत तर्क क्षमताएँ प्रदान करते हैं। यह गाइड कॉन्फ़िगरेशन और सर्वोत्तम प्रथाओं को कवर करती है।

<img src="/docs/images/screenshots/anthropic-model-select.png" alt="Model picker filtered to Anthropic Claude models" className="rounded-lg shadow-lg my-6 w-full" />

## उपलब्ध मॉडल

Cyberstrike अपना मॉडल कैटलॉग [models.dev](https://models.dev) से लाइव पुल करता है, इसलिए सटीक सूची Anthropic की वर्तमान पेशकश को ट्रैक करती है। सामान्य चयन:

| मॉडल | संदर्भ | सर्वोत्तम उपयोग |
|-------|---------|----------|
| `anthropic/claude-opus-4-5` | 200K | सबसे गहरा तर्क — जटिल विश्लेषण, एक्सप्लॉइट अनुसंधान |
| `anthropic/claude-sonnet-4-5` | 200K | संतुलित डिफ़ॉल्ट — सामान्य सुरक्षा परीक्षण |
| `anthropic/claude-haiku-4-5` | 200K | तेज़, कम लागत — त्वरित स्कैन, उच्च मात्रा |

<Aside variant="tip">
  नए फ्लैगशिप (Opus 4.6/4.7/4.8, Sonnet 4.6/5, Fable 5) और हर अन्य Claude मॉडल models.dev अपडेट होने पर स्वचालित रूप से दिखाई देते हैं। पूरी वर्तमान सूची के लिए `/models` चलाएँ। `-latest` उपनाम (जैसे `claude-opus-4-5`) एक परिवार में नवीनतम रिलीज़ को ट्रैक करते हैं; दिनांकित ID (जैसे `claude-opus-4-5-20251101`) एक विशिष्ट संस्करण को पिन करते हैं।
</Aside>

## प्रमाणीकरण

### API कुंजी सेटअप

1. [console.anthropic.com](https://console.anthropic.com) से अपनी API कुंजी प्राप्त करें
2. TUI में `/connect` चलाएँ, **Anthropic** चुनें, और अपनी API कुंजी दर्ज करें

### पर्यावरण चर

```bash
export ANTHROPIC_API_KEY="sk-ant-..."
```

स्थायी उपयोग के लिए अपनी शेल प्रोफ़ाइल में जोड़ें:

```bash
echo 'export ANTHROPIC_API_KEY="sk-ant-..."' >> ~/.zshrc
```

### कॉन्फ़िगरेशन फ़ाइल

```json title="~/.config/cyberstrike/cyberstrike.json"
{
  "provider": {
    "anthropic": {
      "options": {
        "apiKey": "{env:ANTHROPIC_API_KEY}"
      }
    }
  }
}
```

## मॉडल कॉन्फ़िगरेशन

### डिफ़ॉल्ट मॉडल सेट करें

```json title="~/.config/cyberstrike/cyberstrike.json"
{
  "model": "anthropic/claude-sonnet-4-5"
}
```

### मॉडल बदलना

TUI में `/models` का उपयोग करके मॉडल पिकर खोलें और एक अलग Claude मॉडल चुनें।

## विस्तारित सोच

जटिल सुरक्षा विश्लेषण के लिए विस्तारित सोच सक्षम करें:

```json title="~/.config/cyberstrike/cyberstrike.json"
{
  "provider": {
    "anthropic": {
      "options": {
        "thinking": {
          "type": "enabled",
          "budgetTokens": 10000
        }
      }
    }
  }
}
```

### विस्तारित सोच कब उपयोग करें

- जटिल भेद्यता श्रृंखलाएँ
- बहु-चरणीय हमला योजना
- गहन विश्लेषण के साथ कोड समीक्षा
- आर्किटेक्चर सुरक्षा समीक्षा

## टोकन उपयोग

सत्र TUI हेडर में, CyberStrike सबसे हालिया सहायक संदेश के लिए **संदर्भ उपयोग** दिखाता है जिसमें गैर-शून्य आउटपुट टोकन हैं: एक टोकन कुल (इनपुट, आउटपुट, रीज़निंग, और कैश पढ़ना/लिखना) और, जब मॉडल एक संदर्भ सीमा परिभाषित करता है, उस **सीमा का प्रतिशत**। यह **अनुमानित सत्र लागत** भी USD में दिखाता है।

### प्रॉम्प्ट कैशिंग

प्रत्यक्ष Anthropic मॉडल (`providerID` / SDK `npm` `@ai-sdk/anthropic`) के लिए, CyberStrike अनुरोध बनाते समय चयनित सिस्टम और हाल के संदेशों में Anthropic **एफ़ेमरल** कैश कंट्रोल जोड़ता है। इस व्यवहार के लिए `provider.anthropic.options` में कोई अलग `cacheControl` फ़्लैग नहीं है।

## दर सीमाएँ

दर सीमाएँ आपके Anthropic खाते और उत्पाद पर निर्भर करती हैं; वर्तमान कोटा के लिए [Anthropic के दस्तावेज़](https://docs.anthropic.com) देखें।

**पुनर्प्रयास योग्य** API त्रुटियों के लिए, CyberStrike **एक्सपोनेंशियल बैकऑफ़** (2s से शुरू, प्रत्येक प्रयास पर दोगुना, जब कोई `Retry-After` हेडर मौजूद नहीं हो तो 30s पर कैप्ड) का उपयोग करता है और जब प्रदाता उन्हें वापस करता है तो `Retry-After` / `Retry-After-Ms` का सम्मान करता है।

## सर्वोत्तम प्रथाएँ

### मॉडल चयन

| कार्य | अनुशंसित मॉडल |
|------|-------------------|
| त्वरित रिकॉन | `claude-haiku-4-5` |
| वेब ऐप परीक्षण | `claude-sonnet-4-5` |
| जटिल एक्सप्लॉइट | `claude-opus-4-5` |
| कोड समीक्षा | `claude-sonnet-4-5` |

### लागत अनुकूलन

1. दोहराए जाने वाले कार्यों के लिए Haiku का उपयोग करें
2. लंबे सत्रों के लिए `/compact` (या `/summarize`) का उपयोग करें
3. केंद्रित प्रॉम्प्ट के साथ संदर्भ सीमित करें

### सुरक्षा

1. कभी भी API कुंजियाँ रिपॉज़िटरी में कमिट न करें
2. पर्यावरण चर का उपयोग करें
3. समय-समय पर कुंजियाँ बदलें
4. Anthropic डैशबोर्ड पर उपयोग की निगरानी करें

## समस्या निवारण

### अमान्य API कुंजी

```
Error: Invalid API key
```

अपनी कुंजी सत्यापित करें:
- ऐप में Anthropic कनेक्ट करते समय बताए गए प्रारूप से मेल खाती है (API कुंजियाँ आमतौर पर `sk-ant-api…` से शुरू होती हैं)
- कोई अनुगामी व्हाइटस्पेस नहीं
- कुंजी [console.anthropic.com/settings/keys](https://console.anthropic.com/settings/keys) में सक्रिय है

### दर सीमा पार

```
Error: Rate limit exceeded
```

समाधान:
- प्रतीक्षा करें और पुनः प्रयास करें
- अपना टियर अपग्रेड करें
- छोटा संदर्भ उपयोग करें

### मॉडल उपलब्ध नहीं

```
Error: Model not found
```

जाँचें कि मॉडल ID सही है और आपके क्षेत्र में उपलब्ध है।

<Aside variant="tip">
  अधिकांश सुरक्षा परीक्षण कार्यों के लिए Claude Sonnet का उपयोग करें। गहन तर्क की आवश्यकता वाले जटिल विश्लेषण के लिए Opus आरक्षित रखें।
</Aside>

OpenAI सुरक्षा विश्लेषण के लिए GPT-5 परिवार, GPT-4.1, और o-सीरीज़ रीज़निंग मॉडल प्रदान करता है। यह गाइड सेटअप और कॉन्फ़िगरेशन को कवर करती है।

<img src="/docs/images/screenshots/openai-model-select.png" alt="Model picker filtered to OpenAI models" className="rounded-lg shadow-lg my-6 w-full" />

## उपलब्ध मॉडल

Cyberstrike अपना मॉडल कैटलॉग [models.dev](https://models.dev) से लाइव पुल करता है, इसलिए सटीक सूची OpenAI की वर्तमान पेशकश को ट्रैक करती है। सामान्य चयन:

| मॉडल | संदर्भ | सर्वोत्तम उपयोग |
|-------|---------|----------|
| `openai/gpt-5` | 400K | सामान्य सुरक्षा परीक्षण (फ्लैगशिप) |
| `openai/gpt-5-mini` | 400K | त्वरित कार्य, उच्च मात्रा |
| `openai/gpt-5-nano` | 400K | सबसे सस्ता, सरल कार्य |
| `openai/gpt-4.1` | 1M | बहुत बड़ा संदर्भ |
| `openai/o3` | 200K | गहन चरण-दर-चरण तर्क |

<Aside variant="tip">
  नई GPT-5.x रिलीज़ (5.1-5.5, plus Codex और Pro वेरिएंट) models.dev अपडेट होने पर स्वचालित रूप से दिखाई देती हैं। पूरी वर्तमान सूची के लिए `/models` चलाएँ।
</Aside>

## प्रमाणीकरण

### API कुंजी सेटअप

1. [platform.openai.com](https://platform.openai.com) से अपनी API कुंजी प्राप्त करें
2. TUI में `/connect` चलाएँ, **OpenAI** चुनें, और अपनी API कुंजी दर्ज करें

### पर्यावरण चर

```bash
export OPENAI_API_KEY="sk-proj-..."
```

### कॉन्फ़िगरेशन फ़ाइल

```json title="~/.config/cyberstrike/cyberstrike.json"
{
  "provider": {
    "openai": {
      "options": {
        "apiKey": "{env:OPENAI_API_KEY}"
      }
    }
  }
}
```

## मॉडल कॉन्फ़िगरेशन

### डिफ़ॉल्ट मॉडल सेट करें

```json title="~/.config/cyberstrike/cyberstrike.json"
{
  "model": "openai/gpt-5"
}
```

### मॉडल बदलना

TUI में `/models` का उपयोग करके एक अलग OpenAI मॉडल चुनें।

### रीज़निंग मॉडल का उपयोग

o-सीरीज़ (`o3`, `o4-mini`) और GPT-5 Pro वेरिएंट जटिल सुरक्षा विश्लेषण में उत्कृष्ट हैं। `/models` के माध्यम से चुनें।

इसके लिए सर्वोत्तम:
- जटिल भेद्यता श्रृंखलाएँ
- हमले के पथ का विश्लेषण
- क्रिप्टोग्राफ़िक विश्लेषण
- रिवर्स इंजीनियरिंग

## ChatGPT Plus/Pro

TUI में `/connect` चलाकर, **OpenAI** चुनकर, और **ChatGPT Plus/Pro** चुनकर अपनी ChatGPT सदस्यता का उपयोग करें। यह ब्राउज़र-आधारित OAuth फ़्लो ट्रिगर करता है।

<Aside variant="info">
  ChatGPT प्रमाणीकरण के लिए ब्राउज़र-आधारित OAuth फ़्लो आवश्यक है।
</Aside>

## ऑर्गनाइज़ेशन ID

ऑर्गनाइज़ेशन खातों के लिए:

```json title="~/.config/cyberstrike/cyberstrike.json"
{
  "provider": {
    "openai": {
      "options": {
        "apiKey": "{env:OPENAI_API_KEY}",
        "organization": "org-..."
      }
    }
  }
}
```

## कस्टम बेस URL

OpenAI-संगत एंडपॉइंट के लिए:

```json
{
  "provider": {
    "openai": {
      "options": {
        "baseURL": "https://your-endpoint.com/v1"
      }
    }
  }
}
```

## फ़ंक्शन कॉलिंग

GPT मॉडल टूल उपयोग के लिए फ़ंक्शन कॉलिंग का समर्थन करते हैं:

```json
{
  "provider": {
    "openai": {
      "options": {
        "parallelToolCalls": true
      }
    }
  }
}
```

## दर सीमाएँ

OpenAI टियर के अनुसार दर सीमाएँ:

| टियर | RPM | TPM |
|------|-----|-----|
| मुफ्त | 3 | 40,000 |
| टियर 1 | 500 | 200,000 |
| टियर 2 | 5,000 | 2,000,000 |
| टियर 3+ | उच्च सीमाएँ |

### सीमाओं को संभालना

```json
{
  "provider": {
    "openai": {
      "options": {
        "maxRetries": 3,
        "timeout": 60000
      }
    }
  }
}
```

## सर्वोत्तम प्रथाएँ

### मॉडल चयन

| कार्य | अनुशंसित मॉडल |
|------|-------------------|
| त्वरित स्कैन | `gpt-5-nano` |
| सामान्य परीक्षण | `gpt-5` |
| जटिल विश्लेषण | `o3` |
| लागत-संवेदनशील | `gpt-5-mini` |

### लागत अनुकूलन

1. सरल कार्यों के लिए mini मॉडल उपयोग करें
2. उचित अधिकतम टोकन सेट करें
3. लंबे सत्रों के लिए `/compact` उपयोग करें
4. OpenAI डैशबोर्ड पर उपयोग की निगरानी करें

### सुरक्षा

1. पर्यावरण चर में कुंजियाँ स्टोर करें
2. प्रोजेक्ट-विशिष्ट API कुंजियाँ उपयोग करें
3. OpenAI डैशबोर्ड में उपयोग सीमाएँ सक्षम करें
4. समय-समय पर कुंजियाँ बदलें

## समस्या निवारण

### अमान्य API कुंजी

```
Error: Incorrect API key provided
```

सत्यापित करें:
- कुंजी `sk-proj-` या `sk-` से शुरू होती है
- कोई अतिरिक्त व्हाइटस्पेस नहीं
- कुंजी सक्रिय है

### अपर्याप्त कोटा

```
Error: You exceeded your current quota
```

समाधान:
- बिलिंग जानकारी जोड़ें
- उपयोग सीमाएँ जाँचें
- अपना प्लान अपग्रेड करें

### मॉडल एक्सेस

```
Error: The model does not exist or you do not have access
```

कुछ मॉडल के लिए आवश्यक है:
- नवीनतम फ्लैगशिप के लिए उच्च उपयोग टियर
- प्रतीक्षा सूची अनुमोदन
- एंटरप्राइज़ समझौता

<Aside variant="caution">
  रीज़निंग मॉडल (o-सीरीज़ और GPT-5 Pro वेरिएंट) में रीज़निंग चरणों के कारण उच्च विलंबता होती है। लंबे प्रतिक्रिया समय की योजना बनाएँ।
</Aside>

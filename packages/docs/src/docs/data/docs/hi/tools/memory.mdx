## मेमोरी टूल

चार मेमोरी टूल हैं — कोई delete, clear, export, या import ऑपरेशन नहीं है:

| टूल | उद्देश्य |
|------|---------|
| `memory_write` | मेमोरी में एक नोट जोड़ें |
| `memory_read` | संग्रहीत मेमोरी पढ़ें |
| `memory_search` | संग्रहीत नोट्स में खोजें |
| `memory_context` | वर्तमान संदर्भ में प्रासंगिक मेमोरी लाएँ |

## स्टोरेज लेआउट

मेमोरी `.cyberstrike/` के तहत सादा Markdown है:

```
.cyberstrike/
├── MEMORY.md              ← दीर्घकालिक मेमोरी
└── memory/
    └── 2026-07-03.md      ← दिनांकित दैनिक नोट्स
```

- **`MEMORY.md`** टिकाऊ, दीर्घकालिक तथ्य रखता है।
- **`memory/<YYYY-MM-DD>.md`** फ़ाइलें प्रति-दिन नोट्स हैं; प्रत्येक `# Daily Notes - <date>` शीर्षक से शुरू होती है और सत्र चलने पर इसमें जोड़ा जाता है।

वैश्विक मेमोरी (प्रोजेक्ट में साझा) `~/.config/cyberstrike/memory/` के तहत रहती है।

क्योंकि सब कुछ डिस्क पर Markdown है, आप इसे किसी भी अन्य प्रोजेक्ट फ़ाइल की तरह पढ़, संपादित, या वर्शन-कंट्रोल कर सकते हैं।

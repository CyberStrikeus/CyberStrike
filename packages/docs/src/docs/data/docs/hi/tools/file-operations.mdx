## Read टूल

लाइन नंबर के साथ फ़ाइल सामग्री पढ़ें।

### बेसिक उपयोग

```
> Read the contents of src/auth/login.ts
```

### आंशिक फ़ाइल पढ़ना

```
> Read lines 50-100 of src/auth/login.ts
```

### कई फ़ाइलें

```
> Read both config.json and package.json
```

### छवि विश्लेषण

Read टूल छवियों का विश्लेषण कर सकता है:

```
> Read the screenshot at ./evidence/vuln-poc.png
```

### PDF विश्लेषण

```
> Read the security report at ./reports/pentest.pdf
```

## Write टूल

फ़ाइलें बनाएँ या ओवरराइट करें।

### नई फ़ाइल बनाएँ

```
> Write a Python script to exploit the SQL injection to exploit.py
```

### फ़ाइल ओवरराइट करें

```
> Replace the contents of config.json with the secure configuration
```

<Aside variant="caution">
  Write टूल बिना चेतावनी के मौजूदा फ़ाइलें ओवरराइट करता है। आंशिक संशोधन के लिए Edit उपयोग करें।
</Aside>

## Edit टूल

मौजूदा फ़ाइलों में सटीक संपादन करें।

### स्ट्रिंग प्रतिस्थापन

```
> Edit src/auth/login.ts to replace "SELECT * FROM users WHERE id = " + userId with parameterized query
```

### मल्टी-लाइन संपादन

```
> Edit the vulnerable function in auth.ts to add input validation
```

### सभी बदलें

```
> Replace all instances of "http://" with "https://" in config files
```

### सर्वोत्तम प्रथाएँ

1. संदर्भ समझने के लिए पहले फ़ाइल पढ़ें
2. क्या बदलना है इसके बारे में विशिष्ट रहें
3. अद्वितीय मैच के लिए पर्याप्त आसपास का संदर्भ शामिल करें
4. संपादन के बाद परिवर्तन सत्यापित करें

## Glob टूल

पैटर्न मैचिंग द्वारा फ़ाइलें ढूँढें।

### बेसिक पैटर्न

```
> Find all TypeScript files in the project
```

पैटर्न: `**/*.ts`

### कई एक्सटेंशन

```
> Find all JavaScript and TypeScript files
```

पैटर्न: `**/*.{js,ts}`

### विशिष्ट डायरेक्टरी

```
> Find all config files in the src directory
```

पैटर्न: `src/**/config.*`

### सामान्य पैटर्न

| पैटर्न | मेल खाता है |
|---------|---------|
| `**/*.ts` | सभी TypeScript फ़ाइलें |
| `src/**/*.test.ts` | src में टेस्ट फ़ाइलें |
| `**/package.json` | सभी package.json फ़ाइलें |
| `**/.env*` | पर्यावरण फ़ाइलें |
| `**/secret*` | नाम में "secret" वाली फ़ाइलें |

### सुरक्षा स्कैनिंग पैटर्न

```
> Find files that might contain credentials

Patterns:
- **/*.env*
- **/secrets.*
- **/*credentials*
- **/*password*
- **/config.json
```

## Grep टूल

regex से फ़ाइल सामग्री खोजें।

### बेसिक खोज

```
> Search for "password" in all files
```

### Regex खोज

```
> Search for API key patterns in the codebase
```

पैटर्न: `(api[_-]?key|apikey)\s*[:=]\s*['"][^'"]+['"]`

### केस इनसेंसिटिव

```
> Search for "SELECT" case insensitively
```

### फ़ाइल प्रकार फ़िल्टर

```
> Search for "eval(" only in JavaScript files
```

### संदर्भ लाइनें

```
> Search for "TODO" with 2 lines of context before and after
```

### सुरक्षा-केंद्रित खोज

| उद्देश्य | पैटर्न |
|---------|---------|
| SQL Injection | `(SELECT|INSERT|UPDATE|DELETE).*\+.*\$` |
| Command Injection | `(exec|spawn|system)\s*\(` |
| हार्डकोडेड सीक्रेट | `(password\|secret\|key)\s*=\s*['"][^'"]&#123;8,&#125;` |
| असुरक्षित डीसीरियलाइज़ेशन | `(pickle|marshal|yaml\.load)` |
| XSS सिंक | `(innerHTML|outerHTML|document\.write)` |

## फ़ाइल विश्लेषण वर्कफ़्लो

### 1. फ़ाइलें खोजें

```
> Find all files that might handle user input
```

### 2. पैटर्न खोजें

```

```

### 3. संदिग्ध फ़ाइलें पढ़ें

```
> Read the files that matched the SQL pattern
```

### 4. निष्कर्ष दस्तावेज़ करें


## अनुमति विचार

फ़ाइल ऑपरेशन को अनुमति की आवश्यकता हो सकती है:

| ऑपरेशन | अनुमति कुंजी | डिफ़ॉल्ट व्यवहार |
|-----------|----------------|------------------|
| Read | `read` | अनुमत (केवल-पढ़ने) |
| Glob | `glob` | अनुमत (केवल-पढ़ने) |
| Grep | `grep` | अनुमत (केवल-पढ़ने) |
| Write | `edit` | अनुमति आवश्यक |
| Edit | `edit` | अनुमति आवश्यक |

Write और Edit दोनों टूल एकल `edit` अनुमति कुंजी द्वारा गेट किए जाते हैं।

### लेखन ऑटो-अनुमोदित करें

ऑटोमेशन के लिए, `edit` के तहत फ़ाइल-पथ ग्लॉब को कार्रवाइयों में मैप करें:

```json title="~/.config/cyberstrike/cyberstrike.json"
{
  "permission": {
    "edit": {
      "reports/**": "allow",
      "findings/**": "allow"
    }
  }
}
```

वाइल्डकार्ड के रूप में केवल `*` और `?` समर्थित हैं। पूर्ण मॉडल के लिए [अनुमतियाँ](/docs/permissions) देखें।


## सुरक्षा परीक्षण के साथ एकीकरण

### कोड समीक्षा

```
> Analyze all authentication-related files for security issues

1. Find auth files: Glob **/*auth*.{ts,js}
2. Search for vulnerabilities: Grep patterns
3. Read and analyze matches
4. Document findings
```

### कॉन्फ़िगरेशन ऑडिट

```
> Review all configuration files for security misconfigurations

1. Find configs: Glob **/{config,settings}*.{json,yaml,yml}
2. Read each file
3. Check for sensitive data exposure
4. Verify secure defaults
```

### सीक्रेट डिटेक्शन

```
> Scan the codebase for hardcoded secrets

1. Glob all source files
2. Grep for secret patterns
3. Read matches for verification
4. Report findings
```

<Aside variant="tip">
  कुशल कोडबेस स्कैनिंग के लिए Glob और Grep को मिलाएँ। व्यापक शुरू करें, फिर संकीर्ण करें।
</Aside>

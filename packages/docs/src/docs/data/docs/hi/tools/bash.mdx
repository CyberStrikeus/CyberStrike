## अवलोकन

Bash टूल सक्षम करता है:

- सुरक्षा टूल चलाना (nmap, nuclei, sqlmap)
- सिस्टम प्रशासन कमांड
- Git ऑपरेशन
- पैकेज प्रबंधन
- कस्टम स्क्रिप्ट

## बेसिक उपयोग

### साधारण कमांड

```
> Run nmap scan on 192.168.1.1
```

निष्पादित करता है:
```bash
nmap -sV 192.168.1.1
```

### आर्गुमेंट के साथ

```
> Check open ports on target with service detection
```

निष्पादित करता है:
```bash
nmap -sV -sC -p- 192.168.1.1
```

### पाइप्ड कमांड

```
> Find all .env files and search for API keys
```

निष्पादित करता है:
```bash
find . -name "*.env*" -exec grep -l "API" {} \;
```

## सुरक्षा टूल

### नेटवर्क स्कैनिंग

```
> Scan the network 10.0.0.0/24 for live hosts
```

```bash
nmap -sn 10.0.0.0/24
```

### भेद्यता स्कैनिंग

```
> Run nuclei templates against https://target.com
```

```bash
nuclei -u https://target.com -t cves/
```

### वेब परीक्षण

```
> Fuzz directories on target website
```

```bash
ffuf -u https://target.com/FUZZ -w /usr/share/wordlists/dirb/common.txt
```

### पासवर्ड हमले

```
> Test for default credentials on SSH
```

```bash
hydra -L users.txt -P passwords.txt ssh://192.168.1.1
```

## कमांड टाइमआउट

### डिफ़ॉल्ट टाइमआउट

कमांड डिफ़ॉल्ट रूप से 120 सेकंड बाद टाइमआउट होते हैं।

### लंबे समय चलने वाले कमांड

विस्तारित ऑपरेशन के लिए:

```
> Run comprehensive port scan (may take a while)
```

एजेंट उचित टाइमआउट उपयोग करेगा:
```bash
timeout 600 nmap -p- -sV 192.168.1.1
```

### बैकग्राउंड निष्पादन

```
> Start the scan in background
```

```bash
nmap -p- 192.168.1.1 > scan_results.txt &
```

## कार्यशील डायरेक्टरी

### वर्तमान डायरेक्टरी

कमांड वर्तमान कार्यशील डायरेक्टरी में चलते हैं:

```
> List files in current directory
```

```bash
ls -la
```

### डायरेक्टरी बदलें

```
> Navigate to the web directory and list contents
```

```bash
cd /var/www/html && ls -la
```

## पर्यावरण चर

### चर का उपयोग

```
> Use the target IP from environment
```

```bash
nmap -sV $TARGET_IP
```

### चर सेट करना

```
> Set target and scan
```

```bash
export TARGET="192.168.1.1" && nmap $TARGET
```

## आउटपुट हैंडलिंग

### आउटपुट कैप्चर करना

```
> Save scan results to file
```

```bash
nmap -sV 192.168.1.1 -oN scan_results.txt
```

### JSON आउटपुट

```
> Get scan results in JSON format
```

```bash
nmap -sV 192.168.1.1 -oX - | xq .
```

### परिणाम पार्सिंग

```
> Extract open ports from nmap output
```

```bash
grep "^[0-9]" scan_results.txt | cut -d'/' -f1
```

## अनुमति नियंत्रण

### खतरनाक कमांड

विनाशकारी कमांड को स्पष्ट अनुमति की आवश्यकता होती है:

| कमांड प्रकार | उदाहरण | अनुमति आवश्यक |
|--------------|---------|---------------------|
| केवल-पढ़ने | `ls`, `cat`, `nmap` | नहीं |
| फ़ाइल संशोधन | `rm`, `mv` | हाँ |
| सिस्टम परिवर्तन | `apt install` | हाँ |
| नेटवर्क हमले | `msfconsole` | हाँ |

### कमांड ऑटो-अनुमोदित करें

```json title="~/.config/cyberstrike/cyberstrike.json"
{
  "permission": {
    "bash": {
      "nmap *": "allow",
      "nuclei *": "allow",
      "ffuf *": "allow"
    }
  }
}
```

### खतरनाक कमांड ब्लॉक करें

```json
{
  "permission": {
    "bash": {
      "rm -rf *": "deny",
      "dd *": "deny",
      ":(){ :|:& };:": "deny"
    }
  }
}
```

`bash` अनुमति एक ग्लॉब (कमांड स्ट्रिंग के विरुद्ध मैच किया गया) को एक कार्रवाई (`ask`, `allow`, या `deny`) में मैप करती है। वाइल्डकार्ड के रूप में केवल `*` और `?` समर्थित हैं। पूर्ण मॉडल के लिए [अनुमतियाँ](/docs/permissions) देखें।

## सुरक्षा परीक्षण वर्कफ़्लो

### टोही

```
> Perform initial reconnaissance on target.com

1. DNS enumeration
2. Subdomain discovery
3. Port scanning
4. Service identification
```

कई कमांड निष्पादित करता है:

```bash
dig target.com ANY
subfinder -d target.com
nmap -sV -sC target.com
```

### शोषण

```
> Attempt SQL injection with sqlmap
```

```bash
sqlmap -u "https://target.com/page?id=1" --batch --dbs
```

### पोस्ट-एक्सप्लॉइटेशन

```
> Enumerate the compromised system
```

```bash
uname -a
id
cat /etc/passwd
ls -la /home/
```

## टूल एकीकरण

### Metasploit

```
> Search for exploits for Apache 2.4.49
```

```bash
msfconsole -q -x "search apache 2.4.49; exit"
```

### Burp Suite

```
> Start Burp Suite in headless mode
```

```bash
java -jar burpsuite.jar --headless
```

### कस्टम स्क्रिप्ट

```
> Run the custom enumeration script
```

```bash
./scripts/enum.sh $TARGET
```

## त्रुटि हैंडलिंग

### कमांड त्रुटियाँ

विफल कमांड त्रुटि आउटपुट दिखाते हैं:

```
Command failed:
$ nmap -sV nonexistent.host
Host seems down. If it is really up, but blocking our ping probes, try -Pn
```

### पुनर्प्रयास लॉजिक

```
> Retry the scan with -Pn flag
```

```bash
nmap -sV -Pn 192.168.1.1
```

## सर्वोत्तम प्रथाएँ

1. **लक्ष्य सत्यापित करें** - IP और डोमेन दोबारा जाँचें
2. **टाइमआउट उपयोग करें** - लंबे स्कैन के लिए उचित टाइमआउट सेट करें
3. **आउटपुट सेव करें** - हमेशा महत्वपूर्ण परिणाम सेव करें
4. **अनुमतियाँ जाँचें** - अधिकृत एक्सेस सुनिश्चित करें
5. **सफ़ाई करें** - परीक्षण के बाद अस्थायी फ़ाइलें हटाएँ

<Aside variant="danger">
  कभी भी बिना अधिकृति के लक्ष्यों पर कमांड न चलाएँ। अनधिकृत एक्सेस अवैध है।
</Aside>

## समस्या निवारण

### कमांड नहीं मिला

```
Error: command not found: nuclei
```

टूल इंस्टॉल करें या PATH जाँचें:

```bash
which nuclei
export PATH=$PATH:/opt/tools
```

### अनुमति अस्वीकृत

```
Error: permission denied
```

sudo की आवश्यकता हो सकती है:

```bash
sudo nmap -sS 192.168.1.1
```

### टाइमआउट

```
Error: command timed out
```

स्पष्ट टाइमआउट या बैकग्राउंड निष्पादन उपयोग करें।

CyberStrike हार्नेस के साथ इंटरैक्ट करने के कई तरीके प्रदान करता है:

- **[TUI](/docs/usage/tui)** — रियल-टाइम एजेंट आउटपुट, स्लैश कमांड्स और कीबोर्ड शॉर्टकट्स के साथ इंटरैक्टिव टर्मिनल इंटरफ़ेस
- **[CLI](/docs/usage/cli)** — स्क्रिप्टिंग, पाइपलाइन और ऑटोमेशन के लिए नॉन-इंटरैक्टिव मोड
- **[Web](/docs/usage/web)** — सेशन टैब्स, साइड पैनल और एकीकृत टर्मिनल के साथ ब्राउज़र-आधारित इंटरफ़ेस
- **[Desktop App](/docs/usage/desktop-app)** — macOS, Windows और Linux के लिए नेटिव एप्लिकेशन *(जल्द आ रहा है)*

प्रत्येक इंटरफ़ेस एक ही अंतर्निहित इंजन से जुड़ता है और सेशन शेयर करता है, इसलिए आप उनके बीच स्वतंत्र रूप से स्विच कर सकते हैं।

## त्वरित शुरुआत

```bash
# इंटरैक्टिव TUI (डिफ़ॉल्ट)
cyberstrike

# नॉन-इंटरैक्टिव CLI
cyberstrike run "scan example.com for open ports"

# वेब इंटरफ़ेस
cyberstrike web
```

## इंटरफ़ेस चुनना

| इंटरफ़ेस | इसके लिए सर्वोत्तम |
|-----------|----------|
| TUI | दैनिक इंटरैक्टिव मूल्यांकन, स्लैश कमांड्स, कीबोर्ड-संचालित वर्कफ़्लो |
| CLI | CI/CD पाइपलाइन, स्क्रिप्टिंग, टूल आउटपुट पाइपिंग |
| Web | टीम सहयोग, विज़ुअल साइड पैनल, ब्राउज़र-आधारित वर्कफ़्लो |
| Desktop | टर्मिनल के बिना नेटिव अनुभव *(जल्द आ रहा है)* |

सभी इंटरफ़ेस सुरक्षा एजेंट्स, MCP टूल्स और AI प्रदाताओं की पूर्ण रेंज का समर्थन करते हैं।

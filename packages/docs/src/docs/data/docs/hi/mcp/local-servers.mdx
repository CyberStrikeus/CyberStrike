स्थानीय MCP सर्वर आपकी मशीन पर चाइल्ड प्रोसेस के रूप में चलते हैं, stdio पर संवाद करते हैं। यह उन उपयोगकर्ताओं के लिए [Bolt](/docs/mcp/bolt) का एक विकल्प है जो सीधे अपने सिस्टम पर उपकरण चलाना पसंद करते हैं।

<Aside variant="tip">
  **सुरक्षा उपकरणों के लिए Bolt को प्राथमिकता दें।** स्थानीय MCP के लिए प्रत्येक उपकरण को स्वयं स्थापित करना आवश्यक है। पूर्व-स्थापित सुरक्षा-उपकरण प्लगइन्स के साथ अनुशंसित दृष्टिकोण के लिए [Bolt](/docs/mcp/bolt) देखें।
</Aside>

## स्थानीय MCP कब उपयोग करें

- **ऑफ़लाइन वातावरण** — नेटवर्क पहुँच आवश्यक नहीं
- **कम विलंबता** — stdio पर सीधा प्रोसेस संचार
- **कस्टम उपकरण** — आपके अपने MCP सर्वर
- **गोपनीयता** — डेटा आपकी मशीन से कभी नहीं जाता

Cyberstrike डिफ़ॉल्ट रूप से कुछ स्थानीय MCP सर्वर भी सक्षम करता है: `github-security`, `cve`, और `osint`। आपका कॉन्फ़िग इनके ऊपर मर्ज किया जाता है।

## कॉन्फ़िगरेशन स्कीमा

स्थानीय सर्वर फ्लैट `mcp` मैप में एक प्रविष्टि है, सर्वर नाम से कुंजीबद्ध:

```json title="~/.config/cyberstrike/cyberstrike.json"
{
  "mcp": {
    "my-tools": {
      "type": "local",
      "command": ["npx", "-y", "my-mcp-server"],
      "environment": { "API_KEY": "{env:MY_API_KEY}" },
      "enabled": true,
      "timeout": 5000
    }
  }
}
```

| फ़ील्ड | टाइप | विवरण |
|-------|------|-------------|
| `type` | `"local"` | आवश्यक। stdio चाइल्ड-प्रोसेस सर्वर चुनता है। |
| `command` | `string[]` | आवश्यक। कमांड **और उसके आर्गुमेंट्स** एक ऐरे के रूप में। |
| `environment` | object | वैकल्पिक। प्रोसेस के लिए अतिरिक्त एनवायरनमेंट वेरिएबल्स। |
| `enabled` | boolean | वैकल्पिक। लॉन्च पर सर्वर शुरू करें (डिफ़ॉल्ट: true)। |
| `timeout` | number | वैकल्पिक। अनुरोध टाइमआउट मिलीसेकंड में (डिफ़ॉल्ट: 5000)। |

<Aside variant="caution">
  `mcp` ऑब्जेक्ट एक **फ्लैट मैप** है जो सर्वर नाम से कुंजीबद्ध है — कोई `servers` रैपर नहीं है। `command` एक एकल ऐरे है (कमांड + आर्ग्स एक साथ); कोई अलग `args`, `cwd`, `autoStart`, या `restart` फ़ील्ड नहीं है। अज्ञात कुंजियाँ अस्वीकार कर दी जाती हैं।
</Aside>

## TUI के माध्यम से जोड़ना

स्थानीय सर्वर जोड़ने का सबसे आसान तरीका `/mcps` कमांड के साथ TUI से है।

MCP प्रबंधक खोलने के लिए `/mcps` टाइप करें। यह कॉन्फ़िगर किए गए सर्वरों को उनकी स्थिति (`✓` सक्षम / `○` अक्षम) के साथ सूचीबद्ध करता है। सर्वर टॉगल करने के लिए `space` दबाएं, एक जोड़ने के लिए `a`, चयन पर कार्य करने के लिए `Enter`।

स्थानीय सर्वर जोड़ने के लिए: `a` दबाएं → **Local** चुनें → **कमांड** दर्ज करें (जैसे `npx my-mcp-server`) → वैकल्पिक रूप से **एनवायरनमेंट वेरिएबल्स** जोड़ें (`KEY=VALUE, KEY2=VALUE2`) → स्वतः-व्युत्पन्न **नाम** की पुष्टि करें। Cyberstrike सहेजने से पहले कनेक्शन का परीक्षण करता है; यदि विफल होता है, तो सर्वर नहीं जोड़ा जाता।

TUI ठीक ऊपर दिखाए गए स्कीमा को लिखता है।

## उदाहरण

### Node.js सर्वर

```json
{
  "mcp": {
    "filesystem": {
      "type": "local",
      "command": ["npx", "-y", "@modelcontextprotocol/server-filesystem", "/path/to/allow"]
    }
  }
}
```

### Python सर्वर

```json
{
  "mcp": {
    "python-tools": {
      "type": "local",
      "command": ["python", "-m", "mcp_server"]
    }
  }
}
```

### बाइनरी या Docker

चूँकि `command` पूर्ण argv है, आप सीधे बाइनरी चला सकते हैं या इसे Docker में रैप कर सकते हैं — कोई विशेष फ़ील्ड आवश्यक नहीं:

```json
{
  "mcp": {
    "docker-tools": {
      "type": "local",
      "command": ["docker", "run", "-i", "--rm", "--network=none", "mcp-tools:latest"]
    }
  }
}
```

## एनवायरनमेंट वेरिएबल्स

`environment` के साथ सर्वर प्रोसेस को वेरिएबल्स पास करें। सीक्रेट्स हार्ड-कोड करने के बजाय अपने शेल से वेरिएबल संदर्भित करने के लिए `{env:VAR}` का उपयोग करें:

```json
{
  "mcp": {
    "api-tools": {
      "type": "local",
      "command": ["node", "server.js"],
      "environment": {
        "API_KEY": "{env:MY_API_KEY}",
        "DEBUG": "mcp:*"
      }
    }
  }
}
```

## सक्षम और अक्षम करना

सर्वर को कॉन्फ़िगर रखते हुए निष्क्रिय रखने के लिए `enabled: false` सेट करें (या `/mcps` डायलॉग में टॉगल करें):

```json
{
  "mcp": {
    "heavy-tools": {
      "type": "local",
      "command": ["node", "server.js"],
      "enabled": false
    }
  }
}
```

## धीमे-शुरू होने वाले सर्वर

5-सेकंड डिफ़ॉल्ट से अधिक समय लेने वाले सर्वर के लिए `timeout` (मिलीसेकंड) बढ़ाएं:

```json
{
  "mcp": {
    "slow-tools": {
      "type": "local",
      "command": ["node", "server.js"],
      "timeout": 30000
    }
  }
}
```

## समस्या निवारण

- **सर्वर शुरू नहीं होगा** — सत्यापित करें कि `command` का पहला तत्व मौजूद है और निष्पादन योग्य है, और इसकी निर्भरताएं स्थापित हैं। `cyberstrike mcp debug <name>` से कनेक्शन का निरीक्षण करें।
- **कनेक्शन टाइमआउट** — `timeout` बढ़ाएं, या जाँचें कि सर्वर `tools/list` का तुरंत जवाब देता है।
- **कॉन्फ़िग अस्वीकृत** — `mcp` स्कीमा सख्त है; सुनिश्चित करें कि आपने `type` + `command` (ऐरे) और बिना अज्ञात कुंजियों के फ्लैट मैप का उपयोग किया है।

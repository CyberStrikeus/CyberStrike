Bolt एक कंटेनरीकृत MCP सर्वर है जो सुरक्षा उपकरण प्रदान करता है। यह एक Docker कंटेनर (Ubuntu 24.04) में चलता है और प्रत्येक उपकरण को सीधे उजागर करता है — कोई मेटा-टूल नहीं, कोई डायनामिक लोडिंग नहीं, बस आपको जो उपकरण चाहिए उसे कॉल करें।

## Bolt क्यों?

Bolt उन सुरक्षा उपकरणों को चलाने की समस्या हल करता है जिन्हें Linux वातावरण की आवश्यकता होती है। स्थानीय रूप से उपकरण स्थापित करने के बजाय, Bolt उन्हें एक अलग कंटेनर में चलाता है।

| सुविधा | Bolt के बिना | Bolt के साथ |
|---------|--------------|-----------|
| उपकरण स्थापना | प्रत्येक उपकरण के लिए मैनुअल | पूर्व-स्थापित |
| प्लेटफ़ॉर्म सपोर्ट | अधिकांश उपकरणों के लिए केवल Linux | Docker वाला कोई भी प्लेटफ़ॉर्म |
| अलगाव | उपकरण आपके सिस्टम पर चलते हैं | कंटेनर में सैंडबॉक्स्ड |
| अपडेट | मैनुअल | `docker pull` |

## अंदर क्या है

Bolt (`bolt.config.json`, पोर्ट `3001`) उपकरणों को दो तरीकों से उजागर करता है:

- **7 नेटिव प्लगइन्स** — `subfinder`, `nmap`, `nuclei`, `httpx`, `ffuf`, `run-command`, `wordlist`
- **~26 एग्रीगेटेड stdio MCP सर्वर** — जैसे `dnsx`, `amass`, `katana`, `sqlmap`, `wpscan`, `gobuster`, `masscan`, `hydra`, `hashcat`, `john`, `impacket`, और अधिक

प्रत्येक सीधे कॉल करने योग्य उपकरण है — एजेंट इसे एक ही बारी में कॉल करता है, कोई खोज/लोड चरण नहीं।

## त्वरित शुरुआत

### 1. Bolt कंटेनर शुरू करें

```bash
docker run -d \
  --name bolt \
  --restart unless-stopped \
  -p 3001:3001 \
  -v bolt-data:/data \
  -e MCP_ADMIN_TOKEN=$(openssl rand -hex 32) \
  --cap-add NET_RAW \
  --cap-add NET_ADMIN \
  ghcr.io/cyberstrikeus/bolt:latest

# एडमिन टोकन देखें (एक बार उपयोग, पेयर करने के लिए)
docker logs bolt | grep -i token
```

### 2. Cyberstrike के साथ पेयर करें

TUI में `/bolt` डायलॉग खोलें, जोड़ने के लिए **a** दबाएं, URL `http://localhost:3001` दर्ज करें, और एडमिन टोकन प्रदान करें। Cyberstrike सर्वर के साथ पेयर करता है ([प्रमाणीकरण](#प्रमाणीकरण) देखें) और क्रेडेंशियल्स संग्रहित करता है — टोकन स्वयं आपके कॉन्फ़िग में **नहीं** लिखा जाता है।

### 3. उपकरणों का उपयोग करें

```
> Run nmap against 192.168.1.1 with service detection
> Use subfinder to enumerate subdomains of example.com
```

## कॉन्फ़िगरेशन

Bolt सर्वर अपनी **खुद की शीर्ष-स्तरीय `bolt` कुंजी** के तहत कॉन्फ़िगर किए जाते हैं — `mcp` के तहत नहीं। प्रत्येक प्रविष्टि को केवल एक `url` की आवश्यकता होती है (Cyberstrike `/mcp` पथ स्वयं जोड़ता है):

```json title="~/.config/cyberstrike/cyberstrike.json"
{
  "bolt": {
    "local": {
      "url": "http://localhost:3001",
      "enabled": true,
      "timeout": 30000
    }
  }
}
```

| फ़ील्ड | टाइप | विवरण |
|-------|------|-------------|
| `url` | string | आवश्यक। Bolt सर्वर का बेस URL (जैसे `http://localhost:3001`)। |
| `enabled` | boolean | वैकल्पिक। लॉन्च पर कनेक्ट करें (डिफ़ॉल्ट: true)। |
| `timeout` | number | वैकल्पिक। अनुरोध टाइमआउट मिलीसेकंड में (डिफ़ॉल्ट: 30000)। |

<Aside variant="caution">
  Bolt एक `mcp` प्रविष्टि **नहीं** है। कोई `type: "remote"` नहीं, कोई `bolt: true` फ्लैग नहीं, और कॉन्फ़िग में कोई `Authorization` हेडर नहीं — प्रमाणीकरण Ed25519 पेयरिंग द्वारा संभाला जाता है, और एडमिन टोकन केवल पेयरिंग चरण में रहता है।
</Aside>

## प्रमाणीकरण

Bolt **Ed25519 अनुरोध हस्ताक्षर** का उपयोग करता है, जो एडमिन टोकन के साथ एक बार की पेयरिंग द्वारा बूटस्ट्रैप किया जाता है:

1. एडमिन टोकन के साथ `POST /pair` → एक पेयरिंग कोड
2. Cyberstrike एक Ed25519 कीपेयर जनरेट करता है
3. कोड + क्लाइंट पब्लिक कुंजी के साथ `POST /pair/exchange` → सर्वर पब्लिक कुंजी + क्लाइंट ID
4. उसके बाद, प्रत्येक अनुरोध क्लाइंट की निजी कुंजी से **हस्ताक्षरित** होता है

एडमिन टोकन केवल चरण 1 में उपयोग किया जाता है — यह एक स्थायी बियरर क्रेडेंशियल नहीं है और `cyberstrike.json` में कभी संग्रहित नहीं होता।

## TUI प्रबंधन

दो अलग डायलॉग:

- **`/bolt`** — Bolt सर्वर प्रबंधित करता है (जोड़ें/पेयर करें, टॉगल करें, हटाएं)।
- **`/mcps`** — सामान्य स्थानीय/रिमोट MCP सर्वर प्रबंधित करता है।

`/bolt` डायलॉग में: जोड़ने के लिए **a**, सर्वर टॉगल करने के लिए **space**, बंद करने के लिए **esc**।

## उपयोग उदाहरण

```
> Use bolt to scan 192.168.1.0/24 for open ports and services   # nmap
> Find all subdomains of example.com                            # subfinder
> Scan https://target.com with nuclei                           # nuclei
> Fuzz directories on https://target.com                        # ffuf
> Run "dig +short example.com"                                  # run-command एस्केप हैच
```

प्रत्येक एक सीधे टूल कॉल से मैप होता है — कोई लोडिंग चरण नहीं।

## कंटेनर कॉन्फ़िगरेशन

### एनवायरनमेंट वेरिएबल्स

| वेरिएबल | डिफ़ॉल्ट | विवरण |
|----------|---------|-------------|
| `PORT` | 3001 | HTTP सर्वर पोर्ट |
| `HOST` | 0.0.0.0 | बाइंड एड्रेस |
| `MCP_ADMIN_TOKEN` | — | पेयरिंग के लिए उपयोग किया जाने वाला एडमिन टोकन |
| `DATA_DIR` | /data | स्थायी डेटा डायरेक्टरी |

### Docker क्षमताएं

| क्षमता | उद्देश्य |
|------------|---------|
| `NET_RAW` | nmap SYN स्कैन के लिए रॉ सॉकेट |
| `NET_ADMIN` | उन्नत पहुँच की आवश्यकता वाले उपकरणों के लिए नेटवर्क कॉन्फ़िगरेशन |

## API संदर्भ

| एंडपॉइंट | उद्देश्य |
|----------|---------|
| `GET /health` | स्वास्थ्य जाँच — `{ "status": "ok" }` लौटाता है (प्रमाणित एडमिन अनुरोधों को टूल गणना सहित विस्तृत जानकारी मिलती है) |
| `POST /mcp` | MCP JSON-RPC एंडपॉइंट (हस्ताक्षरित अनुरोध) |
| `POST /pair` | एडमिन टोकन के साथ Ed25519 पेयरिंग शुरू करें |
| `POST /pair/exchange` | पेयरिंग कोड + पब्लिक कुंजियों का आदान-प्रदान |

```bash
curl http://localhost:3001/health
```

## समस्या निवारण

- **कनेक्शन अस्वीकृत** — जाँचें कि कंटेनर चल रहा है (`docker ps`), पोर्ट मैप किया गया है (`docker port bolt`), और `curl http://localhost:3001/health` प्रतिक्रिया दे रहा है।
- **फिर से पेयरिंग आवश्यक** — यदि Bolt URL बदलता है, तो Cyberstrike संग्रहित क्रेडेंशियल्स को हटा देता है और आपको `/bolt` के माध्यम से फिर से पेयर करना होगा।
- **उपकरण उपलब्ध नहीं** — `/bolt` में पुष्टि करें कि सर्वर कनेक्टेड है, और एक डायरेक्ट-API मॉडल (जैसे `anthropic/claude-sonnet-4-20250514`, `openai/gpt-4o`) का उपयोग करें।

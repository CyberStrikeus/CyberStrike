Cyberstrike बाहरी उपकरणों को एकीकृत करने के लिए Model Context Protocol (MCP) का उपयोग करता है। **Bolt** हमारा कंटेनरीकृत टूल सर्वर है जो सुरक्षा उपकरणों का एक बड़ा सेट प्रदान करता है; आप किसी भी स्थानीय या रिमोट MCP सर्वर को भी कनेक्ट कर सकते हैं।

## उपकरण जोड़ने के दो तरीके

| दृष्टिकोण | ट्रांसपोर्ट | लाभ | हानि |
|----------|-----------|------|------|
| **Bolt** (अनुशंसित) | StreamableHTTP | पूर्व-स्थापित उपकरण, कंटेनर अलगाव, आसान सेटअप | Docker आवश्यक, नेटवर्क विलंबता |
| **स्थानीय / रिमोट MCP** | stdio / StreamableHTTP | कोई भी MCP सर्वर; स्थानीय के लिए शून्य-विलंबता | आप सर्वर स्थापित और चलाते हैं |

Cyberstrike डिफ़ॉल्ट रूप से तीन MCP सर्वर भी सक्षम करता है: `github-security`, `cve`, और `osint`। आपका अपना कॉन्फ़िग इनके ऊपर मर्ज किया जाता है।

## Bolt

Bolt एक Docker कंटेनर (Ubuntu 24.04, पोर्ट 3001) के अंदर सुरक्षा उपकरण चलाता है। यह **7 नेटिव प्लगइन्स** (`subfinder`, `nmap`, `nuclei`, `httpx`, `ffuf`, `run-command`, `wordlist`) और **~26 एग्रीगेटेड MCP सर्वर** (`dnsx`, `amass`, `katana`, `sqlmap`, `wpscan`, `hydra`, `hashcat`, और अधिक) को उजागर करता है। प्रत्येक उपकरण सीधे कॉल करने योग्य है — एजेंट इसे एक ही बारी में कॉल करता है।

Bolt अपनी **खुद की शीर्ष-स्तरीय `bolt` कुंजी** (न कि `mcp`) के तहत कॉन्फ़िगर किया जाता है और Ed25519 पेयरिंग द्वारा प्रमाणित होता है:

```json title="~/.config/cyberstrike/cyberstrike.json"
{
  "bolt": {
    "local": { "url": "http://localhost:3001" }
  }
}
```

सेटअप और पेयरिंग के लिए [Bolt](/docs/mcp/bolt) पृष्ठ देखें।

## स्थानीय / रिमोट MCP

कोई भी अन्य MCP सर्वर फ्लैट `mcp` मैप के तहत, नाम से कुंजीबद्ध होता है:

```json title="cyberstrike.json"
{
  "mcp": {
    "my-tools": {
      "type": "local",
      "command": ["your-mcp-server"]
    }
  }
}
```

- [स्थानीय सर्वर](/docs/mcp/local-servers) — stdio चाइल्ड प्रोसेस
- [रिमोट सर्वर](/docs/mcp/remote-servers) — StreamableHTTP/SSE, वैकल्पिक [OAuth](/docs/mcp/oauth) के साथ

## TUI प्रबंधन

दो अलग डायलॉग:

- **`/bolt`** — Bolt सर्वर प्रबंधित करें (जोड़ें और पेयर करें, टॉगल करें, हटाएं)।
- **`/mcps`** — स्थानीय/रिमोट MCP सर्वर प्रबंधित करें।

दोनों में: सर्वर जोड़ने के लिए **a**, सर्वर टॉगल करने के लिए **space**, बंद करने के लिए **esc**।

## मॉडल संगतता

<Aside variant="caution">
  सबप्रोसेस-आधारित मॉडल MCP उपकरणों तक पहुँच नहीं सकते। पूर्ण Bolt/MCP एकीकरण के लिए डायरेक्ट-API मॉडल का उपयोग करें।
</Aside>

डायरेक्ट-API मॉडल (जैसे `anthropic/claude-sonnet-4-20250514`, `openai/gpt-4o`) Cyberstrike के अंदर चलते हैं और पूर्ण MCP पहुँच रखते हैं। जो मॉडल एक अलग CLI प्रोसेस में शेल आउट करते हैं, वे नहीं रखते।

## कॉन्फ़िगरेशन प्राथमिकता

MCP और Bolt प्रविष्टियाँ मानक [कॉन्फ़िगरेशन पदानुक्रम](/docs/configuration#configuration-hierarchy) का पालन करती हैं: एक प्रोजेक्ट की `.cyberstrike/` डायरेक्टरी प्रोजेक्ट `cyberstrike.json` को ओवरराइड करती है, जो ग्लोबल `~/.config/cyberstrike/` कॉन्फ़िग को ओवरराइड करता है, जो बिल्ट-इन सर्वर को ओवरराइड करता है।

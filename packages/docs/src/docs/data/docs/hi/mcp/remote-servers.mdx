रिमोट MCP सर्वर HTTP/HTTPS पर कनेक्ट होते हैं, होस्टेड सेवाओं और साझा इंफ्रास्ट्रक्चर तक पहुँच सक्षम करते हैं। ट्रांसपोर्ट StreamableHTTP है (SSE फ़ॉलबैक के साथ)।

<Aside variant="tip">
  **सुरक्षा उपकरण खोज रहे हैं?** पूर्व-स्थापित सुरक्षा उपकरणों के लिए [Bolt](/docs/mcp/bolt) देखें। ध्यान दें कि Bolt अपनी शीर्ष-स्तरीय `bolt` कुंजी के तहत कॉन्फ़िगर किया जाता है, `mcp` के तहत नहीं।
</Aside>

## कॉन्फ़िगरेशन स्कीमा

रिमोट सर्वर फ्लैट `mcp` मैप में एक प्रविष्टि है, सर्वर नाम से कुंजीबद्ध:

```json title="~/.config/cyberstrike/cyberstrike.json"
{
  "mcp": {
    "my-remote": {
      "type": "remote",
      "url": "https://mcp.example.com/mcp",
      "headers": { "Authorization": "Bearer {env:MY_TOKEN}" },
      "enabled": true,
      "timeout": 5000
    }
  }
}
```

| फ़ील्ड | टाइप | विवरण |
|-------|------|-------------|
| `type` | `"remote"` | आवश्यक। HTTP-आधारित सर्वर चुनता है। |
| `url` | string | आवश्यक। सर्वर एंडपॉइंट। |
| `headers` | object | वैकल्पिक। प्रत्येक अनुरोध के साथ भेजे जाने वाले हेडर्स (जैसे API कुंजी)। |
| `oauth` | object \| `false` | वैकल्पिक। OAuth कॉन्फ़िग; OAuth ऑटो-डिटेक्शन अक्षम करने के लिए `false` सेट करें। [OAuth](/docs/mcp/oauth) देखें। |
| `enabled` | boolean | वैकल्पिक। लॉन्च पर कनेक्ट करें (डिफ़ॉल्ट: true)। |
| `timeout` | number | वैकल्पिक। अनुरोध टाइमआउट मिलीसेकंड में (डिफ़ॉल्ट: 5000)। |

<Aside variant="caution">
  `mcp` ऑब्जेक्ट एक **फ्लैट मैप** है जो सर्वर नाम से कुंजीबद्ध है — कोई `servers` रैपर नहीं है। ट्रांसपोर्ट केवल StreamableHTTP/SSE है (कोई WebSocket ट्रांसपोर्ट नहीं), और स्कीमा सख्त है: `retry`, `keepalive`, `proxy`, TLS/`ca`/`cert`, और लोड-बैलेंसिंग फ़ील्ड **मौजूद नहीं** हैं।
</Aside>

## TUI के माध्यम से जोड़ना

MCP प्रबंधक खोलने के लिए `/mcps` टाइप करें, जोड़ने के लिए `a` दबाएं, और **Remote** चुनें। सर्वर **URL** दर्ज करें; सर्वर **नाम** होस्टनाम से स्वतः-व्युत्पन्न होता है (डॉट हाइफ़न बन जाते हैं)। Cyberstrike सहेजने से पहले कनेक्शन का परीक्षण करता है। यह ठीक ऊपर दिखाए गए स्कीमा को लिखता है।

## प्रमाणीकरण

### हेडर के माध्यम से API कुंजी

अनुरोध हेडर के रूप में एक स्थिर टोकन या API कुंजी भेजें। `{env:VAR}` का उपयोग करें ताकि सीक्रेट कॉन्फ़िग फ़ाइल में संग्रहित न हो:

```json
{
  "mcp": {
    "github-remote": {
      "type": "remote",
      "url": "https://api.githubcopilot.com/mcp/",
      "headers": { "Authorization": "Bearer {env:GITHUB_TOKEN}" }
    }
  }
}
```

### OAuth

OAuth का उपयोग करने वाले सर्वर के लिए, एक `oauth` ब्लॉक जोड़ें (या Cyberstrike को ऑटो-डिटेक्ट करने दें)। जब `clientId` छोड़ दिया जाता है, तो डायनामिक क्लाइंट पंजीकरण (RFC 7591) का प्रयास किया जाता है:

```json
{
  "mcp": {
    "oauth-server": {
      "type": "remote",
      "url": "https://mcp.example.com/mcp",
      "oauth": { "scope": "read write" }
    }
  }
}
```

`cyberstrike mcp auth <name>` से प्राधिकृत करें। पूर्ण प्रवाह के लिए [OAuth](/docs/mcp/oauth) देखें। OAuth ऑटो-डिटेक्शन से बाहर निकलने के लिए `"oauth": false` सेट करें।

## सक्षम करना, अक्षम करना और टाइमआउट

सर्वर को कॉन्फ़िगर रखते हुए डिस्कनेक्ट रखने के लिए `enabled: false` सेट करें (या `/mcps` में टॉगल करें)। धीमे एंडपॉइंट्स के लिए `timeout` (ms) बढ़ाएं:

```json
{
  "mcp": {
    "slow-remote": {
      "type": "remote",
      "url": "https://mcp.example.com/mcp",
      "enabled": false,
      "timeout": 30000
    }
  }
}
```

## समस्या निवारण

- **प्रमाणीकरण विफलता** — हेडर सत्यापित करें या OAuth सर्वर के लिए `cyberstrike mcp auth <name>` चलाएं; `cyberstrike mcp debug <name>` से निरीक्षण करें।
- **टाइमआउट** — `timeout` बढ़ाएं, या पुष्टि करें कि एंडपॉइंट पहुँच योग्य है।
- **कॉन्फ़िग अस्वीकृत** — स्कीमा सख्त है; `type: "remote"` + `url` और केवल ऊपर सूचीबद्ध फ़ील्ड के साथ फ्लैट मैप का उपयोग करें।

## अवलोकन

Ollama के लाभ:

- पूर्ण डेटा गोपनीयता
- कोई API लागत नहीं
- ऑफ़लाइन संचालन
- कोई दर सीमा नहीं
- मॉडल पर पूर्ण नियंत्रण

## इंस्टॉलेशन

### macOS

```bash
brew install ollama
```

### Linux

```bash
curl -fsSL https://ollama.com/install.sh | sh
```

### Windows

[ollama.com/download](https://ollama.com/download) से डाउनलोड करें

## Ollama शुरू करना

### सर्वर शुरू करें

```bash
ollama serve
```

सर्वर डिफ़ॉल्ट रूप से `http://localhost:11434` पर चलता है।

### इंस्टॉलेशन सत्यापित करें

```bash
ollama --version
```

## उपलब्ध मॉडल

### अनुशंसित मॉडल

| मॉडल | आकार | सर्वोत्तम उपयोग |
|-------|------|----------|
| llama3.3:70b | 40GB | सर्वोत्तम गुणवत्ता, हाई-एंड GPU आवश्यक |
| llama3.3 | 4.7GB | गुणवत्ता और गति का अच्छा संतुलन |
| codellama:34b | 19GB | कोड विश्लेषण |
| mistral | 4.1GB | तेज़ सामान्य उपयोग |
| mixtral:8x7b | 26GB | उच्च गुणवत्ता, कुशल |
| deepseek-coder:33b | 19GB | कोड सुरक्षा समीक्षा |
| qwen2.5:72b | 41GB | उत्कृष्ट तर्क |

### मॉडल पुल करें

```bash
# Recommended for security testing
ollama pull llama3.3

# For code review
ollama pull codellama:34b

# Lightweight option
ollama pull mistral
```

### इंस्टॉल किए गए मॉडल सूचीबद्ध करें

```bash
ollama list
```

## कॉन्फ़िगरेशन

Ollama एक बिल्ट-इन प्रदाता **नहीं** है — आप इसे कस्टम OpenAI-संगत प्रदाता के रूप में परिभाषित करते हैं। कुंजी शीर्ष-स्तरीय `api` फ़ील्ड (बेस URL, `/v1` प्रत्यय सहित) है; इसे `provider` के तहत `api` URL के साथ सूचीबद्ध करना ही CyberStrike को इसे लोड कराता है (कोई प्रमाणीकरण आवश्यक नहीं)। अपने पुल किए गए मॉडल `models` के तहत परिभाषित करें:

### बेसिक सेटअप

```json title="~/.config/cyberstrike/cyberstrike.json"
{
  "provider": {
    "ollama": {
      "name": "Ollama",
      "api": "http://localhost:11434/v1",
      "models": {
        "llama3.3": { "name": "Llama 3.3" }
      }
    }
  },
  "model": "ollama/llama3.3"
}
```

`npm` डिफ़ॉल्ट रूप से `@ai-sdk/openai-compatible` होता है, इसलिए आपको इसे सेट करने की आवश्यकता नहीं है।

### कस्टम होस्ट

रिमोट Ollama सर्वर के लिए, `api` URL बदलें:

```json
{
  "provider": {
    "ollama": {
      "name": "Ollama",
      "api": "http://192.168.1.100:11434/v1",
      "models": { "llama3.3": { "name": "Llama 3.3" } }
    }
  }
}
```

## उपयोग

TUI में `/models` का उपयोग करके Ollama मॉडल चुनें, या इसे अपने कॉन्फ़िग में डिफ़ॉल्ट के रूप में सेट करें।

## मॉडल कॉन्फ़िगरेशन

### संदर्भ लंबाई

संदर्भ विंडो बढ़ाएँ:

```bash
ollama run llama3.3 --num-ctx 8192
```

या Modelfile में:

```
FROM llama3.3
PARAMETER num_ctx 8192
```

### GPU लेयर

GPU उपयोग नियंत्रित करें:

```bash
OLLAMA_NUM_GPU=999 ollama serve  # Use all GPU layers
OLLAMA_NUM_GPU=0 ollama serve    # CPU only
```

### मेमोरी प्रबंधन

```bash
# Limit VRAM usage
OLLAMA_MAX_VRAM=8G ollama serve
```

## कस्टम मॉडल

### Modelfile बनाएँ

```dockerfile title="Modelfile"
FROM llama3.3

SYSTEM """
You are a security testing assistant specialized in:
- Web application vulnerabilities
- Code security review
- Network penetration testing

Always follow OWASP guidelines and report findings with:
- Vulnerability name
- Severity (Critical/High/Medium/Low)
- Evidence
- Remediation steps
"""

PARAMETER temperature 0.7
PARAMETER num_ctx 8192
```

### कस्टम मॉडल बनाएँ

```bash
ollama create security-assistant -f Modelfile
```

### कस्टम मॉडल उपयोग करें

अपने कॉन्फ़िग में कस्टम मॉडल जोड़ें और `/models` के माध्यम से चुनें:

```json
{
  "provider": {
    "ollama": {
      "models": {
        "security-assistant": { "name": "Security Assistant" }
      }
    }
  }
}
```

## प्रदर्शन अनुकूलन

### हार्डवेयर आवश्यकताएँ

| मॉडल आकार | न्यूनतम RAM | अनुशंसित GPU |
|------------|---------|-----------------|
| 7B | 8GB | 8GB VRAM |
| 13B | 16GB | 12GB VRAM |
| 34B | 32GB | 24GB VRAM |
| 70B | 64GB | 48GB VRAM |

### क्वांटाइज़ेशन

कम मेमोरी के लिए क्वांटाइज़्ड मॉडल उपयोग करें:

```bash
ollama pull llama3.3:q4_0  # 4-bit quantization
ollama pull llama3.3:q8_0  # 8-bit quantization
```

### समानांतर अनुरोध

समवर्ती अनुरोध सक्षम करें:

```bash
OLLAMA_NUM_PARALLEL=4 ollama serve
```

## ऑफ़लाइन उपयोग

### मॉडल पहले से डाउनलोड करें

```bash
ollama pull llama3.3
ollama pull codellama
```

### एयर-गैप्ड सिस्टम

1. कनेक्टेड सिस्टम पर मॉडल डाउनलोड करें
2. `~/.ollama/models/` को एयर-गैप्ड सिस्टम पर कॉपी करें
3. बिना इंटरनेट के Ollama चलाएँ

## Docker डिप्लॉयमेंट

### कंटेनर में चलाएँ

```bash
docker run -d \
  --gpus all \
  -v ollama:/root/.ollama \
  -p 11434:11434 \
  --name ollama \
  ollama/ollama
```

### कंटेनर में मॉडल पुल करें

```bash
docker exec -it ollama ollama pull llama3.3
```

## API संगतता

Ollama `http://localhost:11434/v1` पर OpenAI-संगत API एक्सपोज़ करता है — ठीक इसीलिए ऊपर का कस्टम-प्रदाता कॉन्फ़िग काम करता है (`npm` डिफ़ॉल्ट रूप से `@ai-sdk/openai-compatible` होता है)। `api` फ़ील्ड को उस URL पर पॉइंट करें और CyberStrike OpenAI प्रोटोकॉल पर Ollama से बात करता है।

## समस्या निवारण

### कनेक्शन अस्वीकृत

```
Error: Connection refused
```

सुनिश्चित करें कि Ollama चल रहा है:

```bash
ollama serve
```

### मेमोरी से बाहर

```
Error: CUDA out of memory
```

समाधान:
- छोटा मॉडल उपयोग करें
- क्वांटाइज़्ड संस्करण उपयोग करें
- संदर्भ लंबाई कम करें
- CPU के लिए `OLLAMA_NUM_GPU=0` सेट करें

### धीमा प्रदर्शन

- GPU त्वरण सक्षम करें
- क्वांटाइज़्ड मॉडल उपयोग करें
- `num_parallel` बढ़ाएँ
- थर्मल थ्रॉटलिंग जाँचें

<Aside variant="tip">
  सर्वोत्तम परिणामों के लिए, हाई-एंड GPU के साथ llama3.3:70b का उपयोग करें। सीमित संसाधन वाले सिस्टम के लिए, mistral कम आवश्यकताओं के साथ अच्छी गुणवत्ता प्रदान करता है।
</Aside>

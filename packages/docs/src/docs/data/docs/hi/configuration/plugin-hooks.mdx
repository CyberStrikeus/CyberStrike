एक प्लगइन `(input) => Promise<Hooks>` फंक्शन है जो हुक फंक्शन्स का एक ऑब्जेक्ट लौटाता है। प्रत्येक हुक एक `input` (केवल-पढ़ने योग्य कॉन्टेक्स्ट) और, अधिकांश हुक्स के लिए, एक `output` ऑब्जेक्ट प्राप्त करता है जिसे आप व्यवहार बदलने के लिए **म्यूटेट** करते हैं। हुक से थ्रो करने पर ऑपरेशन रद्द हो जाता है।

<img src="/docs/images/diagrams/plugin-hook-architecture.svg" alt="प्लगइन हुक निष्पादन प्रवाह: LLM कॉल से पहले chat.params/chat.headers, टूल से पहले permission.ask, आर्ग्स संशोधित या ब्लॉक करने के लिए tool.execute.before, फिर आउटपुट बदलने के लिए tool.execute.after" className="my-6 mx-auto max-w-xs" />

प्लगइन को स्कैफोल्ड और पंजीकृत करने के लिए [प्लगइन बनाना](/docs/configuration/creating-plugins) देखें। यह पृष्ठ प्रत्येक हुक का संदर्भ है।

## हुक संदर्भ

| हुक | कब चलता है | आप कर सकते हैं... |
|------|--------------|----------|
| `event` | किसी भी बस इवेंट पर | इवेंट्स का अवलोकन (लॉगिंग, एनालिटिक्स) |
| `config` | कॉन्फ़िग लोड होने के बाद | लोड किए गए कॉन्फ़िग का निरीक्षण/समायोजन |
| `tool` | पंजीकरण | कस्टम टूल्स जोड़ें (नाम → परिभाषा का मैप) |
| `auth` | पंजीकरण | कस्टम प्रमाणीकरण प्रदाता जोड़ें |
| `chat.message` | उपयोगकर्ता संदेश प्राप्त होने पर | संदेश भागों को पढ़ें/जोड़ें |
| `chat.params` | LLM कॉल से पहले | `temperature`, `topP`, `topK`, `options` बदलें |
| `chat.headers` | LLM अनुरोध से पहले | अनुरोध `headers` जोड़ें/संशोधित करें |
| `permission.ask` | अनुमति का अनुरोध होने पर | `status` को `allow`/`deny`/`ask` पर सेट करें |
| `command.execute.before` | स्लैश कमांड चलने पर | `parts` इंजेक्ट करें |
| `tool.execute.before` | टूल चलने से पहले | `args` संशोधित करें, या ब्लॉक करने के लिए थ्रो करें |
| `tool.execute.after` | टूल चलने के बाद | `title`/`output`/`metadata` बदलें |
| `tool.definition` | टूल LLM को भेजा जाने पर | टूल के `description`/`parameters` को फिर से लिखें |
| `shell.env` | शेल कमांड चलने पर | एनवायरनमेंट वेरिएबल्स जोड़ें |
| `experimental.chat.messages.transform` | LLM कॉल से पहले | पूर्ण संदेश सूची को फिर से लिखें |
| `experimental.chat.system.transform` | LLM कॉल से पहले | सिस्टम प्रॉम्प्ट ऐरे को फिर से लिखें |
| `experimental.session.compacting` | संक्षेपण से पहले | कॉन्टेक्स्ट जोड़ें या संक्षेपण प्रॉम्प्ट बदलें |
| `experimental.text.complete` | टेक्स्ट भाग पूरा होने पर | पूर्ण टेक्स्ट को फिर से लिखें |

## सिग्नेचर

प्रत्येक हुक `async` है और `Promise<void>` लौटाता है।

### टूल्स

```typescript
"tool.execute.before"?: (
  input: { tool: string; sessionID: string; callID: string },
  output: { args: any },
) => Promise<void>

"tool.execute.after"?: (
  input: { tool: string; sessionID: string; callID: string; args: any },
  output: { title: string; output: string; metadata: any },
) => Promise<void>

"tool.definition"?: (
  input: { toolID: string },
  output: { description: string; parameters: any },
) => Promise<void>
```

किसी टूल को **ब्लॉक** करने के लिए, `tool.execute.before` से थ्रो करें:

```typescript
"tool.execute.before": async (input, output) => {
  if (input.tool === "bash" && /rm\s+-rf/.test(output.args.command)) {
    throw new Error("blocked: rm -rf")
  }
}
```

### अनुमतियाँ

```typescript
"permission.ask"?: (
  input: Permission,
  output: { status: "ask" | "deny" | "allow" },
) => Promise<void>
```

```typescript
"permission.ask": async (input, output) => {
  if (input.type === "read") output.status = "allow"
}
```

### चैट

```typescript
"chat.message"?: (
  input: { sessionID: string; agent?: string; model?: { providerID: string; modelID: string }; messageID?: string; variant?: string },
  output: { message: UserMessage; parts: Part[] },
) => Promise<void>

"chat.params"?: (
  input: { sessionID: string; agent: string; model: Model; provider: ProviderContext; message: UserMessage },
  output: { temperature: number; topP: number; topK: number; options: Record<string, any> },
) => Promise<void>

"chat.headers"?: (
  input: { sessionID: string; agent: string; model: Model; provider: ProviderContext; message: UserMessage },
  output: { headers: Record<string, string> },
) => Promise<void>
```

### कमांड और शेल

```typescript
"command.execute.before"?: (
  input: { command: string; sessionID: string; arguments: string },
  output: { parts: Part[] },
) => Promise<void>

"shell.env"?: (
  input: { cwd: string },
  output: { env: Record<string, string> },
) => Promise<void>
```

### जीवनचक्र

```typescript
event?:  (input: { event: Event }) => Promise<void>
config?: (input: Config) => Promise<void>
```

### प्रयोगात्मक

```typescript
"experimental.chat.messages.transform"?: (input: {}, output: { messages: { info: Message; parts: Part[] }[] }) => Promise<void>
"experimental.chat.system.transform"?:   (input: { sessionID?: string; model: Model }, output: { system: string[] }) => Promise<void>
"experimental.session.compacting"?:      (input: { sessionID: string }, output: { context: string[]; prompt?: string }) => Promise<void>
"experimental.text.complete"?:           (input: { sessionID: string; messageID: string; partID: string }, output: { text: string }) => Promise<void>
```

## कस्टम टूल्स और प्रमाणीकरण

`tool` और `auth` हुक्स इवेंट्स पर प्रतिक्रिया करने के बजाय क्षमताओं को पंजीकृत करते हैं:

```typescript
return {
  tool: {
    my_scanner: {
      description: "Custom vulnerability scanner",
      parameters: { type: "object", properties: { target: { type: "string" } }, required: ["target"] },
      execute: async (args) => ({ title: `Scanned ${args.target}`, output: await scan(args.target) }),
    },
  },
}
```

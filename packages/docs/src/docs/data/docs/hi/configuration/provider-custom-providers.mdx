## बिल्ट-इन अतिरिक्त प्रदाता

ये **पहले से बंडल** हैं — आपको किसी प्रदाता कॉन्फ़िग की आवश्यकता नहीं। बस API-कुंजी पर्यावरण चर सेट करें और `provider-id/model` के रूप में मॉडल चुनें:

| प्रदाता id | Env var | उदाहरण मॉडल |
|-------------|---------|---------------|
| `groq` | `GROQ_API_KEY` | `groq/llama-3.3-70b-versatile` |
| `togetherai` | `TOGETHER_API_KEY` | `togetherai/meta-llama/Llama-3.3-70B-Instruct-Turbo` |
| `deepinfra` | `DEEPINFRA_API_KEY` | `deepinfra/meta-llama/Llama-3.3-70B-Instruct` |
| `perplexity` | `PERPLEXITY_API_KEY` | `perplexity/sonar` |
| `openrouter` | `OPENROUTER_API_KEY` | `openrouter/anthropic/claude-sonnet-4` |

```bash
export GROQ_API_KEY="gsk_..."
cyberstrike --model groq/llama-3.3-70b-versatile
```

अन्य (`mistral`, `xai`, `deepseek`, `cohere`, `cerebras`, और अधिक) उसी तरह काम करते हैं — उनकी कुंजी सेट करें और `provider-id/model` का उपयोग करें। [AI प्रदाता](/docs/configuration/providers) देखें।

## कस्टम OpenAI-संगत प्रदाता

ऐसे एंडपॉइंट के लिए जो बंडल नहीं है (Fireworks, vLLM, LM Studio, एक प्राइवेट गेटवे), इसे `provider` के तहत परिभाषित करें। लोडिंग शीर्ष-स्तरीय **`api`** फ़ील्ड (बेस URL) से ट्रिगर होती है; `npm` डिफ़ॉल्ट रूप से `@ai-sdk/openai-compatible` होता है, और आप अपने इच्छित मॉडल सूचीबद्ध करते हैं:

```json title="~/.config/cyberstrike/cyberstrike.json"
{
  "provider": {
    "my-endpoint": {
      "name": "My Endpoint",
      "api": "https://api.example.com/v1",
      "options": { "apiKey": "{env:MY_API_KEY}" },
      "models": {
        "my-model": { "name": "My Model" }
      }
    }
  },
  "model": "my-endpoint/my-model"
}
```

### vLLM

```json
{
  "provider": {
    "vllm": {
      "name": "vLLM",
      "api": "http://localhost:8000/v1",
      "models": { "llama-3.3-70b": { "name": "Llama 3.3 70B" } }
    }
  }
}
```

### LM Studio

```json
{
  "provider": {
    "lmstudio": {
      "name": "LM Studio",
      "api": "http://localhost:1234/v1",
      "models": { "local-model": { "name": "Local Model" } }
    }
  }
}
```

<Aside variant="caution">
  कॉन्फ़िग-ओनली प्रदाता इसलिए लोड होता है क्योंकि उसमें `api` URL है — अकेला `options.baseURL` इसे रजिस्टर नहीं करेगा। शीर्ष-स्तरीय `api` फ़ील्ड का उपयोग करें।
</Aside>

## Azure OpenAI

```json title="~/.config/cyberstrike/cyberstrike.json"
{
  "provider": {
    "azure": {
      "name": "Azure OpenAI",
      "options": {
        "apiKey": "{env:AZURE_API_KEY}"
      }
    }
  }
}
```

```bash
export AZURE_RESOURCE_NAME="your-resource"
export AZURE_API_KEY="..."
```

## समस्या निवारण

- **401 Unauthorized** — API कुंजी env var और `{env:VAR}` से संदर्भित होना जाँचें।
- **Model not found** — मॉडल id प्रदाता के प्रारूप से मेल खाना चाहिए और कस्टम प्रदाता के लिए `models` के तहत सूचीबद्ध होना चाहिए।
- **अप्रत्याशित प्रतिक्रिया** — एंडपॉइंट पूरी तरह OpenAI-संगत नहीं हो सकता; टूल कॉलिंग और स्ट्रीमिंग प्रदाता के अनुसार भिन्न होती है।

कमांड सूची खोलने के लिए इनपुट की शुरुआत में `/` टाइप करें (या `Ctrl+P` दबाएँ)। टाइप करते समय फ़ज़ी मैचिंग फ़िल्टर करती है।

## सेशन

| कमांड | उपनाम | शॉर्टकट | क्रिया |
|---------|---------|----------|--------|
| `/new` | `/clear` | `<leader>n` | नया सेशन शुरू करें |
| `/sessions` | `/resume`, `/continue` | `<leader>l` | सेशन पिकर खोलें |
| `/rename` | | `ctrl+r` | सेशन का नाम बदलें |
| `/compact` | `/summarize` | `<leader>c` | सेशन को कॉम्पैक्ट (सारांशित) करें |
| `/fork` | | | सेशन को फ़ोर्क करें |
| `/timeline` | | `<leader>g` | सेशन टाइमलाइन दिखाएँ |
| `/export` | | `<leader>x` | सेशन निर्यात करें |
| `/copy` | | | अंतिम संदेश कॉपी करें |
| `/share`, `/unshare` | | | शेयर करें / शेयरिंग बंद करें |
| `/undo`, `/redo` | | `<leader>u` / `<leader>r` | अंतिम संदेश को पूर्ववत / पुनर्स्थापित करें |
| `/timestamps`, `/thinking` | | | टाइमस्टैम्प / थिंकिंग ब्लॉक टॉगल करें |

|---------|---------|--------|

<Aside variant="caution">
  कमांड नाम बहुवचन हैं (`/models`, `/themes`, `/mcps`)। `/agent-settings`, `/settings`, `/config`, `/vim`, `/provider`, `/model`, या `<leader><leader>`/`Ctrl+Shift+P` कमांड पैलेट जैसा कोई कमांड नहीं है — कमांड सूची `Ctrl+P` से खुलती है।
</Aside>

## @ मेंशन

अपने प्रॉम्प्ट में `@` के साथ किसी फ़ाइल (वैकल्पिक रूप से लाइन रेंज) का संदर्भ दें:

```
@src/auth.ts#45-60 check these lines for vulnerabilities
```

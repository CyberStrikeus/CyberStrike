## फ़ाइल और स्थान

फ़ाइल का नाम `SKILL.md` होना चाहिए। Cyberstrike `.cyberstrike/` के अंदर `skill/` या `skills/` डायरेक्टरी के तहत `**/SKILL.md` खोजता है, और `skills/` (Claude Code लेआउट) के तहत:

```
.cyberstrike/
└── skills/
    └── sql-injection/
        └── SKILL.md
```

## फ्रंटमैटर

केवल `name` और `description` आवश्यक हैं। बाकी वैकल्पिक मेटाडेटा हैं जो वर्गीकरण और किल-चेन लिंकिंग के लिए उपयोग होते हैं:

```markdown title="SKILL.md"
---
name: sql-injection
description: Methodology for testing SQL injection
version: "1.0.0"
author: you
tags: [injection, database]
category: injection
owasp_id: WSTG-INPV-05
tech_stack: [postgres, mysql]
cwe_ids: [CWE-89]
chains_with: [auth-bypass]
prerequisites: [request-capture]
---

Walk the tester through boolean-, error-, time-, and union-based SQLi:
1. Identify injectable parameters …
2. …
```

<Aside variant="caution">
  बॉडी सादा Markdown है — कोई टेम्प्लेटिंग **नहीं** है (कोई `{{target}}`, `{% if %}`, `{% for %}`, या `$ARGUMENTS` नहीं)। फ्रंटमैटर `args`, `model`, `agent`, या `permission` फ़ील्ड्स का **समर्थन नहीं** करता, और फ़ाइल का नाम शाब्दिक रूप से `SKILL.md` होना चाहिए (मनमाने नाम जैसे `my-skill.md` लोड नहीं होते)।
</Aside>

फ्रंटमैटर में `name` स्किल की पहचान से मेल खाना चाहिए — बेमेल होने पर त्रुटि रिपोर्ट की जाती है।

## स्किल्स का उपयोग

लोड की गई स्किल्स एजेंट के लिए उपलब्ध हैं और `/skills` कमांड से ब्राउज़ की जा सकती हैं। जब कार्य के लिए प्रासंगिक हो तो एजेंट स्किल की मेथडोलॉजी को कॉन्टेक्स्ट में लाता है।

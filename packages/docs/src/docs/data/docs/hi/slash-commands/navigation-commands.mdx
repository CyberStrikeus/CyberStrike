ये स्लैश कमांड्स पिकर्स और डायलॉग खोलते हैं। कमांड सूची देखने के लिए TUI में `/` टाइप करें (या `Ctrl+P` दबाएँ)।

<img src="/docs/images/gifs/navigation-commands.gif" alt="कमांड सूची खोलना और पिकर्स में नेविगेट करना" className="rounded-lg shadow-lg my-6 w-full" />

## पिकर्स और डायलॉग

| कमांड | खोलता है |
|---------|-------|
| `/models` | मॉडल पिकर |
| `/agents` | एजेंट पिकर |
| `/themes` | थीम पिकर |
| `/mcps` | MCP सर्वर मैनेजर |
| `/bolt` | Bolt सर्वर मैनेजर |
| `/connect` | प्रदाता कनेक्ट / प्रमाणित करें |
| `/sessions` (`/resume`, `/continue`) | सेशन पिकर |
| `/editor` | संदेश को अपने बाहरी एडिटर में खोलें |
| `/skills` | लोड की गई स्किल्स ब्राउज़ करें |
| `/help` | सहायता दिखाएँ |
| `/status` | स्थिति दिखाएँ |
| `/exit` | Cyberstrike से बाहर निकलें |

<Aside variant="caution">
  कमांड नाम बहुवचन हैं: `/models`, `/themes`, `/mcps` (न कि `/model`, `/theme`, `/mcp`)। `/provider`, `/vim`, `/config`, `/permission`, `/files`, `/cd`, `/tools`, `/version`, `/doctor`, `/docs`, `/changelog`, `/cost`, या `/context` कमांड नहीं है — ये मौजूद नहीं हैं।
</Aside>

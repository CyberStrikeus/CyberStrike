सेशन कमांड्स वर्तमान वार्तालाप का प्रबंधन करते हैं — बनाना, फिर से शुरू करना, शेयर करना, और संदेश इतिहास संपादित करना।

<img src="/docs/images/gifs/session-commands.gif" alt="leader+l से सेशन पिकर खोलना" className="rounded-lg shadow-lg my-6 w-full" />

## जीवनचक्र

| कमांड | उपनाम | क्रिया |
|---------|---------|--------|
| `/new` | `/clear` | **नया** सेशन शुरू करें (`/clear` एक उपनाम है — यह केवल संदेश साफ़ नहीं करता) |
| `/sessions` | `/resume`, `/continue` | पिछले सेशन को फिर से शुरू करने के लिए सेशन पिकर खोलें |
| `/rename` | | वर्तमान सेशन का नाम बदलें |
| `/fork` | | वर्तमान बिंदु से सेशन फ़ोर्क करें |
| `/timeline` | | सेशन टाइमलाइन दिखाएँ |
| `/export` | | सेशन निर्यात करें |
| `/copy` | | अंतिम संदेश कॉपी करें |

## संदेश

| कमांड | उपनाम | क्रिया |
|---------|---------|--------|
| `/undo` | | अंतिम संदेश को पूर्ववत करें |
| `/redo` | | पुनर्स्थापित करें |
| `/compact` | `/summarize` | कॉन्टेक्स्ट पुनः प्राप्त करने के लिए सेशन को कॉम्पैक्ट (सारांशित) करें |
| `/timestamps` | `/toggle-timestamps` | संदेश टाइमस्टैम्प टॉगल करें |
| `/thinking` | `/toggle-thinking` | थिंकिंग ब्लॉक टॉगल करें |

## शेयरिंग

| कमांड | क्रिया |
|---------|--------|
| `/share` | वर्तमान सेशन शेयर करें |
| `/unshare` | शेयरिंग बंद करें |

<Aside variant="caution">
  `/clear`, `/new` का उपनाम है (यह नया सेशन शुरू करता है), और `/continue`, `/sessions` का उपनाम है (यह सेशन पिकर खोलता है)। `/history`, `/memory`, `/cost`, `/save`, `/tag`, `/note`, `/retry`, या `/template` कमांड नहीं है।
</Aside>

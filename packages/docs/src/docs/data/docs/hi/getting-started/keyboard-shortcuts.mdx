Cyberstrike का TUI कुशल नेविगेशन के लिए लीडर-आधारित कीबोर्ड शॉर्टकट द्वारा संचालित है। यह पेज सामान्य डिफ़ॉल्ट सूचीबद्ध करता है। क्रियाओं की पूर्ण सूची और उन्हें कस्टमाइज़ करने के तरीके के लिए, [कीबाइंडिंग](/docs/configuration/keybindings) देखें।

## लीडर कुंजी

लीडर कुंजी डिफ़ॉल्ट रूप से `Ctrl+X` है। कई शॉर्टकट `<leader>` के बाद एक अन्य कुंजी हैं।

लीडर कुंजी बदलने के लिए:

```json title="~/.config/cyberstrike/cyberstrike.json"
{
  "keybinds": {
    "leader": "ctrl+a"
  }
}
```

## सत्र शॉर्टकट

| शॉर्टकट | क्रिया |
|----------|--------|
| `<leader>n` | नया सत्र |
| `<leader>l` | सत्र सूची |
| `<leader>c` | सत्र संक्षिप्त/सारांश करें |
| `<leader>g` | सत्र टाइमलाइन |
| `<leader>x` | सत्र निर्यात |
| `Ctrl+R` | सत्र का नाम बदलें |
| `Ctrl+D` | सत्र हटाएं |
| `Escape` | चल रहे सत्र को बाधित करें |

## नेविगेशन

| शॉर्टकट | क्रिया |
|----------|--------|
| `PageUp` / `PageDown` | एक पेज स्क्रॉल करें |
| `Ctrl+Alt+U` | आधा पेज ऊपर स्क्रॉल करें |
| `Ctrl+Alt+D` | आधा पेज नीचे स्क्रॉल करें |
| `Ctrl+G` / `Home` | पहले संदेश पर जाएं |
| `Ctrl+Alt+G` / `End` | अंतिम संदेश पर जाएं |
| `<leader>y` | संदेश कॉपी करें |
| `<leader>u` | संदेश पूर्ववत करें (रिवर्ट) |
| `<leader>r` | संदेश फिर से करें |

## इनपुट

| शॉर्टकट | क्रिया |
|----------|--------|
| `Enter` | संदेश सबमिट करें |
| `Shift+Enter` | नई पंक्ति |
| `Ctrl+V` | पेस्ट करें |
| `Ctrl+C` | इनपुट साफ़ करें |
| `Escape` | चल रहे सत्र को बाधित करें |

## मॉडल और एजेंट

| शॉर्टकट | क्रिया |
|----------|--------|
| `<leader>m` | मॉडल चयन |
| `<leader>a` | एजेंट चयन |
| `Tab` | अगला एजेंट |
| `Shift+Tab` | पिछला एजेंट |

## इंटरफ़ेस

| शॉर्टकट | क्रिया |
|----------|--------|
| `<leader>t` | थीम चयन |
| `<leader>s` | स्थिति दृश्य |
| `<leader>b` | साइडबार टॉगल |
| `<leader>e` | बाहरी एडिटर में खोलें |
| `Ctrl+P` | कमांड सूची |

## डायलॉग

जब कोई डायलॉग खुला हो (मॉडल चयन, सत्र सूची, आदि), तीर कुंजियों से नेविगेट करें, चुनने के लिए `Enter` दबाएं, और बंद करने के लिए `Escape`। कुछ डायलॉग-विशिष्ट बाइंडिंग:

| शॉर्टकट | क्रिया |
|----------|--------|
| `Ctrl+F` | मॉडल पसंदीदा टॉगल (मॉडल डायलॉग में) |
| `F2` / `Shift+F2` | अगले / पिछले हाल के मॉडल पर जाएं |

## अनुमति प्रॉम्प्ट

जब किसी टूल को अनुमोदन की आवश्यकता होती है, तो तीन विकल्पों के साथ एक इनलाइन प्रॉम्प्ट दिखाई देता है — **एक बार अनुमति दें**, **हमेशा अनुमति दें**, और **अस्वीकार करें**। चुनने के लिए तीर कुंजियों और `Enter` का उपयोग करें; `Escape` अस्वीकार करता है।

## कीबाइंडिंग कस्टमाइज़ करना

अपने कॉन्फ़िग में `keybinds` के तहत डिफ़ॉल्ट ओवरराइड करें। केवल मान्य क्रिया नाम स्वीकार किए जाते हैं (ऑब्जेक्ट सख्ती से मान्य किया जाता है):

```json title="~/.config/cyberstrike/cyberstrike.json"
{
  "keybinds": {
    "leader": "ctrl+x",
    "app_exit": "ctrl+c,ctrl+d,<leader>q",
    "session_new": "<leader>n",
    "session_list": "<leader>l",
    "model_list": "<leader>m",
    "agent_list": "<leader>a",
    "theme_list": "<leader>t",
    "status_view": "<leader>s",
    "sidebar_toggle": "<leader>b",
    "editor_open": "<leader>e",
    "session_export": "<leader>x",
    "session_timeline": "<leader>g",
    "session_rename": "ctrl+r"
  }
}
```

प्रत्येक कॉन्फ़िगर करने योग्य क्रिया और उसके डिफ़ॉल्ट के लिए [कीबाइंडिंग](/docs/configuration/keybindings) देखें।

## कीबाइंडिंग प्रारूप

- **मॉडिफ़ायर**: `ctrl`, `alt`, `shift`, `super`
- **विशेष कुंजियां**: `return`, `escape`, `tab`, `space`, `backspace`, `pageup`, `pagedown`, `home`, `end`
- **लीडर**: `<leader>` (कॉन्फ़िगर की गई लीडर कुंजी से बदला जाता है)
- **विकल्प**: `ctrl+c,ctrl+d` (अल्पविराम एक क्रिया के लिए वैकल्पिक बाइंडिंग अलग करता है)
- **अक्षम करें**: `none`

### उदाहरण

```
ctrl+alt+u          # Ctrl + Alt + U
alt+shift+f         # Alt + Shift + F
<leader>n           # Leader key then N
ctrl+c,ctrl+d       # either binding triggers the action
```

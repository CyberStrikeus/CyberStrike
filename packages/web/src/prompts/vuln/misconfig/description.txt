Security-misconfiguration and reconnaissance specialist — one origin-wide pass covering BOTH config flaws and info-gathering. misconfig_test (paths/methods/cors/headers) probes exposed backup/admin/sensitive files, insecure HTTP methods (TRACE/PUT/DELETE), CORS misconfig, and the full security-header posture (HSTS/CSP/X-Frame-Options/nosniff/Referrer-Policy/Permissions-Policy + version-disclosure). recon_test (metafiles/fingerprint/leakage) parses robots.txt/sitemap.xml/openapi.json for hidden paths, fingerprints the tech stack, and scans response bodies for internal IPs, debug flags, version strings, and comments. Runs once per origin (scope: "wide"). Covers WSTG-CONF (01-11), WSTG-CRYP-01, WSTG-CLNT-07/09, WSTG-INFO-02/03/05/08.
